# Lv.25 世界树二转职业最终实装核对与平衡评审

> 核对口径：本文记录的是**当前代码实际会进入战斗结算的结果**，不是技能种子描述或早期方案的复述。核对日期：2026-09-02。
>
> 主要依据：`src/game/advanced-profession.config.ts`、`src/game/advanced-resource.config.ts`、`src/game/spirit-summoner.config.ts`、`src/database/bootstrap.ts`、`src/game/advanced-passive.service.ts` 与 `src/game/adventure.service.ts`。其中若数据库种子文案、技能面板文案与战斗服务不一致，以战斗服务为准。

## 1. 范围、结论与阅读方式

- 已实装：世界树 12 条常驻二转，完成第三段导师试炼时立即获得固有被动、4 个专属主动技能与本职传承；唤灵师额外获得 5 个召唤灵契，共 9 个主动技能。
- 未实装：设计方案中的 8 条地图隐藏二转、改宗/7 日冷却、分阶段解锁（Lv.30、35、40）、二转专用饰品、设计中的导师专属试炼技与随从机制。
- 专属资源只存在于 PvE 战斗会话，初始为 0、上限 100，战斗结束后不保留。资源不足时不能施放对应技能。
- `壁垒/护盾`在当前引擎中是**百分比减伤状态**，不是额外生命值。相同状态不叠加，取较高数值并刷新较长持续时间；不同减伤来源按乘法相乘。
- 负面状态先经过“破韧 vs 韧性”对抗：持续伤害强度会被压低，控制还会进行概率判定；首领的持续伤害另有每类每回合 1.5% 最大生命上限，剧毒额外限制为最多 3 层有效。

### 1.1 当前通用结算

| 项目 | 当前实现 |
| --- | --- |
| 命中 | `命中 / (命中 + 闪避)`，再加“实际命中率”百分点，最终封顶 100%。机关游侠的固有被动属于后一种。 |
| 直击基础伤害 | `攻击² / (攻击 + 对应防御)`，再乘技能威力、元素/物理克制、易伤、伤害加成与随机 90%–110% 浮动。 |
| 暴击 | `暴击属性 / (暴击属性 + 目标暴击抗性)`；暴伤再以 `1 + 暴伤属性 / (暴伤属性 + 目标暴伤减免)`放大。剑豪、夜刃的“暴击/暴伤属性”均在此之前参与计算，并非直接增加最终概率或最终伤害。 |
| 破防 | 物理技能读物防与`碎甲`；魔法技能读魔防与`破障`。`破障`不会降低物防。 |
| 降疗 | 目标收到的直接治疗、再生等按 `1 - 降疗%`结算；不会让治疗完全失效。 |
| 状态命中 | 有害状态不使用普通命中，而使用破韧、韧性、等级差与状态基础值对抗。蚀毒师传承的“破韧 +8%”会临时提高该次状态施加者的总破韧。 |

### 1.2 二转技能的专精边界

二转主动技当前固定为 Lv.1 的职业技能，**不参与通用专精体系，也不纳入本轮平衡范围**。本文所有 MP、冷却、威力及状态数值均为固定基准值；二转的成长与差异只来自装备、基础属性、武器精通、元素精通、传承与队伍状态。

现有通用技能详情界面仍可能显示统一的专精栏目，但它不应被视为二转技能的可用成长路线；后续若要开放，需要作为独立版本重新设计，而非直接套用现有专精规则。

## 3. 各职业实际主动技能、资源循环与平衡核对

以下 `MP/CD` 是基础值；技能均无二转专属武器限制。终结技还需要 100 点对应资源。

### 3.1 盾卫

- 定位：主坦、单点保护、承压反击。
- 资源：**守势**。盾墙推进 +20；成为敌方主目标 +20；成功盾反 +20；承接代偿守护的转移伤害，按转移前伤害获得、单次最多 +30。
- 固有协同：自身 4%常驻减伤会与壁垒、守护、盾反等乘法叠加，不会把多个壁垒相加。

| 技能 | MP/CD | 实际效果 |
| --- | --- | --- |
| 盾墙推进 | 110 / 2 | 单体 115%物理伤害；命中前即写入 2 回合嘲讽，自己获 12%减伤（2）与 20 守势。嘲讽会强制敌方优先攻击盾卫。 |
| 代偿守护 | 190 / 3 | 生命比例最低队友获得 2 回合守护；其**首次单体伤害**的 35%转给盾卫。盾卫同时获得 2 回合 20%伤害减免；转移伤害会按该减伤结算，之后守护消失，并按转移前伤害获得守势（单次最多 30）。 |
| 不动如山 | 300 / 4 | 自身 35%减伤、20%控制抗性（2）。在持续期间作为敌方主目标承受第 3 次攻击后，获得一次 90%物理反击架势。 |
| 壁垒裁决 | 650 / 7，100守势 | 全体 145%物理伤害；选定主目标额外 ×1.60 并嘲讽（2）；全队获得 15%减伤壁垒（2）。 |

**核对与建议。** 循环可用，且守势获取清晰。`代偿守护`现在会同步给盾卫 2 回合 20%伤害减免，数据库种子、技能面板与实战一致；转移伤害会先吃到该减伤。终结技的主目标 ×1.60 是可接受的坦克爆发，但不应再叠加新的易伤来源。

### 3.2 战旗使

- 定位：范围压制、破阵窗口、物理队节奏。
- 资源：**战意**。每个被自身技能命中的目标 +15；范围技能对 4 个目标可一次获得 60。

| 技能 | MP/CD | 实际效果 |
| --- | --- | --- |
| 震地号令 | 110 / 2 | 全体 105%物理伤害，命中后减速 20%（2）；每命中一个目标 +15 战意。 |
| 破阵军令 | 190 / 3 | 单体 130%物理伤害、物防 -8%（2）；下一次来自**其他队友**的技能直击 +12%，命中后消耗该窗口。 |
| 凯旋战旗 | 300 / 4，50战意 | 全队伤害 +10%、控制抗性 +15%（2）；存活敌人不少于 3 时，全队立即回复 8%最大生命。 |
| 百战横扫 | 650 / 7，100战意 | 全体 170%物理伤害；每个同时带减速、束缚、眩晕之一的目标，使其自身这次伤害 +15%，最多 +60%。 |

**核对与建议。** 破阵窗口可被剑豪、夜刃等立即消耗，配合明确。当前“战意”没有实现“被自身控制的敌人在回合开始 +10”，且范围命中可很快充满 100；4 敌场景通常两次范围技即可接近终结。建议给每次施法增加 30–45 点资源上限，或补回控制回合奖励并削弱范围命中收益，以让单体和群怪循环差异更合理。

### 3.3 剑豪

- 定位：单体物理爆发、破甲后处决。
- 资源：**裂势**。暴击 +20；命中已有削弱目标 +20；断势追斩命中易伤/追猎再 +20。一次行动可能获得 40–60。

| 技能 | MP/CD | 实际效果 |
| --- | --- | --- |
| 裂甲斩 | 110 / 2 | 150%物理伤害、物防 -15%（2）；目标施放前已有碎甲时，再获得 3%易伤（2）。 |
| 断势追斩 | 110 / 2 | 135%物理伤害；目标有易伤或追猎时伤害 ×1.35，并 +20 裂势。 |
| 绝隙处决 | 300 / 4，60裂势 | 185%物理伤害；目标生命低于 35%时伤害再 ×1.45；击杀后该技能剩余冷却减半。 |
| 断钢一闪 | 650 / 8，100裂势 | 单体 245%物理伤害，强制不能暴击；清除目标全部易伤，每层再 +8%本次伤害。 |

**核对与建议。** 固有被动与传承都只放大暴击属性，不会绕过敌方暴抗。输出定位足够鲜明，但裂势在“暴击 + 已削弱 + 断势追斩条件”同时成立时偏快，终结技可能第 2–3 次有效技能就可使用。建议限制单次行动裂势最多 +40；这样仍奖励团队破防，又能满足设计中“终结技约 4–6 回合一次”的红线。

- 资源：**奥能**。每次首次加入异种印记 +25；命中元素弱点每个命中目标 +15；火冰雷齐全后用四相共鸣补风可直接充满。

### 3.5 唤灵师

- 定位：多灵持续输出、续航、减伤与控场补位。
- 固有被动：无该被动时所有职业的召唤上限是 1；唤灵师持有灵息后为 **3**。灵兽不是队员，不占四人位、不获得经验，拥有独立 HP、双防、命中、闪避、暴击与速度，可被怪物以 28%概率单点攻击并在 HP 归零后退场。
- 属性继承：灵兽 HP 与八项战斗属性均按契主当前面板的固定比例生成，召出后固定至本场结束；不随契主之后的临时增益重算。
- 资源：**灵契**。每只灵行动 +15；灵线牵引另 +20；队友实际获得治疗时，场上存活的唤灵师各 +15；部分群体壁垒技也会 +15。

### 3.6 战斗法师

- 定位：近中距离魔法爆发与攻防切换。
- 资源：**法刃**。每个物理或魔法行动 +20；与上一行动类别不同再 +15。普通攻击也被视为物理行动。

| 技能 | MP/CD | 实际效果 |
| --- | --- | --- |
| 秘法突刺 | 60 / 1 | 近战 120%魔法伤害；若上一行动为物理，伤害 ×1.35。施放作为魔法行动，获得 20 法刃。 |
| 相位格挡 | 190 / 3 | 25%减伤、20%闪避（1）；成功闪避一次敌方攻击时额外 +30 法刃。 |
| 破法回旋 | 190 / 3，50法刃 | 全体 120%魔法伤害；目标有元素印记时获得 10%易伤（2）。 |
| 星火决斗 | 650 / 7，100法刃 | 单体 210%火魔法伤害，自身 20%减伤（2）；击杀重置相位格挡。 |

**混合攻击公式核对。** 对战斗法师所用的**物理类别技能**，基础攻击为 `min(实际魔攻, 实际物攻 + 实际魔攻×35%)`，之后仍按物理类别读取物防、物理克制与物理技能加成。该公式不会高于魔攻。

**核对与建议。** 公式本身已实装，但“秘法突刺”在数据上是`magic`，因此它实际使用纯魔攻与魔防结算；混合公式只会作用于战斗法师携带的其他物理类别技能，不作用于普通攻击，也不作用于自身四招中的任何一招。这使“物理→秘法突刺”的 35%连段存在，但“物理技能吃魔攻”的核心卖点在标准法师技能池里覆盖面很窄。建议给秘法突刺增加明确的混合攻击标记，或新增一项物理类别二转技；不建议单纯把它改为物理类别，否则会改变其应走魔防结算的定位。法刃可在三次交替行动内达到 100，充能速度符合终结窗口目标。

### 3.7 夜刃

- 定位：单体物理爆发与低血斩杀。
- 资源：**破绽**。暗影标定 +20；暴击 +20；命中受控、破甲、破障、易伤、DOT 等削弱目标 +20；背隙连刺满足条件再 +20。

| 技能 | MP/CD | 实际效果 |
| --- | --- | --- |
| 暗影标定 | 110 / 2 | 105%物理伤害；命中后追猎（3），自己的下一次攻击额外 +20%，并 +20 破绽。 |
| 背隙连刺 | 60 / 1 | 基础 125%物理伤害；目标同时有追猎和易伤/碎甲/束缚/眩晕时改为 ×1.36，即等价 170%总系数，并 +20 破绽。 |
| 残月割喉 | 300 / 4，60破绽 | 175%物理伤害；目标低于 40%时改为 215%；命中后施加 40%降疗（2）。 |
| 无声终章 | 650 / 8，100破绽 | 仅可对带追猎目标使用；230%物理伤害；击杀返还 50 MP，并获 50%减伤（1）。 |

**核对与建议。** 固有被动与传承使夜刃的低血收束强于剑豪，两个职业已不是同一条暴击被动。背隙连刺当前是一次 170%伤害计算，不是两次独立 85%命中，因此不会分别触发两次暴击、吸血、资源或状态；建议在面板中明确“等价总系数 170%”，或改成真正两段结算。破绽可在标定后的两次有效攻击内迅速达到 80–100，建议先用 8 回合首领模拟检查终结技是否稳定早于第 4 回合，再决定是否给单次资源上限。

### 3.8 蚀毒师

- 定位：剧毒消耗、双防削弱、降疗与首领压制。
- 资源：**毒性**。持续伤害结算 +15；对已有剧毒或已削弱目标成功施加新状态 +20。
- 首领保护：剧毒先受破韧/韧性压制，单层每回合最多 1.5%最大生命、最多 3 层；毒血引爆按剩余剧毒的 40%计算且单次不超过首领最大生命 6%。其他同类 DOT 对首领也会按效果代码合计封顶 1.5%每回合。

| 技能 | MP/CD | 实际效果 |
| --- | --- | --- |
| 蛇吻 | 60 / 1 | 105%物理伤害与可叠加剧毒（3）。普通目标每层每回合 5%最大生命，最多 5 层；首领见上方限制。 |
| 腐蚀雾 | 190 / 3 | 全体 90%暗魔法伤害，物防/魔防各 -8%（2）；已有剧毒的目标额外叠 1 层剧毒。 |
| 毒血引爆 | 300 / 4，50毒性 | 165%暗魔法伤害；立即结算剩余剧毒 60%（首领 40%），清除后保留 1 层、1 回合剧毒。蚀痕会放大这段结算。 |
| 万毒封喉 | 650 / 7，100毒性 | 160%暗魔法伤害；剧毒补至 3 层；降疗 60%（2），首领为 30%。 |

**核对与建议。** 首领上限和韧性对抗已让剧毒可以保留职业特色而不直接跳过首领血量设计。普通怪 5 层 ×5%=25%最大生命/回合仍然非常高，应以“普通怪短战快速结束”为目标监控，而不是再提高倍率。技术上，`advanced_venom_source`记录的是目标最近一次蚀毒师技能来源，当前所有该目标上的 DOT 结算都可能给这名蚀毒师 +15 毒性；多人蚀毒师或队友灼烧时归因不够精确。建议把 DOT 来源写入每条状态实例，限定毒性与蚀痕只读取自身剧毒。

### 3.9 机关游侠

- 定位：命中辅助、追猎、束缚/减速与协同追击。
- 资源：**筹码**。弱点测绘 +20；自身或队友命中自己施加追猎的目标时 +15。

| 技能 | MP/CD | 实际效果 |
| --- | --- | --- |
| 钩索陷阱 | 190 / 3 | 80%物理伤害；以 50%基础概率束缚（1），并施加追猎 15%（2）。首领会移除束缚并改为 30%减速（1）。 |
| 弱点测绘 | 110 / 2 | 100%物理伤害；目标获得测绘（2）：全队命中属性 ×1.15、暴击属性 ×1.08；自身 +20 筹码。 |
| 诱导烟幕 | 300 / 4，50筹码 | 全队 15%减伤与 20%闪避（1）；敌方全体命中 -15%（1）。 |
| 百发协猎 | 650 / 7，100筹码 | 需目标带追猎；160%物理伤害与 20%易伤（2），再由速度最高的另一名队友追加一次 70%基础物理协同追击。 |

**核对与建议。** 固有的实际命中 +5pp 能直接降低高闪避目标波动；测绘则提高命中、暴击属性，两个入口不会重复。协同追击不触发被选队友的技能、被动、吸血或资源，符合设计。设计中的“敌人被减速/束缚 +20筹码”未实现；若要补齐，必须限定每回合一次，避免逐个敌人状态回合把筹码过快充满。当前无该入口时，单体首领下筹码主要靠追猎命中，节奏较稳。

### 3.10 圣愈者

- 定位：低血急救、净化、再生续航。
- 资源：**信念**。愈合祷言在治疗前目标低于 50%时 +25；净罪之手净化到控制时 +20。
- 柔光：直接治疗 +5%，自己施加的再生为基础值再 +1%最大生命；不放大清泉鹿的治疗，因为灵兽治疗没有读取契主的治疗加成。

| 技能 | MP/CD | 实际效果 |
| --- | --- | --- |
| 愈合祷言 | 60 / 1 | 治疗最低血队友 `90%魔攻 + 8%目标最大生命`，再生 6%（2；柔光后 7%）；治疗前低于 50%则 +25 信念。 |
| 净罪之手 | 190 / 3 | 净化最低血队友的全部可净化负面状态，治疗 60%魔攻；若净化前存在控制，再给 10%壁垒（1）并 +20 信念。 |
| 共鸣弥撒 | 300 / 4，50信念 | 全队治疗 `65%施法者魔攻 + 5%各自最大生命`，施加 6%再生（2；柔光后 7%）；施放前低于 40%者获祷言（3）。 |
| 复苏圣域 | 650 / 8，100信念 | 全队立即回复 18%最大生命（受柔光 +5%影响），净化 1 个异常，10%再生（2；柔光后 11%）；不能复活。 |

**核对与建议。** 即时治疗、再生、低血信念与净化控制均已实装，危机处理能力符合定位。`净罪之手`当前清除的是全部可净化异常，不是设计中的“最多两个”，实际强度偏高；建议要么把文案同步为“全部”，要么把实现收敛为最多两个。`祷言`能叠层、能给晨星祷者 +10 信念，但目前没有任何圣愈者技能消费/转化祷言，属于只有标识与协同、没有自身后续收益的半实现状态；建议让共鸣弥撒按祷言层数追加小额治疗或将祷言改为纯晨星协同状态。

### 3.11 圣盾使

- 定位：预防减伤、团队抗爆发、信念循环。
- 资源：**信念**。自身标记来源的任意壁垒使队友承伤时，每名受护者每回合首次 +10；分担守护成功时 +15。自身使用基础“守护祝福”也会被标记为圣盾来源，能回流信念。
- 20%壁垒配合固有 3%减伤时，常规承伤为 `1 - 0.80×0.97 = 22.4%`总减伤；光幕 10%时为 12.7%。同名壁垒不叠加，只取高值。

| 技能 | MP/CD | 实际效果 |
| --- | --- | --- |
| 守望壁垒 | 110 / 2 | 最低血队友获得 15%减伤壁垒、20%控制抗性（2）。 |
| 分担圣约 | 190 / 3 | 两名最低血队友各获 20%减伤（2）；队中任一战士二转额外获得 10 点其专属资源。 |
| 光幕回响 | 300 / 4，50信念 | 全队 10%减伤、5%再生（1）；每名队友的壁垒本回合首次承伤后，回复 7%最大生命。 |
| 不灭穹顶 | 650 / 8，100信念 | 全队 20%减伤（2）与一次濒危不倒；受到致死伤害时保留 1 HP 并消耗该状态。 |

**核对与建议。** 壁垒承伤回信念已经接入守望、分担、光幕、穹顶和基础守护祝福，且按受护者独立计数，循环健康。`不灭穹顶`当前对所有常规致死伤害生效，没有区分设计中建议排除的“处决型必死机制”；未来副本出现脚本处决时应加 `bypassUndying` 标记。数据库种子中穹顶附带的 10%再生不会在当前专属分支中执行，实际以本表为准。整体防护已较强，不建议继续上调数值，先做首领连续三回合压力测试。

### 3.12 晨星祷者

- 定位：光属性副输出、驱散、元素使爆发放大。
- 资源：**信念**。当前只有成功驱散敌方增益 +25，以及队友通过愈合祷言/净罪之手获得祷言时 +10；“光术命中暗性目标 +25”尚未接入。

| 技能 | MP/CD | 实际效果 |
| --- | --- | --- |
| 晨星烙印 | 60 / 1 | 125%光魔法伤害，晨星印记（2）；下一次**元素使技能**对该目标的元素反应伤害 +20%。 |
| 驱邪裁词 | 190 / 3 | 135%光魔法伤害；驱散一个敌方壁垒/战吼/雾隐等可驱散增益，成功时全队回 4%最大 MP，并 +25 信念。 |
| 审判连祷 | 300 / 4，50信念 | 165%光魔法伤害；实际施加单个 50%易伤（2）。 |
| 破晓宣告 | 650 / 7，100信念 | 全体 150%光魔法伤害；逐个驱散一个增益，每次成功都刷新全队 8%减伤壁垒（1）。 |

**核对与建议。** 晨星烙印与元素使的交互已接通，但不适用于其他职业的“元素技能”。审判连祷的数据种子先写 25%易伤，战斗分支又刷新为 50%，由于易伤不叠层，当前不是“2 层 25%”，而是**单个 50%易伤**；这是二转中最需要优先复核的数值偏差。建议改为 25%易伤，或实现真正的“两段各 25%且有总上限”的独立状态。否则它在 300 MP/4 CD 下仍会对全队直击形成过高放大。另建议补回“光术命中暗性/带可驱散增益目标 +25 信念”，否则无圣愈者队伍中晨星的终结技循环不稳定。

### 5.2 任务与导师试炼差异

- 当前 12 条常驻任务均为“岩脊山麓击杀 3 次 → 指定怪物击杀 5 次并交付 3–4 个岩脊核心 → Lv.30 导师 Boss”。剧情已经按职业写入，第三段 Boss 也按角色私有生成。
- 设计稿中的跑腿、不同材料、试炼随从、专属机制与特殊应对尚未接入。当前导师模板主要复用普通玩家/怪物技能序列，因此“职业理解检查”的力度低于设计目标。
- 当前实现已按角色、职业、任务阶段隔离试炼目标；其他玩家不会在悬赏、地图或探索中看到该导师试炼 Boss。

| 二转主动技专精 | 方案中曾沿用通用专精设想 | 当前明确不纳入二转范围；二转技能固定为 Lv.1 基准值。 |

## 6. 平衡评审与建议优先级

当前没有同装备、同等级的自动化 8 回合木桩统计，因此不能宣称已经达到设计中“主输出 +15%–22%、元素单体不高于夜刃 90%”等红线。下列结论依据实际公式、资源速度、状态叠加和首领限制，仍需要实战数据确认。

### P0：先修正“数据/文案/结算不一致”

1. **审判连祷的 50%易伤。** 这是当前最明显的实战强度偏差。建议先降为 25%，再决定是否需要真正的双层机制。
2. **圣愈者祷言缺少消费结果。** 现在属于无效堆层。建议共鸣弥撒按祷言层数为低血目标追加小额治疗，或让复苏圣域消耗祷言转为一次性壁垒；每目标每回合限制一次。
3. **盾卫代偿守护的自身减伤缺口。** 要么补回种子中的 20%，要么删除过期表述；不能让技能数据库与实际承伤不同。

### P1：控制资源速度，维持终结技 4–6 回合窗口

1. 剑豪：单次行动裂势上限建议 40，避免暴击/削弱/追斩三重叠加一次 +60。
2. 元素使：元素弱点回能建议每次施法最多一次；保留四相成环 +100，强调完成循环而非范围扫弱点。
3. 唤灵师：立即牵引的灵兽行动不应额外产生灵契，或限制每回合灵兽回应最多 +45；否则三灵 + 灵线会过早群星超载。
4. 战旗使：若群怪实测第 2 回合即可 100 战意，将“每命中 +15”改为每次施法最多 +30–45，或用控制回合奖励替代一部分范围收益。
5. 晨星祷者：补充光术命中暗性/强化目标的信念来源，使其在没有圣愈者的队伍也能稳定形成 4–6 回合终结循环。

### P2：补齐归因与组合边界

1. 为每条 DOT 记录施加者；蚀毒师的蚀痕、毒性只能读取自己的剧毒，避免多人/多 DOT 误归因。
2. 明确唤灵师“队友获得壁垒”的完整技能白名单，或改为按实际`barrier`施加事件统一奖励一次，避免遗漏守望与分担圣约。
3. 晨星烙印的“元素反应”要么明确限定元素使，要么改为统一的反应标签；不要在文案中泛称所有元素反应。
4. 给战斗法师增加可用的混合物理入口，并用模拟确认它不会因物防/魔防双重优势超过剑豪或夜刃单体上限。
5. 为穹顶增加“脚本处决不可拦截”标记，提前避免副本机制被通用保命状态绕过。

## 7. 最终状态摘要

世界树 12 职业的固有被动、传承、资源与主要技能连段已大体进入实际 PvE 战斗，元素四系循环、三灵独立行动、首领剧毒限制、圣盾回信念、二转私有导师 Boss 均已落地。二转技能当前保持固定数值，不进入专精成长。现阶段最应优先处理的不是继续堆数值，而是少数文案与分支结果不一致、晨星 50%易伤、祷言无消费、资源归因/上限以及设计稿中尚未实现的隐藏分支与导师专属试炼。
