# 熔铸材料与装备词条对比

数据以当前 `fusionProfileFor` 的实际准入、`fusionGain` 的结算公式和物品种子为准。下表的“上限占比”只适用于普通熔铸材料；它表示**单次成功熔铸**相对于目标辅词条上限 `C` 的增量，不代表装备上的总词条值。

## 通用计算与词条上限

普通材料的单次增量为：

`C × min(60%, 20% × (材料价值 / 20)^(log(2)/log(5))) × 0.75～1.25`

因此价值 20 时平均提高 `20% C`，价值提升五倍时平均提高 `40% C`，符合“价格提高五倍、数值只提高两倍”的曲线。普通材料每次成功时有 **60%** 概率命中表中“目标词条”，有 **40%** 概率从该装备可出现、且尚未达到上限的其他常规辅词条中等权随机抽取；目标词条已满时，会直接改抽其他可用词条。熔铸可新增常规词条，不受打造时随机词条槽位数量限制。

以 **Lv.30、普通品质** 为例，常规辅词条上限如下。优秀、精良、稀有、传说、史诗依次再乘以 `1.15 / 1.30 / 1.50 / 1.70 / 2.00`。

| 装备 | 可熔铸的常规词条 | `C` |
| --- | --- | ---: |
| 武器 | 物攻或魔攻（依武器类型）、命中、闪避、暴击、暴伤、暴击抗性、暴伤减免、速度 | 攻击 248.4；其余 496.8 |
| 武器 | 魔力上限、破韧 | 993.6；248.4 |
| 武器 | 对应元素精通 | 16.5 |
| 防具或盾牌 | 物防、魔防 | 124.2 |
| 防具或盾牌 | 生命上限 | 496.8 |
| 防具或盾牌 | 命中、闪避、暴击、暴伤、暴击抗性、暴伤减免、韧性、速度 | 248.4 |
| 防具或盾牌 | 对应元素抗性 | 16.5 |

元素精通/抗性的 Lv.30 上限为旧档位的一半，即 `16.5`；元素材料在武器上只给精通，在防具或盾牌上只给抗性。

## 特殊材料

这些材料使用固定百分比范围，不走价值曲线，也不是常规装备辅词条池的一部分。目前百分比词条没有 `forgedEquipmentCaps` 的绝对数值上限，实际可叠加次数由装备熔铸次数上限控制；每条成功增量都会独立写入熔铸记录。

“全战斗属性”包含生命、魔力、物攻、魔攻、物防、魔防、命中、闪避、暴击、暴伤、暴击抗性、暴伤减免、韧性、破韧与速度。

## 记录与回退边界

每次成功熔铸创建一条 `equipment_fusions` 记录；同次实际增加的每一个属性再创建一条 `equipment_fusion_effects` 记录。因此例如一块陨铁产生的 15 条百分比属性，或一份天空粉尘产生的 6 条六维百分比，均能按“材料—属性—实际增加值”单独读取，为后续逐条回退保留完整依据。

当前未在物品种子中创建的旧预留 profile（如 `root_heart`、`river_shell`、`tide_shell`、`star_mud_core`、`frost_crystal`、`thunder_core`、`eclipse_core`）不属于上述“当前可投入”的材料清单；它们在物品真正入库前不会出现在熔铸材料列表中。
## 提纯通用材料分档

怪材按自身来源等级改用不同的提纯产物名称：Lv.1–20、21–40、41–60、61–80、81–100 各有一组名称。材质类别写在物品说明中（布料、皮革、骨钢、甲壳、鳞甲），这不是品质分级。成功产量只提升一次：Lv.1–10 为 1 倍，Lv.11 级及以上固定为 1.2 倍；后段来源材料以更高价值参与熔铸增量曲线。

名称采用统一的玄幻锻材风格，不直接使用地图名。Lv.21–40 的一套为“灵纺布匹、韧鞣灵革、轻质骨钢片、铸纹甲壳板、叠锻鳞甲片”；Lv.1–20 使用更基础的灵麻布卷、兽鞣皮革、碎骨钢片、硬甲壳片、粗鳞甲片，之后每 20 级继续递进。

普通打造开放 Lv.5–30、每 5 级一档，并按装备等级选择对应材料套装：Lv.5–20 使用 Lv.1–20 套；Lv.25–30 使用 Lv.21–40 套。材料数量按 20 级循环：Lv.5 与 25 相同；Lv.10 与 30 比它们多 20%；循环内每再提升 5 级再增加 20%，数量向上取整。Lv.30 史诗图纸装备同样使用 Lv.21–40 套；精炼与熔铸的材料准入不随此规则改变。

Lv.25 起的普通打造主材按构造分配到四张 Lv.30 地图：长剑、盾牌、轻甲、板甲用岩脊核心；拳刃、重甲用炉心赤晶；法杖、法书、法球、布甲用雾沼心；匕首、皮甲用幽纹黑晶。
