## 1. 定稿需求与当前实现

### 1.1 按用户要求固定

| 项目 | 规则 |
|---|---|
| 基础掉率 | 普通小怪 3%；大怪 2%；精英 1%；BOSS 0.5% |
| 来源 | 击杀对应怪物取得对应怪物卡片；召唤物卡由对应来源BOSS掉落 |
| 执法者 | 按星级/骷髅强度掉落不同机制卡，涵盖移动、感知、交涉等 |
| 明确不掉卡 | 首领部位、转职试炼、测试怪 |
| 常规部位组 | 武器/副手；上装/下装；头肩/腰带/鞋子；项链/手镯/戒指 |
| 强卡限制 | 高数值、强机制卡只允许一个明确部位，不能跨整个部位组使用 |
| 武器/副手 | 主要承担输出 |
| 上装/下装 | 主要承担生存 |
| 头肩/腰带/鞋子 | 命中、暴击、破韧等辅助输出；允许少量生存 |
| 首饰 | 元素精通、元素抗性、治疗量及辅助输出 |
| 强度分工 | 小怪弱数值；大怪高数值；精英概率修正、减伤等；BOSS 实际概率提升、属性附魔等 |
| 服务入口 | 铁匠铺与锻造师均新增附魔 |
| 附魔槽 | 每件装备同时只有 1 个附魔；可以重新附魔，整体覆盖旧附魔 |
| 熔铸升级 | 保留已有附魔 |

“只能附魔一次”在此按“同时只能保留一张卡的附魔”解释，否则会与“重新附魔会覆盖”冲突。单部位限制不代表角色只能装备一张 BOSS 卡；可以在不同合法部位使用不同 BOSS 卡。

### 1.2 已实现方案与验证边界

现行实现采用固定卡片数值、独立附魔属性层、附魔成功率 100%、无卡片合成升级、卡片按模板等级定档、卡片专用掉落公式和统一手续费。执法者按星骷掉卡、召唤物卡由来源BOSS掉落、首领部位与转职试炼不产卡均已接入；真实数据库迁移、实机 QQ 交互和线上经济数据仍未验证。

DNF 仅借鉴“怪物身份 → 卡片 → 指定部位附魔”“强卡部位收窄”的结构。DNF 历史上也有武器/上衣/下装攻击卡，因此本作“上装下装偏生存”以用户要求为准，不宣称这是 DNF 原版部位规则。资料参考：[DNF 部位附魔图鉴索引](https://wap.gamersky.com/z/dnf/355367_34902/)、[DNF 历史卡片部位与属性示例](https://www.gamersky.com/handbook/202405/1750294.shtml)。不移植其版本数值、职业属性或卡片升级系统。

## 3. 卡片和装备规则

### 3.1 卡片字段

常规卡片名固定为“怪物显示名·卡片”，标识为 `monster_card_<monsterCode>`；执法者另外附加星骷版本后缀和机制名，以专项表为准。同模板同配置版本的卡片属性完全相同，不再随机品质、随机词条或随机部位。

| 字段 | 含义 |
|---|---|
| monsterCode / cardCode | 对应模板与卡片标识 |
| cardTier | normal / large / elite / boss，采用模板品阶 |
| cardLevel | 图鉴显示的模板基准等级 |
| minimumEquipmentLevel | `5 × floor(cardLevel / 5)`，最低 1；例如 Lv.32 卡要求 Lv.30 装备 |
| allowedSlots | 部位白名单；高数值或机制卡长度严格等于 1 |
| effects | 完整数值集合；多效果一并附加、一并被覆盖 |
| version | 卡片设计版本，写入附魔时保存快照 |
| sourcePolicy | 正常击杀、来源BOSS附加表、执法者星骷版本；部位/试炼不创建卡片 |

模板等级高于当前常规打造阶段的卡属于后续内容。不能把 Lv.80 模板默认下调为 Lv.30 卡。刷新等级、编队等级和迷宫动态升降级不改变卡片固定数值，也不因黄金/梦幻词条生成更强版本；这些因素只影响战斗及掉率。这样同名卡保持可堆叠和可比较。上线前固定 registry 中的基准等级，运行时不动态读取可能被改写的模板等级。

### 3.2 部位和兼容

| 玩家显示 | 当前实际槽位映射 | 属性方向 |
|---|---|---|
| 武器/副手 | weapon / offhand | 物攻、魔攻；强力属性攻击仅武器 |
| 上装/下装 | upper / lower | 生命、物防、魔防、韧性、减伤、暴免 |
| 头肩/腰带/鞋子 | shoulder / waist / feet | 命中、暴击、暴伤、破韧、速度、小额防御 |
| 项链/手镯/戒指 | necklace / bracelet / ring | 指定元素精通、抗性、治疗增幅、辅助输出 |

现有“腰部/脚部”在附魔 UI 显示为“腰带/鞋子”，仍映射原槽位。白名单用实际槽位，不按文字包含匹配。“武器/副手”卡可用于盾牌，攻击值作为角色附魔属性生效：这是本方案允许的附魔例外，不改变盾牌打造词条池。附魔值按卡片全文计入一次，不再次乘副手武器折算；武器本体仍走原副手算法。避免换一种副手类型让同一卡片属性忽大忽小。

一件装备附魔不消耗打造副词条数量，不占稀有特殊词条，不参与熔铸次数与词条上限。任何非装备物品、机巧人偶、异械、时装、任务道具都不能当成十个槽位装备使用。神器若属于真实合法装备槽位，可附魔，不覆盖其原效果。

### 3.3 消耗与流通

- 一次消耗对应卡片 1 张，附魔必定成功，无概率失败损卡。
- V1 不新增附魔材料。铜币费 = `cardLevel × 品阶系数`，系数依次为 10 / 20 / 40 / 80；Lv.32 BOSS 卡为 2,560 铜币。
- 两入口费用、成功率、卡片数值一致；不让副职业等级随机放大卡片。锻造师可从本职入口操作，其他玩家从铁匠铺操作，沿用店铺资格而不是强迫转职。
- V1 附魔不额外赠送熟练度，避免反复覆盖低级卡刷熟练度；如后续增加需单独设计。
- 正常战斗产出的卡片可堆叠、可交易，堆叠上限为 999。卡片不作为普通锻造材料、不允许熔铸或交涉赠礼自动消耗。
- 绑定卡附魔使装备继承更严格的绑定；非绑定卡不能解除原装备绑定。覆盖不返还旧卡。
- 不提供拆卡和抽取，装备销毁时附魔随之销毁；卖出或转移装备时附魔跟随装备，受现有交易与绑定规则约束。

## 4. 数值标尺

### 4.1 V2：按武器与装备后面板分类定值

旧版0.25A/0.75A/1.25A统一倍率已废止。所有直接物攻、魔攻均重算；小怪生命、防御、命中等分别提高；BOSS提高机制价值。详细模型与逐卡对照见附录D和[V2强度复核](./怪物卡片强度复核V2.md)。

参考模型采用现行分段六维成长、同级精良80品质的10件装备、真实副词条加权期望、0.5副手折算、甲类逐件和套装属性；剑盾/法杖法书/双匕首三构筑等权。它是可复算的设计基准，未读取线上人物分布，不能称为全服平均。角色L级使用max(1,5×floor(L/5))级装备作为参照。

W=同级参考主武器主属性实得；B_k=三套角色在原甲类/套装百分比前的同项“六维派生+装备固定值”均值。卡片属性固定，不按使用者面板动态变化。

| 类别 | 普通小怪 | 大怪常规 | 大怪高额、唯一部位 |
|---|---|---|---|
| 物理/魔法攻击 | 10%W | 18%W | 22%W |
| 生命/魔力 | 8%B_k | 11.2%B_k | 14.4%B_k |
| 单项物防/魔防 | 6%B_k | 8.4%B_k | 10.8%B_k |
| 命中/闪避/双暴双抗/韧性/破韧 | 12%B_k | 16.8%B_k | 21.6%B_k |
| 战斗速度 | 8%B_k | 11.2%B_k | 14.4%B_k |
| 单元素精通/抗性 | 3+floor(L/5) | 前者×1.8 | 前者×2.2 |
| 精英/BOSS机制 | 精英保持修正特色；BOSS使用逐怪固定强化表 | 不用直接攻击大数替代机制 | 一律唯一部位 |

BOSS中唯一直接攻击附加项“大学者·噶”的魔攻也按25%W重算；其他BOSS通过实际概率、元素伤害、治疗、减伤等形成价值。双属性卡分摊预算。固定数值保留两位小数；升级不自动提升卡片定值，不吃装备品质/副手折算第二遍，人物原有适用的总倍率按统一汇总作用一次。

Lv.30参考武器主属性实得300.50，参考主攻均值888.14。小怪攻击+30.05，大怪攻击+54.09，高额单槽+66.11；原大怪+214.24相当于武器主属性71.30%，已全部废止。小怪生命+362.82、物防+90.85、命中+157.55，分别约为参考角色同项的8%、6%、12%提升，详细换算含甲类倍率见附录D。

乌兹来源卡明确分工：骷髅法师只提供魔法攻击+54.09；痛苦幽魂改为戒指限定暗元素精通+18。两张不再同属性同数值。

### 4.2 四种“概率”必须分清

| 描述 | 含义 | 例子 |
|---|---|---|
| 暴击 +X 点 | `critRateBp` 在当前项目是参与对抗的评分，不直接当成概率百分点 | 收益取决于敌方暴免 |
| 命中修正 +4% | 补足剩余未命中部分的 4% | 基础命中 60% → 61.6% |
| 闪避修正 +4% | 敌人对自己的结算命中率乘 0.96 | 敌人命中 60% → 57.6% |
| 实际暴击 +3 个百分点 | 对抗算出基础暴击后加 0.03，仍受敌方暴免修正 | 基础 20% → 23%，再乘敌方修正 |

“实际概率”是战斗实际命中/暴击提升，不是提高卡片掉率。当前卡表没有提高怪物卡掉率的递归附魔。

精英的命中、闪避、暴免、暴抗修正复用既有数学含义。来自多张卡和套装的同类修正采用剩余量相乘合并：`c合并 = 1 - ∏(1-ci)`，而非无限相加。例：套装命中修正 25% 加卡 4%，合并为 28%，不会写成 29%。

卡片减伤独立乘剩余伤害：`D新 = D原 × ∏(1-r卡)`。两张 3% 减伤的综合额外减伤为 5.91%，不直接把现有所有减伤字段改成新算法。根冠公羊卡的生命上限+20%在原生命上限后独立乘1.20，不额外恢复当前生命，换装不得凭空回血。卡片治疗量相加为独立治疗增幅层，再作用于原治疗值；不放大药剂固定回血、吸血、被治疗增幅及自然回复，除非卡片明确写明。

当前实现使用专用字段 `actualCritRatePct`。结算为 `clamp(基础对抗暴击+实际百分点,0,1) × (1-目标暴免修正)`；必暴技能仍服从原必暴规则。实际命中使用 `actualHitRatePct`：先加入基础对抗命中，经过原命中倍率/最低命中规则，再进行命中修正与防守方闪避修正。所谓实际 +3 不代表能越过敌方所有防御机制固定增加最终 3 点。UI 展示作用阶段。

仅“卡片来源”的实际命中合计和实际暴击合计各自封顶 +12 点；上限不削弱现有职业、技能、神器来源。组合计入上限，例如国王+8与乌兹+6合计按12计入。

### 4.3 BOSS 属性附魔

属性附魔范围按具体卡片描述执行。瓦尔克卡片为“攻击赋予火属性”，不再提供火元素精通，取消“无元素普通攻击”的限定，并移除火元素伤害提高8%的独立效果。赋予火属性不额外生成第二段伤害，不改变攻击原有的物理/魔法伤害类别。下列无元素普攻限制及原属性优先规则，仅适用于其他仍注明“无元素普通攻击”的属性卡。

实现字段 `attackElementAll` 只用于保留瓦尔克“攻击赋予”这一卡片版本与文案标识，不扩大元素继承范围。当前可观察的结算仍是：技能始终读取技能自身元素，中性技能保持无元素；普通攻击先读取武器/神器原生元素，仅在原生元素为空时读取卡片赋予。因此该字段不会覆盖原生元素，也不会令无元素技能继承火属性。

- 当前卡表提供火、冰、雷、暗、光五种武器属性卡；其附带的元素精通只增强对应元素。V2部分卡另外具有对应元素伤害+8%的卡片独立乘算层，原对应元素伤害×1.08，每段只乘一次，不额外生成伤害段，不作用于其他元素、召唤物或治疗。
- 普攻原本已有元素时保持原本元素；技能自身元素优先；无元素技能不因武器卡自动改元素，需未来明确标注可继承武器属性。
- 元素附魔仍走既有元素精通与抗性结算，不忽略免疫和耐性，不获得额外独立命中、暴击或触发次数。
- 原神器/武器固定属性优先于卡片赋予；预览中明确提示“当前武器已有属性，卡片的属性赋予不生效，其他附加属性仍生效”。
- 副手没有第二次属性攻击；只有武器槽上的属性卡有效。双体首领、三首蛇母等不用多张属性卡在一个装备上叠加。

## 5. 掉落规则与最终公式

### 5.1 判定单位

每个合资格、真实被击杀的常规怪物实例，对自己的卡进行 1 次独立判定；成功生成 1 张，失败 0 张。来源BOSS另外对其白名单中的每张召唤物卡独立判定一次，详见专项表；执法者对当前星骷版本判定一次。同场击杀多只不同怪物，各自判定，不与材料、装备、技能书争夺掉落槽，不分摊基础掉率。

全队只判定一次，不是每人各 roll 一次。队伍合资格人数 N 只统计现有奖励成员，最多 4 人；随从、召唤物、NPC 和无体力奖励资格成员不计入。沿用当前资格的角色倒地情况，不额外要求存活或尾刀归属。

只有击杀结算掉卡。交涉成功、逃跑、失败、退出、拾荒、购买普通宝箱和战后补领材料不能生成卡。复活同一实例不清除卡片结算标志。多人同时结算或接口重试不能再 roll。

### 5.2 定稿公式

所有输入以比例参与运算，25% 记 0.25：

```text
p0 = 品阶基础掉率（0.03 / 0.02 / 0.01 / 0.005）
P  = 组队加成：1人0；2人0.60；3人1.00；4人1.50
T  = 怪物有效 dropPct 合计 / 100
E  = 合资格队员各自最强有效掉落药剂的加成之和
O  = 全队最高全知者等级对应加成；(等级-1)×5%，最高50%
A  = 全队个人掉落天赋/祝福加成的幸运权重平均值
w_i = 1 + 0.2 × clamp(幸运_i / 100, -1, 1)
A = Σ(w_i × a_i) / Σw_i
L = ∏w_i（隐藏幸运关闭或旧会话未启用时取1，归属等权）
G = 适用卡片的全局掉落倍率，默认1

M = G × (1 + P + T + E + O + A) × L
p队 = clamp(p0 × M, 0, 1)
q_i = w_i / Σw_i
p个人_i = p队 × q_i
```

**关键新增口径**：旧 `dropBonusPct` 在材料掉落部分会直接加概率百分点；卡片把相同标示值解释为相对掉率提升，并纳入 A。20% 使单人 BOSS 卡 0.5% → 0.6%，不是 20.5%。不能不声明就把旧算法和新公式混用。上线需把相关天赋描述写清“材料按原规则；卡片为相对提升”，或另设专用卡片效果字段并兼容现有来源。

旧材料逻辑会随机选择一个参照成员读取个人天赋；卡片当前实现改为同一幸运权重下的加权平均值，让概率可预览、可审计。在线性未封顶区间，两者期望一致；封顶区间不保证等价，以本公式为准。个人天赋帮助全队生成，但不令本人独占卡片。

P/T/E/O/A 同层相加；G/L 在外层相乘。不要把“4人 +150%、一瓶大药 +100%、黄金 +100%”错算成 `2.5×2×2`，正确为 `1+1.5+1+1=4.5` 倍。

### 5.4 特殊来源边界

城镇执法者按用户最新要求开放卡片掉落，按真实追捕战开始时的星级/骷髅档位选择对应版本；基础率仍按精英1%、BOSS0.5%。当前代码排除追捕普通奖励，需要独立接入卡片结算，不连带开放经验材料。详见[执法者与召唤物专项](./执法者星骷机制卡与召唤物来源V1.md)。

召唤物本身死亡不roll卡片，但其卡片加入对应来源BOSS掉落表，每张独立判定一次，不需要实际召唤过，不按召唤次数增加。乌兹增加5张对应卡，哥布林国王增加哈巴龙和两种王庭侍卫卡。用召唤物自身品阶基础率，继承母体本场加成。本体卡仍为0.5%，两类卡不互斥。

首领部位、转职试炼和测试怪不产卡；仅作为状态的三首、阶段转换和历史部位模板不建立独立卡片物品。PVP玩家和域民切磋也不产怪物卡。

卡片 V1 不经过 `ordinaryTalentItem` 的普通材料翻倍/预览/复制链。B03、I03 对卡片的倍率均为 1，不能只靠小怪卡稀有度“普通”判断是否翻倍。其他声称“普通战利品”的天赋也必须统一将卡片排除；真正通用 `dropBonusPct` 则按 A 接入。此为新增品类边界，需写进玩家天赋说明，避免误导。

每个条目超出100%只保证该卡 1 张，不产出第二张；来源BOSS的不同条目可同时成功。未来活动另开“额外卡片次数”才能增加次数，不能复用材料多批机制暗中翻倍。基础概率保持用户原值，不新增每日次数限制、不设置隐形衰减或伪随机保底。

## 6. 铁匠铺与锻造师附魔流程

两个入口新增“装备附魔”，共同调用同一服务。顺序：选装备 → 按合法槽位/等级筛选背包卡片 → 预览 → 确认 → 消耗与覆盖 → 展示结果。

预览至少展示：装备名及实例号、实际槽位和等级、当前完整附魔、新卡完整属性、旧效果将被整体替换、卡片数量 1、铜币费用、绑定结果。已有附魔时按钮显示“确认覆盖附魔”，首次显示“确认附魔”。相同卡相同版本相同效果重复附魔应提示“已经具有相同附魔”，不扣卡不收费。

```text
装备附魔｜Lv.30 赤铁长剑
当前：哥布林战士·卡片｜物理攻击 +37.82
本次：熔炉监工·瓦尔克·卡片
效果：攻击赋予火属性
消耗：对应卡片×1；铜币×2560
结果：旧附魔全部被覆盖；装备绑定状态保持不变
[确认覆盖附魔] [返回选卡]
```

预览读取卡片真实固定数值，不能拿装备等级重新计算。上例哥布林战士为Lv.21基准卡；装备Lv.30不会令其数值按Lv.30放大。

装备已穿戴、战斗/隐藏副本锁定、寄售、交易托管时拒绝执行，并说明原因；沿用工作坊卸下后操作的方式。操作凭据绑定角色、入口、装备 ID/版本、卡片 ID/绑定分桶、价格及过期时间。10 分钟有效；新旧附魔或装备发生变化必须重新预览。

QQ 蓝色命令链接采用“不直接发送”；不得使用不支持的 `qqbot-cmd-enter show`。无资格/无材料的操作展示不可点击状态，不留可绕过的旧确认入口。

## 7. 附魔保留、属性汇总与数据安全

### 7.1 数据实现

新增 `equipment_enchantments`，以 `instance_id` 为主键/唯一键，包含 owner 校验所需关联、card_code、monster_code、card_version、effects_json、allowed_slot_snapshot、created_at、updated_at、revision。效果保存附魔时快照，卡片平衡更新不偷偷回写历史装备。本次明确删除瓦尔克卡片精通属于定向修正：该卡升至版本3，启动初始化会把既有瓦尔克附魔同步为“攻击赋予火属性”、移除 `elementMastery_火` 并递增附魔修订号；其他卡片快照不变。

卡片放入现有背包及绑定分桶；卡片定义另设 registry，并复用 `item_definitions` 承载可交易物品，使用明确的 `monsterCard` 品类标记。无需为每张卡建立独立装备实例。

属性汇总：原装备属性与精炼/熔铸按原规则结算完成 → 加入固定附魔属性 → 合并角色已有合法总增幅 → 建立战斗快照。机制效果写入专门的卡片修正/实际概率/元素赋予层。不要把效果简单塞入 `effect_json` 再被品质、精通、重铸和旧装备上限清理重复处理。

### 7.2 变更矩阵

| 装备操作 | 附魔结果 |
|---|---|
| 普通材料熔铸 | 卡名、版本、数值保持 |
| 熔铸升级 Lv.25→30 | 保留，不自动按 Lv.30 放大 |
| 重铸洗练 | 保留，不进入副词条洗练池 |
| 精炼、品质突破成功/失败 | 均保留，不乘新的品质系数 |
| 旧重铸删除旧实例并创建新实例 | 事务内把原附魔完整转到新实例，不能外键级联先删掉 |
| 史诗升阶/其他换实例升级 | 如果属于原装备升级必须迁移；跨槽位不兼容时在预览前拒绝该路线，不能静默抹掉卡 |
| 替换装备/卸下再穿上 | 跟随装备；卸下不生效，穿上再计入一次 |
| 交易/寄售/取回 | 跟随装备及绑定规则 |
| 销毁/分解 | 随装备消失，不返卡，预览注明 |
| 重新附魔 | 新快照整体替换旧快照，多效果也不残留 |

卡片的最低等级只在首次附魔和合法迁移时校验；升阶不损失。当前没有降级授权；未来若降低装备等级到卡片门槛以下，应拒绝降级，而不是悄悄关掉或抹掉附魔。

### 7.3 事务和幂等

掉落账本用 `(source_spawn_id, reward_channel='monster_card', card_code)` 唯一键；记录资格列表、公式版本、p0、P/T/E/O/A/L/G、p队、随机数、归属权重、领取人及卡片版本。没有掉卡也要记录已判定。采用两阶段持久化：先提交不可变的判定及归属结果，成功条目标记pending；再用独立发奖事务锁定pending条目、入背包并改为granted。入包失败仅回滚发奖事务，判定记录不回滚；重试读取原随机数和领取人，不能重新随机。未掉卡条目直接完成，后台可重试pending，但无权重roll。来源BOSS附加卡用母体实例ID和所代表的召唤物code记账。无奖励资格的对象在进入随机判定前拒绝；执法者采用独立卡片资格，不因旧普通奖励过滤而漏发。

附魔事务锁装备、报价、卡片库存及附魔记录；检查归属、状态、等级、槽位、库存绑定桶和报价版本；条件扣币/扣卡必须 affectedRows 符合；更新附魔、重算角色、写操作账本、写凭据结果同事务提交。重复点同一凭据返回原结果，不能扣第二张卡。异常全部回滚，保留旧附魔。

两入口、背包快捷附魔、直接命令和历史按钮都必须走相同服务校验。附魔操作不直接修改共享物品定义，不能让同型号其他玩家装备一起获得或失去卡片。

## 8. 平衡和验收

单人无加成预期每张卡击杀数：小怪约33.33、大怪50、精英100、BOSS200。这是几何分布均值，不是200次必出；BOSS200次至少一张概率约63.30%，500次约91.84%。四人共享卡不能把队伍掉率当成自己的掉率，完整数据见计算表。

实际经济应按“合资格击杀速度 × 单次概率”衡量：BOSS刷新/通关时长、队伍人数、药剂覆盖率和卡片可交易性都会改变供给。本稿没有线上击杀统计，不能声称稀有度和玩家毕业周期已通过实测。建议观测每千次合资格击杀的产卡量、每小时卡片供给、覆盖销毁率、交易价格和各部位附魔使用率后再调数值，不暗改用户指定的基础掉率。

实现验收范围：

1. 逐怪表中每个开放的“模板×卡片版本”组合恰有一张 registry 卡，无重复 code，所有高额/机制卡只有一个槽位；执法者星骷、召唤物来源映射及禁止产出的部位/试炼明确区分。
2. 掉率确定性测试覆盖基础、所有队伍人数、同人药剂取强、多人相加、词条、全知者、负幸运、天赋混编、全局倍率、100%封顶及零资格；校验配套计算表。
3. 概率测试用固定随机数验证阈值两侧，用统计抽样辅助验证；不能把一次模拟出卡当成概率正确的证据。
4. 同战斗多怪、双体召唤、蛇母多首、复活、重复结算、断线重试均无重复卡；药剂只扣一场。
5. 两入口首次附魔、覆盖、同卡拒绝、余额不足、卡片过期报价、并发双击、绑定传播、别人装备拒绝及事务回滚。
6. 熔铸/升级/精炼/突破/洗练/换实例旧重铸逐项验证卡名与快照字节一致；同类型另一实例完全不变。
7. 攻击、防御、生命、魔力、命中评分、暴击、破韧、元素、治疗、实际概率都从人物详情进入真实 PvE/PvP 战斗；不能只展示不生效。
8. 概率修正不改写六维转换、甲类套装原值、神器原特效；卡片字段新接入时要单测专属公式和来源层。
9. 正式实现后运行项目要求的 `npx tsc --noEmit`，按修改范围运行集成测试。定向测试通过不代表已完成实机 QQ、真实数据库迁移或线上玩家验证。

## 9. 当前实施状态

当前源码已经按“定稿公式与逐怪表 → 卡片 registry 与附魔独立存储 → 战斗产卡和审计 → 人物/战斗属性 → 两处附魔入口 → 熔铸重铸迁移路径”接通，并完成定向自动化验证。正式发布前仍需执行真实数据库迁移、实机 QQ 交互和线上数据观察；历史附魔保留及失败回滚仍是发布验收项。

### 3. 机制精确定义

#### 3.1 地图移动与感知

地图移动速度是单次移动格数，不是战斗 `speed` 或出手顺序。当前实现按 `基础最大步长=min(10,原敏捷步长+原装备移速+卡片常驻格数)` 计算，再应用负重惩罚、取整、最低1格。凯尔充能增加的2格也受绝对10格上限限制；达到10格时明确显示无额外格数收益。

负重惩罚减少20%指原移动惩罚率乘0.8，原惩罚30%变24%，不是变10%。莱拉地形减耗仅降低地形附加部分：基础耗体力4、地形额外4，减耗后消耗7，不是总消耗8×0.75。内部可累计小数体力或结算向上取整，V1定为最终总消耗向上取整，且不得小于基础消耗。

常驻移动加格来自同槽卡自然互斥；和凯尔充能可组合但受10格限制。移动仍受碰撞、路径每格事件、门槛、跨地图/楼层规则与剩余体力限制，不能一次跳过事件。充能按角色状态持久化，换装、传送、进入战斗时清零；反复卸装不能刷新次数。自动移动也逐次记录。

普通感知半径在原地图感知值后增加整数格；卡片来源合计最多+3格，同类多个+1/+2不是无限扩大。仅扩展普通地表可见怪物、资源和地标的观察范围；不扩大 PvP攻击距离、技能射程、交涉距离、采集距离或拾取范围。地下迷宫固定1格、剧情遮蔽和未解锁区域优先，卡片不能穿墙、穿层或揭开隐藏地图。

凯尔的NPC交谈距离是明确单独例外，只限普通NPC交谈；不能越过楼层、区域、剧情门槛或隔墙触发。原需近身的商店/提交物品仍按原距离，卡片不远程购物。

追迹只保存“最后确认坐标”，目标离开感知后不持续更新；不会暴露玩家或追捕者位置。到达标记位置可能发现怪物已离开。目标死亡标记清除，移动计数到期清除，切地图/楼层清除；BOSS标记也不追踪跨阶段虚拟部位。标记不增加攻击/交涉可选目标。

遭遇降低仅用于已有可随机发生的野外移动遭遇，`p新=p原×(1-r)`；主动接战、追捕、剧情强制战、地宫固定战不受影响。如果某路线没有这种随机遭遇判定则该效果无作用，不能虚构减少怪物刷新数量。

当前源码尚无普通随机野外遭遇判定、地形附加体力消耗事件，以及地表连续路径移动与墙体视线判定；因此依赖这些底层事件的遭遇降低、地形附加体力减免、逐格事件与墙体遮蔽约束目前没有可观察效果，保留为待相应底层事件接入后生效的数据规则。已接线的地图移动上限、感知半径和追迹等效果不受此状态说明影响。

#### 3.2 交涉成功和重判

先走全部交涉资格与黑名单；只有合法对象进入概率公式。卡片不能让城镇执法者、禁止交涉BOSS、转职试炼或已开战目标变得可交涉。

设原 `negotiationProbability` 结算值为p：`p新=min(1,p+Σδ卡)`，卡片来源合计上限+10个百分点。例：原20%，戴四骷髅琳恩+5及索拉+5，变30%；戴五骷髅各+6，按上限也是30%，不是32%。戒指/项链单槽覆盖让玩家选择交涉机制组合。

加成读取实际执行交涉动作的角色；不把全队四人装备相加。交涉成功率与送礼/交谈引发敌意的概率是两条独立流程，成功率卡不顺带降低敌意。原概率0且是“资格禁止”时不能补到正数；原概率0但合法、只是心情差时可按上述公式增加。

“中性礼物敌意降低15%”为 `a新=a原×0.85`；讨厌礼物、明确拒绝保护、强制开战和已存在冷却均不受益。每场一次原概率重判相当于该次触发概率 `a²`，不是额外一次交涉成功 roll。例 a=20%，重判后最终触发开战为4%。重判第二次消耗同一动作，不再扣礼物、不加第二份心情和熟练度、不形成重判递归。

一次性次数按交涉 session 和角色持久化，开始时装备快照固定。退出重开同一怪物仍沿用该怪物上的已用状态；换卡、换入口不能刷新。多人重判保护同一动作最多1次，取实际执行者的效果，不让不同玩家轮流救回无限次。礼物揭示只揭示配置已有喜好，若全部已知则显示“喜好已全部掌握”，不伪造收益。

当前机制字段分别使用 `mapMoveBonus`、`mapPerceptionBonus`、`mapBurdenPenaltyReductionPct`、`mapRandomEncounterReductionPct`、`neutralGiftAggressionReductionPct`、`negotiationActualBonusPct`、`negotiationRetryPolicy` 等；不借用战斗命中、speed或六维感知字段代替。

### 6. 执法者奖励路径与资格

真实追捕战胜利后，对该场阵容中实际被击败的每名执法者进行一次卡片判定。战斗失败、逃跑、旧追捕清理、管理员生成、旁观者触发、再次读同一战报都不判定。当前实现套用主文合资格玩家和共享分配公式，并显式计算追捕玩家的卡片资格快照；无体力奖励资格则不掉卡，不会因普通 `rewardMembers` 为空而令执法者卡永远0掉落。

星骷不同版本各自固定效果，一次击杀只roll当前版本，不同时roll低档卡。五星有4名精英时各1%，不把整场压缩成一个1%；五骷髅是凯尔0.5%加三名精英各1%。来源与计算见掉率文档。

### 9. 连续击杀、期望、分位数与活动覆盖

指定卡固定每次概率p：n次至少1张=`1-(1-p)^n`；期望首次取得击杀数=`1/p`；达到至少x取得概率所需次数=`ceil(log(1-x)/log(1-p))`。p=0时永不可得，p=1时一次必得。以下均为指定卡，不是任意卡池。

若药剂仅覆盖部分战斗，必须分段乘积：`P至少1张=1-∏t(1-pt)`，不能把高药剂率当全程。例如单人BOSS前10次用大药p=.01、后90次无药p=.005，100次至少1张=`1-.99^10×.995^90`=42.399107%；期望张数=10×.01+90×.005=0.55。药剂按场次而非怪物数量消耗，一场多只BOSS的每个合法来源共享本场药剂状态。

将概率换算为时间需实际每小时合资格击杀数K：平均卡数/小时=`K×p`（单卡），预计首张小时数=`1/(K×p)`；多条目用`K×Σpj`。目前没有线上K，本文不伪造刷取时长。

### 10. 对照旧材料公式，避免直接套用

非互斥普通材料在现有实现的大致路径：先算 `b=clamp(p0×G×(1+P+T+E+O)+d,0,1)`，其中d为随机参照成员的直接概率加成；再经`dropBatches`按幸运及合资格普通天赋倍率K得到期望批数`e=b×L×K`，批数为floor(e)加小数伯努利。至少一批概率为min(1,e)，可以多批，不等于单次伯努利卡片公式。互斥材料组还有另一层权重选品，不能用本节简式覆盖。

单人无其他加成，若把0.5%BOSS卡直接插进旧材料表，并有20%直接加成，会到20.5%，相对原基础扩大41倍；本卡片方案为0.6%。因此卡片必须使用专用roll函数和明示的相对加成口径。本轮不修改材料规则。

### 11. 核算说明

本文件所有数值由确定性公式脚本计算，概率显示最多6位小数百分比，内部不按显示值反算；期望张数使用真实概率。独立条目公式的前提是战斗加成和成员权重冻结、各条目随机数独立。若未来加入共享保底、互斥卡池或次数天赋，需重新计算联合概率，不能沿用当前表。
