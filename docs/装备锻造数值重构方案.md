# 装备锻造数值重构方案（评审稿）

> 状态：设计评审，尚未改动游戏逻辑。
>
> 目标：以同等级六维均等的白板角色为锚点，统一打造、精炼、熔铸的数值上限；让装备品质决定实际发挥，稀有度决定原始上限与主词条强度。

## 1. 本方案的结论与前提

本方案将装备的**原始数值上限**分为三档：

```text
攻击 : 防御 : 常规其他数值 = 1 : 1 : 2
```

但这只代表同一装备内部的数值预算，不代表 1 点攻击、1 点防御、1 点生命、1 点命中在战斗中等价。生命、命中、暴击等属性的基础量纲不同，最终仍需用实战伤害、命中率和生存时间验证。

本文按以下理解编写；其中有歧义的部分已在第 8 节列出：

- 本次重构的直接范围是：**打造装备、其精炼、其熔铸**。商店制式装备、任务装备、神器是否同步重标，需另行决定。
- `普通 100% 品质` 是每个等级、每个类型的原始上限基准；品质只把最终发挥从 60% 拉到 100%，不改变词条结构。
- 稀有度乘算主词条和所有辅材词条的上限；普通为 `1.00`，每提升一档乘 `1.20`。
- 武器不能出现物防/魔防词条；防具不能出现物攻/魔攻词条。
- 防具文字中“继续叠加主词条攻击也减半”与“防具没有攻击词条”冲突。本文按后一句执行，并将其理解为：**额外的单防御词条上限为防具基底的 1/2**。

## 2. 白板角色与装备基底

### 2.1 白板定义

当前角色创建时，基础六维总值随机为 `80～120`，成长六维总值随机为 `8～12`。为了使装备不受角色随机出生影响，建议锻造系统固定取其中位期望值并均分：

```text
每项基础属性 a = 100 / 6 = 16.6667
每项成长属性 g = 10 / 6 = 1.6667
等级 L 的每项白板六维 x(L) = a + g × (L - 1)
```

当前派生公式下，六维均等时：

```text
物攻 = 魔攻 = 8 + 4.3 × x(L)
物防 = 8 + 4.25 × x(L)
魔防 = 8 + 4.3 × x(L)
```

因此：

```text
武器普通基底 W(L)
= (白板物攻 + 白板魔攻) / 2 × M(L)
= (8 + 4.3 × x(L)) × M(L)

防具普通基底 A(L)
= (白板物防 + 白板魔防) / 4 × M(L)
= (4 + 2.1375 × x(L)) × M(L)

装备等级倍率 M(L)
= 1.2 ^ floor(L / 10)
```

即 Lv.1～9 为 `×1.00`、Lv.10～19 为 `×1.20`、Lv.20～29 为 `×1.44`，以此类推；Lv.50 为 `×2.48832`。

建议所有内部结算保留至少两位小数，装备详情展示时保留一位小数，角色最终面板仍沿用现有向下取整规则。

### 2.2 基底参考表

| 等级 | 单项白板六维 x(L) | 单攻 / 单魔攻 | 单物防 | 单魔防 | 等级倍率 M(L) | 武器基底 W(L) | 防具基底 A(L) |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 1 | 16.67 | 79.67 | 78.83 | 79.67 | 1.00000 | 79.67 | 39.62 |
| 5 | 23.33 | 108.33 | 107.17 | 108.33 | 1.00000 | 108.33 | 53.88 |
| 10 | 31.67 | 144.17 | 142.58 | 144.17 | 1.20000 | 173.00 | 86.03 |
| 20 | 48.33 | 215.83 | 213.42 | 215.83 | 1.44000 | 310.80 | 154.53 |
| 50 | 98.33 | 430.83 | 425.92 | 430.83 | 2.48832 | 1072.05 | 532.97 |

这个曲线已从“装备显著”变成“装备主导”。Lv.50 普通 100% 品质单主词条武器提供 `1072.05` 点单攻，约为同级白板单攻的 249%；五件普通防具各提供 `532.97` 点双防时，合计约为白板双防的 625%。即使是 0% 品质，仍分别约为白板单攻的 149% 与白板双防的 375%。这可以作为高装备驱动 RPG 的方向，但不能再按“角色成长为主体”的平衡预期处理。

## 3. 词条上限模型

令：

```text
B = W(L)（武器）或 A(L)（防具）
R = 稀有度倍率
Q = 品质发挥倍率 = 0.6 + 品质 / 250
```

其中品质为 `0～100`；因此 `Q` 为 `0.60～1.00`。

原始词条上限以 `B × R` 为基准，最终实际发挥为：

```text
最终词条值 = 原始词条值 × Q
```

### 3.1 武器上限

| 词条类别 | 原始上限（普通 100% 前） | 说明 |
| --- | ---: | --- |
| 主物攻或主魔攻 | `B × R` | 长剑为物攻；法杖/法书/法球为魔攻 |
| 魔力、命中、暴击、暴伤 | `B × 2 × R` | 高权重副词条 |
| 生命、闪避、速度、韧性等 | `B × R` | 常规副词条 |
| 额外同类攻击 | `B × 0.5 × R` | 例如法杖继续追加魔攻 |
| 物防、魔防 | `0` | 武器禁止防御词条 |

匕首、拳刃的双攻主词条需要单独确认。若保留双攻，则建议每一项各为 `B × 0.5 × R`，使双攻合计仍等于一把单攻武器的 `B × R`，避免双攻武器天然获得两倍主词条预算。

### 3.2 防具上限

| 词条类别 | 原始上限（普通 100% 前） | 说明 |
| --- | ---: | --- |
| 主物防 | `B × R` | 每件防具均有 |
| 主魔防 | `B × R` | 每件防具均有 |
| 生命、闪避、暴免、暴抗 | `B × 2 × R` | 高权重副词条 |
| 魔力、命中、速度、韧性等 | `B × R` | 常规副词条 |
| 额外单物防或单魔防 | `B × 0.5 × R` | 本文对歧义文本的解释 |
| 物攻、魔攻 | `0` | 防具禁止攻击词条 |

现有数据模型中，建议将“暴击、暴伤、暴免、暴抗”分别落为 `critRateBp`、`critDamageBp`、`critResistBp`、`critDamageReductionBp`。它们都是基础点数（bp），不要直接混用百分数。

### 3.3 稀有度倍率与一级概率

```text
稀有度倍率 R = 1.2 ^ 稀有度阶数
```

| 稀有度 | 阶数 | R | Lv.1 锻造师概率 |
| --- | ---: | ---: | ---: |
| 普通 | 0 | 1.0000 | 60% |
| 优秀 | 1 | 1.2000 | 30% |
| 精良 | 2 | 1.4400 | 10% |
| 稀有 | 3 | 1.7280 | 未定义 |
| 传说 | 4 | 2.0736 | 未定义 |
| 史诗 | 5 | 2.4883 | 未定义 |
| 神器 | 6 | 2.9860 | 未定义 |

一级锻造师的期望主词条倍率为：

```text
60% × 1 + 30% × 1.2 + 10% × 1.44 = 1.104
```

也就是一级锻造师平均比纯普通装备高 10.4%，波动可见但不会过分拉开。

> 建议：未定义高阶品质概率前，Lv.1 仅产出普通、优秀、精良；不要继续沿用旧的“辅材评分越高越高品质”的概率公式，否则会和固定 `60/30/10` 冲突。

## 4. 辅材与熔铸

### 4.1 小兽材与专属兽材

辅材直接增加原始词条值，且不得超过第 3 节对应上限。

| 装备类别 | 小兽材：攻击/防御倾向 | 小兽材：其他倾向 | 专属兽材 |
| --- | ---: | ---: | ---: |
| 武器 | 单项物攻或魔攻 `+1～2` | 单项其他数值 `+2～4` | 对应小兽材数值 ×5 |
| 防具 | 单项物防或魔防 `+1～2` | 单项其他数值 `+2～4` | 对应小兽材数值 ×5 |

推荐按现有材料命名做第一版映射：

| 倾向 | 小兽材示例 | 专属兽材示例 |
| --- | --- | --- |
| 物攻 | 兽骨 | 魔力獠牙 |
| 魔攻 | 兽核 | 精制/专属魔力核心（待定） |
| 物防 | 兽皮 | 专属硬壳类材料（待定） |
| 魔防 | 基础鳞片 | 魔力鳞片 |
| 速度 | 兽筋 | 专属兽筋（待定） |
| 命中 | 普通感知类材料（待定） | 魔力心核 |
| 闪避 | 普通轻质材料（待定） | 魔力绒毛 |

当前项目的 `beast_*`、`magic_*`、`refined_*` 并不完全等同于“小/专属/精制”三层概念。因此实现前必须完成一张**材料代码 → 倾向 → 档位**的明确配置表；不能再对未配置材料使用默认生命或默认攻击回退。

### 4.2 熔铸

熔铸使用与打造辅材同一套单次增量和同一套词条上限：

```text
熔铸后原始词条 = min(打造词条上限, 当前原始词条 + 材料本次增量)
```

建议取消旧逻辑中“所有熔铸属性容量总和最多为 2”的跨属性总预算。因为新模型已经把每一条词条的上限与稀有度绑定；再保留总容量会导致不同属性互相挤占，玩家无法根据材料直观规划。

熔铸失败、次数上限、消耗规则可以维持现有框架；变化仅是成功后的属性增量和封顶规则。

### 4.3 精炼

精炼只改变品质，不改稀有度、不改原始词条、不重掷辅材。

```text
品质 Qlt: 0～100
品质发挥倍率 Q = 0.6 + Qlt / 250
```

例如，同一件 Lv.20 普通武器主词条原始物攻为 `310.80`：

| 品质 | 发挥倍率 | 实际主词条物攻 |
| ---: | ---: | ---: |
| 0% | 0.60 | 186.48 |
| 50% | 0.80 | 248.64 |
| 80% | 0.92 | 285.94 |
| 100% | 1.00 | 310.80 |

“只能放入对应主材精炼”建议采用以下规则：

| 装备等级 | 唯一可用精炼主材 |
| --- | --- |
| Lv.5、10 | 活木 |
| Lv.15、20 | 陨铁 |
| Lv.25、30 | 星铜 |
| Lv.35、40 | 月银 |
| Lv.45、50 | 曜金 |

对于 Lv.25 以上武器，配方中虽包含低阶矿材，但精炼仅认最高阶的当级主材。例如 Lv.25、Lv.30 武器只允许星铜精炼。

## 5. 具体数值案例

以下案例采用第 2 节的固定白板，数值保留两位小数；实际装备展示可保留一位。

### 案例 A：Lv.20 普通 100% 法杖

```text
武器基底 B = W(20) = 310.80
稀有度 R = 1.00
品质 Q = 1.00
```

| 项目 | 上限 | 说明 |
| --- | ---: | --- |
| 主魔攻 | 310.80 | 法杖唯一主攻击 |
| 魔力 / 命中 / 暴击 / 暴伤 | 621.60 | `B × 2` |
| 生命 / 闪避 / 速度等 | 310.80 | `B × 1` |
| 额外魔攻 | 155.40 | `B × 0.5` |
| 物防 / 魔防 | 0 | 武器禁用 |

假设打造时出现以下词条：主魔攻 `310.80`、命中 `300`、额外魔攻 `80`。该装备 100% 品质时实际就是这些数值；若品质为 50%，则实际为魔攻 `248.64 + 64`、命中 `240`。

若投入 80 个魔攻倾向小兽材，每个掷出 `+2` 魔攻，总计 `+160`，仍只能得到额外魔攻 `+155.40`，多出的 `4.60` 会被封顶。因此界面需要在放料时显示“本次可生效 / 将溢出”的预览。

### 案例 B：Lv.20 精良 80% 长剑

```text
B = 310.80
R = 1.44
Q = 0.92
```

原始主物攻上限：

```text
310.80 × 1.44 = 447.55
```

实际主物攻：

```text
447.55 × 0.92 = 411.75
```

原始高权重命中上限为 `895.10`，实际为 `823.50`；原始额外物攻上限为 `223.78`，实际为 `205.87`。

这说明稀有度与品质会交叉影响：精良 80% 的主词条为普通 100% 的约 `1.44 × 0.92 = 1.3248` 倍；但精良 0% 只有普通 100% 的 `86.4%`。这符合“高品质精炼依然有价值”，但玩家必须能清晰看到原始值、品质发挥后数值和可精炼空间。

### 案例 C：Lv.20 普通 100% 轻甲

```text
防具基底 B = A(20) = 154.53
R = 1.00
Q = 1.00
```

| 项目 | 上限 |
| --- | ---: |
| 主物防 | 154.53 |
| 主魔防 | 154.53 |
| 生命 / 闪避 / 暴免 / 暴抗 | 309.06 |
| 魔力 / 命中 / 速度等 | 154.53 |
| 额外单物防或单魔防 | 77.27 |
| 物攻 / 魔攻 | 0 |

假设这件轻甲有主双防、生命 `250`、闪避 `100`、额外物防 `60`，均不超过上限。若精炼到 50% 品质，则上述所有装备词条统一按 `0.8` 生效，不会只强化主词条。

### 案例 D：Lv.5 防具的专属材料粒度

Lv.5 防具基底为 `53.88`，额外单防御上限是：

```text
53.88 × 0.5 = 26.94
```

专属防御材料按“5 倍小兽材”会产生 `+5～10` 单防御，因此需要 3～6 个高掷值专属材料才会填满额外单防御词条。它不再像旧基底方案那样在低等级直接溢出。

但装备主词条已相对角色基础值极高；低等级不溢出不等于材料粒度完全合理。建议仍采用以下规则：

1. 材料按剩余空间结算，界面提前提示溢出；
2. 一次放入多个材料时显示累计可达值，避免玩家反复试错；
3. 为后续专属材料设置随等级成长的增量或稀有档位，避免 Lv.50 时固定 `5～10` 过于微弱。

推荐优先采用第 1 项：不改用户指定的上限，也避免玩家无提示浪费材料。

## 6. 数值合理性分析

### 合理的部分

- **等级锚定稳定。** 装备基底来自同级白板角色，且每 10 级再获得一档明确的 `×1.2` 装备成长；后续调整六维成长时，装备曲线仍可复算。
- **品质与稀有度职责分离。** 稀有度决定潜力，品质决定发挥，精炼不会洗掉已有材料投入。
- **材料投入可预期。** 小兽材 `1～2 / 2～4`、专属材料五倍的规则比现有“正态抽取 + 随机额外百分比”更容易被玩家理解。
- **低阶装备不会完全无用。** 0% 品质仍有 60% 的发挥；优秀或精良低品质装备可以通过精炼逐渐追上其稀有度潜力。

### 主要风险

- **装备主导程度极高。** Lv.50 普通 100% 武器单主攻击为 `1072.05`，是白板单攻 `430.83` 的 249%；0% 品质仍为 149%。这意味着没有装备的角色与有一把普通武器的角色会出现超过 3 倍的攻击差距。
- **五件防具会重写防御曲线。** Lv.50 普通防具每件主双防 `532.97`，五件合计 `2664.85`，约为白板双防的 625%。若怪物攻击与防御公式不同比例上调，防具会使普通怪伤害快速失去威胁。
- **高权重副词条远大于白板同类属性。** Lv.50 普通防具的生命/闪避/暴免/暴抗上限为每件 `1065.94`；五件同向满词条为 `5329.70`，已经超过白板生命 `3561.67`，也远超白板命中/闪避 `767.33`。必须限制同类高权重条的重复与装备槽叠加。
- **固定辅材在高等级会变弱。** `+1～2 / +2～4 / ×5` 的材料在 Lv.50 数百至上千的上限前，需要消耗数十到数百份才能填满词条。材料产量和可放入数量需要同步上调，或改为按基底百分比给值。
- **稀有度高于品质时可能反直觉。** 精良 0% 低于普通 100%。这是可接受的设计取向，但必须在详情页清楚显示“原始上限 / 品质发挥后”。
- **所有装备一并改造的迁移风险很高。** 若商店、任务、神器也纳入“所有装备”，既有 `effect_json`、装备实例与玩家面板都需要重新标定，并要处理已存在装备的历史数值。

### 建议的首轮限制

1. 同一件装备的高权重副词条不重复，或重复时第二条起只按 50% 上限计算。
2. 在打造和熔铸面板实时展示：当前值、原始上限、品质后上限、投入后溢出量。
3. 保留 0.01 精度存储，详情一位小数展示，角色面板最后再向下取整，避免多次精炼/熔铸产生累计舍入损失。
4. 先按 Lv.20、Lv.50 实战模拟重标怪物攻防与生命；若不准备同步提高怪物数值，建议将新基底整体乘以 `0.3～0.5` 后再测试。
5. 先只重构打造装备；制式装备和神器单独建立数值表，避免无意削弱剧情奖励。
6. 为 Lv.1 以外的锻造师等级明确稀有度概率表，再实施；不要把旧辅材评分概率与新职业概率混在一起。

## 7. 实施范围与代码落点

正式开发时，需要同步调整以下模块：

| 模块 | 调整内容 |
| --- | --- |
| `src/game/constants.ts` | 提供固定白板基底与武器/防具基底计算函数 |

| `src/game/character.service.ts` | 保持品质统一缩放所有数值词条；补齐暴伤/暴免/暴抗的展示与结算校验 |
| `src/game/adventure.service.ts` | 确认所有战斗修正字段都按品质缩放，且不对同一百分比重复计算 |
| `src/response/blacksmith.ts` | 打造/熔铸预览、主材限定、溢出提示、稀有度概率说明 |
| `src/response/equipment-detail.ts` | 同时展示原始值、品质后实际值、词条上限 |
| `src/game/admin-audit.service.ts` | 用新上限和新词条数量规则校验已打造装备 |
| 数据迁移 | 若旧打造装备继续保留，需定义转换或标记为旧版本规则 |

## 8. 实施前需要确认的事项

1. “所有装备”是否包含商店装备、任务装备、神器，还是仅指打造装备及其熔铸？
2. 匕首、拳刃是否保留双攻主词条？若保留，是否采用每项 `B/2` 的总预算方案？
3. 防具的“额外单防御 `B/2`”是否是原意？文本中出现了“攻击”但又禁止防具攻击词条。
4. `magic_*`、`refined_*` 哪些属于“专属兽材”？精制材料是否仍能进入打造和熔铸，数值是五倍、额外倍率，还是仅用于精炼？
5. Lv.2 及以上锻造师的稀有度概率、是否开放稀有以上品质，以及辅材是否会影响概率？
6. 暴击、暴伤、暴免、暴抗的 `B × 2` 是按 bp 数值直接计算，还是需要额外换算系数？建议先按 bp 直接计算，再根据战斗测试调整。
