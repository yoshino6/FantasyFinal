# 卡片强度复核 V2：装备后面板、全部攻击重算与BOSS强化

日期：2026-09-17。状态：已实现并通过定向自动化测试；尚未实机或真实数据库验证。主文与逐怪表已同步；基础掉率按用户新要求改为小怪3%、大怪2%、精英1%、BOSS0.5%；来源、附魔覆盖和升级保留规则未变。

## 1. 旧稿问题与本次结论

旧稿使用旧打造副词条上限乘统一系数，未以穿齐装备后的收益校准。Lv.30两张大怪魔攻各+214.24，分别相当于参考主武器实得300.495的71.30%，叠两槽等于补进1.43把主武器的主属性；同时小怪生命卡+142.83只带来约3.15%生命提升（计轻甲套装后仍是同一相对比例）。这不是合理的品阶梯度。

本轮所有直接物攻/魔攻逐项重算，包括小怪、大怪和BOSS附带攻击；不是只修正乌兹两张卡。攻击卡压低，小怪生存与辅助属性加强；BOSS加强实际概率、元素、减伤、治疗及属性攻击机制。

## 2. 测算模型和真实性边界

没有读取线上人物分布，因此以下是**按当前源码计算的标准装备角色均值**，不是声称全服平均。六维按`standardPlayerAttribute`，采用真实分段成长`playerGrowthShares`，不使用每级恒定10点的旧模型。等级L对应装备等级max(1,5×floor(L/5))；Lv.1–4属于等级预算参考，不保证存在对应打造配方。

对剑盾、法杖+法书、双匕首三种配置等权计算；每套10件：主副手、五件轻甲、三件常规首饰。参考装备为精良、80品质、每件2条随机副词条；副手固定值乘0.5。主词条、词条上限、品质系数、甲类逐件倍率及套装生命/魔力15%均依据当前源码。匕首双攻0.9、副手盾牌双防也纳入。

随机词条用正式权重、不放回抽2条的解析入选概率；截断正态掷值期望约0.619546。数值取整前求期望，最终展示取两位小数，故与真实单件按0.01取整/人物向下取整有细小误差。神器、史诗特效、定向极品词条、专精、进化、成就、天赋、食物和二转被动不计入；这些来源通常改变实际占比，需要按玩家构筑判断。不能直接把怪物的虚拟装备均值当作玩家均值。

复算脚本：[怪物卡片强度测算V2.cjs](./怪物卡片强度测算V2.cjs)，在项目根目录运行`node docs/怪物卡片强度测算V2.cjs`。脚本只读取源码纯函数，不连接数据库。

## 4. 新预算（只用于生成固定卡值）

| 属性 | 普通小怪 | 大怪常规 | 大怪高额单部位 |
|---|---|---|---|
| 物攻/魔攻 | 同级主武器实得W的10% | W的18% | W的22% |
| 生命/魔力 | 装备后、百分比前同项基准的8% | 11.2% | 14.4% |
| 双防中的单项 | 同项基准的6% | 8.4% | 10.8% |
| 命中/闪避/双暴双抗/韧性/破韧 | 同项基准的12% | 16.8% | 21.6% |
| 战斗速度 | 同项基准的8% | 11.2% | 14.4% |
| 单元素精通/抗性 | 3+floor(L/5)点 | 前者×1.8 | 前者×2.2 |

双属性卡拆分总预算，不能每项拿完整比例。强数值仍限制一个部位。元素低级不再沿用打造池为0而无法出效果的假设；本表现有低级卡仍保留既有方向，不擅自全换元素。精英火元素卡相应从8改为16，避免被普通Lv.25元素卡反超。

这里的百分比是**设计预算比例**，最后写入卡片的是固定点数；不读取使用者面板动态百分比加成。百分比前基准包含装备固定值，随后已有轻甲套装/甲类单件等作用于角色总属性，因此8%预算在参考角色上就是约8%同项提升，不重复乘两遍。

Lv.30普通生命+362.82，在轻甲套装后增加417.24、约8%；普通单防+90.85、约6%；普通命中+157.55，在甲类倍率后增加约183.78、约12%。若对抗双方原本命中/闪避相等，命中评分+12%使命中50%→约53.99%，绝非实际命中+12个百分点。普通攻击约+30.05，只有参考武器主属性10%、主攻约3.38%；大怪约+54.09，为武器18%、主攻约6.09%。

针对伤害公式A²/(A+D)，A=D时+30.05攻击约提升5.10%直击伤害，+54.09约提升9.23%；这不含额外暴击/元素，不能把攻击占比直接当最终伤害占比。

大怪骷髅法师保留唯一魔攻方向+54.09；痛苦幽魂改为**戒指限定暗元素精通+18**，不再是同来源同等级同效果的两张卡。其他不同区域同属性可以存在；不再允许同一个来源卡表出现两张完全相同的部位与效果。

新增“指定元素伤害提高8%”是卡片专用乘算层，仅对持有者本人已经结算为该元素的伤害生效：原元素结算伤害×1.08，每次伤害只乘一次，不能给无元素/其他元素技能额外附伤；不放大召唤物、药剂或非伤害治疗。低级暗卡凭属性转换和8%效果可长期有用途，瓦尔克火卡靠攻击赋火和30点精通形成特色，冰卡仍以更高精通区分。

根冠公羊“生命上限提高20%”是独立卡片生命比例层，对既有最终生命上限乘1.20，不能把效果当成+20点。仅生命上限，不额外恢复20%当前生命；装备/卸下沿用当前生命比例或上限约束的统一装备规则，不能反复换装回血。

卡片实际命中/暴击合计上限由8各调为12个百分点；源自其他系统的原值不受本卡片上限影响。装备国王+8与乌兹+6时卡片实际暴击合计按12计；敌方暴免修正仍生效。BOSS减伤10%独立乘剩余伤害，对应有效生命约+11.11%，并不与原系统减伤百分比相加到免伤。两张不同槽10%/8%减伤综合17.2%，不会成为18%简单加算。

治疗卡主要加强主动治疗，不改变药剂。高BOSS的6–8实际概率、元素8%伤害、8–10%减伤和10–12%治疗应有明显价值；最终还需正式战斗验证，不能声称已经实测平衡。

## 7. 组合检查与适用限制

两张小怪攻击卡占W20%，两张常规大怪攻击卡占W36%；以参考主攻均值计约6.77%与12.18%。武器+副手可双附魔，因此预算在单卡阶段已留出两槽叠加空间。高额22%攻击卡只落武器，不能同一张再附魔副手。BOSS武器与大怪高额攻击卡互相竞争同一槽。

上装+下装两张普通生命卡约+16%生命；三件头肩腰带鞋子同类评分卡合计约+36%评分，在基础50%对抗时提升到约61.04%。此为可感知的入门附魔整套收益，不应误读成单卡+36个百分点。所有高额卡、BOSS卡与机制卡仍遵守槽位竞争。
