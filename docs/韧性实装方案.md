# 韧性实装方案

> 状态：核心属性、面板与 PvE 负面状态对抗已实装；装备词条与熔铸扩展待后续开放。
>
> 适用范围：PvE 与 PvP 使用同一套结算。本文的等级表覆盖当前 Lv.1～30 的主线平衡区间；公式可直接外推至更高等级。

## 1. 目标与边界

韧性是已存在于角色面板的派生战斗属性，基础公式保持不变；破韧作为与韧性对应的进攻型派生属性，玩家与怪物都拥有并显示：

```text
韧性 = 体质 × 4 + 精神 × 3 + 感知
破韧 = floor(感知 × 2.4 + 力量 × 0.8 + 智力 × 0.8)
```

感知在破韧中占 60% 权重，是控制穿透的主属性；力量使物理招式更容易击穿意志，智力使法术压制更稳定，各占 20%。因此盗贼与高感知怪物是更稳定的控制施加者，物理与法系仍保留基础贡献。

感知本身已主导暴击，并参与命中、闪避；速度公式维持不变。为避免感知因新增破韧而超模，命中、闪避中感知系数从 `8` 下调至 `4`，减少的总权重均分给体质、精神、力量、智力；敏捷仍以 `20` 保持主导。破韧的总六维系数为 `4`，恰为韧性总系数 `8` 的一半；感知每点提供 `2.4` 破韧，但力量、智力仍各提供 `0.8`，避免控制构筑只堆单一属性。

```text
命中 = 闪避 = (100 + 敏捷×20 + 感知×4 + 智力×5 + 力量×3 + 体质×3 + 精神×3) / 5
```

六维平均时，上式与暴击、暴免、暴伤、暴抗均为 `134 + 38n / 3`；因此 Lv.30 都是 `514`。六维平均时，破韧为韧性的 `50%`；破韧是专门作用于韧性对抗的进攻属性，不要求每个职业或每件装备都与韧性取相同面板值。

实装后，韧性只处理**命中后附加的负面效果**，不降低技能本体的直接伤害，也不改变命中、闪避、暴击、暴伤、护甲、元素抗性和速度的现有计算。

处理分为两层：

1. 强控：按攻击方破韧、防守方韧性及等级差重算生效概率，因此正常同级目标会大概率抵抗强控。
2. 持续负面效果：未被完全抵抗的流血、灼烧、中毒、撕裂与减益，会降低数值并酌情缩短持续回合。

正面效果、治疗、护盾/减伤、回蓝、净化以及自我强化不受韧性影响。

## 2. 效果分类

| 类别 | 当前效果 | 韧性处理 |
| --- | --- | --- |
| 强控 | `stun`（眩晕，无法行动） | 进行完整的强控抵抗判定；失败则不施加。 |
| 软控 / 行动压制 | `bind`、`slow`、`imbalance` | 不会被完全抵抗；按负面效果倍率降低数值与回合。当前 `bind` 仅降低速度、闪避，因此不视为强控。 |
| 持续伤害 | `burn`、`poison`、`bleeding`、`rending` | 每回合伤害比例与持续回合均受负面效果倍率影响。 |
| 防御削弱 | `vulnerability`、`armor_shatter`、`sword_break` | 降低减防数值与持续回合。 |
| 正面 / 特殊 | `barrier`、`regeneration`、`mana_regeneration`、`purify`、`sprint` 等 | 不受影响。 |

后续新增“无法行动、跳过回合、沉默、睡眠、恐惧、冻结”一类效果时，统一登记为强控；不必再为每个技能单独写概率公式。

## 3. 破韧与韧性对抗

令：

```text
B       = 施加者当前破韧（六维派生值 + 装备/熔铸/增益）
T       = 承受者当前韧性
K       = min(1, 2 × B / max(1, B + T)) // 韧性对抗系数，范围 0～1
d       = 施加者等级 - 承受者等级
L       = d ≥ 0 ? 1.1^d : 0.9^(-d)     // 等级压制倍率
```

破韧是**平面穿透值**，但状态对抗不复用命中或暴击：系数 `K` 仅由攻击方破韧 `B` 与防守方韧性 `T` 决定。`B = T` 时恰好得到 `K = 1`；破韧更高时固定为 `1`，不再继续提高本次状态效果。

因此，当双方同级且 `B = T` 时，`K = 1`、`L = 1`：强控实际概率恰为技能基础概率，持续负面效果倍率恰为 `100%`，数值与持续回合均不变。

普通直击的命中仍按现有“命中 vs 闪避”结算，暴击仍按“暴击 vs 暴免”结算；韧性不介入直击伤害、命中或暴击本身。只有攻击已经命中、准备附加敌对状态时，才使用本节的 `K`；本次实际是否暴击也不会改变 `K`。

等级倍率不做中途截断，最后仅对概率做安全夹取。也就是说，等级高一级时是在当前实际概率上乘 `1.1`，低一级时乘 `0.9`：

```text
50.0% → 55.0% → 59.5%       // 每高一级
50.0% → 45.0% → 40.5%       // 每低一级
```

### 3.1 强控实际概率

`P0` 为技能/效果原本配置的强控基础概率，例如当前眩晕效果的 `50` 即 `50%`。

```text
强控实际概率 P = min(100%, P0 × K × L)
```

结算顺序固定为：技能命中 → 强控抵抗判定 → 成功时写入状态。未命中时当然不会触发强控判定。

六维平均同级角色在无额外破韧装备时，Lv.30 的 `B=260`、`T=520`，因此 `K=520/780≈66.7%`。一个基础 50% 的眩晕实际约有 33.3% 概率生效，目标约有 66.7% 概率抵抗，符合“强控应大概率被韧性抵抗”的定位。

示例：施加者与目标均为 Lv.30 六维平均白板，目标韧性为 520，技能基础眩晕概率为 50%，施加者只有 260 点六维派生破韧、没有额外破韧装备。

| 施加者相对等级 | 等级倍率 L | 实际眩晕概率 | 抵抗概率 |
| --- | ---: | ---: | ---: |
| 低 2 级 | 0.810 | 27.0% | 73.0% |
| 低 1 级 | 0.900 | 30.0% | 70.0% |
| 同级 | 1.000 | 33.3% | 66.7% |
| 高 1 级 | 1.100 | 36.7% | 63.3% |
| 高 2 级 | 1.210 | 40.3% | 59.7% |

只保留 `100%` 的最终上限，避免极端等级压制越过概率边界；破韧为 `0` 时，强控实际概率为 `0`，不会依赖命中或暴击获得保底成功率。

### 3.2 持续负面效果的降效

软控与防御削弱等非持续伤害的敌对负面效果，使用：

```text
负面效果倍率 M = 0.50 + 0.50 × K      // 范围 50%～100%
实际数值       = 原数值 × M
实际回合       = max(1, round(原回合 × M))
```

持续 1 回合的效果至少保留 1 回合。

灼烧、流血、中毒、撕裂的**每跳掉血**直接使用与强控相同的破韧、韧性和等级乘算：

```text
每跳实际掉血 = 原每跳掉血 × min(1, K × L)
```

因此同级六维平均角色无额外破韧时，`K≈66.7%`：例如“流血 4%/回合，持续 3 回合”会变为“流血 2.7%/回合，持续 3 回合”。双方同级且破韧等于目标韧性时，`K×L=1`，每跳掉血与持续时间均保持原始数值。

该规则同样用于软控与防御削弱：例如同级同韧性的“迟缓 20%，2 回合”变为“迟缓 15%，2 回合”；“碎甲 8%，3 回合”变为“碎甲 6%，2 回合”。

可叠加效果仍遵循原有最大层数限制；每次成功附加都以当次双方韧性计算后的数值写入状态，再按既有叠层规则处理。韧性不会减少已经叠上的层数。

## 4. 数值基准：六维平均玩家的正常韧性

“六维平均玩家”定义为当前锻造与数值校准所使用的标准白板：

```text
初始六维总和 = 100，平均分配至六维
每级成长总和 = 10，平均分配至六维
无职业额外成长、无装备韧性词条、无百分比韧性、无临时增益
```

因此每一项六维在 Lv.`n` 时均为：

```text
A(n) = 100 / 6 + (10 / 6) × (n - 1)
```

```text
T(n) = 4A(n) + 3A(n) + A(n)
```

### 4.1 玩家与怪物的破韧面板

破韧字段命名为 `tenacityPierce`，数据库缓存列为 `tenacity_pierce`，显示名为“破韧”，单位与韧性相同，使用平面值而非百分比。最终面板值为：

```text
基础破韧 = floor(最终感知 × 2.4 + 最终力量 × 0.8 + 最终智力 × 0.8)
最终破韧 = floor((基础破韧 + 装备平面破韧 + 增益平面破韧) × (1 + 破韧百分比 / 100))
```

| 对象 | 取值来源 | 持久化 / 展示 |
| --- | --- | --- |
| 玩家 | 最终六维（含成长、职业、装备六维）再叠加装备、熔铸、食物和战斗增益。 | `characters.tenacity_pierce` 与角色详情、战斗详情同步更新。 |
| 普通/精英/首领怪物 | 怪物最终六维（模板基础值、成长、等级、词条）派生；未来首领词条可额外提供平面或百分比破韧。 | 由 `monsterCombatStats` 实时得出，在怪物详情和战斗详情中显示；无需为普通刷新的怪物重复落库。 |

所有玩家与怪物都拥有基础破韧；控制与敌对负面效果始终只按“破韧对韧性”对抗。命中、闪避、暴击、暴免仍只服务于直击结算，装备与熔铸提供的额外破韧才属于可自由堆叠的状态进攻构筑。

### 4.2 破韧数值锚点

以 Lv.30 六维平均目标（韧性 520）为例，攻击者六维派生破韧为 260，基础强控概率为 50%：

| 攻击者额外破韧 | 攻击者总破韧 | 对抗系数 K | 强控实际概率 | 说明 |
| ---: | ---: | ---: | --- |
| 0 | 260 | 66.7% | 33.3% | 无额外破韧的同级基准。 |
| 100 | 360 | 81.8% | 40.9% | 一条中等破韧词条的收益。 |
| 200 | 460 | 93.9% | 46.9% | 明确的控制向投入。 |
| 260 及以上 | 520 | 100.0% | 50.0% | 破韧等于目标韧性，恢复技能原始控制概率。 |

建议额外破韧只出现在武器、攻击型副手、饰品、技能或熔铸的进攻位，不放进五件防具的普通词条池；防具仍以韧性为主。以当前 Lv.30 普通 100% 锻造基准估算，单条武器额外破韧词条的原始上限建议为同级武器基准 `B × 0.25`，约 `124`；配合 260 点基础破韧后仍不会单条触及穿透上限，仍需专门构筑才能达到上限。

## 5. 实装清单

1. 在基础属性层新增 `tenacityPierce` / `tenacity_pierce`，按力量、智力、感知派生，角色重算属性时同步缓存；怪物战斗属性与详情属性同步派生并展示。
2. 在锻造词条、熔铸效果、装备详情和物品图鉴加入“破韧”字段；额外破韧只开放给武器、攻击型副手、饰品和指定进攻增益。
3. 在战斗共用层抽出“攻击者破韧、承受者韧性、等级差、强控概率、负面倍率”纯函数；命中与暴击不进入状态对抗，避免重复放大进攻收益。
4. 将当前仅对少数眩晕技能存在的临时概率判定替换为所有 `effect_type='control'` 的统一判定。
5. 在附加敌对负面状态时，先将计算后的 `value` 和 `remaining_turns` 写入 `combat_status_effects`；回合结算只读取已写入的结果，不在每回合重复计算。
6. 角色韧性和破韧直接读取已有 / 新增的角色缓存属性；怪物韧性和破韧均由既有六维派生公式计算，无需为普通刷新怪物新增独立数值列。
7. 战斗日志增加两类提示，沿用现有状态文本样式：

   ```text
   $韧性$抵抗了眩晕（基础50.0% → 实际25.0%）
   #韧性#流血降效：4.0%→3.0%，3→2回合
   ```

8. 技能详情中的基础概率和基础效果数值保持原样；只有实际战斗日志显示被韧性、破韧修正后的结果，避免把“技能原始配置”与“本场对抗结果”混淆。

## 6. 验收场景

1. 同等级且破韧等于目标韧性的两个角色：50% 基础眩晕稳定保持 50% 实际生效率，负面效果数值与回合不变。
2. 在上一场景中，施加者每高一级，实际强控概率依次乘 `1.1`；每低一级依次乘 `0.9`。
3. 同级六维平均角色无额外破韧时，3 回合流血/灼烧的每跳比例约为原值 66.7%，持续 3 回合。
4. 强控抵抗成功后，不创建对应状态，目标本回合与后续回合均可正常行动。
5. 护盾/减伤、再生、回蓝、净化、冲刺等正面状态的数值和回合完全不变。
6. PvE 与 PvP 使用相同双方韧性、等级差输入时，得到相同的强控概率与负面效果倍率。
7. Lv.30 六维平均施加者对 Lv.30、韧性 520 的目标，额外破韧从 `0→100→200→260` 时，总破韧依次为 `260→360→460→520`，50% 基础眩晕概率依次约为 `33.3%→40.9%→46.9%→50.0%`；超过 260 的额外破韧不再提高本目标的概率。

## 7. 最终六维派生公式（已复核）

令体质、精神、力量、智力、敏捷、感知分别为 `体、精、力、智、敏、感`。以下均为装备、职业成长和临时六维加成结算后的最终六维；装备提供的直接战斗属性与百分比加成在此基础上继续叠加。

```text
生命上限 = 120 + 20体 + 4精 + 5力 + 2智 + 2敏 + 2感
魔力上限 =  60 +  2体 +16精 +  力 + 8智 +  敏 + 3感

物理攻击 = 8 + 0.5体 + 0.2精 + 2力 + 0.2智 + 敏 + 0.4感
魔法攻击 = 8 + 0.2体 +   精 +0.2力 + 2智 +0.4敏 + 0.5感
物理防御 = 8 +   2体 +0.25精 +  力 +0.25智 +0.5敏 +0.25感
魔法防御 = 8 + 0.2体 +   精 +0.2力 + 2智 +0.4敏 + 0.5感

命中 = 闪避 = (100 + 3体 + 3精 + 3力 + 5智 + 20敏 + 4感) / 5
暴击 = (100 + 2体 + 2精 + 2力 + 4智 +  8敏 +20感) / 5
暴伤 = (100 + 2体 + 2精 + 8力 + 4智 +  2敏 +20感) / 5
暴抗 = (100 +20体 + 4精 + 2力 + 2智 +  2敏 + 8感) / 5
暴免 = (100 + 4体 +20精 + 2力 + 2智 +  2敏 + 8感) / 5

韧性 = 4体 + 3精 + 感
破韧 = floor(2.4感 + 0.8力 + 0.8智)
速度 = 100 + 8敏
```

### 7.1 六维平均复核

Lv.`n` 的六维平均白板为：

```text
A(n) = 100/6 + (10/6) × (n - 1)
     = 15 + 5n/3
```

代入后，命中、闪避、暴击、暴伤、暴抗、暴免六项的系数和均为 `38`，故它们严格使用同一基准值：

```text
对抗属性基准 Q(n) = (100 + 38A(n)) / 5
                    = 134 + 38n/3
```

| ---: | ---: | ---: | ---: | ---: |
| 1 | 16.7 | 146.7 | 133.3 | 66.7 |
| 10 | 31.7 | 260.7 | 253.3 | 126.7 |
| 20 | 48.3 | 387.3 | 386.7 | 193.3 |
| 25 | 56.7 | 450.7 | 453.3 | 226.7 |

平均六维下，`韧性 = 8A`、`破韧 = 4A`，因此破韧在取整前严格为韧性的一半；实际面板仅会受整数取整和非平均六维分配影响。破韧为专属的控制/负面状态进攻属性，故不与前述六项直击对抗属性做同值要求。
