# 怪物卡片逐怪设计表 V1（强度修订 V2）

配套：[主设计](./怪物卡片与装备附魔设计V1.md)｜[最终掉率](./怪物卡片最终掉率计算V1.md)。状态：已实现并通过定向自动化测试；尚未实机或真实数据库验证。

本表从当前源码的显式 SQL 模板和地表配置提取，按 code 去重检查。每行卡名为“怪物名·卡片”，cardCode 为 `monster_card_` 加该行模板 code。不是随机效果池：一行就是一张卡的完整固定属性。卡片门槛为 floor(基准等级/5)×5，最低1级。

哥布林等级按 `seedEpicForgeContent` 最后生效的20–30级覆盖值；它在 bootstrap 中的调用晚于旧9–20级重设。刷新/编队的动态等级不生成新卡版本。表内各数值使用V2装备后面板分类预算计算；所有直接攻击值改按同级主武器实得10%/18%/22%/25%；机制卡使用明确固定值。所有数值已固定进入怪物卡片注册表；后续调平衡需同步设计表、生成数据与卡片版本。

本表常规/召唤物卡片 **167张**（含8张由来源BOSS投放的召唤物卡）；另见[执法者专项表](./执法者星骷机制卡与召唤物来源V1.md)的21张当前阵容版本和7个备用方向。首期计划可产出的固定卡片版本合计188张。转职试炼与首领部位不创建卡片。

“部位”只写一个名称的卡就是唯一部位卡；标记单槽不代表限制玩家全身只能用一张精英/BOSS卡。实际概率单位为百分点，暴击/暴伤单位为点。
