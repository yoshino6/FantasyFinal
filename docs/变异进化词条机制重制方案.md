# 变异进化词条机制重制方案

> 第三版实现迭代稿｜已接入现有进化、战斗与独立业务流程。完整替换第二版的“基础 3%＋条件 1%”写法，覆盖现有全部 180 条词条。

## 1. 这次的设计方向

**一条词条只给一个核心效果。** 可以直接加属性，可以在明确条件下给较高收益，也可以改变一次结算的方式。不要为了凑预算给每条都拆成两个小加成。

示例：

- 致密骨板：双防 +4%。
- 踏风趾骨：风天造成伤害 +10%。
- 逆搏：生命不高于 30% 时，受到伤害降低 12%。
- 潮汐心室：溢出治疗的 20% 转为自身 MP。
- 迟发疼痛：单次伤害超过最大生命 20% 的部分，降低 25%。
- 梦境触须：抵挡本场第一次可普通驱散的硬控。

输出效果不区分物理／魔法、近战／远程、火系／雷系等职业路线。表中统一写“造成伤害”“攻击”“命中”“暴击”；直接提高进攻属性时用“双攻”，同步提高物攻与魔攻。条件可以是天气、生命、魔力、目标状态、护盾、队伍和资源行为，但不要求某一职业专属技能。

附带负面仍可通过稳定处理完整消除，正面不缩水。没有变异专属回合时限、倒计时、每隔若干回合或指定行动序号；普通效果满足条件就生效，仅少量强机制限制次数。

## 2. 数值定位与简明口径

### 2.1 重新理解 3%–5%

| 效果类型 | 建议起点 | 评估方式 |
| --- | --- | --- |
| 无条件属性／收益 | 通常 3%–5% | 看真实属性公式与实际收益，不把加 4% 命中直接当成增伤 4% |
| 常见条件 | 通常 6%–10% | 看血量、护盾、目标状态等条件的覆盖率 |
| 较苛刻条件 | 通常 10%–20% | 看触发难度、兑现机会及主动构筑能达到的覆盖率 |
| 资源转换／特殊机制 | 采用适合机制的独立参数 | 看转换基数、资源上限及行为改变，不强行写成 4% 属性 |

此前的 3%–5% 保留为**常驻强度与普通混合场景的参考预算**，不再是触发数值上限，也不要求条件不满足时仍获得 3% 保底。条件玩家主动维持得好，应当允许明显高于常驻收益。

例如风天增伤 10%，假设某测试脚本的有效输出中有 40% 发生在风天，折算约为 4%；这里的 40% 只是算例，不是已测天气频率。在风天专门战斗可以完整得到 10%，不能又以“超过 5%”将其压回常驻水平。与此同时，几乎无成本便能永久满足的条件要按接近常驻评估，不能假装它很稀有。

I 阶数值见表，全部为测试建议，尚未完成平衡模拟。II 阶原则：常驻 4% 可升至 5%，条件 10% 可升至 12%，已经强势的特殊能力只改善小额容量，不直接翻倍或增加使用次数。没有统一将所有字段乘 1.5 的规则。

### 2.2 共用说明集中写，词条不重复抄

- **伤害**：由该玩家自身普攻、技能和其原生持续伤害造成的合法伤害，统一适配职业。副产物如变异反伤、残像和回响不再触发其他变异产出。固定机制伤害、系统处决、不能被增减的特殊伤害遵守原规则。
- **双攻／双防**：物攻与魔攻／物防与魔防同时按同一比例增加；单次攻击仍只使用自身原有攻击属性，不把两项相加。
- **命中、闪避、暴击、韧性等属性百分比**：按现有对应属性相对提升，最终概率仍由原公式计算，不直接增加同等百分点。“暴击伤害”作用于暴击额外部分。
- **转换**：按原有效伤害、原治疗、原溢出、原实际消耗计算，不用包含变异追加收益的新数值再计算。原伤害／治疗保持，除非文字明确写“分摊”。
- **护盾**：复用现有生命盾。变异产生的盾不设置自身持续回合，消耗后减少、战斗结束清空；每条来源存量上限为接收者最大 HP 的 8%。原技能盾的既有期限不因此被移除或刷新。
- **HP／MP 回复**：不超过实际缺失，不触发复苏，不对死亡单位补发；回血仍受原禁疗与减疗影响。伤害转 MP 每次主行动最多回复 3% 最大 MP，不能凭首领血量无限回满。
- **“本场曾经”**：只记录真实成功事件，不按回合衰减。对目标的观察记录保留到战斗结束，不要求连续操作或下一击立刻兑现。
- **“当前防御／正在吟唱”**：读取现有战斗状态，不额外创建变异时限。普通状态增益不延长技能原本的持续期。
- **材料百分比**：用持久化小数份额累计，满整件兑现，不掷低概率骰子。只增加合格普通产物，不复制装备、催化剂、唯一任务物品、管理员发放和再次兑换所得。
- **负面**：只在未稳定时存在，可清除；天气／血量等正面触发条件、禁止递归和原物品消耗不属于附带负面，稳定不会把“风天 +10%”变成全天 +10%。

### 2.3 次数限制只保留 8 条

时隙突触、梦境触须、镜湖皮、冬眠胸腔、回声心、云阶足骨为每战一次；潮汐囊每战储存／兑现一份跨场准备；逆熵腺为每角色一次返还。其余 172 条不增加战斗次数限制。根须胃的“每场 1 个、每业务日 2 个”属于稳定介质产出上限，不属于回合或战斗次数机制。容量上限、叠层上限、同源不重复结算属于机制边界，不按回合重置。

新增次数集中在免控、净化、冷却、逃离重试、复苏联动和跨场储存，不能蔓延成每个词条都写“每战两次”。

## 5. 特殊机制的明确边界

玩家只需看到表中的一句效果，以下细节属于实施与测试规则，不要把它们全部塞回词条正文。

| 机制 | 必须固定的结算口径 |
| --- | --- |
| 属性加成 | 双攻、双防都是各自增加，不互相相加；不重写六维换算。百分比按现有同类属性区间合并，避免重复加乘 |
| 统一伤害 | 同一条件同时支持原生物理、魔法、元素和持续伤害；群攻按各实际目标判定，禁止物理专用／法系专用版本 |
| 余像症 | 只对已经通过资源检查且实际尝试命中的原主攻击生效，未命中部分按非暴击、防御及抗性正常折算后的预计伤害计 15%；不吃命中后才成立的触发增益，不再次命中判定或暴击，不执行控制 |
| 断片视界 | 取该次原有效伤害的 4% 作为独立附伤，不再重复吃原暴击和攻防倍率，不递归吸血／反伤／回响；不是绕过原攻击免疫的第二次主攻击 |
| 世界树瞳 | 开战默认第一个合法主目标为标记；正常改选主目标时同步更新，无新技能栏；全队同名只取最高效果，切换即撤旧标记；首领机制免疫与防御最低值照常 |
| 主目标与观察 | 自动战斗沿现有选敌生成主目标，群攻不会同时标记所有目标；代码不得通过多次点选但不行动来刷“命中／受击观察” |
| 碎镜复眼 | 单次原主行动最多形成一个合并溢出池，按 25% 分配给剩余敌人中生命比例最低者；接收端伤害最多其最大 HP 的 10%，尊重阶段保护与原免疫，不继续产生溢出转移 |
| 迟发疼痛 | 按同一敌方原主行动对自己的伤害聚合判断阈值，防止拆段规避。原伤害为 D、最大 HP 为 H，结果为 min(D,0.2H)+max(0,D-0.2H)×0.75；不产生延后欠款 |
| 镜湖皮 | 不反射硬控、机制标记、不可普通驱散状态或持续伤害；被反射状态使用原数值和原持续规则，来源仍做一次正常抵抗判定，不互相反射 |
| 梦境触须 | 仅阻止一份真正会命中的普通硬控，未命中／已抵抗不消耗次数；同次攻击的伤害、其他效果照常，不能挡首领机制 |

| 共感痛 | 仅在有其他存活玩家队友时提供 5% 单体减伤；队伍只剩自己时按负面受到 3% 额外伤害，多个拥有者同名效果不重复叠加 |
| 云阶足骨 | 仅在本场首次受到敌方直接伤害后建立一次速度增益；反伤、持续伤害、队友伤害和战斗外伤害不触发，速度增益持续到本场结束 |
| 潮汐囊 | 记录真实战斗内原溢出，每次结算只产生一个带来源会话 ID 的准备，下一战开战时消费；不会因为多次治疗重复兑现，卸下来源词条不能继续领取 |
| 代谢阀门 | 只处理纯 HP／MP 恢复品的实际溢出；按原始 HP 与 MP 份额分别计算，将溢出总量的 20% 转为另一项资源，不返还物品，也不参与复苏、增益和解毒道具 |
| 逆熵腺 | 仅返本次实际已扣的费用，记录在角色而非词条上；封存、净化、重复获得和升阶不重置，不退款历史处理，也不奖励本来免费的操作 |

元素抵抗类是“适应某种来袭环境”，不会限制玩家自身的输出类型。吟唱、治疗、伙伴、采矿属于玩法条件，角色可选择适合自身已有能力的词条；不要求每一条对每种操作都生效。

治疗与盾转换全部读取原始基数；新增回复、附伤、反伤、盾回收不再触发转换。有效治疗与溢出分别记账，多个转换合计不能消费超过一份原始溢出。盾容量可限制积存，但不能再额外规定“每两回合一次”。

## 6. 负面消除、槽位和阶数

### 6.1 稳定只清负面

沿用建议费用 **2 个稳定介质**，清除该记录全部附带负面，保留正面原数值和触发条件。不削弱收益，不恢复“温和型”，不把消除负面做成临时状态。

- 逆搏稳定后仍是低血减伤 12%，只是没有受疗 -4%。
- 骨髓躁动稳定后仍是双攻 +5%，施法不再额外扣 HP。
- 共感痛稳定后仍保留有其他存活玩家队友时的 5% 单体减伤；清除负面后不再受“队伍只剩自己时受到伤害 +3%”影响。
- 畏光稳定后仍只在夜间增伤 10%，白昼不再降命中。
- 没有负面的词条提示“无需稳定”，不得扣材料。

未清除负面时，额外 HP 消耗不致死；无法支付时本次整条不触发并给出原因，不能在未稳定状态只拿正面。完成稳定后完全移除对应额外支付校验。普通技能原耗魔、恢复品原道具、稳定处理原材料等基本费用照常。

### 6.2 槽位与已拥有档案

继续每部位一个稳定／稀有槽、一个偏差槽。偏差稳定后沿用现有进入稳定槽的行为，槽位冲突时先展示替换预览，再原子封存旧项并启用新项；不会删掉任一记录。稀有词条清负面后仍是稀有，使用独立 `negativeCleared` 标记。

增加免费档案启用／替换，只能选已拥有记录。暂停偏差仍占本部位偏差归属，恢复必须重查槽位，不能双开。战斗及交涉中禁止注射、稳定、暂停、封存、替换和改设置，所有直接命令与旧按钮由服务层统一拒绝。

最大 HP／MP 变化按现有比例调整并向下取整，不把稳定和换装当免费补满。特例次数绑定角色与会话，重连、复苏、阶段切换均不刷新。普通材料小数份额跨天保留，不因封存复制或重置。

### 6.3 II 阶只强化原来的一个效果

| I 阶形态 | II 阶建议 |
| --- | --- |
| 属性 +4%／普通收益 +4% | 同项变为 +5% |
| 属性 +5% 且已达到常驻预算 | 默认保持 5%，完成公式测算后再决定是否可提高，不能自动变 7.5% |
| 条件增伤／减伤 8%／10%／12% | 分别建议 10%／12%／15%，仍需满足原条件 |
| 转换比例 4%／5%／20% | 分别建议 5%／6%／25%，保持原来源及容量边界 |
| 已有较高属性或特殊比例 | 逐条显式配置，未审核先保留 I 阶，不套通用乘数 |
| 完全抵挡、净化、反射状态、冷却 -1、逃离重试 | 不增加次数、不扩大作用权限；可保留行为相同的 II 阶观测记录 |
| 逆熵腺一次性返还 | II 阶不重置、不追加第二次返还 |

不增加第二个小效果补偿难升阶的词条。先保证每条的主机制清楚且合理，再决定是否值得强化数值。

调和针剂保留固定收益和概率，封存偏差改为玩家预览选择，可选不处理。定型保留最多三项选择及原 ID，不额外复制一份同名效果。本轮不扩展 30 级后反复抽取机制。

## 7. 玩法组合示例

没有额外套装奖励，每项只按自己的条件生效；条件不满足就没有该项收益，不强塞通用保底。

| 组合 | 实际玩法 |
| --- | --- |
| 踏风趾骨＋风纹角膜 | 风天同时获得较高伤害与命中，天气是选择出行时机的理由 |
| 命线之眼＋断续痛＋逆搏 | 把低血生存与斩杀阶段结合，触发时明显强势；净化后不必忍受减疗 |
| 余像症＋追迹瞳＋稳握腕骨 | 命中不稳定时有残像保留部分伤害，并通过目标观察与命中属性改善后续攻击；不是未命中就免费再打一整次 |
| 叶脉皮＋岩王脊＋潮汐心室 | 溢出治疗可在盾与魔力之间分配，高盾存量支持双防提升；同一份溢出不能重复转换 |
| 碎镜复眼＋古兽髓＋脉冲心室 | 多敌战中取得优势，击杀时转移过量伤害并回复缺失生命，单体首领战不保证同样效率 |
| 视觉过饱和＋余震回路＋世界树瞳 | 由队伍制造减益和控制，所有输出职业都能利用目标窗口，无需指定元素或伤害类型 |
| 星砂肤＋星尘肝＋矿脉视 | 夜间日常资源路线，分别作用于采矿产物、观察委托奖励和现有观察视野，不共用累计账本 |

## 8. 结算与验证重点

### 8.1 高条件收益不能用假覆盖率解释

分别测白昼／夜间、不同天气、低血／满血、有盾／无盾、单体／群体、不同职业和手动／自动战斗。

对每条记录：实际条件覆盖率、满足条件时增幅、整个场景的有效增幅、玩家可主动维持条件的成本。生命线、护盾线、敌我数量都必须按真实快照判定，不能用“有条件”三个字就默认允许无限高数值。

特别检查“本场曾受伤／曾命中”“敌人最大 HP 更高”“装一件恢复品”等容易常驻的条件，其数值不能按低频事件处理。本稿对此分别给 5%–10% 左右而非 20% 爆发，但仍需实际验证。

纯属性、条件输出、生存与资源转换分别用对应公式评估；伤害转盾／转治疗按实际有效量计，不把全部溢出也算生存收益。稀有强机制单独披露收益，不拿一次免控硬凑成已验证的 4%。

### 8.2 普通材料与兑换

跨代码收益使用明确固定价值表，不能假设一份矿材等于一个介质；没有通过经济验证的兑换项不投放。每项仅对原始正常产出提取额外价值，不再给一份基础 +3% 后又加兑换奖励。

固定份额持久化累计，拆分一次采矿、换日、重启均不改变总收益。交易转移、商店回购、管理员发放、退货、兑换产物不再次产生额外份额。材料费用减免只对真实已支付费用计提，不能用折让本身再生成折让。

道具部分返还、跨角色赠与、稳定清负面和奖励份额必须与原行为同事务，扣款／奖励有幂等键。跨角色按固定顺序锁定，失败回滚。

### 8.3 无回合限制不等于可以无限重复结算

- 普通正面按每次合法原事件计算，无回合计数器；群攻、多段按原总基数聚合，拆段不多赚。
- 变异附伤不再触发变异，治疗与盾回响不互相套娃。
- 8 个次数特例有独立会话或角色标记，其余词条不偷加隐藏次数。
- 原生持续伤害可以获得通用伤害加成，但同一收益只能在应用／跳伤其中一处计算一次。
- 天气战斗内使用统一快照，场外资源使用行为提交时的世界环境；不读取客户端时间。
- 群体保护、标记降防同源取最高值，不把人数变成倍率。
- PvP 使用同一效果目录，特殊控制、逃离与首领保护均尊重原规则；必要的 PvP 调整要明确列值，不能悄悄失效。

## 10. 迁移、验收与交付边界

迁移先 dry-run、导出清单并备份，保留原记录 ID、代码、来源、阶数、获得时间、暂停／封存状态和定型引用。旧已稳定偏差必须识别为负面已清除；旧原本无负面的稳定／稀有记录，不因新设计加了负面而突然扣玩家资源。无法判断的封存记录单列核对，未知代码保留快照。

新旧效果按版本互斥读取，不能叠加旧 `effect_json`。活动战斗使用旧快照至结束，或等会话结束后统一切换；不半场换规则。资源上限变化保持当前比例，不通过迁移或稳定补满。重复执行不重复收费／返还，回滚不得覆盖上线后的合法新增记录。

验收要求：

- 180 条旧名称／代码完整对应，每条一个核心正面效果，不残留“基础 +3% 再 +1%”模板。
- 直接属性、条件收益和特殊机制均有真实实现，不只修改文案。
- 输出加成职业通用，不出现物理专用、魔法专用、远程专用或指定元素攻击专用。
- 每项附带负面均可清除，清除前后正面数值和适用条件一致。
- 普通效果没有变异回合限制，只有 8 项明示的次数例外。
- 高条件数值按真实覆盖率和主动维持成本复核，常驻效果保留 3%–5% 参考预算，不声称所有场景都被强行限制在 5%。
- 多段、群攻、持续伤害、反射、回复转换、复苏、重连、逃离、首领阶段和资源重放不产生重复收益。
- 档案启用与稳定槽位变更有服务层锁、条件写与失败回滚。
- 实施后执行 `npx tsc --noEmit` 及对应机制、迁移测试；既有错误列明基线，管理员模拟与真实玩家验证分别记录。
