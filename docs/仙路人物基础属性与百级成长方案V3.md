# 仙路人物基础属性与百级成长方案 V3

日期：2026-09-09。状态：**数值设计与标准模型校准，待确认，未实装。**

配套：[仙路前期玩法总案](./仙路前期玩法与现有系统衔接方案V2.md)、[五艺专属支线](./仙路五艺专属支线任务设计V1.md)。本稿已按用户最新要求收敛：**只平衡每个境界六维属性提供的收益与正常战斗天赋收益。**

## 1. 当前范围

- 圆满奖励是独立记录的固定六维点数，不是直接增伤百分比。
- 一转、二转对应的能力由功法、战技、神通弥补。本轮不设计职业属性补偿，撤回此前每维每份+0.40的筑道成长建议。
- 撤回旧道果伤害/治疗1.80～3.00、灵力支付0.65～0.45、补给与造诣4～6倍、材料支付0.35～0.25的整组奖励。
- 每境圆满对齐同档常规战斗天赋的收益，后续境界提高固定点数以匹配世界成长，不逐境再叠一个增伤50%。
- 剧情、炼丹、五艺和独立晋境方向保留；本轮不额外扩写职业能力、生产加成或PVP新规则。

## 2. 人物属性怎么算

```text
仙路自身六维 = 出生固定六维
             + 出生固定成长 × 仙路累计成长份数
             + 已证道果固定六维
```

再按现有规则接入装备、状态与派生面板。固定道果不写回出生值或成长系数，不随下一次升级重复放大。

当前源码的普通成长按每十级增加一份固定成长：10/20/30/100级累计9/29/59/549份。仙路用独立境界事件推进，末端预算与同阶段世界对齐；不能既领普通升级属性，再领同一份仙路属性。

沿用前期节点建议：炼气一层0份，二至十三层每次+0.75份，十三层9份；筑基前/中/后/圆满11/17/23/29份；结丹32/41/50/59份。进入圆满阶段不等于已完成圆满考验，固定道果在考验通过后取得。修为条与技能成长另走各自规则。

出生随机禀赋保留，普通职业已写入的成长不作为仙路出生值。多艺兼修、换功法、重登和补发不重复取得同一道果。

## 3. 与正常战斗天赋怎么比较

### 3.1 对照条件

取A01类“合格主动直击伤害×1.50”作为这一轮的常规战斗基准。固定人物基础、装备、敌人和攻击动作，只比较两种变化：一侧增加该天赋直击效果，另一侧增加仙路道果六维。**功法与一转二转差异不进入本轮属性预算。**

不是要求六维把最终输出也提高50%。六维同时增加生命、攻防、命中、闪避和暴击对抗，如果先把输出拉到1.50，再附送全部生存收益，仍会过高。

本轮采用稳定互攻下的预算指标：

```text
输出比 = 加道果后的单次行动期望直击 / 无道果时的同项值
承伤比 = (新HP / 原HP) × (原每次受击期望 / 新每次受击期望)
互攻预算指标 = 输出比 × 承伤比
```

在不回血、双方按固定频率持续互攻的简化模型中，这个指标反映被击败前可造成的相对伤害预算。常规直击×1.50、其余不变时该指标是1.50。**它不是胜率、全场景战斗力，也不是直接增伤倍率。**

### 3.2 使用的当前公式与边界

- `growth-rules.ts`：标准出生六维总和100、出生总成长10，六维均分，读取现行分段成长预算。
- `constants.ts`：六维各加1，双攻双防各加4.3，HP/MP各加34.4，命闪及暴击对抗评分各加8.6；评分不等于概率百分点。
- `combat-math.ts`：普通直击取`攻击²/(攻击+防御)`；命中、暴击、暴伤对抗按双方评分比例计算期望。本次忽略向下取整、最低1伤害和随机波动。
- 装备基准：普通名义单攻武器为原躯体攻击的0.5倍，五件护甲对应防御合计为原躯体防御的1倍；两侧使用相同装备，装备不随道果点数重新生成。
- 对手采用同阶段对称标准面板，所有行动均为可受基准天赋影响的普通主动直击；不使用孤注爆发作基准。
- 不加入职业、二转、技能循环、控制、回复、元素、套装修正、百分比装备或随从；速度只影响先后而未转化为额外行动收益。按最大MP支付也不视为额外续航。

基础公式为本轮实际读取源码，计算结果保存在`.data/xiandao-early-design-20260909/attribute-balance-reference.json`。这是标准期望模型，不是运营数据库实战。

### 4.1 前期效果写法

- **炼气圆满·周天自成：**体质、精神、力量、智力、敏捷、感知各增加4点。
- **筑基圆满·道基无隙：**六项属性各再增加4点；已证道果累计各增加8点。
- **结丹圆满·金丹无漏：**六项属性各再增加5点；已证道果累计各增加13点。

进入下一境保留旧道果，表中的累计值不能再完整加一次。结丹完成事件只加本次5点，不能在旧8点上再加13点。

### 4.2 增加的真实面板与收益

下表是累计道果的独立贡献，未计装备百分比、临时状态与取整。

| 圆满阶段 | HP、MP各增加 | 双攻、双防各增加 | 标准期望输出比 | 标准承伤比 |
| --- | ---: | ---: | ---: | ---: |
| 炼气 | 137.6 | 17.2 | 1.217 | 1.246 |
| 筑基 | 275.2 | 34.4 | 1.218 | 1.251 |
| 结丹 | 447.2 | 55.9 | 1.202 | 1.234 |

结丹并非增伤48.3%；在这个模型里是期望输出约增加20.2%，承伤预算约增加23.4%，共同接近常规战斗天赋的互攻收益档位。上述承伤预算包括HP、防御、闪避与暴击抵抗的综合影响，不能再额外乘一次这些分项。

## 5. 30～100为什么不会失控

基础成长继续提高，固定道果点数按同样的收益目标扩大。其收益在相应境界保持接近常规战斗天赋的一档，而不是十次圆满乘出十份增伤。

以标准角色为例：

进阶初期仍保留上一境固定点数，因此相对当前基础的优势会暂时减小；本境圆满再补到对应档位，形成“积累成长—证成道果”的节奏。不让上一境道果随新等级自动重估出新点数。

## 6. 本轮结论的适用范围

在标准装备与对称普通直击场景中，十档指标约1.483～1.524，接近基准1.50。附加检查把装备固定值预算取0.6/1/2.5档、对手面板取0.75/1/1.5档：前三境指标范围分别约1.438～1.551、1.445～1.558、1.412～1.515。这些档位是敏感性条件，不宣称是实际怪物或已核对的品质装备。

六维均分仅是第一轮基准。偏科禀赋、百分比装备、先手击杀、必中、高控制或治疗场景可能改变收益，不能据此宣布所有构筑验收通过。这里完成的是道果固定点数的设计校准，不是完整玩家路径或PVP验收。

接下来若要实装，只需围绕这张属性表补实际配装和战斗入口验证；职业能力另由功法、战技、神通设计解决，生产技能也不再塞进道果收益预算。固定点数一经确认，再实现唯一圆满事件、来源重算和重复领取防护。

## 7. 配套文档的同步边界

旧六项全局奖励全部停止作为实现依据。恢复丹、修为丹、仙符按配方基础数量产出，材料实际支付，五艺造诣不受道果倍增；取消原倍数后的升品耗时需要另行重测，不能沿用旧速度结论。

PVP只保留前稿的待确认适配事项，本轮不决定竞技是否计入固定道果，也不更改永久成长。若后续采用不同模式快照，应验证来源重算与HP/MP还原，不直接删改永久属性或靠进出模式治疗。

本轮仅修改设计文档、记录标准模型计算结果；未改游戏代码、普通天赋或玩家状态，未运行数据库迁移、实战或客户端验收。
