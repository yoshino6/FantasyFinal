# 幽暗密林深处·哥布林国王与横冲直撞哈巴龙

> 状态：待实施设计稿
>
> 范围：本文件只定义数值、技能与战斗机制；不包含本轮源码、数据库或掉落实现。

## 1. 定位与出场

- 区域：`dark_forest_deep`（幽暗密林深处）。
- 遭遇：固定为一场双体 Boss 遭遇，不混入普通 2–4 人哥布林编队池。
- 核心敌人：Lv.30 哥布林国王、Lv.30 横冲直撞哈巴龙。
- 开场护卫：2 只 Lv.28 王庭精锐，各自固定携带 3 个技能。
- 推荐队伍：4 名 Lv.25 以上、拥有稳定范围伤害、净化与控制应对能力的玩家。
- Boss 分类：两名核心个体均使用 `boss` 属性生成档；王庭精锐使用 `elite` 档。

本 Boss 的难点不是单纯数值，而是“合体压场 → 分离双线 → 击杀后狂暴”的目标优先级转换。首阶段必须在范围伤害、护卫清理与蓄力技防守之间取舍；二阶段则必须避免过早击杀其中一体、让另一体带着完整状态进入狂暴。

### 2.1 合体阶段的双目标与双生命池

合体不等于合并成单一目标。阶段一战场上同时显示两个可选目标：`哥布林国王·驾驭中` 与 `横冲直撞哈巴龙·载王中`；两者没有第三生命池，也不分担受到的伤害。

- 玩家可自由选择国王或哈巴龙作为单体技能目标；伤害、持续伤害、控制与减益均只写入被选中的那个个体。
- 范围伤害分别命中两个核心目标，并各自计算伤害、命中和减伤；不能把一次范围伤害合并为单次结算。
- 合体期间每次 Boss 行动均按哈巴龙速度进行：**哈巴龙先施放一个本体技能，国王紧接着对该技能下达对应号令，使其获得额外效果。**这是一整次联合行动；国王与哈巴龙均不另行获得独立行动，也不会在同一回合各放一个独立技能。
- 任一个体当前生命降至最大生命的 50% 以下，即刻中断合体，触发阶段转换。合体阶段的致死伤害将该个体保留为 `1` 点生命后再分离，避免跳过分体与狂暴机制。
- 阶段二开始时，两者以合体阶段各自剩余的**当前生命值**登场，不回满血、不补盾、不清除玩家已施加的持续伤害。

这样既保留“二者有一个半血即分开”的条件，也让首阶段存在明确的集火与目标选择。

## 4. 阶段一：王驾合体

阶段一从开战持续至国王或哈巴龙任一方当前生命低于最大生命的 50%。每次行动以哈巴龙速度结算：哈巴龙负责释放主力技能和基础伤害，国王立即附加与之绑定的王令强化；国王与哈巴龙都不额外取得单独行动。

### 4.1 哈巴龙主力技与国王号令

前三项为哈巴龙瞬发主力技；第四项是哈巴龙唯一的蓄力范围技。每次施放时，国王自动接续表内对应的号令强化，不消耗额外回合，也不单独进入技能循环。基础伤害均以哈巴龙的物攻结算；国王号令的雷击部分以国王魔攻结算。

| 优先级 | 哈巴龙主力技能 | 类别 / 冷却 / 蓝耗 | 哈巴龙基础效果 | 国王同步号令：额外效果 |
|---:|---|---|---|---|
| 1 | `habadragon_royal_charge`·横冲冲阵 | 物理 132% / 2 / 72 | 冲撞当前最高仇恨目标。 | `破阵王令`：追加 42% 雷属性魔法伤害，并施加 `imbalance 16%，2 回合`；目标已有 `slow` 或 `bind` 时，追加伤害提高至 65%。 |
| 2 | `habadragon_royal_stomp`·裂地重踏 | 物理范围 102% / 3 / 88 | 对全体玩家造成打击伤害，并附加 `slow 14%，2 回合`。 | `滞敌王令`：所有被减速目标额外受到 32% 雷属性魔法伤害；命中至少 2 人时，为哈巴龙获得 `践踏加势`，使下次蓄力技伤害 +15%。 |
| 3 | `habadragon_royal_tail_sweep`·横尾扫阵 | 物理范围 90% / 3 / 82 | 对全体造成较低伤害，并对当前最高仇恨目标追加一次 65% 物理追击。 | `猎首王令`：若追击目标已有失衡，追击必定命中且附加 `裂甲 12%，2 回合`；否则施加 `王令标记`，使其下一次受到的单体伤害 +12%。 |
| 4 | `habadragon_royal_cataclysm_trample`·末日践踏 | 物理范围 142% / 5 / 130 | 先蓄力 1 回合，再于下一次行动对全体造成践踏伤害。 | `雷震王令`：末日践踏命中后追加 58% 雷属性魔法范围伤害，并独立判定 `bind 18%，1 回合` 与 `imbalance 18%，2 回合`。 |

### 4.2 蓄力规则与战报

当 `末日践踏` 可用且本阶段已至少施放两次哈巴龙瞬发主力技时，二者优先进入蓄力：

```text
【哥布林国王】高举王旗，哈巴龙的四蹄踏得地层嗡鸣。
#末日践踏#下一次行动将对全体发动雷震践踏！
```

- 蓄力回合不直接造成伤害，哈巴龙获得 25% 减伤；国王同时维持雷震王令的蓄能，防止被过于轻易跳过机制。
- 蓄力不可被眩晕直接取消；若被控制，技能延迟到其下一次可行动时释放。
- 蓄力期间若有任一核心个体低于 50% 生命，优先进行阶段转换，取消本次践踏，避免“分体后仍放合体大招”。

### 4.3 阶段一循环与变招

基础循环：

```text
横冲冲阵（破阵王令） → 裂地重踏（滞敌王令） → 横尾扫阵（猎首王令） → 蓄力·末日践踏 → 末日践踏（雷震王令）
```

变招规则：

- 两名以上玩家带有 `bind` 或 `slow` 时，优先 `横冲冲阵`，利用破阵王令的控制目标增伤。
- 3 名以上玩家生命低于 55% 时，跳过横尾扫阵，立即开始 `末日践踏` 蓄力。
- 当前仇恨目标生命低于 35% 时，优先 `横尾扫阵`，以猎首王令将追加追击压向该目标。
- 王庭盾卫存活且拦截效果可用时，先由盾卫施放拦截，再允许哈巴龙蓄力；国王的雷震王令仍作为该次践踏的附加效果，不构成额外行动。

## 5. 阶段转换：王座分裂

触发后立即展示一次性战报：

```text
【哥布林国王】从哈巴龙背上翻身跃下，王旗引落暴雷。
【横冲直撞哈巴龙】发出震耳欲聋的咆哮，撕开被践踏的地面。
#王座分裂#二者分离，分别行动！
```

- 解除两名核心目标的合体联动状态；“哥布林国王”与“横冲直撞哈巴龙”继续保留为原有的两个目标，并转为各自独立行动。
- 两者保留合体阶段的当前生命、魔力、冷却与可驱散状态；合体专属蓄力状态被删除。
- 分离当回合不额外插队攻击；从下一次正常行动顺序开始各自行动。
- 目标仇恨继承：国王继承原仇恨表的 60%，哈巴龙继承 100%，使哈巴龙更倾向继续压制前排，国王更容易转向脆弱后排。

哈巴龙主打高物理伤害与控制链，优先攻击仇恨最高目标；其控制旨在为国王的雷令与连雷创造窗口。

| `habadragon_crushing_stomp`·碎地重踏 | 物理范围 106% / 3 / 82 | 对全体造成打击伤害，附加 `slow 16%，2 回合`。三名以上玩家无减速时优先。 |

哈巴龙循环：`蛮龙冲阵 → 碎地重踏 → 铁尾囚笼 → 蛮龙冲阵`；生命低于 60% 时，将下一次可用的 `裂颚汲战` 插入循环首位。

## 7. 濒死狂暴：孤王 / 孤龙

当国王或哈巴龙任一方死亡时，另一方立即获得一次性、不可驱散的 `royal_beast_enrage`，持续 3 个自身行动回合：

```text
#孤王狂怒#或#孤龙狂怒#同伴倒下，存活者的怒火彻底失控！
命中 +200%｜暴击 +200%｜暴伤 +200%｜攻击吸血 40%，持续 3 回合。
```

- “命中 / 暴击 / 暴伤 +200%”均为相对该个体当前战斗数值的百分比强化，不能与同名狂暴重复叠加。
- 攻击吸血以造成的**实际生命伤害**为基数，回复 40%；减伤、免疫和过量伤害不会虚增回复。
- 狂暴持续期间，国王禁用 `王庭再征`，改为优先 `雷令 → 王庭连雷`；哈巴龙禁用普通循环，优先 `蛮龙冲阵 → 裂颚汲战`。
- 三回合结束后只移除狂暴，不恢复阵亡同伴，也不补充王庭精锐。

## 8. 特殊实现状态与边界

| 状态 / 标记 | 用途 |
|---|---|
| `kingbeast_fused` | 合体联动识别；两个核心目标保留各自承伤与状态，每次行动由哈巴龙施放主力技、国王自动附加对应号令。 |
| `kingbeast_charge` | 末日践踏蓄力标记；阶段转换时强制移除。 |
| `kingbeast_phase_two` | 防止重复分离；每场战斗只转阶段一次。 |
| `royal_elite_summons` | 记录国王补召次数，上限 2。 |
| `royal_beast_enrage` | 死亡触发的 3 回合不可驱散强化。 |
| `royal_intercept` | 盾卫对核心 Boss 的下一次单体减伤，消耗后删除。 |

边界规则：

- 阶段一持续伤害只结算给其施加目标；范围持续伤害则分别结算给两名核心个体。
- 国王与哈巴龙分离后，均可被独立选中、独立控制、独立击杀。
- 若一次范围伤害同时令两者低于半血，只触发一次“王座分裂”。
- 若分离后的同一段伤害同时击杀二者，不触发狂暴；直接进入胜利结算。
- 王庭精锐被召唤后不计入本体经验与核心战利品，但应按现有召唤怪规则不重复掉落。

## 9. 验收口径

1. 两名核心个体均为 Lv.30 Boss，最终生命均为各自基础派生生命的 `×3`。
2. 开战固定出现国王与哈巴龙两个可选核心目标，以及 2 名 Lv.28、各有 3 技能的王庭精锐；哈巴龙主导行动与承伤计算，国王只在同次行动附加号令，不共享生命或承伤。
3. 合体阶段只有 4 个哈巴龙主力技，其中只有 `末日践踏`需要蓄力 1 回合；每个主力技均由国王在同次行动自动附加一项对应号令，不新增独立行动。
4. 任一核心生命低于 50% 后，只出现一次明确的分离战报；二者转为可独立选取的目标。
5. 分离后国王固定拥有雷术、强化、补召在内的 4 技能；哈巴龙固定拥有 4 个近战控制技能。
6. 一方死亡时，另一方准确获得 3 个自身行动回合的狂暴：命中、暴击、暴伤各 +200%，攻击吸血 40%。
7. 自动战斗、鉴识详情、战斗日志与胜利结算均能识别合体、分离、补召和狂暴状态；不会重复阶段转换、无限补召或重复触发狂暴。
