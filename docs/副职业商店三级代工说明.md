# 副职业商店三级代工

四家店恢复副职业服务，继续保留购买、出售、闲聊、关于职业、离开及原有任务入口。

| 商店 | 恢复的服务 |
| --- | --- |
| 铁匠铺 | 打造、图纸打造、精炼、熔铸、制作维修包 |
| 糖水屋 | 提纯、炼金；包含选材、一键配方、确认及继续尝试 |
| 异工坊 | 分解、构造 |
| 百味书屋 | 明鉴、识踪、巧思 |

店主服务统一按副职业 **3 级**计算成功率及产出加成，消耗玩家背包材料和原有费用，不增加任何个人副职业熟练度，也不修改玩家的副职业等级或资格。个人入口继续使用玩家自身等级。

服务复用个人面板的处理函数和参数；店铺按键使用独立的“店铺”指令前缀。选材、翻页、搜索、确认和继续操作均保留来源；离开对应店铺后不能继续代工。炼金确认单区分个人与店铺来源，不能跨来源使用。

配方材料、图纸等原有要求继续生效。普通玩家不能查看或保存个人炼金配方、查看炼金手记；当前炼金师仍可使用这些个人记录。店铺不开放四级炼金的点灵与育成，也不代替玩家获得四级解构的自动解锁资格。

全知者的明鉴与巧思沿用现有能力说明，识踪沿用现有区域线索功能。咨询不会赋予玩家全知者战斗被动。

店铺来源与按钮测试、机巧消息回归、独立隔离 MySQL 实际扣料及熟练度验证通过。全项目 `npx tsc --noEmit` 最终仍被本次未修改的 `src/game/negotiation.service.ts` 三处类型错误阻断（第 5、109、142 行）。共享机巧数据库套件重跑也被并行修改的隐藏职业初始化中 `obtain_source` 列歧义阻断；独立店铺数据库测试不依赖该初始化。

无需新增数据库迁移；更新代码并重启游戏服务后生效。尚未重启服务或进行 QQ 客户端验收。
