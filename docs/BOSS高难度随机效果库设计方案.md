# BOSS 高难度随机效果库设计方案

> 状态：设计稿，尚未实装。
>
> 范围：只新增高难度 BOSS 的随机战斗效果与遇战面板展示；不调整现有 11 档难度的基础属性倍率、经验、掉率、掉落表、刷新时间、首杀成就与 BOSS 原有机制数值。
>
> 正式对象：当前 17 组区域／迷宫 BOSS 遭遇。任务 BOSS、二转试炼、切磋 NPC、首领测试和 `boss_component` 部位均不独立抽取。

## 1. 目标与原则

高难度不再只是数值倍率更高，而是在每次 BOSS 生成时附加一组可提前看见的战斗规则。玩家进入战斗前即可根据词条调整队伍、技能与装备。

1. 效果分为 **10 个普通效果** 与 **每组 BOSS 2 个专属效果**。
2. 所有效果均为整场恒定被动，不能被净化、驱散、偷取、复制或延长。
3. “不可驱散”只保护效果本体，不给予效果产物额外豁免。例如词条产生的治疗仍受治疗降低、禁疗与生命上限约束，词条施加的控制仍参与韧性对抗并可被正常解除。
4. 随机结果在 BOSS 刷新或迷宫遭遇生成时确定并持久化。逃跑、战败、掉线、重进战斗或换队挑战不会重抽；该 BOSS 被击败并在下次刷新后才重新抽取。
5. 同一场遭遇内不允许抽到重复效果。两个专属槽必定是该 BOSS 的两种不同专属效果。
6. 效果默认只归属于遭遇主 BOSS。召唤物、王庭随从、三首分体和格鲁恩／瓦尔克部位不另行抽取；专属效果明确写到这些单位时，才改变它们的行为。

## 2. 难度抽取规则

| 难度 | 普通效果 | 专属效果 | 合计 |
| --- | ---: | ---: | ---: |
| 普通、强大、英雄 | 0 | 0 | 0 |
| 深渊、地狱 | 随机 1 个 | 0 | 1 |
| 猩红、腐化、神圣 | 随机 1 个 | 随机 1 个 | 2 |
| 黄金、璀璨、梦幻 | 随机 1 个 | 2 个全部获得 | 3 |

所有候选暂按等权抽取。若后续实战数据显示个别组合过强，应通过“互斥组合表”处理，不暗改某个效果的抽中概率。

固定剧情档不参与随机。首领测试只有在管理员显式指定高难度时才按相同规则生成，且测试结果不影响正式地图 BOSS。

## 3. 普通效果库（10 个）

以下名称全部为四字。文中的“直击伤害”指技能或普通攻击直接造成并实际扣除生命的伤害，不含持续伤害、反射伤害、生命支付、部位传伤及其他机制扣血。

| 名称 | 效果 | 结算边界与对策 |
| --- | --- | --- |
| **血潮归元** | BOSS 造成的所有直击伤害，按实际扣除生命总量的 **20%** 回复自身生命。 | 多目标技能先汇总本次实际生命伤害再治疗一次；受治疗降低与禁疗影响，不从护盾吸收量、过量伤害、持续伤害或反伤中吸血。 |
| **荆甲反噬** | BOSS 受到近程直击伤害后，向伤害来源反射该次实际生命伤害的 **20%**。 | 只计算 BOSS 实际损失的生命，不计算护盾吸收与溢出；远程、持续伤害、召唤物机制伤害不触发；反射不能再次触发吸血、反射、追击或暴击。 |
| **万法同劫** | BOSS 所有以敌方为对象的技能均改为敌方全体，原单体直击与附带效果逐人独立结算。 | 自身强化、友军辅助、召唤和场地技能不改变对象；原本已经是全体的技能不重复增伤。命中、暴击与控制对每名玩家分别判定。 |
| **愈战愈勇** | BOSS 每完成 1 次实际行动，后续造成的伤害提高 **4%**，最多叠加 10 层。 | 跳过行动不叠层，额外行动会叠层；层数属于该不可驱散效果的内部计数，战斗结束清零。鼓励队伍避免无限拖延。 |
| **绝境猎杀** | 对当前生命低于 **35%** 的目标造成直击伤害时，最终伤害提高 **25%**。 | 以每段伤害命中前的生命比例判断；治疗、护盾与保护类技能均可正常反制。 |
| **魔泉不涸** | BOSS 每次实际行动开始时回复最大魔力的 **10%**。 | 不超过魔力上限，不触发治疗或吸血事件；沉默等限制技能使用的效果仍正常生效。无魔力消耗机制的 BOSS 抽到时也不会改成额外伤害。 |
| **重峦护体** | 每个战斗回合内，BOSS 首次受到的直击伤害降低 **35%**。 | 只保护第一段实际命中的直击伤害；持续伤害不会消耗次数，多段技的后续段与后续队友可正常输出。 |
| **定魂守魄** | 玩家对 BOSS 施加控制时，最终成功率乘以 **70%**。 | 控制成功后持续时间与解除方式不变；不影响破甲、中毒、禁疗等非控制减益。 |
| **残阳返照** | BOSS 首次降至 **30%** 生命以下时，回复最大生命的 **18%**，每场一次。 | 治疗受治疗降低与禁疗影响；触发伤害照常结算，若 BOSS 已死亡则不触发。 |
| **怒意回锋** | BOSS 每受到 1 次暴击直击，获得 1 层怒意，最多 3 层；下一次造成直击伤害时，每层使该次伤害提高 **8%**，随后清空。 | 同一多段技能可累计，但只在 BOSS 下一次成功造成直击伤害时消耗；未命中不消耗。 |

## 5. 多目标与特殊遭遇归属

| 遭遇 | 随机与生效规则 |
| --- | --- |
| 哥布林国王王庭 | 整场只抽 1 套，以哥布林国王为词条根。普通效果只处理国王／哈巴龙的核心行动，不让侍卫重复触发；专属效果可以按说明改变整个王庭。 |
| 三首雾沼蛇母 | 三首共享 1 套抽取结果。普通效果的“每次 BOSS 行动”按每只蛇首的实际行动计算；一次伤害或一次治疗只由实际行动的蛇首触发，不能三首重复结算同一事件。 |
| 格鲁恩、瓦尔克 | 词条归本体。部位不独立抽取，也不自动拥有普通吸血、反刺、护体等效果；只有两个对应专属效果可以改写部位规则。 |
| 幽影狼王、乌兹及其他召唤 | 召唤物不独立抽取普通／专属效果，也不因继承基础难度词条而复制新效果。召唤物造成的伤害不计入【血潮归元】，除非专属效果明确说明。 |

若一场战斗存在多个互不隶属的自然 BOSS，则每个自然 BOSS 各自携带自己的抽取结果；但同一次伤害只能按实际受击对象触发对应效果。

## 6. 效果组合优先级

1. 原技能先确定基础对象，再由【万法同劫】把“敌方单体／多体”提升为敌方全体。
2. 每名目标分别完成命中、暴击、控制与伤害结算。
3. 受到伤害侧依次处理护盾、减伤与实际生命扣除。
4. 以实际生命扣除量触发【荆甲反噬】、专属溅射、吸血与其他事后效果。
5. 机制伤害统一标记为“不可再触发”，不能引发吸血、反射、暴击、追击、部位传伤或另一轮机制伤害。
6. 同名治疗统一进入现有治疗结算，因此禁疗时为 0，治疗降低按现有规则计算，不允许专属代码直接写生命绕过。
7. 【万法同劫】与本来就强化目标数量的专属效果相遇时，只扩大一次。例：【蚀锁双生】变为全体束缚，但其盾反减冷却仍最多计算 2 人。

建议首版设置一组硬互斥：**【血潮归元】与所有“按造成伤害额外治疗”的专属增量相加后，总吸血比例封顶 35%**。这是结算上限，不改变面板列出的原始效果。

高难度 BOSS 的随机效果不依赖鉴识等级，进入遇战面板即可看见名称与完整效果摘要；鉴识仍只负责原有属性、抗性和详细技能信息。

## 8. 数据与实现落点建议

### 8.1 数据形态

继续复用 `monster_spawns.traits_json`，不新增数据库表。难度词条保持原对象，新增长期稳定的效果对象：

```ts
type BossRandomEffectTrait = {
  code: 'boss_random_effect';
  name: '';
  version: 1;
  common: string[];
  exclusive: string[];
};
```

示例：

```json
{
  "code": "boss_random_effect",
  "name": "",
  "version": 1,
  "common": ["blood_tide_recovery"],
  "exclusive": ["uzz_fourfold_horde", "uzz_dragon_return"]
}
```

`name` 留空，避免现有通用“词条名称拼接”把内部结构当成一个前缀显示；遇战与战斗页由专用展示函数读取效果定义。

### 8.2 生成时机

1. 先确定现有难度词条。
2. 按难度代码计算普通／专属槽位数。
3. 从配置库无放回抽取，并把代码数组写入 `traits_json`。
4. 多目标遭遇先创建根效果集合，再让子单位只保存根引用或在创建战斗会话时关联根单位，禁止对子单位再次调用随机函数。
5. 旧的存活 BOSS 可在首次读取时按既有难度补抽并持久化一次；不能每次打开遇战面板临时抽取。

建议新增集中配置 `src/game/boss-random-effects.config.ts`，只放定义、难度槽位与展示摘要；战斗触发集中在 `src/game/boss-random-effects.ts`，避免把 44 个效果继续散进 `adventure.service.ts` 的主循环。

### 8.3 版本与兼容

- `version: 1` 固定本轮规则。以后改数值时，新刷新的 BOSS 使用新版本，已生成的 BOSS 继续按其持久化版本解释，避免玩家查看后规则悄然变化。
- 旧实体补抽必须排除 `boss_test`、`advanced_profession_trial`、`main_quest_goblin_king`、`main_quest_evolution`、`npc_sparring`、`boss_component` 与 `summoned`。
- 基础难度代码仍是成就、经验和掉落判断的唯一依据；随机效果代码不得参与首杀难度识别或重复计算奖励。

## 9. 验收清单

### 9.1 抽取与持久化

- 11 档难度逐档验证槽位数量，尤其区分代码中“深渊／地狱”的历史英文命名。
- 同一 BOSS 重复查看、逃跑和战败重进时结果不变；击败后下次刷新可以变化。
- 黄金、璀璨、梦幻恰好获得 1 普通 + 2 个不同专属；同一效果不重复。
- 王庭、三首、部位和召唤物整场只存在一套根效果，不发生重复抽取或重复触发。

### 9.2 战斗边界

- 吸血、返照、酸露滋生、影咒、王兽血盟等所有治疗均实测受禁疗／治疗降低影响。
- 反射与机制溅射不递归，不触发吸血、暴击、追击、成就伤害重复记账或部位二次传伤。
- 【万法同劫】覆盖普攻以外的所有敌方目标技能入口，包括 BOSS 专用状态机；自身强化、召唤与友军技能不误伤玩家。
- 控制增强仍经过韧性对抗；不可驱散的是随机效果本体，不是它施加的普通状态。
- 自动战斗、机巧、召唤灵、炼金投掷和多段／群攻路径均验证一次，确保受击与反射只结算预期次数。

### 9.3 UI 与回归

- 有鉴识与无鉴识玩家均能在遇战面板看见完整随机效果。
- 战斗开始、手动回合、自动战斗回合和重新查看状态都显示一致的紧凑名称。
- `/BOSS词条` 的原有 11 档属性与奖励文案不变，只新增随机效果说明入口。
- 运行针对随机、持久化、17 组专属触发和递归保护的测试后，再执行 `npx tsc --noEmit`；若全库检查被既有问题阻断，需将基线错误与本功能错误分开报告。
