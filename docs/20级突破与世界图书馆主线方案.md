# 20级突破与世界图书馆主线方案

## 目标与边界

在玩家达到 `Lv.20`、经验达到 20 级升级阈值且当前境界为【窥尘】时，开启第二道等级瓶颈主线。主线以“寻找突破奥秘”为核心，玩家从冒险者公会取得一条不完整的旧借阅线索，前往世界树上的【世界图书馆】，依次调查大厅、阅览室、资料室、休息室与无尽回廊，最终寻访大学者【噶】并接受试炼。

本方案遵守以下原则：

- 用户提供的核心文案原样保留，不改写关键台词与突破描写。
- 公会不能直接得知【噶】的所在地；找到她需要连续调查至少五处线索。
- 图书馆作为世界树地图上的建筑，内部房间使用蓝色按钮或 Markdown 蓝色链接切换。
- 【噶】为仅限任务拥有者看见的 22 级人形 Boss；战斗不是随机施法，而是有明确循环、条件变招和阶段机制。
- 哥布林国王主线专属遭遇同步下调为：国王 Lv.18、红龙 Lv.18、两名护卫 Lv.16；后续召唤护卫也固定 Lv.16。

## 完整剧情流程

### 1. 公会：不是答案，而是一张残页

任务按钮：`[关于 突破的奥秘]`（蓝色）。

> 莫妮卡翻遍了公会的晋升条例、委托档案和旧百科，仍没能找到二十级后突破的先例。她神色有些为难地合上档案：“这种情况……我还从没见过。公会的晋升记录里，也没有谁会在二十级后被这样拦住。你似乎是个特例。”
>
> 莫妮卡沉吟片刻，像是忽然想起什么，转身从旧档的夹层里抽出一页发黄借阅条交给你：“公会这里查不出更多东西了。不过我曾见过这张纸——上面写着‘灵阶的自我演化’，馆藏章来自世界图书馆；借阅者的名字被水渍抹去了，只余一个像‘噶’的模糊偏旁。”
>
> 她轻轻摇头：“我无法替你指出那个人在哪。但若真有人研究过你遇到的状况，答案恐怕只会藏在世界树上。”

结尾按钮：`[前往 世界图书馆]`（蓝色，指向世界树坐标）。

### 2. 大厅：目录只给出方向

任务按钮：`[查阅 总目录]`。

> 接待树灵看了借阅条很久，最终也没能认出借阅者，只将厚重目录推到你面前。“这类记录很少，大多只是无从解释的个例，未必能回答你的问题。”
>
> 你用很久才在“生物奥秘”与“灵阶异常现象”的交叉索引里找见一张破损索引卡。卡片没有名字，只有一行铅笔字：
>
> “进化不是赐福；无法承受感知者，终会先被世界吞没。”
>
> 批注下方印着阅览室的旧索引号。

结尾按钮：`[前往 阅览室]`（蓝色）。

### 3. 阅览室：从页边批注找到推荐信

任务按钮：`[检索 生物奥秘]`。

> 旧索引并未给出研究者姓名。书架上的大多数条目，都只是对少数失控者留下的零碎描述，既没有共同规律，也没有可供复制的突破方法。你翻过一整排关于寿命、灵魂与异常感知的书，终于在一本夹页中找见同样的笔迹。
>
> 批注写道：真正的突破会扩大感知，代价则是灵魂必须承受万千信息的涌入；若来者的灵魂本就带着不属于此世的痕迹，变化或许会比常理更早降临。
>
> 页面角落压着一枚褪色火漆，旁边写着：
>
> “推荐信未寄出，封存于资料室第七列。”

结尾按钮：`[前往 资料室]`（蓝色）。

### 4. 资料室：推荐信没有直接写出门牌

任务按钮：`[翻阅 第七列档案]`。

> 第七列并不是第七排书架，而是一组按生命形态归档的无编号木盒。你根据批注中的术语反复比对，才在最底层找出一封未寄出的推荐信。
>
> 信中写道：“若你遇见了无法归入既有灵阶的变化，请去找【噶】。她不会接待慕名而来的人，但会记得真正读懂这封信的人。”
>
> 信封内侧还有一行短笺：她偶尔会在休息室喝苦茶，随后走进没有尽头的门。

结尾按钮：`[前往 休息室]`（蓝色）。

### 5. 休息室：确认无尽回廊的门

任务按钮：`[询问 守馆人]`。

> 守馆人看到推荐信后沉默良久，才为你续上一杯同样苦涩的茶。
>
> “她不在任何固定书库。无尽回廊里的每一扇门都可能通向一段知识，也可能什么都没有。她研究的，正是那些无法被现有记录解释的人。别靠运气；带着这封信，记住她写下的那句话——进化从不替人承担代价。”
>
> 他将推荐信重新封好交还。书页间吹来微凉的风，像有一扇门正在远处等待。

结尾按钮：`[前往 无尽回廊]`（蓝色）。

### 6. 无尽回廊与研究室

#### 踏入回廊

你推开通往无尽回廊的门，身后的图书馆仿佛被骤然拉远。这里没有窗，也看不见尽头；两侧的墙壁由深色木纹与古老书脊交错而成，一扇扇门嵌在其中，门牌上的文字会在你注视时悄然变化。

有些门后传来翻页声，有些门缝里漏出星光，还有些门前堆着无人认领的手稿与早已熄灭的魔石灯。你沿着回廊走了很久，脚步声被层层门扉吸走，连时间都像被安静地折进了书页里。

直到你取出那封封存引荐函。信封上的火漆依旧暗淡，回廊尽头却有一扇原本毫不起眼的木门轻轻震了一下。门上没有门牌，只有一道细长的裂纹，像一只正在睁开的眼睛。

你走近时，门后的锁扣自行转动。苦涩的茶香先一步从缝隙里漫出，仿佛里面的人早已知道你会到来。

#### 门后的研究室

你说明来意，将封存引荐函放在桌上。门内没有立刻传来回应，只有纸张翻动的轻响。片刻后，一只苍白的手从门缝后伸出，取走了信。

那只手的主人端详了火漆许久，才低声说道：“原来如此。”

木门随之敞开。屋内比你想象得更朴素：古老木桌、堆满笔记的书架、几件正在自行演算的晶质仪器。坐在桌后的女子看上去不过二十余岁，神情却带着一种与年纪并不相称的疲惫与平静。

她示意你坐下，随手为你斟了一杯茶。茶水颜色深得近乎发黑，入口后苦味沿着舌根漫开，久久不散。

“她很少替人写这种信。”女子将引荐函放到桌边，终于抬头看向你，“所以我本来以为，它不会再被人送到这里。”

她顿了顿，像是在衡量该从何处说起。

“你应该很好奇，我为什么看上去这么年轻。实际上，我已经一百零八岁了。”

你还未从这句话中回过神，她便偏过头咳嗽了几声。那阵咳嗽并不剧烈，却让桌角一盏魔石灯的光随之晃动。

“你的情况，信里已经说得很清楚。你不是单纯地卡在力量不足的地方，而是碰到了一扇从未为常人开启的门。”

她指尖轻敲桌面，桌上的晶片依次亮起，又很快熄灭。

“我这些年研究的，正是这种门后的东西。突破的确存在，但它不会只带来力量。感知、记忆、对世界的理解——它们都会一起被推向更远处。承受得住的人或许能继续前进；承受不住的人，则会在看清世界之前先被它压垮。”

“代价？”你望向她，“我从异世界来到这里，本就不知道自己该走向哪里。若连自己都无法保护，若不能抵达这世间的极致，我又该如何弄明白来到此处的意义？”

【噶】安静地看着你。许久之后，她眼底的审视渐渐散去，露出一丝几乎看不出来的笑意。

#### 试炼

“那就用你的行动回答我。”

她抬起右手，研究室中央的空气泛起深蓝色涟漪。一柄细长法杖自虚空中缓缓浮出，杖身仿佛封着一片静默的深海，压抑而磅礴的力量让四周的书页无风自动。

“我会压制力量。你也可以去找帮手。”

她握住法杖，苦茶的余味仍在空气中萦绕。

“击败我。让我看看你的信念，是否真的足以承受进化之后的世界。”

### 出招循环、变招与阶段机制

Boss 的行为应在现有怪物行动选择器中按模板代码 `scholar_ga` 分支实现，不采用“所有可用技能随机抽取”。

#### 阶段一：检验（100%～61%）

基础循环：

```text
标本标记 → 观测法弹 → 以太缚线 → 认知剥离 → 镜式推演 → 回到标本标记
```

变招优先级：

1. 场上没有被标记的存活玩家时，优先【标本标记】。
2. 至少两名玩家未被减速/束缚时，优先【以太缚线】。
3. 有被束缚或减速的目标时，优先【认知剥离】并锁定其中生命比例最低者。
4. 已标记目标且【镜式推演】可用时，以【镜式推演】替代下一次普通法弹。
5. 上述条件均不满足时按基础循环推进；技能冷却或魔力不足时回退普通攻击，不跳过循环计数。

#### 阶段二：校验（60%～31%）

进入条件：首次低于 60% 生命时，强制施放一次【深蓝护壁】；该阶段标志只触发一次。

循环切换：

```text
以太缚线 → 档案雷暴 → 镜式推演 → 观测法弹 → 认知剥离
```

变招优先级：

1. 护壁施放完成后的下一次可用范围技必定为【档案雷暴】。
2. 若全队中生命低于 55% 的成员至少两人，提前施放【档案雷暴】。
3. 若有生命低于 40% 且已被标记的成员，优先【认知剥离】；这是可预期的点杀窗口，队友可用治疗、护盾或控制打断节奏。
4. 【以太缚线】处于冷却时，改用【观测法弹】维持循环，不以随机技能替代。

#### 阶段三：证明（30%以下）

进入条件：首次低于 30% 时，若技能可用，立即施放一次【进化演算】；每场战斗最多一次。

循环：

```text
进化演算（仅一次） → 档案雷暴 → 标本标记 → 镜式推演 → 认知剥离 → 档案雷暴
```

变招优先级：

1. 仍有【深蓝护壁】时，优先控制与范围技，不连续施放高倍率单体法术。
2. 护壁消失后，若目标已被标记且低于 45% 生命，则【镜式推演】→【认知剥离】形成终结连招。
3. 【进化演算】没有无敌、吸血、复活或召唤效果；难点来自看得懂的范围压制和条件点杀，而不是不可反制的数值墙。

### 设计可读性
