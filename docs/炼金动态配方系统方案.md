# 动态炼金配方系统方案（首版）

> 状态：方案稿，尚未改动运行代码、现有配方或玩家数据。
>
> 目标：以「主材 + 辅材 + 反应剂」三槽动态反应替换现有少量精确匹配配方。每个槽位都可投入怪材、锻材、炼材或粒子；槽位职责决定其作用，材料类别不再决定能否放入。主材确定成果方向，辅材收束用途，反应剂决定形态、强度与奇异效果；若主材或辅材投入粒子，则大概率转为受价值守恒约束的粒子转化。系统首版提供 60 种左右可获得药剂/符咒模板，并由材料组合自然形成数百条有效配方。

## 1. 设计结论

- **不再维护** `主材代码 → 固定产物代码` 的白名单配方表；旧 `alchemyRecipes` 在正式实施时删除。
- 仍然使用一个主材、一个辅材、一个反应剂；每个槽位只能选择一种物品、可投入 1～99 份。同一物品可放入多个槽位，但背包数量必须覆盖总消耗。
- 三个槽位都可选择具有炼金档案的 `怪材`、`锻材`、`炼材` 或 `粒子`。装备、成品药剂、任务物品和未配置炼金档案的物品不可放入；不再按“怪材槽”或“粒子槽”拦截。
- 成功后获得药剂、战斗符咒或炼金材料；大成功提升品质/数量或进入稀有结果池；失败可能产出残渣，也可能炸炉。
- 玩家初始不会看到精确产物。界面只显示「推演方向」和材料线索；首次炼出某个成品后，才在个人图鉴中记录完整结果与常用组合。
- **提纯独立保留**：一键提纯、怪材提纯与五类通用甲材不属于本方案的清空范围。

## 2. 与现有系统的差异

当前实现以 `alchemyRecipes` 精确匹配主材、辅材、反应剂，未命中就不能开始炼金；成功率固定为基础值加职业等级与反应剂奖励。新系统改为先计算三类材料的炼金标签，再从结果池抽取成品。

```text
旧系统：兽核 + 空 + 空 = 魔力粉尘（唯一结果）

新系统：
主材标签决定「灵能 / 生命 / 防护 / 异变」的大方向
辅材标签决定「回复 / 增益 / 干扰 / 符咒 / 探索」的小方向
反应剂标签决定「稳定 / 元素 / 转化 / 失控」的最后形态
主材或辅材为粒子时，优先转入「粒子转化」候选池
→ 在符合条件的结果模板中按权重抽取
```

这样怪材新增后只要添加材料标签，不必再写一条条三元组；同一怪材也能经不同辅材、反应剂产生不同用途。

## 3. 材料标签与玩家可推理线索

### 3.1 标签原则

每种可炼金材料配置 1 个主相、1～2 个辅相、1 个稳定度与 1～2 句线索文案。标签只在服务端参与判定；玩家通过材料描述、投料文本和已发现配方逐渐摸清规律。

| 标签 | 主要含义 | 常见来源示例 | 可推导方向 |
| --- | --- | --- | --- |
| 生机 | 修复、再生、体力 | 肉块、根心、绒毛、草药 | 生命回复、再生、抗性 |
| 灵能 | 魔力、施法、感知 | 兽核、魔力微弧、灵性器官 | 魔力回复、吟唱、元素药 |
| 韧护 | 坚硬、护持、减伤 | 骨、壳、甲、鳞 | 护盾、防御、减伤药 |
| 迅捷 | 传导、行动、躲闪 | 筋、羽、爪、风性素材 | 速度、命中、闪避、先制 |
| 锋锐 | 伤口、暴击、穿透 | 獠牙、爪、刃性怪材 | 暴击、破甲、流血类药剂 |
| 凝胶 | 黏附、延续、渗透 | 各色凝胶、腺液、毒囊 | 持续回复、投掷药、异常状态 |

### 3.2 通用怪材映射

地图怪物独有部位素材不按名称硬写配方，而是在初始化时按其材质、区域与怪物主题赋予标签。五类基础怪材的默认倾向如下：

| 基础怪材 | 默认标签 | 首版可形成的常见方向 |
| --- | --- | --- |
| 毛发、绒毛 | 生机、迅捷 | 再生、闪避、经验增幅 |
| 胶皮、筋、凝胶 | 凝胶、迅捷 | 持续回复、投掷药、速度 |
| 骨、架、石 | 韧护、锋锐 | 防护、破甲、抗暴 |
| 甲、壳 | 韧护、潮汐 | 护盾、净化、减伤 |
| 鳞、片 | 韧护、灵能 | 元素抗性、魔力护持 |
| 兽核与区域核心 | 灵能 + 区域元素 | 回蓝、元素、稀有符咒 |

示例：河壳的主相为潮汐、辅相为韧护；以能量余烬反应时容易得到回蓝或净化药，以雷元素微尘反应时则更容易走向震荡药剂或水雷符咒。

### 3.3 粒子材料与槽位职责

粒子不再专属于反应剂槽；它可投入任一槽位。三个槽位仍有职责差别，而不是材料类别差别：

| 槽位 | 投入怪材/锻材/炼材时 | 投入粒子时 |
| --- | --- | --- |
| 主材 | 提供药剂、符咒或材料提取的大方向 | 成为粒子转化的主导源，显著提高转化为另一种粒子的概率 |
| 辅材 | 修正用途、稳定度与副效果 | 扰动/校准主反应，显著提高转化为另一种粒子的概率 |
| 反应剂 | 充当载体、黏合剂或稳定剂；可支持基础、非元素反应 | 提供元素定型、成功率与风险修正，是常规药剂路线最稳定的选择 |

反应剂不单纯提高成功率，而是决定结果形态。粒子作为反应剂时使用以下倾向；同一张表的元素与风险也会在粒子投入主材或辅材时保留。

| 反应剂 | 反应性质 | 成功倾向 | 风险 |
| --- | --- | --- | --- |
| 血肉残渣 | 肉体结合 | 生命、再生、药膏 | 低 |
| 能量余烬 | 活化放热 | 回蓝、爆裂、强效药 | 中 |
| 魔力微弧 | 定向塑形 | 元素药、经验/掉落秘药 | 低 |
| 木元素微尘 | 生长扩散 | 再生、自然抗性 | 低 |
| 金元素微尘 | 固化淬炼 | 防护、破甲、减伤 | 低 |
| 水元素微尘 | 稀释回流 | 治疗、净化、回魔 | 低 |
| 冰元素微尘 | 冷凝保存 | 迟滞、稳定、高品质保存剂 | 低 |
| 火元素微尘 | 点燃爆发 | 灼烧、爆炎、强效药 | 高 |
| 雷元素微尘 | 震荡跃迁 | 眩晕、天罚、连锁效果 | 高 |
| 光元素微尘 | 净化祝福 | 守护、经验、驱散 | 中 |
| 暗元素微尘 | 扭曲遮蔽 | 迷乱、混乱、掉落干扰 | 高 |

## 4. 动态判定流程

### 4.1 五步决策

```text
1. 读取主材标签，计算成果大类权重；先检查主材、辅材是否为粒子。
2. 读取辅材标签，对大类进行收束、转向或叠加副效果。
3. 读取反应剂标签，决定剂型、元素、稀有池资格与风险。
4. 检查主材与辅材的等级差；超过阈值时先展示风险确认，不消耗材料。
5. 结算稳定度、成功/大成功/失稳/炸炉。
6. 从最终候选池按权重抽取模板，并生成数量、品质、文案与图鉴记录。
```

### 4.2 主材决定大类

主材只决定候选大类，不锁死成品。每个主材提供总计 100 点初始权重，例如：

| 主材标签例 | 初始候选权重 |
| --- | --- |
| 生机 + 灵能 | 生命回复 45、魔力回复 25、再生 20、祝福 10 |
| 韧护 + 潮汐 | 防护 45、净化 25、生命回复 20、元素抗性 10 |
| 锋锐 + 凝胶 | 攻势 35、异常投掷 35、流血/中毒 20、奇异 10 |
| 暗蚀 + 灵能 | 干扰 40、掉落/探索 20、诅咒 25、奇异 15 |
| 雷鸣 + 炎性 | 爆发 40、控制 30、天罚 15、炸炉倾向 15 |

### 4.3 辅材决定小类

辅材在候选池中加权，而不是要求某一具体物品：

- 同相辅材：对应大类 `+35`，稳定度 `+8`。
- 相邻辅材：对应大类 `+18`，可增加一个副效果。
- 相冲辅材：奇异池 `+25`，失稳概率增加；不是无效组合。
- 防护、潮汐类辅材更容易产出保命和净化药；锋锐、炎性类辅材更容易产出攻击性投掷物；光辉、暗蚀对祝福/诅咒结果有决定性加权。

### 4.4 反应剂定型与粒子转化

反应剂为粒子时，按以下规则确定输出形态与最终标签：

- 血肉残渣：药膏、药剂、再生剂；更偏向己方单体。
- 能量余烬：浓缩剂、爆裂瓶；数值提高但提高失稳。
- 魔力微弧：秘药、符咒、元素浓缩液；更容易触发大成功。
- 元素微尘：对应元素的战斗药剂、抗性剂、投掷瓶或符咒。
- 反应剂为非粒子材料时：其标签作为载体/稳定标签参与结算，可产出基础至上位的非元素药剂、药膏或材料提取物；成功率额外 `-5%`，不能单独开启元素、天罚、混乱等奇异池。
- 三槽均为非粒子材料时：可以炼金，但仅能进入基础、下位的非元素结果池，且不能开启奇异池；这是玩家在没有粒子时的低风险试配路线。

主材或辅材投入粒子时，先进行一次粒子转化判定；命中后不再抽取药剂/符咒模板，而是结算粒子产物：

| 主材/辅材的粒子情况 | 进入粒子转化池的概率 | 未进入转化池时 |
| --- | ---: | --- |
| 两者均非粒子 | 0% | 按常规动态配方结算 |
| 仅主材为粒子 | 80% | 按常规路线结算；需至少有一种非粒子材料提供档位与成果方向 |
| 仅辅材为粒子 | 70% | 按常规路线结算；主材仍提供成果方向 |
| 主材、辅材均为粒子 | 95% | 剩余 5% 只可能得到残渣/失稳副产物，不会产出高价值药剂 |

反应剂槽中的粒子不会单独触发粒子转化——它是常规炼金的正常催化方式。若三个槽位均为粒子，则强制进入粒子转化池。

### 4.5 素材等级、档位与最终成品

相同的反应类型只说明产物方向相同，**不会让 Lv.10 素材与 Lv.50 素材稳定产出同一件最终成品**。每个怪材/锻材/炼材记录其掉落或提纯来源的 `source_level`；粒子记录 `particle_level`。材料等级保留实际来源等级，展示和成品命名时向下归整为 5 的倍数，最低为 Lv.1。

```text
常规反应有效素材等级 L
  = 主材、辅材中所有非粒子材料 source_level 的最低值

若主材、辅材只有一份非粒子材料：L = 该材料的 source_level
若主材、辅材均为粒子：强制进入粒子转化，不生成药剂/符咒
反应剂槽中的非粒子材料只提供载体/稳定作用；粒子只提供元素/催化作用，均不抬高 L
```

使用最低有效等级可以防止“Lv.50 主材 + Lv.10 辅材”无代价炼成 Lv.50 成品；想做高等级成品，主材和辅材都必须跟上。最终成品同时受素材等级、素材阶位和特殊钥匙约束：

| 有效素材等级 `L` | 等级允许的最高成品档位 | 同方向产物示例 |
| --- | --- | --- |
| Lv.1～10 | 基础 | 微愈药、微蓝剂、初阶药膏 |
| Lv.11～25 | 下位 | 复苏药、回响魔露、初阶抗性剂 |
| Lv.26～45 | 中位 | 强效回复剂、净化剂、控制投掷瓶 |
| Lv.46～70 | 上位 | 高效秘药、强元素药、稀有诅咒 |
| Lv.71～100 | 超位/奇异候选 | 天罚、返生、相位等；仍须 Boss 素材与特性钥匙 |

```text
最终成品档位上限
  = min(有效素材等级上限, 非粒子材料阶位上限, 组合/特性钥匙上限)
```

同一方向在不同等级带使用不同的成品模板与物品代码；例如 Lv.10 的生命方向是「微愈药」，Lv.50 的生命方向在满足 Boss/阶位门槛后才可能是「高效生命秘药」。即使名称相近，物品的等级、效果值、商店锚价与可堆叠代码也不同。等级带内的品质仍按第 5.2 节随机，不用品质替代素材等级。

粒子转化不使用上述药剂档位，而使用每种粒子的 `particle_level` 与 `particle_conversion_cap`：来自 Lv.10 素材的粒子最多转化为 Lv.10 及以下的同价值粒子；来自 Lv.50 素材的高阶粒子才可能参与 Lv.50 范围内的转化，且仍受第 5.4 节总价值守恒限制。

#### 主辅材等级差风险与二次确认

主材和辅材各自都有可比较的来源等级：非粒子取 `source_level`，粒子取 `particle_level`；反应剂槽是催化/载体，不参与等级差检查。系统计算：

```text
等级差 Δ = abs(主材来源等级 - 辅材来源等级)
```

| 等级差 | 状态 | 实际影响 | 交互 |
| --- | --- | --- | --- |
| Δ ≤ 10 | 匹配 | 无额外惩罚 | 直接进入炼金确认 |
| Δ = 11～14 | 轻微失衡 | 稳定度 `-4` | 正常确认页显示“轻微失衡” |
| Δ = 15～29 | 明显失衡 | 稳定度 `-10`，炸炉率额外 `+3%` | 必须弹出风险确认 |
| Δ ≥ 30 | 严重失衡 | 稳定度 `-20`，炸炉率额外 `+8%`；最终成品仍以低等级素材为上限 | 必须弹出高风险确认 |

风险确认面板只显示定性警告，不展示等级差、有效素材等级、成品上限、稳定度、成功率或炸炉率等具体数据；例如：

```text
⚠️ 素材等级能量相差过大
继续炼金风险极高，是否继续？

[确认炼金]  [取消]
```

- 点击 `[确认炼金]` 后才锁定本批材料、再次核验背包数量并开始五段炼金消息；确认交互只能由发起人使用，过期或重复点击无效。
- 点击 `[取消]` 或确认超时只关闭本次投料会话，不扣除任何材料、不获得熟练度，也不写入发现/配方记录。
- 批量炼金先展示同一风险确认；确认后每一批都继承该等级差惩罚并独立判定成功、失败与炸炉，避免玩家借批量操作绕过风险。

### 4.6 多份投放、反应能量与批次

每个槽位只能选择**一种**具有炼金档案的物品，但可投入 1～99 份：主材决定大方向，辅材修正小方向，反应剂提供元素定型、载体或稳定性。相同物品可以放入多个槽位，但背包数量必须覆盖三个槽位的总消耗。

每个材料档案新增以下不展示给玩家的平衡字段：

| 字段 | 说明 |
| --- | --- |
| 炼金阶位 | 普通 / 大型 / 精英 / Boss / 传奇素材；非粒子材料决定可触及的最高药剂档位，粒子另有转化阶位上限 |
| 炼金能量 | 单份材料能提供的反应容量，决定可执行多少批次 |
| 标签权重 | 此材料对生机、灵能、潮汐等方向的贡献 |
| 亲和系数 | 同标签反应时的轻微效率修正，范围 0.85～1.20 |
| 特性钥匙 | 例如“雷鸣核心”“暗蚀腺体”“圣性残片”；仅用于开启天罚、迷乱等特殊池 |

#### 单份炼金能量

```text
非粒子材料能量 = 10 × 阶位系数 × 地图等级系数 × 亲和系数
粒子能量 = 固定催化能量 × 元素/稳定修正

阶位系数：普通 1.00｜大型 1.25｜精英 1.60｜Boss 2.00｜传奇素材 2.50
地图等级系数：Lv.1～10 为 1.00；之后每 10 级增加 0.08，Lv.41～50 为 1.32
```

粒子的基础催化能量建议为：血肉残渣 5、能量余烬 6、魔力微弧 8、元素微尘 10。这样一份低级普通怪材与一份基础粒子能完成一轮基础反应；高阶产物自然需要更多份数或更高阶来源。

#### 成品档位与稀有度门槛

| 成品档位 | 每轮最低能量需求（主 / 辅 / 剂） | 材料门槛 | 可出现内容 |
| --- | --- | --- | --- |
| 基础 | 10 / 8 / 5 | 三槽均为可炼金物品，且至少有一份普通以上非粒子材料 | 小回复、基础增益、残渣转换 |
| 下位 | 18 / 14 / 9 | 任意非粒子材料至少大型 | 中回复、再生、抗性、探索药 |
| 中位 | 30 / 23 / 15 | 至少一份非粒子材料为精英，另有一份不低于大型 | 强回复、净化、投掷控制药 |
| 上位 | 48 / 37 / 25 | 至少一份非粒子材料为 Boss，另有一份至少精英 | 高效秘药、强元素药、稀有诅咒 |
| 超位/奇异 | 75 / 58 / 38 | Boss 素材 + 对应特性钥匙 + 至少一种元素微尘或魔力微弧 | 天罚、混乱、返生、相位等 |

**普通材料或低阶粒子堆得再多，也只能增加基础批次，不能越过对应的档位或转化阶位上限。** 大量低阶素材可以稳定生产低阶药剂；高阶效果必须由对应怪物阶位、区域核心或 Boss 部位提供钥匙。这是控制掉落稀有度与战斗强度的第一道边界。

#### 批次数与消耗

系统先根据本次抽到的成品档位，计算每一批所需的材料份数：

```text
每批主材需求份数 = ceil(主材需求能量 / 单份主材能量)
每批辅材需求份数 = ceil(辅材需求能量 / 单份辅材能量)
每批反应剂需求份数 = ceil(反应剂需求能量 / 单份反应剂能量)

主材可用批次 = floor(主材投入数量 / 每批主材需求份数)
辅材可用批次 = floor(辅材投入数量 / 每批辅材需求份数)
反应剂可用批次 = floor(反应剂投入数量 / 每批反应剂需求份数)
最终批次数 = min(三者可用批次, 玩家本次选择的上限 99)
```

- 每个批次都固定消耗对应份数的主材、辅材和反应剂；剩余材料继续用于下一批，不会出现半份材料或按比例扣除的情况。
- 若单份材料的能量超过当前档位需求，超出的部分只转化为稳定度或品质加成，不会跨批次“储能”，也不会提升到高于模板上限的效果。
- 方向由这一种主材、这一种辅材和这一种反应剂的标签共同决定，规则直观且便于玩家从结果反推材料性质。
- 若三槽能量不足以完成 1 批，只显示“反应能量不足”，不会消耗材料。
- 玩家可选择“只炼 1 批”验证方向，或选择“炼至上限”进行批量炼金；批量最多 99 批并一次确认。

### 5.2 最终产出数量与品质

每个批次独立结算一次成功、大成功、失败或炸炉。最终数量不是把三槽投料直接相乘，而是成功批次数的累积：

| 成品档位 | 普通成功 | 大成功 | 数值品质 |
| --- | --- | --- | --- |
| 基础、下位 | 成品 ×1 | 成品 ×2 | 同一模板的效果按 90%～100% 抽取 |
| 中位 | 成品 ×1 | 成品 ×1，额外获得 1 份同方向基础/下位副产物 | 效果按 92%～105% 抽取 |
| 上位 | 成品 ×1 | 成品 ×1，并提升为“佳品” | 效果按 95%～110% 抽取 |
| 超位/奇异 | 成品 ×1 | 成品 ×1，并提升为“奇品”或进入同池稀有模板 | 效果按 100%～115% 抽取；每场限制不变 |

所有效果均受模板硬上限限制；“佳品/奇品”只在模板允许的区间内取值，绝不突破该药剂的战斗上限。高阶材料带来的主要收益是解锁档位、提高稳定度和增加批次数，而不是无限放大单件药剂数值。

示例：投入 12 份普通兽核、10 份河壳、8 份魔力微弧，若最终命中下位回蓝池且能量满足 6 批，则结算 6 次独立反应；其中 4 次成功、1 次大成功、1 次失败，最终得到对应回蓝药剂 ×6（4 + 2），并获得一次失败副产物。它不会合成为“600% 回蓝药”。

### 5.3 怪材价值与效果强度的平衡

材料的**商店价格/市场价格不能直接参与战斗效果公式**，否则价格调整或市场波动会让同一药剂变强或变弱。常规药剂运行时只读取固定的 `alchemy_tier`、`alchemy_energy`、标签、特性钥匙与风险值；商店价格只用于事后经济校验。粒子转化则使用独立、不可由玩家交易影响的 `alchemy_reference_value` 做价值守恒校验，绝不读取商店或市场实时价格。

平衡以三条线同时约束：

1. **战斗线**：模板确定效果上限、持续时间、目标数、每场次数与 Boss/PvP 降级规则。任何材料都不能突破模板上限。
2. **稀有线**：高档效果受材料阶位和特性钥匙限制；大量普通素材只能批量生产低档药，不能堆出天罚符咒。
3. **经济线**：按怪物掉率、平均掉落量、提纯/炼金失败损耗，计算每瓶的期望材料成本；成品的商店参考价与玩家交易锚价应高于该成本，防止通过商店材料或产物反复套利。

建议建立每个模板的“战斗价值点”与“期望成本”对照表：

| 模板档位 | 单件战斗价值目标 | 期望材料成本目标 | 说明 |
| --- | --- | --- | --- |
| 基础 | 1～2 点 | 6～15 铜 | 常规补给，可稳定量产 |
| 下位 | 3～5 点 | 18～45 铜 | 地图探索常用消耗品 |
| 中位 | 6～9 点 | 55～120 铜 | 需要大型/精英素材，具有明确战术价值 |
| 上位 | 10～14 点 | 150～320 铜 | Boss 素材参与，单场使用限制更严 |
| 超位/奇异 | 15～20 点 | 400 铜以上 | 极低掉落与严格次数限制，不进入普通商店 |

“战斗价值点”只用于设计评审，不直接显示给玩家；它把治疗比例、增益幅度、控制回合、目标数量、持续时间和每场次数统一换算，确保例如一次眩晕不会被定价成与一瓶小回复药同级。

### 5.4 粒子转化：价值守恒与阶位上限

主材或辅材为粒子而触发转化池时，产物只能是粒子、炼金残渣或低价值的稳定载体；**不会抽取药剂、符咒或高价值战斗道具**。每一种可炼金物品都额外配置不展示的 `alchemy_reference_value`（炼金基准价值）与 `particle_conversion_cap`（可转化粒子阶位上限），两者随掉落阶位、地图等级和稀有度初始化后固定。

```text
本批投入基准价值 V_in
  = Σ(本批实际消耗份数 × 对应 alchemy_reference_value)

普通成功的粒子产出价值 V_out ≤ floor(V_in × 85%)
大成功的粒子产出价值 V_out ≤ V_in
失败或炸炉的产出价值 V_out < V_in
```

- 任意一次粒子转化都不得使产物总基准价值超过该批实际投入的总基准价值；大成功只减少损耗，不能额外创造价值。
- 产物粒子的最高阶位不得超过本批所有投入物的 `particle_conversion_cap`；若三槽均为粒子，则不得超过其中**最高阶粒子**。低阶粒子即使大量堆叠，也不能直接炼成更高阶粒子。
- 产物的元素优先继承主材粒子，其次辅材粒子，最后反应剂粒子；没有粒子来源时不得产出元素微尘。元素不同只代表转化方向，不提高基准价值。
- 先按上限选取可产出的粒子种类与等级，再向下取整计算数量；若剩余价值无法再换取一份产物，则损耗为反应逸散，不返还为额外材料。
- 粒子转化不允许通过“低价值粒子 + 任意填料”变成更高价值产物。高阶粒子的转化必须由对应高阶怪材/核心提供足够的阶位上限和基准价值，且最终总价值仍不得超过投入。

这套规则只约束经济型的粒子转化；正常药剂仍按模板的战斗强度、材料阶位和掉率平衡，不把价格直接换算成治疗或伤害。

## 6. 成功、失败与炸炉

### 6.1 概率模型

```text
稳定度 = 主材基础稳定 + 辅材修正 + 反应剂修正 + 炼金师等级修正 - 等级差惩罚
成功率 = clamp(45%, 92%, 64% + 炼金等级×2% + 稳定度)
大成功率 = clamp(2%, 18%, 3% + 炼金等级×0.8% + 魔力微弧修正)
炸炉率 = clamp(1%, 18%, 失稳值 - 炼金等级×0.5% + 等级差炸炉修正)
```

大成功只会在成功判定后结算；炸炉只会在失败判定中结算。高风险组合可以有更高稀有池权重，但不能以故意炸炉刷取高价值产物。

| 结果 | 材料消耗 | 产出 |
| --- | --- | --- |
| 普通成功 | 消耗该批次分摊的三槽材料 | 按当前候选池获得成品 ×1；粒子转化时按第 5.4 节获得守恒后的粒子 |
| 大成功 | 消耗该批次分摊的三槽材料 | 常规路线按第 5.2 节结算双产物、副产物或佳品/奇品；粒子转化只将价值回收率提高至上限，不额外创造价值 |
| 普通失败 | 消耗主材与反应剂；辅材有 30% 概率保留 | 炼金残渣 / 少量血肉残渣 / 能量余烬 |
| 炸炉 | 消耗全部三材 | 无成品；返还 1～2 份无用残渣，不造成角色伤害，不损毁装备 |

## 7. 五段炼金消息与文案库

一次炼金固定发送五条独立消息，便于玩家阅读反应过程，也让材料规律通过文本逐步显露。

1. **投入主材**：说明主材的本质和大方向。
2. **投入辅材**：说明辅材如何牵引、收束或冲突。
3. **投入反应剂**：说明粒子如何点燃、冷却、稳定或扭曲反应；非粒子则说明其如何承载、黏合或压制反应。
4. **反应判定**：成功、大成功、普通失败或炸炉。
5. **最终结果**：明确消耗、获得、效果摘要、首次发现提示与熟练度。

### 7.1 文案生成规则

文案由标签模板拼接，不以具体物品名硬编码。首版至少配置：主材模板 48 条、辅材模板 48 条、反应剂模板 36 条、判定模板 32 条、结果模板 80 条；加上材料名称与元素替换后可生成数千种不重复组合。

```text
主材模板：
「{主材}在研钵中裂开，{主相描述}缓慢浮出液面。」
「{主材}的{部位特征}与药液相触，反应先朝{大类线索}倾斜。」

辅材模板：
「{辅材}拉住了逸散的{标签}，药液开始显出{小类线索}。」
「两种素材彼此排斥，瓶壁浮现{冲突元素}色的细纹。」

反应剂模板：
「{反应剂}落入液面，{元素}的粒子将反应压向{剂型线索}。」
「微粒跳动得过快，火候正在越过安全刻度。」

非粒子反应剂模板：
「{反应剂}沉入液面，{标签}像骨架一样托住尚未定型的药液。」
「{反应剂}吸走了浮沫，反应失去元素锋芒，却变得更易控制。」
```

失败文案不会直接泄露唯一正确答案，而会给可行动线索，例如“药液过于黏滞，或许需要更能导流的辅材”“雷光没有锚点，光辉或坚硬素材也许能稳定它”。

### 7.2 五段示例

```text
① 主材：你将【星泥核心】压入坩埚，暗水般的灵能在液面下缓缓旋转。
② 辅材：一片【河壳】沉入旋涡，潮汐性的硬壳让失序的波纹暂时收束。
③ 反应剂：暗元素微尘被撒入其中，瓶口升起一缕不肯散去的灰紫雾气。
④ 反应：雾气突然回卷成环——反应成功，且出现了异常浓缩。
⑤ 结果：获得【雾痕迷乱药剂】×2。敌方单体命中、闪避降低 20%，持续 2 回合。首次发现，已记入炼金图鉴。
```

## 8. 发现、保存与界面

- 炼金界面显示三个槽位、各材料的简短已知线索、稳定度区间（低/中/高）和风险提示（安全/不稳/危险），**不提前显示精确产物**。
- 主、辅材等级差达到 15 级时，提交炼金不直接扣料，而是先显示“素材等级能量相差过大、风险极高”的定性警告；不展示任何具体数值，仅提供 `[确认炼金]`、`[取消]` 两个按键。
- 当前固定的「当前基础推演：成品名」改为「反应倾向：生命回复 / 雷鸣控制 / 暗蚀干扰……」。
- 成功后记录个人发现：成品模板、用过的三材、结果等级和首次发现时间。
- 配方不在投料前保存。只有本次炼金**成功产出成品后**，第五条“最终结果”消息才出现 `[保存入配方]` 按键；失败、炸炉和未产出成品的尝试不能保存。
- 点击保存后，记录本次主材、辅材、反应剂、实际产物模板、产物档位与风险信息。系统自动生成可重命名的“已验证配方”，避免把尚未验证的猜测误存为快捷操作。
- `player_alchemy_formulas` 改为已验证组合的快捷记录。它显示最近/常见结果、成功次数与风险级别；大成功和奇异结果另行记录，不当作必出结果。
- 配方详情提供 `[快速炼金]` 与 `[批量炼金]`：快速炼金直接装填三槽后再确认一次；批量炼金可选 1～99 次，先展示材料需求、预测成功区间与可能结果，再确认执行。每一轮仍独立判定成功、大成功、失败与炸炉，并汇总为一条结果；批量模式不逐轮发送五段过程文案。

## 9. 数据与迁移设计

### 9.1 需要新增的数据结构

| 表/配置 | 关键字段 | 用途 |
| --- | --- | --- |
| `alchemy_material_profiles` | `item_code`、可用槽位、`source_level`、炼金阶位、能量、标签 JSON、稳定度、风险、特性钥匙、文案主题、`alchemy_reference_value`、`particle_conversion_cap` | 任意怪材、锻材、炼材与粒子的炼金性质；三槽共用同一准入规则 |
| `alchemy_particle_profiles` | `item_code`、`particle_level`、催化能量、元素、定型规则、成功/风险修正、粒子阶位 | 粒子投入任一槽位时的专属转化与催化规则 |
| `player_alchemy_sessions` | `character_id`、三槽物品/数量快照、等级差、风险修正、确认令牌、过期时间 | 风险确认期间的临时投料会话；确认时重新校验背包，取消/超时不消耗 |
| `alchemy_output_templates` | `code`、大类、所需标签、权重、品质档、效果 JSON、稀有度 | 约 60 个成品模板 |
| `alchemy_text_templates` | `stage`、标签条件、文案、权重 | 五段消息文案库 |
| `player_alchemy_discoveries` | `character_id`、模板码、首次时间、成功次数、最佳结果 | 个人发现与图鉴 |
| `player_alchemy_formulas` | 主/辅/反应剂、首次结果模板、名称、风险快照、成功次数 | 已验证配方的快捷炼金 |
| `player_alchemy_formula_results` | `formula_id`、模板码、次数、最近结果 | 快捷配方的结果统计 |

模板可以先以 TypeScript 常量实现，再在稳定后迁入数据库；材料资料应通过 `item_code` 绑定，避免依赖可修改的显示名称。

### 9.2 旧配方清空边界

正式实施版本执行一次迁移：

```sql
DELETE FROM player_alchemy_formulas;
DELETE FROM player_alchemy_sessions;
```

- 只清空炼金快捷配方和正在编辑的炼金槽位。
- **不删除**背包材料、已拥有药剂、提纯记录、炼金师等级和熟练度。
- 删除旧 `alchemyRecipes` 与其对应“精确配方”提示；旧的固定产物仍可作为新模板池中的普通成品复用。

## 11. 验收标准

- 三槽均可放入任意已配置炼金档案的怪材、锻材、炼材或粒子；系统按槽位职责解释反应，而不以材料类别阻止投放。
- 主材或辅材为粒子时，按 80% / 70% / 95% 的规则大概率进入粒子转化池；产物总基准价值不高于实际投入，低阶粒子不得靠堆叠转化为高阶粒子。
- 首版至少有 60 个成品模板，实际有效组合达到数百条；每种模板有用途、数值上限、风险与战斗结算。
- 三槽各只能放入一种材料、可投入多份；系统按每批所需份数与数量瓶颈计算批次数，普通材料不可通过堆叠跨越高阶与奇异产物门槛。
- 主辅材等级差达到 15 级时，必须显示“风险极高”的定性确认，不泄露等级差、成品上限或概率数值，并只提供确认炼金/取消；取消、超时或重复点击均不消耗材料。
- 玩家能从材料和过程文本中判断“什么材料偏治疗、回蓝、防护、控制、探索或奇异”，但无法仅靠界面提前锁定所有稀有结果。
- 每次单次炼金严格依次发送 5 条消息；第五条仅在成功产出时显示“保存入配方”按键。失败与炸炉也必须完整结算消耗、返还与熟练度。
- 已保存配方支持快速炼金与 1～99 次批量炼金；批量执行前必须显示材料需求与风险确认，执行后必须给出成功/大成功/失败/炸炉的汇总。
- 所有战斗道具均有目标范围、持续时间、叠加规则、Boss/PvP 降级规则和每场限制；不存在无条件斩杀或永久增益。
- 清空旧配方时不误删玩家背包、职业进度、提纯数据或已拥有物品。
