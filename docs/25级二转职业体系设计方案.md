# Lv.25 二转职业体系设计方案

> 版本定位：主职业二转；适配现有四人队伍、全员确认后按速度结算的回合制战斗。
>
> 设计目标：每个基础职业提供三条世界树常驻传承与两条地图隐藏传承；五条分支均有独立的资源循环、回合决策与队伍职责。任何四人队都能通关常规内容，但合理搭配可在首领、高压群怪或持续作战中获得明显优势。

## 1. 已有系统与设计边界

### 1.1 现有基础

项目当前基础职业为战士、法师、盗贼、牧师，职业成长分别偏向：

| 基础职业 | 现有成长倾向 | 现有职业武器 | 二转的核心职责 |
| --- | --- | --- | --- |
| 战士 | 体质、力量 | 长剑、盾牌 | 承伤、威胁控制、近战压制 |
| 法师 | 精神、智力 | 法杖、法书 | 元素输出、范围处理、控场 |
| 盗贼 | 敏捷、感知 | 匕首、拳刃 | 破绽输出、追击、削弱 |
| 牧师 | 体质、精神 | 法书、法球 | 治疗、护盾、净化、增益 |

现有队伍最多四人，行动采用回合制并按速度结算；战斗内已有冷却、魔力、仇恨、护盾、持续伤害、控制、属性修正、净化、回合开始结算等基础能力。本方案**不引入前后排格位、反应操作或实时走位**；“前线”均指通过仇恨成为主要受击目标，而非地图站位。

### 1.2 二转总规则

1. 解锁条件：角色 Lv.25、已完成 Lv.20 突破主线、已选择基础职业、完成对应传承任务。
2. 选择方式：每个基础职业共有五条合法二转：世界树三条常驻传承、地图两条隐藏传承；角色最终只能选择其中一条。首次转职免费。
3. 改宗规则：在非战斗状态、完成 7 日冷却及缴纳“回响结晶”后可重置二转。重置只返还二转技能点，不改变基础职业、等级、装备、主线和副职业。
4. 二转不替换基础职业编码。建议新增 `advanced_profession_code` 字段与 `advanced_profession_definitions` 表；基础职业提供原成长与武器精通，二转只提供专精被动、职业资源和专属技能。
5. 二转技能独立于怪物掉落技能：Lv.25 获得 3 个一阶专属技能与 1 个职业被动；Lv.30、Lv.35 分别解锁一个技能栏位；Lv.40 解锁终结技。基础技能与已学通用技能仍可带入。
6. 每名角色最多装备 4 个主动二转技能（含终结技）；专精被动常驻。这样可保持现有快捷栏与回合选择界面可读。
7. Lv.30 后额外解锁 1 个“旁修被动槽”。角色可向其他二转导师偷学 1 条传承被动；本职被动始终以原强度常驻，偷学被动按“旁修数值”生效。不能偷学自己的分支、不能同时装备两条旁修被动。

### 1.3 数值口径

- 下文“威力”沿用现有技能的百分比口径：`100` 约等于一次标准技能结算，范围攻击需按目标数折算，总伤害不可长期超过同等级单体流派。
- “治疗系数”以施法者魔法攻击为基准；“护盾系数”以目标最大生命值与施法者魔法攻击中较低的合理量结算，避免高血战士被无限放大。
- “1 层”默认最多 5 层；每回合结束衰减 1 层，除非技能另有说明。所有层数、标记和冷却均写入当前战斗会话，战斗结束清空。
- 数值严格对齐当前玩家技能库：1 回合冷却通常为 `60–70 MP / 108–115%`（如奥术飞矢、风刃）；2 回合为 `105–140 MP / 115–125%`（如重击、毒刃、雷枪）；3 回合为 `190–250 MP / 122–130%`（如冰缚、奥术枷锁、盾反）；4 回合为 `300 MP`（如圣佑）；6 回合为 `650 MP`（如法力祝福）。二转终结技采用 `650 MP / 7–8 回合`，仅在资源满值时施放。治疗、护盾、控制和资源回复须相应降低伤害或延长冷却。
- 本方案沿用现有“攻击技能至多附带一个常规效果”的原则：常规弱化为 `15–20% / 2 回合`；硬控为 `50% 基础概率 / 1 回合`，并以较低威力和较长冷却交换。二转所述“额外效果”优先使用已有的减速、束缚、眩晕、易伤、护盾、再生、法力再生、破甲等结算入口。

| 现有技能参考 | 当前数值/效果 | 二转复用原则 |
| --- | --- | --- |
| 奥术飞矢 | `115% / 60 MP / CD 1`，单体能量远程 | 作为无附加效果的基础单体魔法基线 |
| 重击、毒刃 | `125% 或 120% / 110 MP / CD 2`；毒刃附带持续效果 | 中冷却攻击可附一项伤害或弱化，但不能同时给高伤、强控与资源满额 |
| 冰缚、奥术枷锁 | `128% 或 122% / 225 或 210 MP / CD 3`；带束缚/压制 | 控制技以 CD 3 和约 190–250 MP 为基线，首领降级处理 |
| 盾反、盾击 | `250 MP / CD 3`；前者高减伤反击，后者眩晕后给易伤 | 高防御或硬控必须占用一整次关键行动，不能附加同级输出 |
| 战吼、圣佑 | `190 MP / CD 3`、`300 MP / CD 4`；提供全队增益/减伤 | 全队保护技以 190/300 MP 和 CD 3/4 为下限，不与高额范围伤害绑定 |
| 治疗祷言、法力祝福 | `60 MP / CD 1` 的低血治疗再生；`650 MP / CD 6` 的全队法力持续恢复 | 治疗描述始终说明目标选择与持续回合；大范围资源恢复仅能作为终结级效果 |

二转技能描述统一采用“动作 + 目标/范围 + 伤害或治疗 + 状态数值与回合 + 条件/首领降级”的短句结构，保持与现有“发动刺击冲撞，并提升自身速度”“以冰霜束缚远程目标，有概率使其无法行动”等描述同一可读性。

## 2. 共用战斗机制

### 2.1 专精资源

每个二转仅有一种专属资源，资源上限为 100。资源不跨战斗保留。资源获得应在日志中明确展示，例如“元素共鸣 +25（75/100）”。

| 资源 | 主要获得方式 | 主要消耗方式 | 设计目的 |
| --- | --- | --- | --- |
| 守势 | 承受攻击、嘲讽命中、格挡 | 高额减伤、反击、团队保护 | 让坦克主动承压而非只堆防御 |
| 奥能 | 施放不同元素、命中弱点、队友触发元素状态 | 高阶法术、扩散、爆发 | 让法师轮换元素并配合队友 |
| 破绽 | 暴击、命中带状态敌人、队友控制敌人 | 背刺、处决、偷取行动窗口 | 把盗贼的爆发建立在团队创造机会之上 |
| 信念 | 治疗低血目标、护盾吸收伤害、净化控制 | 群体保命、祝福、反转危机 | 避免牧师只在掉血后被动补血 |

地图隐藏分支使用灼志、霜令、风暴电荷等同样上限 100 的资源；其获得与消耗规则在第 7 节逐条定义，仍受“一次伤害事件只获得一次资源”的全局限制。

### 2.2 新增通用状态

以下状态是二转所需的最小扩展；必须在战斗详情中显示名称、层数/剩余回合、来源职业和可被哪些效果消耗。

| 状态 | 归属 | 规则 | 反制与边界 |
| --- | --- | --- |
| 易伤 | 敌方 | 每层使其受到的最终伤害 +3%，最多 5 层 | 首领最多承受 3 层；不可由同一技能无限续时 |
| 破甲 | 敌方 | 物理防御降低 8%，持续 2 回合 | 仅由物理破防技能施加；与现有护甲削弱取高不叠加 |
| 破障 | 敌方 | 魔法防御降低 8%，持续 2 回合 | 由元素或腐蚀类技能施加；仅影响后续魔法伤害 |
| 元素印记 | 敌方 | 火、冰、雷、木、光、暗六类各可共存 1 个；法师可消耗形成反应 | 首领的控制型反应降级为减速/减伤，不跳过行动 |
| 追猎 | 敌方 | 被盗贼锁定；首次受特定技能命中会消耗并触发追加效果 | 单目标仅 1 个，转火即失效 |
| 守护 | 友方 | 本回合首次受到的单体伤害，按比例转移给施加者 | 每名受护者同一时刻仅 1 个；不能转移自伤与持续伤害 |
| 祷言 | 友方 | 获得治疗或护盾时叠层，达到阈值后触发专精效果 | 最多 3 层；战斗日志提示阈值 |

### 2.3 跨职业协作原则

1. 协作只提高“时机质量”，不要求固定职业组合。例如法师可自己消耗元素印记，但由盗贼、战士、牧师协助时效率更高。
2. 强控制不链锁：眩晕、束缚、沉默等硬控制作用于首领后，使其获得 2 回合“抗控”，期间同类控制转为减速或易伤。
3. 一回合最多触发一次“协同追击”和一次“元素反应”；多名角色满足时按速度最高的触发，防止四人多段倍率失控。
4. 任何转移伤害、反击、追击都不再次触发同类反击/追击，杜绝递归结算。

### 2.4 可偷学的传承被动

每条二转传承额外拥有 1 条**传承被动**：本职角色完成对应的 **Lv.30 Boss 导师试炼**、正式二转时自动常驻；其他已二转且角色达到 Lv.30 的角色，可在该导师处完成一次 5 分钟左右的“旁修课”，交付 1 枚回响结晶后将其加入图鉴并装备。旁修课只复现机制，不重复给转职奖励或 Boss 首通奖励。

- 一名角色仅能装备 1 条旁修被动；卸下、替换不消耗材料，战斗外进行。偷学效果用表中的“旁修”数值结算，通常约为本职的 `60%–70%`。
- 被动不消耗 MP、没有独立快捷栏；同一触发事件内，**本职被动先结算、旁修被动后结算**。若两者会施加同名状态，只保留数值更高、持续更长的一项。
- 每条被动都避开二转专属资源，保证任何基础职业都能理解和使用；只在原职业有意义的部分（例如护盾、净化、持续伤害）会自然形成搭配取舍，而不是强迫所有职业都要偷学。
- 偷学不能触发资源获得、召唤、反击、协同追击或二次伤害；涉及伤害转移的效果同样带“不可再触发”标记。这样它扩展构筑，但不替代本职资源循环与终结技。

| 二转 | 传承被动 | 本职效果 | 旁修效果与组合价值 |
| --- | --- | --- | --- |
| 盾卫 | **护阵余韵** | 自身带嘲讽、守护或护盾结束行动时，生命比例最低的队友获得 1 回合 `6%` 伤害减免，每回合一次。 | 减伤为 `4%`。可让有护盾能力的牧师或战斗法师补足保护窗口，但不会转移伤害或替代盾卫。 |
| 战旗使 | **共鸣号令** | 自身对敌人施加减益后，该敌人下一次受到队友技能伤害 `+8%`，并获得 `+10%` 命中；每回合仅标记一个目标。 | 伤害提升 `+5%`。适合先手控制的寒霜卫士、影行者或有驱散/易伤的辅助，制造清晰集火信号。 |
| 剑豪 | **临界识破** | 每回合首次以单体伤害技能命中带破甲或易伤的目标时，获得 `+10%` 暴击。 | 暴击为 `+6%`。将队友创造的破防窗口转为爆发，适合夜刃、战斗法师等单体输出。 |

| 元素使 | **异相共鸣** | 本回合首次给目标施加一种其当前没有的常规减益或元素印记时，回复 `4%` 最大 MP。 | 回复 `2%` 最大 MP。奖励多状态队伍轮换上减益，且每回合只触发一次，不能靠范围多目标回满蓝。 |
| 唤灵师 | **灵契余荫** | 每场战斗首次有队友生命降至 `50%` 以下时，为其施加 2 回合 `8%` 最大生命护盾。 | 护盾为 `5%` 最大生命。可给脆皮输出提供一次容错，与圣愈者的低血治疗形成“先盾后疗”。 |

| 潮影猎手 | **收潮** | 击杀或协助击杀敌人时，回复 `5%` 最大生命与 `5%` 最大 MP；每回合一次。 | 双回复均为 `3%`。适合群怪和精英编队的续航选择，单 Boss 战几乎没有收益，避免全面最优。 |

| 圣盾使 | **守壁余响** | 护盾吸收伤害后，护盾目标获得 1 回合 `20%` 控制抗性；每目标每回合一次。 | 控制抗性为 `12%`。适合盾卫、战斗法师、星誓祭司等会主动上盾的组合，避免护盾只等同加血。 |

| 根脉祭司 | **新芽复苏** | 净化队友的控制或持续伤害后，为其施加 2 回合再生，每回合回复 `3%` 最大生命。 | 每回合回复 `2%` 最大生命。为带净化的队伍提供后续续航，和即时治疗的圣愈者形成不同节奏。 |
| 星誓祭司 | **月环共担** | 每回合首次有队友生命降至 `35%` 以下时，其下一次受到的单体伤害有 `12%` 转移给施加者。 | 转移比例为 `8%`。可由坦克或高血职业偷学来替脆皮接一次伤害；转移伤害不再触发守护、反击或任何偷学被动。 |

## 3. 战士二转：守住敌人的锋芒

世界树常驻的战士三条分支对应“主坦保护”“反击控场”“破防主输出”。三者均保留剑盾、嘲讽和盾击的基础价值，但只有盾卫是稳定主坦。

### 3.1 盾卫（`bulwark_guard`）

## 8. 二转专属三段任务与导师试炼

### 8.1 统一结构与 Lv.30 导师 Boss 规则

二转不以一次对话直接授予。二十条传承均采用“三段任务”：**第一段认识导师的遗憾或原则；第二段用简单的跑腿、收集或讨伐证明玩家愿意践行它；第三段击败导师亲自化作的 Lv.30 试炼 Boss。**前两段不设置低概率掉落、复杂解谜或强制满队，预计各 10–15 分钟；第三段才检验战斗理解。

1. 所有任务在角色 Lv.25、已完成 Lv.20 突破后可接；隐藏传承只额外要求先抵达对应地图并发现 NPC，不额外提高等级门槛。
2. 第一、二段可单人完成，第二段的击杀与采集允许队友协助，但只给已接任务的角色计数；任务材料均为任务物品，不占交易与市场路径。
3. 第三段在导师所在地开启“传承回廊”，导师以 **Lv.30 Boss** 形态出战。可 1–4 人进入，只有接任务者获得转职结算；队友获得常规战斗奖励，不会替代其个人试炼。
4. Boss 的等级、技能威力和冷却固定按 Lv.30 模板结算；生命按入场人数为 `100% / 160% / 215% / 265%`，伤害不随人数增幅。败北只将角色送回导师旁，保留前两段进度并允许重试。
5. 每位 Boss 固定携带 3 个现有技能作为可读基础，再额外携带 1 个全新的“导师试炼技”。现有技能仍沿用 `奥术飞矢 115% / 60 MP / CD1`、`冰缚 128% / 225 MP / CD3`、`盾反 250 MP / CD3`、`圣佑 300 MP / CD4` 等现行口径；新技能遵循相同的蓝耗、冷却、威力和状态边界，不偷偷提高同名技能威力。

### 8.7 任务完成、命名与未来转职边界

- 三段任务完成后，导师只授予二转称号、专属资源与技能，不授予“王、圣、终焉、裁决、领主”等高阶头衔。三转可升级为地区认可的专业称号，四转再承接史诗/传说称号与世界树深层叙事。
- 每条任务的第一、二段产出一段“传承手记”；第三段胜利后合成为该职业的“基础传承证”。手记用于图鉴与重温剧情，不作为随机强化材料。
- 导师 Boss 战胜后保留“切磋”入口，可按 Lv.30 固定难度反复挑战，但只在首次给转职、称号和图鉴记录，避免刷取收益。

## 9. 四人队伍协作范式

下面是推荐而非强制的搭配。每个范式都保留至少一名承压者、一种保护/续航来源、一个主要输出轴与一个机制位。

| 队伍范式 | 构成示例 | 回合协作 | 适用内容 | 明确弱点 |
| --- | --- | --- | --- |
| 稳步开荒 | 盾卫 + 圣愈者 + 元素使 + 夜刃 | 盾卫嘲讽守护，圣愈者预留净化，法师挂双印记，盗贼在控制窗口处决 | 初见首领、高压未知机制 | 清群较慢，依赖单点输出节奏 |
| 破甲速攻 | 战旗使 + 剑豪 + 夜刃 + 圣盾使 | 战旗使破甲/增伤 → 剑豪与夜刃同步爆发 → 圣盾挡反扑 | 可预读的单体首领、限回合目标 | 长期治疗不足，控制/持续伤害压力大 |
| 元素压场 | 盾卫 + 元素使 + 唤灵师 + 晨星祷者 | 主坦维持仇恨，四元素/光印记反应，唤灵补续航，晨星祷者驱散 | 多目标、元素弱点、强化型怪物 | 物理破防低，怕高魔抗单体 |
| 蚀毒消耗 | 盾卫 + 蚀毒师 + 唤灵师 + 圣愈者 | 坦克稳住，蚀毒叠毒与降防，林灵和治疗维持血线，慢速磨杀 | 高血 Boss、治疗型敌人 | 开场爆发很低，不适合短时间击杀 |
| 游击控制 | 战旗使 + 机关游侠 + 战斗法师 + 圣盾使 | 陷阱减速 → 群控 → 战斗法师范围消耗，护盾覆盖敌方反击 | 高闪避、多目标、控制型敌人 | 对硬直免疫首领的斩杀效率一般 |

### 9.1 关键协同示例

1. **破甲处决**：战旗使“破阵军令” → 剑豪“裂甲斩” → 夜刃“暗影标定/背隙连刺” → 目标低于 40% 后“残月割喉”。这是物理队的短回合爆发链，但需保留护盾或守护覆盖首领反击。
2. **元素爆发**：元素使以“炽霜交替”铺火/冰印记 → “雷暴导链”补雷印记 → “四相共鸣”补风并充满奥能 → “天穹序列”引爆四印记，再由剑豪/夜刃收束。
3. **保人反打**：首领大招前，盾卫“代偿守护”指定脆皮 → 圣盾使“光幕回响” → 战斗法师或夜刃进入近身爆发。伤害转移和护盾以现有回合结算顺序结算，先减伤/护盾，再转移伤害。
4. **控制窗口**：机关游侠“钩索陷阱” → 战旗使“震地号令” → 元素使“雷暴导链”。对首领，束缚降级为减速，但依然满足破绽/战意的协同条件。

## 10. 世界树常驻导师、任务与界面

### 10.1 统一任务流程

1. Lv.25 时，冒险者公会解锁“传承试炼”入口，显示世界树三位导师的**一句话定位、资源循环、推荐武器、难度标签**，不直接展示所有精确数值；地图隐藏传承只显示模糊传闻及其所在区域方向。

## 11. 实现数据与结算要求

### 11.1 建议数据模型

| 数据 | 形式 | 用途 |
| --- | --- | --- |
| `characters.advanced_profession_code` | 可空字符串 | 保存已选二转分支，不污染基础 `profession_code` |
| `advanced_profession_definitions` | 配置表 | `code`、基础职业、名称、定位、资源定义、本职被动与旁修被动数值、技能编码、解锁条件 |
| `player_advanced_professions` | 角色进度表 | 选择时间、重置冷却、已获技能点、终结技解锁状态 |
| `player_stolen_passives` | 角色旁修表 | 来源二转编码、导师旁修课完成时间、是否已解锁、当前是否装备；每名角色最多 1 条 `equipped=true` |
| `player_advanced_profession_quests` | 任务进度表 | 分支编码、当前段数（1–3）、材料计数、导师 Boss 首通时间；改宗后保留已读剧情，不保留未完成的另一分支材料 |
| `player_hidden_advanced_discoveries` | 角色发现表 | 隐藏 NPC 编码、首次发现时间、线索进度；不因改宗而清除 |
| `map_npcs` 扩展 | 复用现有地图 NPC 表 | 12 位世界树导师与 8 位隐藏传承者的名称、坐标、互动类型；隐藏 NPC 通过发现表决定是否展示详情 |
| `combat_profession_resources` | 战斗会话表或 `combat_members` JSON | 每个战斗成员当前资源、上限、每回合触发上限 |
| `combat_status_effects` 扩展 | 复用现有表 | 易伤、追猎、守护、祷言、元素印记等状态；来源应能追溯 |

技能定义继续复用现有 `skill_definitions`、`skill_effects`、冷却和目标范围字段。只有“消耗/获得资源”“消耗特定状态”“协同追击”“灵体固定结算”需要在战斗服务加入数据驱动的专属处理器；不要将每个二转技能的名称硬编码进主回合循环。

传承被动建议存为统一的 `passive_definitions` 配置：`trigger`、`conditions`、`native_values`、`borrowed_values`、`per_turn_limit`、`cannot_retrigger`。战斗开始时将本职被动与已装备旁修被动展开为实例；同名状态取高值，伤害转移、协同与反击实例必须写入 `cannot_retrigger=true`，不允许用职业名称分支判断。

### 11.2 推荐结算顺序

```text
提交所有行动
  → 按速度排序
  → 校验冷却、MP、专精资源、目标状态
  → 支付 MP/资源
  → 施放前状态与护盾/减伤修正
  → 命中、伤害/治疗、状态施加
  → 处理一次协同追击或元素反应
  → 更新仇恨、获得资源、写入战斗日志
敌方行动
回合末：持续伤害、再生、护盾/状态时长、灵体固定行动、层数衰减
```

### 11.3 必须避免的实现问题

1. 不能让二转被动改变基础职业成长写回角色成长字段；成长应由基础职业统一结算，二转被动在派生属性/战斗修正层叠加。
2. 任何一次行动的资源变化上限为 100；一次伤害事件最多触发一次资源获得，防止范围多段无限充能。
3. 效果作用到已死亡、逃离或不存在的目标时静默跳过且写调试日志，不能中断整场队伍战斗。
4. 召唤灵体、协同追击、转移伤害均必须设置“不可再触发”标记，杜绝递归。
5. PvP 初期建议关闭“濒危不倒”和所有硬控制的额外行动剥夺；待专门平衡后再开放。二转首版应先在 PvE 进行完整验收。

## 12. 平衡与验收

### 12.1 平衡红线

- 同档装备、同等级、单体木桩 8 回合模拟中，单体主输出（断钢/夜刃）相对基础职业提升目标为 `15%–22%`；辅助/坦克自身伤害提升不超过 `10%`。
- 元素使对 3 个目标的总输出可高于单体流派，但单目标 8 回合输出不得高于夜刃的 `90%`。
- 圣愈者与圣盾使在四人首领战的总有效治疗/减伤接近；前者在突发低血回合更强，后者在可预读大招回合更强。
- 一名盾卫不能在同档首领连续 3 回合无治疗支援下稳定承受全部伤害；一名牧师也不能单独抵消首领的全体大招。
- 终结技应是“每场 1 次左右的关键窗口”，而非每两回合可用。平均充能速度目标为 4–6 回合，且需要正确的职业行为而非仅普攻。
- 单条旁修被动在 8 回合首领战中的平均有效收益（伤害、治疗、减伤、资源按等价折算）不得超过本职被动的 `70%`，且不能使原本无护盾/净化/控制的职业稳定获得完整同类循环。群怪特化的“收潮”等被动在单 Boss 战必须明显降效。

### 12.2 最小测试矩阵

| 场景 | 队伍 | 验收点 |
| --- | --- | --- |
| 单人普通怪 | 每个二转各一套同级白板/打造装 | 不因资源机制导致比基础职业更慢或无法自给 |
| 旁修组合 | 每个二转各装备 1 条异职业被动，覆盖护盾、净化、减益、击杀、伤害转移触发 | 每回合至多触发一次；按旁修数值结算；同名状态不叠层，伤害转移/反击/协同不递归 |
| 双人精英 | 坦克 + 每种输出/辅助 | 资源获得、守护、追猎、元素印记均可被理解地触发 |
| 四人群怪 | 壁垒开荒、元素压场、游击控制 | 范围伤害、控制抗性、协同上限不会造成连锁卡死 |
| 四人首领 | 壁垒开荒、破阵速攻、蚀毒消耗 | 治疗/护盾不溢出为无敌，输出窗口可被首领反制 |
| 异常状态压力 | 含眩晕、束缚、减速、持续伤害的敌人 | 净化、抗控、首领硬控降级、状态到期顺序正确 |
| 回归/重置 | 已二转角色切换分支 | 不丢基础技能、装备、副职业、任务；战斗中不可重置 |

每次调整须记录：平均回合数、队伍剩余生命/魔力、药剂消耗、各职业资源获得/溢出次数、终结技实际施放回合、协同触发次数。若某一分支只能靠特定另一分支才能正常运作，应降低前置条件或补充独立触发路径。

## 13. 分阶段上线建议

1. **第一阶段：框架与四分支试点**：盾卫、元素使、夜刃、圣愈者。先验证守势、奥能、破绽、信念和四类基础协同状态。
2. **第二阶段：世界树其余八分支与导师**：复用试点结算器，补齐 12 位常驻导师，重点验证灵体固定结算、协同追击、驱散和护盾转移。
3. **第三阶段：八条隐藏传承与地图线索**：先接入 NPC 发现记录、地图标记与两段式前置，再按区域等级依次开放；隐藏分支不得仅靠更高数值压过世界树常驻分支。
4. **第四阶段：内容接入与 PvP**：为 Lv.25–50 区域首领增加可读的元素弱点、可驱散增益、群体压力与处决窗口；PvE 数据稳定后，再单独设计 PvP 系数、控制抗性和终结技限制。

这套体系的完成标准不是“二十个职业都能打出更高数字”，而是玩家能在战斗日志、导师试炼、地图发现和队伍配置中清楚感受到：谁负责创造窗口、谁负责吃下压力、谁负责把窗口兑现为胜利。
