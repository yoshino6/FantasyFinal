# 格鲁恩与瓦尔克：单体压制强化方案 V3（机制惩罚修订）

状态：待确认方案，未实装。此次按最新要求替换之前的审判设计。

## 1. 本次定案方向

取消固定回合判负、终末审判、限时秒杀，以及单独新增的“必须打断否则团灭”大招。通过现有技能与BOSS特性产生压迫力：

- 格鲁恩：高压岩甲反震；不泄压会让山体修复，打得越急越容易得不偿失。
- 瓦尔克：炉火造成降疗与短时禁疗；孤立违令或放任炉温失控，会给BOSS提供修复资源。
- 正确操作能解除负面影响并获得输出窗口，不设置整场倒计时。
- 治疗可以救场，但不能代替泄压、停炉与团队分工。持续走对机制的低输出队伍允许慢慢取胜，不因职业或战斗时间被强制处死。

仅修改格鲁恩、瓦尔克的方案，另外三只BOSS不动。基础六维、成长、难度通用属性、常规技能基础威力、元素抗性、地图和掉落不变。普通档有完整机制，高难只通过专属词条强化，不增加梦幻基础属性。

本文替代此前V3新增的高额百分比群伤堆叠、劳损、共振余震和审判章节，不能把旧方案与本修订同时叠加。现有源码的普通攻击循环保留，具体替换项如下。

## 2. 统一规则

### 2.1 公平性与时序

- 触发条件的回合战报先发，必要的新状态/形态预警后发；需要响应的新惩罚从下一完整玩家轮开始生效。
- 不根据治疗职业、血量厚薄或本场治疗总量额外处罚，只根据公开战斗状态与机制结果。
- 不新增穿透无敌、免死、时间守护的规则。反震仍经过护盾与适用保护，不直接设置角色死亡。
- 普通机制成功不得重置BOSS阶段。BOSS回血跨过阶段血线，也不倒退阶段、不重复播放转场或刷新限次资源。
- 退出重进按既有规则恢复BOSS初始状态；重载同一会话则保留状态和计数，不能刷新负面或重复回血。

### 2.2 恢复与降疗口径

降疗针对“接受生命恢复的目标”，而非施法者，覆盖技能、持续治疗、药品、吸血、被动回血、生命再生和固定/比例回复。统一在治疗管线最后应用一次，不能各入口重复相乘；溢出治疗不产生额外收益。

- 同类降疗取最大值，不相加；本方案普通降疗上限75%，禁疗为短时100%。
- 不削减MP恢复，不自动削减护盾；护盾救场属于合法应对，但不能解除BOSS回血或炉温。
- 免死保留生命、复活及其初始生命按原有独立语义处理，不因禁疗取消。复活不视为净化；随后治疗仍受剩余负面影响，不刷新禁疗计时。
- BOSS机制回血走正式治疗管线，受玩家合法降疗、禁疗影响。优先通过机制阻止回血，也允许相关构筑提供另一种应对。
- 回血上限为当前生命上限，不复活已死亡BOSS，不增加生命上限，也不把溢出自动变成护盾。
- 新增BOSS机制回血全来源合计每轮最多恢复其最大生命10%；专属词条最多15%。均按最终实际恢复累计，不因多人失误逐人乘算。
- 普通回血不无限永久加攻击，所有层数有上限。反复失败仍可反复修复：这是防止忽略机制磨死BOSS的关键，不能设成“熬完两次回血就永远没有”。

## 3. 格鲁恩：高压反震与山体修复

### 3.1 保留当前压力与阶段骨架

初始压力20；普攻+6，直击技能+10，纯辅助/道具/充能-8，防御-18；承重点原附加规则保留。混合技能实际有直击时按攻击技能分类。追击、反击、DOT、宠物不重复增加行动压力。

70%/35%阶段、原崩震循环、高压本体易伤收益、第三阶段移除测重均保留。山崩保持现有35%最大生命伤害基线，不采用上一版50%/60%的新数值；其他崩震也不新增25%/45%的百分比群伤。

### 3.2 新被动：逆震岩甲

压力达到60以上并保持到回合结束时，格鲁恩岩甲闭合，发出叙事预警；下一完整玩家轮才可反震。

| 攻击命中前压力 | 反震比例 |
| --- | --- |
| <60 | 岩甲关闭，不反震 |
| 60–84 | 本次对BOSS实际生命伤害的20% |
| 85–100 | 本次对BOSS实际生命伤害的35% |

具体规则：

- 只反弹玩家主动普攻/主动技能的直接伤害；物理与魔法都适用，不改变现有元素弱点。
- 以扣除BOSS减伤与护盾后的实际扣血计，排除溢出。反震不再计算一次BOSS防御、元素或暴击。
- 多段按同一个玩家行动累计，每名玩家每个正常回合反震原始伤害总额最多为其最大生命15%；额外行动共用上限。
- DOT、反击、独立追击和召唤物不触发反震；不会将宠物伤害转嫁给主人。此类构筑仍要面对山体修复，不能将“所有流派必须同样挨反伤”作为设计目标。
- 反震不再反弹、不触发额外追击/吸血/连锁。通过正式受伤结算，护盾与保命正常生效。
- 本次攻击直接击杀BOSS，不结算死后反震；正常胜利优先。
- 读取攻击前压力，当前行动造成的加压随后结算，不追溯惩罚刚把压力抬到60的这一次攻击。
- 有效泄压使压力降至60以下时立即关闭。若同轮重新涨至60，需回合末再次预警，下轮才重新启用。

结果：高压输出依然有收益，但不能持续站桩无代价吃易伤红利；可以先泄压关闭岩甲，也可以消耗盾与治疗主动承担有限反伤。

### 3.3 强化现有技能：崩震后地脉回流

只在现有崩震真正执行后，根据该次崩震结算前压力判断，不按成员逐个判定：

| 崩震前压力 | 新增结果 |
| --- | --- |
| <30 | 逆脉卸力，无修复；保留失稳输出窗口 |
| 30–59 | 正常崩震，无修复 |
| 60–84 | 崩震后恢复BOSS最大生命6% |
| 85–99 | 崩震后恢复BOSS最大生命10% |

- 不是每轮被动回血，只在高压崩震失败时恢复。
- 主动泄压到60以下即可阻止回血，降到30以下仍有额外输出奖励。
- 回血发生在攻击结果之后；若同次合法结算中BOSS已经死亡，不再回血。
- 修复不叠新的护盾，也不清空玩家施加的全部减益。
- 不新增“半队必须做某动作”的硬性人数检查。多人压力通过实际行动涨压自然产生，团队可以自行决定分工。

### 3.4 压力100：山崩与岩层重铸

达到100时锁定山崩预兆，替代旧的“单个玩家行动后立刻山崩”。本轮结束发预警，下一完整玩家轮结束：

- 若已降至85以下：取消山崩，不触发修复，也不补一个常规崩震。
- 否则：执行现有35%最大生命山崩与原减速/易伤，随后BOSS恢复最大生命10%，压力重置35。
- 不再移除普通护盾，让队伍有保护补救；伤害与适用防御/减伤按现有管线计算一次。
- 山崩替代该轮常规崩震，不重复回血、追震或额外本体行动。
- 清算后压力重置35，岩甲随之关闭，留下重整窗口。

这不是新增审判大招，而是给现有压力失控增加可响应窗口和修复后果。不断硬吃山崩再奶满，会使已经打掉的BOSS生命反复恢复。

### 3.5 专属词条：围绕压力强化，不同时全面加码

以下替换当前词条效果，不在旧效果上继续叠加：

- **山心共振**：逆震岩甲反震比例改为30%/45%，每名玩家每正常回合上限改为最大生命20%；取消旧的“高压直击额外+50%、穿防25%”，避免同时强化全部伤害通道。
- **地脉复铸**：高压崩震修复改为8%/15%，山崩修复改为15%；替换旧的“首次逆脉卸力后20%生命护盾”。正确卸力不再反而奖励BOSS护盾。

格鲁恩不再另加降疗或禁疗，保留与瓦尔克的差异。

## 4. 瓦尔克：灼伤压制治疗，错令给炉心供能

### 4.1 保留炉令与集体停炉

轻锤=普攻、重锻=主动技能、固炉=防御/道具/充能；停炉要求与领班投票规则保留。硬控停工者不计有效分母，也不算错误动作。

- 集体违令是正确解法，不受新增“违令惩罚”。
- 保留原鞭痕代价及孤立惩戒6%，不采用上一版15%/25%的追加伤害与个人劳损。
- 成功停炉保留破绽、降温与隔次取消工序，并获得下面的冷却疗伤效果。
- 全员无法有效行动时，不能凭零人判定成功或BOSS回血；原有待结算炉令顺延一轮。

### 4.2 强化炉渣喷流：灼封伤口

赤热阶段现有“炉渣喷流”命中玩家时，附加1层灼封；白热裁决只给主目标附加1层，不给每个溅射目标额外上层。基础技能威力与命中判定不变。

- 每层使目标接受生命恢复降低25%，最多3层，即25%/50%/75%降疗。
- 首次附加的回合只显示灼封状态和异动，从下一正常回合开始影响治疗，避免同轮速度顺序让治疗忽然失效。
- 新增层也从下一正常回合生效，不能追溯削减已经完成的治疗；每人每轮最多新增1层。
- 每次附加后保留至接下来两个完整玩家轮结束，同层不重复施加多个乘区。
- 可以通过适用的负面净化清除；每次成功集体停炉，全队灼封清1层。
- 成功总罢工清空全队灼封；炉温连续一个完整回合低于30，也清空全队灼封。
- 没有净化职业也可通过停炉和降温解除，不以带某职业作为硬门槛。

作用：高温持续挨打后，只奶不处理炉温，治疗效率越来越低；正确停炉会同时恢复治疗空间。

### 4.3 封炉失败：短时禁疗，而不是秒杀

沿用现有100炉温预警、补发炉令、完整响应轮和“成功停炉取消清算”：

- 清算本身仍使用现有普通技能威力，不新增45%/60%最大生命伤害。
- 未停炉成功：除既有伤害、鞭痕和温度重置外，全队获得“焦灼封脉”，从下一正常回合开始禁疗，覆盖恰好一个完整玩家轮。
- 禁疗不能因为多段、额外回合或重复消息延长。持续期间再次触发也不刷新，结束后至少一个完整玩家轮不能再次被本机制禁疗。
- 封脉可被适用净化解除；成功集体停炉也立即解除；护盾、防御、免死和复活仍保留原作用。
- 封脉结束后只保留未自然到期的灼封层数，不自动再补3层降疗。
- 禁疗产生于封炉机制明确失败，不是BOSS随机普攻就封死全队治疗。

### 4.4 新被动：炉心汲养

两类错误给BOSS修复机会，每次炉令/工序事件只结算一次：

| 事件 | BOSS恢复 |
| --- | --- |
| 有人违令但未达到停炉票数 | 最大生命6% |
| 封炉清算未被取消 | 最大生命10% |
| 第三阶段总罢工失败 | 最大生命10% |
| 集体停炉或总罢工成功 | 不触发上述恢复 |

- 孤立违令的回血按本次事件算，不是每个违令者各回6%；鞭痕伤害及原抽检仍走既有逻辑。
- 同轮同时符合孤立违令与清算，只取高者10%，不叠为16%；总罢工与封炉同轮到期时优先总罢工，另一清算取消，不延迟补罚。
- 满员全服从时保留现有3%回血、全场最多两次，不新增常驻每轮回血。全服从会继续加温，随后面临可取消的封炉。
- 总罢工成功后永久关闭炉心汲养，清除灼封与封脉，保留原双防降低及温度上限80。玩家赢得机制后应能收尾，不继续刷新新的回血惩罚。
- 失败回血可受玩家降疗/禁疗影响；不能把这写成绕过所有技能效果的直接改血量。

### 4.5 专属词条

同样是替换旧效果，不与旧版追加灼烧/附伤全部叠加：

- **永燃余烬**：封炉失败后炉温仍重置75；灼封延长为接下来3个完整玩家轮，层数上限仍为3。移除旧的额外5%灼烧3回合，不延长禁疗时长，不取消禁疗后的保护间隔。
- **拘魂连锻**：孤立违令回血改为8%，清算/总罢工失败回血改为15%；替换旧抽检后其他违令者4%最大生命附伤。成功总罢工仍能永久关闭这部分回血。

瓦尔克不另外加伤害反弹；治疗压制与炉令协作已经足够构成独立打法。

## 5. 两只BOSS的玩法区别

| 项目 | 格鲁恩 | 瓦尔克 |
| --- | --- | --- |
| 无视机制的代价 | 继续攻击会反震，高压崩震修复山体 | 灼封使治疗打折，错令使炉心回血 |
| 玩家主要决策 | 泄压关闭岩甲，或用保护承担有限反震 | 分配服从/违令，控制炉温并留净化 |
| 能否靠奶代替机制 | 奶能挡反震，却不能阻止高压回血 | 奶受灼封限制，也不能代替集体停炉 |
| 正确应对的收益 | 关闭反震、阻止回血、低压失稳输出 | 恢复治疗、阻止回血、停炉破绽 |
| 明确不做 | 禁疗、固定期限、无限反伤 | 反伤、无限禁疗、正确违令也被罚 |

不承诺“任何纯治疗队伍绝对不可能赢”。若队伍一直正确处理机制并有有效伤害，允许长线取胜；要限制的是忽略机制依靠血厚硬磨，而不是禁止持久战本身。

## 6. 展示、自动战斗和结算要求

- 战斗面板显示可观察的岩甲、灼封、封脉及原有压力/炉温，不展示公式、破解人数或最佳操作。
- 岩甲首次闭合、首次灼封、封脉等关键变化在触发回合完整战报后提示；治疗被削减时在实际治疗日志中显示有效回复，避免玩家误以为技能失效。
- 格鲁恩反震日志与BOSS修复日志需准确反映实际伤害/实际回血，不能把上限前数值写成最终结果。
- 自动战斗识别反震风险、灼封/封脉、停炉与修复条件；不在禁疗时无意义连续施放纯治疗。
- 自动使用玩家实际可用的保护、净化和道具，不擅自改配置或替手动队员操作；混合手动行动必须纳入压力及票数预测。
- 纯净化技能是否降低压力按原动作分类；有直击的混合技能不能借“附带治疗”伪装成泄压。
- 成功净化后，同一技能随后发生的治疗可正常生效；先治疗后净化则治疗受抑制。遵守技能既有事件顺序，不暗改所有技能顺序。
- 反震、降疗、BOSS修复都走统一服务结算，不能只在面板或普通攻击入口实现。

## 7. 验证计划与实施顺序

先验证通用治疗与反射管线，再接格鲁恩压力条件、瓦尔克灼封和汲养；最后更新自动策略与提示。本文未执行这些实施步骤。

必须测试：

1. 两只×1–4人×现有难度，对比正常机制、偶发失误、全程站桩和纯治疗拖延。
2. 记录每轮BOSS实际回血、玩家实际有效治疗、反震、净化和输出窗口；不能只看平均总伤害。
3. 格鲁恩多段/群攻只按实际生命损失计，溢出、DOT、追击、反射链和额外回合不绕过或重复上限。
4. 60/85/100压力边界、首次预警、同轮降压再升压、山崩取消与高压回血均符合时序。
5. 药品、持续治疗、吸血、被动、比例回血都只应用一次降疗；护盾、免死和复活不被误删。
6. 禁疗有完整一轮上限和至少一轮间隔；无净化队伍仍能通过停炉/降温处理，不形成无限封疗。
7. BOSS多来源回血去重，最大生命上限、玩家禁疗、阶段锁定和死亡优先均有效。
