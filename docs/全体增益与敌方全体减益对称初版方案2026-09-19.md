# 全体增益与敌方全体减益对称调整初版方案（2026-09-19）

## 1. 本轮目标

把“对敌方全体攻击附带的减益 debuff”与“对我方全体施加的增益 buff”按同一数值预算对齐：同档位、同冷却、同行动成本的技能，无论加在我方身上还是减在敌人身上，净收益应大致相同。数值不要求严格相等，允许按技能强弱、命中条件、吟唱、资源成本在约 5%～10% 内波动。

### 1.1 双方数值换算基准

我方增益 `G` 与敌方减益 `D` 按“提升倍率相等”换算：

```text
1 + G = 1 / (1 - D)
所以 D = G / (1 + G)
```

| 我方增益 G | 敌方减益 D |
|---:|---:|
| +10% | -9.1% |
| +12% | -10.7% |
| +15% | -13.0% |
| +18% | -15.3% |
| +20% | -16.7% |
| +25% | -20.0% |
| +30% | -23.1% |
| +35% | -25.9% |
| +40% | -28.6% |
| +50% | -33.3% |
| +60% | -37.5% |
| +100% | -50.0% |

反向同理：敌方减益 `D` 对应我方增益 `G = D / (1 - D)`。

### 1.2 分档参考区间

| 档位 | 我方全体增益 | 敌方全体减益 | 说明 |
|---|---:|---:|---|
| 基础 | 攻击/减伤 8%～10%；命中/速度/闪避 16%～20% | 攻击 8%～9%；易伤 10%～12%；命中/速度/闪避 16%～18% | 低冷却、低成本、可循环 |
| 下位 | 攻击/减伤 12%～15%；命中/速度/闪避 24%～30% | 攻击 11%～13%；易伤 14%～17%；命中/速度/闪避 22%～26% | 有明显用途，冷却 1～3 |
| 中位 | 攻击/减伤 15%～20%；命中/速度/闪避 30%～40% | 攻击 13%～17%；易伤 16%～21%；命中/速度/闪避 26%～34% | 冷却 3～6，允许高条件或吟唱 |
| 二转专属 | 攻击/减伤 12%～20%；命中/速度/闪避 24%～40% | 攻击 12%～18%；易伤 15%～23%；命中/速度/闪避 24%～36% | 由职业定位和专属资源决定 |

调整规则：

1. 吟唱、高蓝耗、长冷却、需要专属资源的技能取区间上沿，可再高约 10%～20%。
2. 复合多 Buff 技能按总预算分摊：2 项各取单项的 65%～80%，3 项各取 45%～60%。
3. 命中、速度、闪避等“对抗/行动”属性数值固定按同档攻击数值的 **2 倍** 取值；暴击/抗暴类可取 1.6～2 倍。例如攻击增益 12% 时，速度/命中增益为 24%；攻击减益 12% 时，速度/命中减益为 24%。
4. 回合减伤/受伤降低直接参考同档攻击数值：攻击增益 12% 时，减伤增益取约 12%。敌方易伤/受伤增加可以比攻击减益偏高约 20%～30%（约 1.2～1.3 倍）：攻击减益 12% 时，易伤可取 15%～16%。护盾、再生、驱散、硬控是独立机制，不套用属性换算，但护盾量按同档资源成本单独对齐。
5. 控制概率不按属性对称换算，保留概率、韧性、Boss 抗性边界；只有“命中/闪避/速度/攻防”等属性减益参与换算。
6. Boss 机制技能可以超过玩家上沿，但必须由阶段、部位、预警或高冷却承担成本；数值不再无条件比玩家高一倍以上。
7. 怪物技能整体允许比玩家同档略强，但超过玩家基准的比例不超过 50%（即怪物数值 ≤ 玩家基准 × 1.5），且仍遵守档位边界与机制成本；Boss 专属阶段技能不受此限，但要有阶段、部位或预警成本。
8. 命中率修正类按现有“补足未命中部分”语义结算，不以最终百分点直接等同于属性百分比。
9. **单体技能也按本方案调整**，缩放基准：给自身的增益约为群体的 2～3.5 倍，给队友的增益约为群体的 1.5～2.5 倍，给敌方的减益约为群体的 1.5～2.5 倍；双目标按单体的 70%～80% 取值，再套 2 倍规则。

### 1.3 单体缩放基准

以下“单体参考值”按“群体参考值 × 缩放倍数”计算，数值允许按技能强弱微调：

| 档位 | 群体参考 | 单体自身增益 | 单体队友增益 | 单体敌方减益 |
|---|---|---|---|---|
| 基础 | 攻击 8%～10%；速度/命中 16%～20% | 攻击 16%～35%；速度/命中 32%～70% | 攻击 12%～25%；速度/命中 24%～50% | 攻击 12%～25%；速度/命中 24%～50% |
| 下位 | 攻击 12%～15%；速度/命中 24%～30% | 攻击 24%～52%；速度/命中 48%～105% | 攻击 18%～37%；速度/命中 36%～75% | 攻击 18%～37%；速度/命中 36%～75% |
| 中位 | 攻击 15%～20%；速度/命中 30%～40% | 攻击 30%～70%；速度/命中 60%～140% | 攻击 23%～50%；速度/命中 45%～100% | 攻击 23%～50%；速度/命中 45%～100% |

双目标技能取单体参考值的 70%～80%；三目标再酌情下调。纯伤害、纯控制概率、护盾/再生/净化类仍按既有机制处理，不强制套用此表。

## 5. 万法同劫转全体时的附效规则

`boss-random-effects.config.ts` 的 `all_methods_calamity` 目前把单体技能改为全体时只把威力折为 65%，附效数值不变。按本轮对称原则，转全体时：

1. 威力仍按原 65% 折算。
2. 属性类减益改为原单体的 50%，且速度/命中/闪避保持攻击档 2 倍（如单体 -30% 减速 → 全体 -15%）。
3. 双属性减益各改为原单体的 60%～70%（如单体双防 -20% → 全体各 -12%～-14%）。
4. 减伤类效果改为原单体的 50%（如单体减伤 30% → 全体 15%）。
5. 硬控概率改为原单体的一半，且仍受韧性/Boss 抗性约束；Boss 阶段机制不参与折半。
6. 持续伤害按原单体的 50% 数值执行，并遵守每目标 DOT 上限。

## 9. 本轮补充说明
