# 副职业成品售价与失败损耗修订

日期：2026-09-06。适用于铁匠铺、糖水屋、异工坊当前基础成品货架。

## 定价规则

成品零售价上调到原价至少两倍，概率制作再加失败损耗。玩家卖给商店的回收范围、回收倍率和实际到账规则保持原样；本次不以成品的 `trade_price` 直接生成零售价。

- 铁匠铺：采用制式装备独立零售价 `blacksmith_shop_items.buy_price` 的两倍，缺少该条目时使用同等级制式装备价格。Lv.5/10/15 分别为 400/800/2000 铜币。常规打造成功率为 100%，不添加虚构的失败费；维修包由 80 调整至 160 铜币。
- 异工坊：基础材料的既有锚价属于半价回收值，先乘 2 还原获取成本；逐层展开构件、基材与最终异械的制作配方。最终售价至少为旧售价两倍，再按累计失败净消耗上浮。
- 糖水屋：以原货架零售价两倍为起点，再摊入标准供货条件下的炼金失败损耗；洗练露同时计入魔力粉尘和草木萃取液的前置失败损耗。

每成功一批的材料倍率为：

`(1 - (1 - 成功率) × 失败返料比例) / 成功率`

例如成功率 50%、失败不返料时，材料成本为 2 倍；失败返还 80% 时为 1.2 倍。前置步骤先算自身期望成本，再计入下一步的投入，避免漏算或重复摊销。

炼金供货采用店主 Lv.3、同档低阶材料、主辅不额外叠加同标签稳定度、粒子催化剂的预算：本体成功率 86%，前置萃取 87%。与实际炼金共用成功率公式。不同玩家的真实配方成功率可能不同；此处是固定零售预算，未把随机大成功、多产、额外匠心或最佳标签搭配当成稳定收益来压低售价，也未改动玩家的实际炼金概率。

在店主等级下必定成功且前置步骤也无失败的异械，保持两倍基础价；有失败步骤时按上述公式继续上浮。高阶商品仍不向基础货架开放。

## 验证

货架显示、成品购买、旧购买命令使用同一价格函数；服务端按最新规则扣款，不采信旧消息中的价格。真实 SQL 测试验证洗练露货架价与扣款均为 838 铜币。

`npx tsc --noEmit` 通过；50 项相关回归全部通过，无失败或跳过，覆盖失败返料、递归前置成本、基础商品翻倍、隔离库购买扣款和原有收购。未向真实玩家执行买卖，未进行 QQ 客户端点击验证。
