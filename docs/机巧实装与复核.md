## 共同经历

入口为“机巧 → 详情 → 回忆”，也可输入 `机巧 回忆 <人偶编号>`。默认仅在私密会话展示，按发生时间倒序，每页5条。

记录的重大事件包括：

- 诞生、与当前玩家初识、认主、命名、第一次随行。
- 第一次并肩作战、第一次共同胜利、第一次战胜每一种正常 Boss、第一次实际挡刀。
- 每次十级突破，以及其他等级实际领悟新技能。
- 战斗停机、维修后醒来或休整到期后醒来；队伍获胜也不会漏掉人偶停机。
- 久别至少三天后的重逢、亲密阶段突破、归档休眠、恢复展示、回路重调。

每条保存发生时间和名字快照，并按事件保存突破等级、新技能、Boss 名称与等级、命名前后名字等事实。当前名字另行显示。自然恢复使用实际到期时间，避免把刷新面板的时间误写成醒来时间。

事务中的唯一事件键防止重复确认、重复结算和刷新重复记事。跨多个十级的培养逐级记录突破；重调保留旧成长日志，不重新抽技能或重复产生突破记录。历史初识、随行、参战、胜利和十级突破可以依据旧操作日志补记，沿用原日期；没有日志证据的经历不推测、不补造。

重大事件不会受语录180天去重窗口影响。回忆只展示重大经历，不再提供语录收藏与分享；历史收藏数据保留，不迁移或删除。

## 机巧主流程

- 四级解构师制造灵枢素体，并可预览、确认补齐缺少的前置构件；已有构件优先，不重复展开扣料。
- 四级炼金师制作纯粹的灵魂痕迹、点灵和12种育成原液。点灵失败仅消耗2份天空粉尘，未形成新实例；低境界额外保留主线粉尘。
- 出生保存实例种子、12核心性格之一、4条兼容词条、1～2个普通技能。技能库包含96普通技能与32特殊技能，领悟按强度权重和性格倾向抽取。
- 只通过投入原液获取经验。培养支持混合顺序、带材料来源的余额和目标等级；每级15项属性按性格与材料权重随机分配，普通级30次、十级120次抽取。
- 培养预览展示耗材与预计等级，隐藏人格相关抽取概率；确认后展示实际属性前后数值。拆分培养与批量培养一致，包含受伤时的生命、魔力取整。回路重调不重抽技能，原料与手续费分开计算。
- 主人等级或境界回退时，只截取已有成长记录形成当场有效面板，不改写人偶原始等级、技能和成长。
- 人偶是独立战斗单位，有自己的行动、资源、冷却、控制状态和护主行为，使用人物同一套伤害公式，无额外0.60伤害折扣。主目标跟随主人；不能穿戴装备或分享战斗经验。
- 整个设置页及旧设置指令已取消。改名仅保留详情名称旁入口；随行即参战，收起即离队，简单操作直接完成。旧策略、挡刀开关、手动战斗指令和陪伴模式不参与运行决策。技能选择、护主与称谓按隐藏性格和当前局势决定。

## 语录与绑定复核

语录使用1296条完整种子句，按人格、事件和真实事实筛选，称呼、自称来自出生性格。认主成功额外打招呼；主动问候、日常问候、材料升级及休息回应、战斗对白均使用独立消息。群聊也可触发内置互动，旧自定义语句不会因此公开。认主与成长对白使用确认令牌记录投递状态，明确失败可重试原句，成功或投递不确定不重复发送；语录失败不回滚已完成的操作。战斗历史保留完整原文，消息展示时拆出对白，普通战斗、自动战斗和伏击接管共用拆分规则。

有限词库耗尽时安静陪伴；没有部署生成模型，也不宣称已经实现无限对话或连续30天每日问候均不重复。模型训练、更多语气片段、演示战等仍属于设计文档的后续建议。

绑定库存分为个人绑定、交易绑定和未绑定，按此前确认的规则优先消耗绑定份数。不可逆制造的新成品可重新交易，个人专属限制继续保留；拆解、互转和容器产物继承对应绑定。实例成交保留原ID和属性，购买后绑定，认主/装备/启用异械后个人绑定。寄售中的实例不能使用或改造。

本轮复核补充了商店购入、仓储转存、盲盒产物、精炼熔铸个人材料以及旧装备触发器升级的边界；被绑定的库存不进入战败掠夺候选。已使用的旧实例依据真实装配状态或使用标记补绑定，其他旧库存不凭空推测过去交易史。

## 本轮面板复核

- 主面板加深显示认主与随行数量，列表普通文本展示等级、归属、绑定状态，无刷新按键。
- 性格词条和技能倾向隐藏，包括实例寄售及培养预览。
- 详情使用阴影进度条与百分比显示培育度，属性成对排列，正确标签为“暴免／暴抗”。
- 底部三行按钮为“技能／成长／回忆”“培养／维修”“返回机巧”；未认主人偶显示认主。技能、成长和材料选择均分页，避免平台按钮超限。

## 验证及边界

- TypeScript：`npx tsc --noEmit` 通过。
- 本轮机巧成长、战斗及消息结构测试20项通过，覆盖旧策略不生效、性格护主、详情按钮、独立对白与发送失败回执。此前134项相关回归作为历史记录，本轮未重跑全部无关模块。
- 隔离数据库：18项通过，新增首次认主问候并发、失败重试、发送后幂等、旧设置确认拒绝与随行兼容旧陪伴模式检查；覆盖可重复初始化、绑定优先、点灵失败净扣料、双确认、认主、培养、事务失败回滚、十级留档、历史名字、问候投递、战斗重大事件、停机恢复、旧日志补记、实例寄售、使用绑定与素体构造链。
- SQL 测试仅使用新建的 `fantasyfinal_automaton_test_*` 数据库，确认不是业务库且不存在后才创建，结束后删除该测试库。
- `git diff --check` 通过。

这些结果不代表真实 QQ 客户端已经验收，也不代表线上多人 Boss 战斗、长期经济供需或全部人格食谱的实战平衡已经实测。本轮没有执行生产发布或推送分支；上线前仍需在实际客户端验证消息和战斗表现。数值测算属于可复算预算，不能替代真实战斗与玩家市场数据。

## 2026-09-07：晴儿的四级炼金教学

- 当前炼金师达到 Lv.4 后自动登记支线「瓶中之外的世界」；任务栏、炼金面板与糖水屋提供前往或交谈入口。更新前已达四级的玩家也会补触发。
- 在晴儿所在坐标交谈后，保存支线完成时间，解锁 `[造物] [育成]`。重复交谈可重温剧情，不改写首次完成时间。
- 新指令为 `/炼金 造物`、`/炼金 育成`；投料、确认、继续尝试、取消和返回均沿炼金入口衔接。旧的 `/机巧 造物`、`/机巧 育成` 提示迁移。
- 未学习时，炼金面板与手记不显示造物、育成链接；服务端阻止提前查看配方、投料和确认制造。已购买机巧与原液的普通玩家仍可正常认主、培养。
- 复用 `player_side_quests`，任务代码 `alchemy_world_beyond_bottles`，无需新增表。灵枢素体仍由四级解构师构造，晴儿不提供代工。

教学剧情：

> 晴儿从柜台下翻出一本卷角手记，纸页间滚出一枚小齿轮。“药瓶可装不下炼金的全部秘密。”她笑着画下灵魂与躯壳相连的阵纹：“这叫造物；再以不同原液滋养，便是育成。它会慢慢长出自己的本领和脾气。”你正要伸手，她却合上手记：“先别急！灵枢素体得找四级解构师想办法构造。我教你点亮它，可不替你拧螺丝哟。”

配方与页面补充：造物、育成页使用同一分组引用模板，材料按「持有量/所需量」显示，底部为「返回机巧」按键。专用配方的概率是炼金四级基准：灵魂痕迹80%、点灵60%、育成原液90%；四级后每级增加5个百分点，封顶100%。点灵每次仍需20粉尘，失败只耗2；十一级成功率95%。预览与实际判定共用概率函数，并在确认时校验等级和版本；手记保存实际等级、概率。四级每具人偶平均净耗粉尘约21.3333份，制造预算已同步重算。

本次复核：`npx tsc --noEmit` 通过；隔离数据库测试18/18通过，包含四级教学门槛、现场交谈、重复提交、各级成功率、60%临界判定、20/2粉尘消耗与旧确认拒绝。实际 Format 页面生成检查通过，造物/育成均有分组加粗引用、数量比、配方链接及底部返回机巧。未进行真实 QQ 客户端验收，未推送或发布。

## 名称与互动显示补充

战斗中的机巧只显示本名，玩家召唤物、机巧和 NPC 随从使用 `〖名称〗`，涵盖行动、受击、恢复、退场和状态列表。名称本身不写入主人前缀或“（机巧）”后缀。普通角色与怪物保持原有显示。

全部人偶额外互动共用以下两行格式，认主、主动问候、每日问候、成长、休息及战斗对白均适用：

```text
〖名称〗
“嗨，要打起精神啊!”
```
