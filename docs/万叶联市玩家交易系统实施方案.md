# 万叶联市玩家交易系统实施方案

## 一、目标与边界

万叶联市采用**匿名订单交易所**，不提供指定对象的面对面转让。

- 玩家仅能发布卖单或求购单，系统按价格、时间自动撮合。
- 物品和铜币在订单生效时进入交易所托管，成交、取消、过期均在事务内结算。
- 首期仅开放可交易的堆叠材料、药剂、食物与普通消耗品。
- 地图、货币、任务物品、特殊物品、礼物、图纸、家具与装备实例不可交易。
- 当前项目已有 `is_tradeable`、`trade_price` 与角色铜币余额，可作为首期交易校验和价格锚点。

## 二、玩家界面

进入「万叶联市」后提供以下入口：

- 浏览市场
- 搜索物品
- 我要出售
- 发布求购
- 我的订单
- 成交记录
- 市场行情
- 本周手续费

商品详情建议展示：

```text
【哥布林耳】
市场参考价：铜币×18
今日允许挂单区间：铜币×13～27
近 24 小时成交：386 个
当前最低售价：铜币×19
当前最高求购：铜币×17
预计手续费：3%～8%
```

## 三、订单与撮合

采用“价格优先、时间优先”的匿名订单簿。

- 卖单价格低者优先成交。
- 买单价格高者优先成交。
- 同价订单按创建时间排序。
- 成交价采用**较早挂出的订单价格**。
- 允许部分成交，剩余部分保留为开放订单。
- 玩家不可查看订单对手身份，不能指定买家或卖家。
- 同一角色不能成交自己的订单。

匿名撮合是反小号倒卖的第一层：低价卖单不能被指定大号接走，只会匹配当时最优、最早的市场订单。

## 四、动态价格与价格区间

每个物品维护市场参考价 `P`。

初始价格：

```text
P0 = max(1, item_definitions.trade_price × 2)
```

其中 `trade_price` 为 NPC 基础回收价，用来避免无成交物品没有价格锚点。

每日参考价：

```text
成交均价 = 最近 24 小时有效成交额 / 有效成交数量

P新 = 旧参考价 × 50%
    + 成交均价 × 35%
    + NPC锚定价 × 15%
```

有效成交必须满足：

- 双方不是同一角色或同一风控关联组；
- 达到最低成交额与数量门槛；
- 未被风险系统标记；
- 不是回滚、补偿或管理员修正订单。

波动限制：

```text
单日：P新 ∈ [P旧 × 0.92, P旧 × 1.08]
七日：P新 ∈ [七日前参考价 × 0.70, 七日前参考价 × 1.45]
```

挂单区间：

```text
卖单：ceil(P × 0.70) ～ floor(P × 1.50)
买单：ceil(P × 0.65) ～ floor(P × 1.55)
```

新物品或成交样本不足时，使用较窄区间：

```text
卖单：P × 0.85 ～ P × 1.20
买单：P × 0.80 ～ P × 1.25
```

供求修正：

```text
供求比 = 有效求购量 / max(1, 有效卖单量)
供求修正 = clamp(0.90, 1.10, 1 + ln(供求比) × 0.05)
最终参考价 = P新 × 供求修正
```

版本更新、Boss 掉率调整或大型活动后的 48 小时内，单日价格波动上限降至 5%。

## 五、手续费与周成交额

手续费由卖家在成交时支付，买家无需额外付费。按自然周累计的**已成交销售额**实施分段累进：

| 本周累计成交额 | 对应区间手续费 |
| --- | --- |
| 0 ～ 10,000 铜币 | 3% |
| 10,001 ～ 50,000 铜币 | 5% |
| 50,001 ～ 150,000 铜币 | 8% |
| 150,001 ～ 500,000 铜币 | 12% |
| 500,000 铜币以上 | 16% |

跨档时按区间拆分计算，而不是整笔交易跳档。

附加规则：

- 发布卖单免费。
- 取消未成交订单免费。
- 发布后 2 分钟内撤单：收取订单价值 0.5%，最低 1 铜币。
- 高频撤单后提升为 2%，抑制刷盘口和假供需。
- 手续费进入“万叶基金”，用于世界树活动、市场任务、限时 NPC 商品和物价调控；不建议全部销毁，以免长期铜币紧缩。

## 六、反小号与风控

### 强制限制

- 禁止自买自卖。
- 禁止同一关联账户组互相成交。
- 开放交易前需满足：注册满 72 小时、Lv.10、已登记冒险者、累计获得铜币达到门槛。
- 新交易者前两周周成交额上限为 20,000 铜币。
- 普通玩家周成交额上限为 300,000 铜币。
- 单笔买单最大金额为 100,000 铜币。
- 每日单物品挂单上限为 20，总挂单上限为 60。

### 风险评分

为角色维护 `market_risk_score`。以下行为增加风险：

- 长期贴近最低价出售、最高价求购；
- 高频只与固定少数账户成交；
- 新角色向高资产角色集中输送稀有资源；
- 大量撤单、改价、短时间反复挂单；
- 成交价格持续贴近价格上下限；
- 角色产出、升级进度、铜币来源与成交规模明显不匹配。

| 风险等级 | 处置 |
| --- | --- |
| 低 | 正常交易，仅记录 |
| 中 | 降低周额度，成交延迟 10 分钟 |
| 高 | 新订单进入审核队列，禁挂 24 小时 |
| 极高 | 冻结订单与托管资产，通知管理员复核 |

普通玩家应即时结算；延迟结算只针对高风险订单。

## 八、事务流程

卖单：

```text
锁定背包物品
→ 校验可交易性、数量、价格区间、额度
→ 从背包扣除并写入托管
→ 创建卖单
→ 尝试撮合
```

买单：

```text
锁定角色铜币
→ 校验价格区间与额度
→ 预扣「单价 × 数量」
→ 创建买单
→ 尝试撮合
```

成交：

```text
锁定买卖订单
→ 校验剩余数量与预扣余额
→ 计算分段手续费
→ 发放物品给买家
→ 发放净铜币给卖家
→ 更新订单、周成交额与行情统计
→ 写入成交及风控记录
```

取消或过期：卖单返还未成交物品；买单返还未使用铜币。

## 九、首期配置建议

| 项目 | 推荐值 |
| --- | --- |
| 订单有效期 | 72 小时 |
| 单个卖单最大数量 | 999 |
| 单个买单最大金额 | 100,000 铜币 |
| 新交易者周上限 | 20,000 铜币 |
| 普通玩家周上限 | 300,000 铜币 |
| 撤单冷却 | 2 分钟 |
| 高风险延迟结算 | 10 分钟 |

第一周采用观测期：价格区间更窄、风控先记录不自动冻结、每天查看热门物品成交与铜币流向。一周后根据真实产出和成交数据逐步放宽。
