# 势力传闻牵制与交谈区披露规则

## 目标与口径

- 一个势力在同一四小时时段只能有一个传闻方向；不能同时出现该势力的涨价、跌价预言。数据库已有 `(period_key, instrument_code)` 唯一键。
- 每段安排一组题材关联的两个不同开放势力，一条利好、一条利空，方向总和为零。五组按四小时时段轮转，每个开放势力在连续五段中都有一次机会。它们是域民对经营事件的猜测，不是向玩家保证买卖收益。
- 不允许整个发行市场因统一行为一起抬价或一起压价。现有结算按发行份额加权维持市场参考总值，正负影响是相对分配；若发生价格变化，千分铜币参考价不可能全部同向变动。整铜币报价可能因舍入显示“部分不动”，不能据此声称所有报价必有一涨一跌。
- 新闻有 `预言→应验/反转` 的因果链。82% 是事件应验的抽取概率。新结算会在可行时强制对应的整铜币报价方向，但限幅、总值守恒或资金覆盖不足时会明确记为“行情受阻”，所以 82% 仍不是任何情况下的股价命中承诺。

## 已接入的本轮规则

1. 四小时结算为下一段轮转一组关联势力：银铃钱庄/万叶商盟、冒险者总公会/赤铁驿路同盟、炉火锻造师协会/星轮解构师协会、月露炼金师协会/墨灯全知者协会、世界树议会/雾海摆渡同盟。随机决定组内谁利好、谁利空；各取本势力对应的 12 条文案之一。每组只抽一次 82% 应验/18% 反转，两条共用结果，故它们对经营分的新闻作用仍保持相反方向，不会出现“一条应验、一条反转”后双利好或双利空。配对表示争夺同轮投资关注与资金，不代表真实经营一定互为反面。旧数据若有单条或同向传闻不会被追溯改写。
2. 闲聊区当前段最多有一条传闻可能被听到：同一时段用固定规则选出全服一致的公开摘录，再对每名角色保留原有 25% 听到概率；同一角色反复查看不会刷新。另一条不会通过换角色、反复点开或上一段历史全文泄露。
3. 上一段也只展示同一条公开摘录的应验/反转文本；未公开事件仍会影响结算，但只可从行情和业务公告推测，不会列出完整传闻。旧时段只有一条新闻时不展示全文。
4. 行情栏仍披露实际整铜币价格及主要业务因素。公告不得把“事件应验”误写成“股价同向兑现”；两者不一致时给出真实报价与相对定价说明。

## 牵制如何传导

单个势力经营分由已结算业务、每日委托和传闻事件组成；同一来源去重并限制刷分。结算先求全市场按 `当前参考价 × 发行份额` 加权的平均经营分，再用各势力相对平均值计算目标价。因此甲乙受利好时，其他不活跃势力可能被动回落；反过来，全体同样利好时相对分为零，不会凭空制造全市场资产增值。随后执行单轮/日限幅、整铜币成交报价限幅和资本覆盖检查。NPC 调仓只动用已入账资本，不另造币，也不反向产生经营分。

这套规则保证“消息不在同一势力自相矛盾”和“全市场参考价值不集体同涨同跌”。例如该势力利好 +3、其他势力真实经营均为 +10，原始目标价可能相对下跌；如今求解器会在可行时把它调到至少上涨 1 铜币，并让其他势力在总值内承担偏移，而不是只在文案里声称兑现。

## 已接入的整铜币方向约束

1. 生成时使用最新价格、下一时段的营业日锚点和当前已入账的投资资本进行预检：从轮转起点依次寻找可在限幅、总值、资金覆盖内实现相反报价方向的一组。没有可行组就不发方向预言；下一轮新增交易、真实业务仍可能改变可行性。
2. 结算先计算真实业务和新闻形成的目标价，再为两条新闻施加实际整铜币报价至少相差 1 铜币的方向约束。应验时按原传闻方向，反转时按反方向；求解同时保持发行份额加权总值不变，并遵守单轮 ±5%、营业日 ±20% 及整铜币交易限幅。
3. 约束无解时回到不加传闻方向约束的真实经营目标价；若资本无法覆盖该价格则全体暂缓调价。每条新闻按最终**实际整铜币报价**独立记 `matched` 或 `blocked`，并保存“限幅或市场总值牵制”“资本不足”等原因。即使事件应验，也不会把受阻行情写成涨价兑现。记录与价格在同一个结算事务内提交。
4. 旧时段新闻会保留旧价格行为，不追溯改价；迁移后旧记录的 `price_status=pending` 表示当时没有方向约束记录。历史展示会明确写出这个口径。

待完成的是长周期真实样本统计：分别记录 `事件应验率`、`整铜币同向率`、`受限幅或清算阻断率`，上线前用多日、多人、多势力信号回放测试。当前只有定价单测，没有声称真实运营命中率已达某个百分比。

若策划坚持“任何情况下严格 82% 的价格方向命中”，它与保总值、限幅和资金覆盖同时存在时可能数学上无解。当前实现采用可行性判断与诚实公示，不把不可达目标伪装成已保证。

## 验收点

- 同一新时段正负传闻各一条、势力不重复；同一势力单时段至多一条；五组连续五段轮转覆盖全部开放势力。
- 当前预言与上一段历史各最多公开一条，且全服使用同一摘录；重复访问不可刷出隐藏文本。
- 交易所只报告实际价格，不把新闻应验当作涨价证明。
- 实际价格仍满足加权参考总值、单轮 ±5%、日累计 ±20% 与清算资本覆盖规则。
- 对可行的新闻组，整铜币方向应按应验/反转实际命中；不可行时显示受阻原因，不得破坏资金或限幅。长期实际命中率仍需运营数据验收。
