# 成就系统第一期实装记录

日期：2026-09-09。状态：界面、永久账本与部分实际结算入口已实现，尚未全量完成与逐条验收，未重启正式机器人。

## 已实现的公共能力

- `/成就 [分类] [页码]`：顶部仅[全部]与本人有已解锁成就的分类；一页最多10条，①～⑩编号、成就名称蓝色链接、全服名次和完成率。
- `/成就详情 <编号>`：仅本人已解锁可读；只投影简介、稀有度、属性、完成时间、名次、比例。隐藏条件、解法、未解锁条目，蓝色链接不自动发送。
- 独立永久身份、事件收据、累计/同生涯进度、固定六维奖励、全服计数、首位公告队列。与原业务同事务提交，回滚不产生名次和奖励。
- 账户注销不删除成就表；重新注册按相同QQ身份重新计算六维。没有额外的首位永久属性。
- 首位奇珍匣与每10个新成就的奇珍匣已进入永久账本；兑换、三种消耗品的战斗使用、每周积珍入口尚未完成。
- 全群公告按达成时已知群表保存目标、每项首位成就单独发送一条消息，公开角色名、成就名与引用格式简介，不显示具体要求。发送状态不明保留uncertain，不盲目重发；真实平台发送尚未验收，群表无法发现机器人从未见过的群。
- 初次初始化只补充分母身份，不猜测玩家过去的战斗次数、完成顺序或首位。
