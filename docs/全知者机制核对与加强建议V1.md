# 全知者机制核对与加强建议 V1

日期：2026-09-06。状态：建议方案，未实装。本轮只读核对源码并新增本文，没有修改游戏逻辑或数据库。下面的建议数值均为初始测试值。

## 1. 目前到底有哪些能力

| 模块 | 当前代码行为 | 体验上的问题 |
| --- | --- | --- |
| 明鉴 | 自动提供鉴识资格；识珠保底为副职业等级、最高 4；慧眼保底为副职业等级，Lv.4 起再加 1。与已学习鉴识取较高值。 | 面板写成“Lv+”，容易被理解为叠加；普通玩家把鉴识学满后，全知者的信息优势明显减小。 |
| 掉率光环 | `(副职业等级−1)×5%`，最高 Lv.11 为 50%；队伍只取最高全知者等级。 | Lv.1 为 0；加成混入总掉率，不显示具体贡献；多人全知者的同类光环不叠加。 |
| 巧思领悟 | 战斗胜利时个人领悟概率直接增加同样的百分点，最高 +50 个百分点；仍需符合怪物技能规则、源技能序列等条件。 | 强度不一定低，但技能发现逐渐齐全后价值下降，且玩家看不到研究积累。 |
| 技能贯注 | `/技能贯注` 有职业检查与面板，正文明确“规则与技能石功能将在后续开放”。 | 核心产出玩法尚未实装，巧思介绍却已经宣传可以贯注。 |
| 地表识踪 | 追踪本区域最新生成的有效 Boss，经 3～6 个线索节点后揭示坐标；提供最高阶锻材名称。 | 不能选目标；线索必须精确到达节点；没有距离数值；多开面板与走路之外缺少操作。 |
| 识踪中断 | 被其他战斗占用的目标会使尚未完成的追踪写入中断；现流程没有该条追踪恢复分支。 | 暂时有人挑战也可能永久中断这次生成实例的线索，不利于接续追踪。 |
| 地宫识踪 | 全知者本人是队长或未组队时，沿当前层可走路线提示首领方向，必要时引导石阶。 | 全知者不是队长时无法提供这项作用，队伍信息协作受限。 |
| 熟练度 | 每次符合奖励条件的胜利按怪物平均等级获得约 `1.2^floor((等级−1)/10)` 点期望熟练度，一场结算一次。 | 观察、研究和完整追踪没有独立成长奖励；全知者实际靠刷战斗练级。 |

掉率与领悟必须分开理解。例如 Lv.5 全知者加成 20%：不计其他修正时，基础掉率 10% 变为 12%；基础领悟率 10% 则变为 30%。不建议因体感偏弱就同时翻倍这两个数值。

等级上限目前是 **11**，不是 5。升到 Lv.5 累计需要 12,600 熟练度，升到 Lv.11 累计需要 111,442,600。若持续击败平均 Lv.30 的敌人，期望每场仅 1.44 点，升到 Lv.5 已约需 8,750 场；这是固定条件的公式估算，不是玩家实际时长统计。核心新玩法不宜全部锁在极高等级。

代码依据：`src/game/omniscient.service.ts`、`src/game/secondary-profession.ts`、`src/game/adventure.service.ts` 的鉴识和胜利结算、`src/game/dungeon.service.ts` 的 `dungeonTrackingHint`、`src/response/bookshop.ts`、`src/response/skill-list.ts` 的 `skillInfusionHandler`。

已有设计文档曾提出“旁注”“反证”和区域见闻；本轮没有在相关游戏与响应源码中找到这两个同名能力的实现，不能算作现有能力。

## 2. 推荐定位

让全知者通过 **发现线索 → 验证规律 → 制定对策 → 制成知识成果** 获得收益。

锻造师提供长期装备，炼金师提供有成本的战术消耗品，解构师提供材料加工与异械；全知者提供可靠的战斗判断、探索效率和可制作的知识物品。这样个人冒险有收益，队伍也能感受到带上全知者带来的变化。

建议优先实现下列六项，先补齐操作与产出，再依据数据调整已有光环。

## 3. 六项核心加强

### 3.1 观测手记：把看过的信息变成自己的研究

复用当前怪物图鉴和鉴识信息，新增个人的观测记录层。记录首次见到、实际观察到的技能、验证过的抗性、遭遇地点、Boss 阶段和部位机制。已有图鉴内容继续可看，不能要求玩家为旧权限重新刷研究。

每种怪物分为「初见、辨识、熟悉、洞悉」。进度来自不同事实，例如亲眼见过喷火、命中弱点、破坏部位、成功阻止蓄力。重复看面板不加进度；同一场同一事实只结算一次，未知内容明确显示未知，不凭空生成真实机制。

交互建议：`观测手记｜怪物｜技能｜区域｜上一页｜搜索｜下一页`；支持“未完成”“有新发现”筛选。自动战斗结束后只推送本次新发现摘要。

收益：形成长期收藏和研究目标，为后面的破绽、技能石与勘察报告提供依据。熟练度奖励按首次事实和阶段突破发放，不能无限刷查看按钮。

### 3.2 破绽标注：把情报转化为队伍能利用的优势

已辨识的目标可选一个有证据支持的破绽。每场初始获得 2 点「洞察」，验证一个新机制可回复 1 点，每场最多获得 3 点。一次标注消耗 1 点，单独的标注按钮不占普通行动，但每回合仅一次；效果只强化下一次满足条件的完整行动。

| 标注方向 | 建议初始效果 | 触发条件 |
| --- | --- | --- |
| 元素破绽 | 下一次正确元素的完整攻击行动，最终伤害 +12% | 已观察到该元素确为弱点；不存在弱点时不提供。 |
| 构造破绽 | 下一次针对指定部位的完整攻击行动，对该部位伤害 +15% | 目标有可攻击部位，且已完成构造观测。 |
| 失衡时机 | 下一次攻击获得命中修正 +15% | 已辨识目标闪避或蓄势动作。 |
| 防备提示 | 下一次符合预警类别的受击伤害 −15% | 已观察到对应招式或当前有效预警。 |

同一队伍对同一目标最多保留一个标注；多名全知者共享单回合标注次数和总收益预算。多段技能以整次行动为单位，不能每段消耗一次标记再触发额外标记。不能直接修改绝对免疫、无敌或强制剧情机制。

这些效果比高成本药剂温和，优势在于无需消耗制作材料、可根据知识主动选择。自动战斗提供“手动 / 优先危险预警 / 优先弱点 / 优先部位”策略。

PVP 首版只依据当前战斗公开动作积累洞察；不读取对手未公开技能配置、背包或尚未确定的随机行动，伤害类标注建议减半并独立校准。

### 3.3 反证预判：识别危险，给出有依据的应对

针对已经研究过的敌人，检查当前真实状态，显示下一步动作的大类和推断依据。例如：

> 炉心亮度持续升高，且排压部件仍在运作。下一步可能释放火属性范围攻击；破坏排压部件可削弱其蓄势。

必须区分“已确定的吟唱动作”“符合已验证规律的倾向”“信息不足”。只有战斗逻辑已锁定行动时才显示确定结论，随机决策不能提前编造为确定招式。

先支持危险范围攻击、强控制、治疗/护盾、召唤/部位联动、阶段切换五类；只在危险变化时提示，不每回合重复全文。只有现存机制确实存在中断或削弱方法时才提供对应建议。

收益：让研究改变决策。普通鉴识继续负责属性与状态查询，全知者增加时机、条件与因果解释。

### 3.4 技能贯注：优先补齐当前已承诺的产出

建议做成可交易的「技能研习石」，使用后获得该技能的发现资格，仍按现有门槛和技能点费用学习。首版不复制技能等级、专精投入或绑定能力，不产生免费技能点。

制作需：自己已发现且完成研究的可传授技能、对应怪物见闻/样本、空白技能石和制作费。普通可领悟技能使用白名单；职业专属、剧情绑定、Boss 专属及其他禁传能力不因贯注绕过限制。

采用确定性制作：材料与研究条件齐全就产出，先展示具体技能、费用及成果再确认。研究资格永久保留，但每颗石头都消耗可追踪的样本和物料；同一批样本不能重复结算。别人使用石头不会给制造者恢复样本，防止循环复制。

入口放在全知者首页「技能贯注」，支持「可制作 / 缺少材料 / 未完成研究」和技能关键词筛选。交易、使用、已有发现、死亡/战斗限制以及掉线重试都需要明确实现。

这项优先级最高：它直接补齐全知者目前缺少的可交易职业成果。

### 3.5 主动勘察：能选目标，线索可以接续

把识踪扩成“首领 / 指定怪物 / 炼材 / 锻材 / 解构素材 / 当前任务目标”的选择面板，根据已知地图、资源池与任务对象生成线索。

- 支持锁定追踪目标，不被新刷出的另一只 Boss 自动替换。
- 节点进入合理感知半径即可推进，显示距离区间、可走方向及追踪进度，不要求盲踩精确坐标。
- 目标正在战斗时显示“踪迹被战斗扰乱，等待确认”；战斗结束后依据存活状态恢复或结束追踪。
- 全知者即使不是队长，也能向当前队伍提供地宫路径提示；多人只提供一条合并提示。
- 地宫沿可走路径，不能给出穿墙方向；地图状态变化后重新计算。
- 首次完成追踪、验证资源点可以增加少量熟练度，按生成实例去重。

现有锻材感知扩为三种制作职业需要的资源；信息来自当前可验证来源，枯竭或过期的点位明确标记，不能保证库存或未来刷新时间。

### 3.6 知识成果：让探索也能形成成品

除了技能石，再增加两类低维护成本的知识成品：

| 成品 | 制作依据 | 使用收益 |
| --- | --- | --- |
| 勘察报告 | 实地验证过的一处资源区域或追踪线路，加纸墨材料 | 给购买者一次有效的区域引导，标明勘察时间与适用区域；目标变动时提供失效状态。 |
| 作战批注 | 已洞悉的怪物种类，加对应研究样本与纸墨 | 战前使用，下一场对应怪物战斗获得一次预设标注，不能与现场全知者标注叠加。 |

不单独出售“静态文字答案”作为核心经济价值：这些内容容易被转述。成品应绑定一次实际游戏引导或受限战斗效果，同时保留可读的研究说明。

书屋若参与售卖，按全知者成品白名单供应基础报告；不把学习、研究或贯注服务藏回城镇商店。导师课程仍在个人成长入口。

## 4. 成长与原有能力的加强

建议保留现有 Lv.11 上限与已获熟练度；先增加研究、勘察和产出三种成长来源，随后结合实际每日收益重估各级所需时间。不要直接修改所有副职业共用曲线，以免连带改变刚调整过的炼金、锻造与解构。

| 全知者等级 | 建议新增内容 |
| --- | --- |
| Lv.1 | 观测手记、主动勘察、一次基础标注，入门即可有主动玩法。 |
| Lv.2 | 队伍线索共享、危险预判基础类别。 |
| Lv.3 | 基础技能石贯注、勘察报告，进入实际产出循环。 |
| Lv.4 | 完整破绽选择与部位研究，承接当前识珠成长。 |
| Lv.5 | 作战批注、更丰富的研究对象，六项核心玩法全部开放。 |
| Lv.6～11 | 更多同时追踪栏、手记整理与批量操作能力、内容型研究课题和称号；不再主要依赖大幅追加全队伤害。 |

原掉率光环保留队伍最高值规则；结算增加“明鉴影响了哪些掉落判定”的可验证摘要，不能每次掉物都归功于全知者。可以使用同一个随机数比较加成前后阈值，只有确实改变结果才归因。

原领悟加成先保持，增加“已见招式、尚未发现技能”的研究进度和受限保底。保底仅作用于满足实际观测条件的可领悟技能，不能挂机观察从未使用的技能；与现有概率领悟统一结算，已经发现的技能不重复发放。

## 5. 实施优先级与验收

1. **先修清晰度与已有缺口：** 明鉴的“保底取强”文案、巧思贯注占位、目标占用导致追踪永久中断、非队长识踪共享。
2. **补产出：** 技能石贯注和最小可用观测手记；让新增研究马上有实际用途。
3. **补战斗操作：** 破绽标注、反证预判和自动战斗策略；先覆盖一批真实机制明确的怪物。
4. **补探索与长期目标：** 可选勘察、报告/批注、区域课题与成长来源。
5. **再定最终数值：** 比较全知者与另外三个副职业在单人、四人队、普通刷怪和 Boss 战中的战斗回合、材料收益、探索耗时及可交易净产出。

重点验收：重复观测不刷经验；队伍多全知者不无限叠加；标注按整次行动结算；预判来自真实状态；没有可验证反制时不编造建议；技能石不绕过学习限制、不循环制造；更换副职业后研究档案保留但职业能力按当前资格启用；新系统不清空旧鉴识、技能发现或熟练度。

最终建议：优先完成 **技能贯注、观测手记、破绽标注、主动勘察**。这些功能分别补齐经济产出、长期积累、战斗参与和探索效率，能够直接改善全知者“面板有三项、实际可做的事很少”的体验。
