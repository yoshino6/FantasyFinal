# 二转职业固有与传承被动强化方案

> 状态：设计提案，尚未写入战斗与数据库。
>
> 覆盖范围：世界树 12 个常驻二转，以及当前已开放的 4 个隐藏二转。本文中“战豪”按现有职业名 **剑豪**（`ironbreaker`）处理。

## 1. 强化目标

二转固有被动不应只是一个很小的通用百分比，而应让角色在进入战斗时就有明确的成长方向；传承被动则要让队友、出招顺序、资源或状态之间产生新的配合，而不是把本职效果简单缩小后给旁修。

本方案采用两层结构：

| 层级 | 作用位置 | 设计原则 |
| --- | --- | --- |
| 固有被动·静态层 | 角色详情属性缓存 | 无条件生效，在六维、装备数值词条、进化与装备百分比之后统一结算；查看角色详情会刷新并展示。 |
| 固有被动·战斗层 | 战斗开始或对应事件 | 仅处理无法写入人物面板的职业规则，例如灵位、元素循环、治疗量、实际命中率。 |
| 传承·本职 | 该二转本人装备传承时 | 保留职业核心循环，允许改变资源、出招窗口或队友协作。 |
| 传承·旁修 | 其他职业装备该传承时 | 保留可理解、可组合的一段核心价值；不复制召唤物、器械、筹策等专属系统。 |

### 1.1 统一术语与结算口径

| 文案用词 | 精确含义 |
| --- | --- |
| `暴击率修正 +33%` | 暴击属性与目标暴击抗性对抗后得到基础概率 `P`；按 `P + (1 - P) × 33%` 提升未满足的暴击概率。不是增加 33 点暴击属性，也不是直接增加 33 个百分点。 |
| `抗暴率修正 +X%` | 对方暴击率对抗和全部正向修正完成后，按 `P × (1 - X%)` 降低当前被暴击概率；例如被暴击率 60%、抗暴率修正 25%，结果为 45%。它不增加暴击抗性数值。 |
| `命中率修正 +X%` | 命中属性与目标闪避对抗后得到基础概率 `P`；按 `P + (1 - P) × X%` 提升未满足命中概率。仍受不可命中、特殊闪避与引擎概率上限约束。 |
| `破韧命中修正 +X%` | 破韧与目标韧性对抗后得到控制/减益基础命中概率 `P`；按 `P + (1 - P) × X%` 提升未满足的状态命中概率。不是增加 X 点破韧。 |
| `控制抗性 +X%` | 韧性/破韧对抗后的控制最终命中概率乘以 `1 - X%`；不影响燃烧、破甲等非控制减益。 |
| `暴伤属性 +X%` | 人物暴击伤害属性增加 X%，只在暴击已经发生后参与暴击伤害结算；它不是“概率修正”。 |
| `暴伤抗性修正 +X%` | 只降低暴击相对普通伤害多出的“额外暴伤段”。若一次暴击原本为普通伤害的 200%，暴伤抗性修正 25% 后为 `100% + (200% - 100%) × 75% = 175%`；不会把暴击伤害压低到普通伤害以下。 |
| `穿透 X%` | 本次伤害结算时忽略目标对应防御的 X%；物理技能看物防，魔法技能看魔防。 |
| `生命护盾` | 可真实抵消伤害的独立护盾层，单层不超过持有者生命上限；按生成先后消耗，持续结束即消失。 |
| `减伤壁垒` | 一段持续时间内的伤害减免状态，不是生命护盾。 |

元素使的“四元素精通各 +50”也不是“元素伤害直接 +50%”。当前元素倍率按精通与抗性差值的曲线结算：在目标对应抗性不变、差值从 0 提升到 50 时，约等于取得 **35.5% 的元素倍率**；差值越高，边际收益越低。因此该数值足够成为元素使的主要固有优势，不再叠加泛用魔法伤害百分比。

多个正向修正同时存在时，统一按未满足概率合并：`P正 = 1 - (1 - P) × ∏(1 - 正向修正)`。随后再结算负向修正：`P最终 = P正 × ∏(1 - 负向修正)`。同名来源不叠层。

以暴击属性 `200`、目标暴击抗性 `300` 为例：对抗后的原始暴击概率约为 `37.0%`；剑豪获得“暴击率修正 +33%”后，最终概率为 `37.0% + (100% - 37.0%) × 33% = 57.8%`。实际提高约 `20.8pp`，会随原始对抗概率而变化；它不改动人物面板中的暴击属性数值。

### 1.2 通用边界

- 同名传承状态不叠层，只刷新为更高来源和较长持续时间。
- “每回合一次”按施放者、目标或队伍的限定会在每条效果中写清，避免多人队伍无限触发。
- 传承的直接伤害增幅只作用于技能直击，不放大百分比持续伤害、真实护盾吸收或治疗溢出。
- Boss 的剧毒、燃烧等每回合最大生命掉血上限保持既有规则；传承不能绕过该上限。
- 二转主动技能暂不接入专精系统；以下被动也不产生专精入口。

## 2. 世界树常驻二转

### 2.1 盾卫·根壁体魄 / 不退护阵

定位：主坦、承伤转移、队友濒危保护。

**固有被动·根壁体魄**

| 静态属性 | 数值 |
| --- | ---: |
| 最大生命 | +18% |
| 物理防御 | +15% |
| 魔法防御 | +12% |
| 控制抗性 | +15% |

这组属性只服务于“站得住并持续守护”，不直接提高输出。它会在装备与进化百分比完成后加入角色详情缓存，保证盾卫面对 30 级 Boss 的高额单段伤害仍有可用的承伤余量。

**传承·不退护阵**

| 使用者 | 效果 |
| --- | --- |
| 本职盾卫 | 自身回合结束时，若自身持有嘲讽、守护、减伤壁垒或生命护盾之一，则为当前生命比例最低的其他队友施加 `护阵` 1 回合。该队友第一次受到技能直击时，先按其自身减伤结算；随后其中 25% 伤害转移给盾卫，转移量不超过该队友最大生命的 12%，其余未转移部分再获得 12% 减伤。每名盾卫每回合仅触发一次。 |
| 旁修 | 满足同样前置时，为生命比例最低的队友施加 `护阵` 1 回合；其第一次受到技能直击获得 8% 减伤。无伤害转移、无上限转移计算。 |

伤害转移不再次触发“受盾保护”“承伤返资源”及反伤类事件，防止循环。该传承让本职盾卫能主动用守势、守护、壁垒维持队伍阵型；旁修只保留安全的濒危保护。

### 2.2 战旗使·列阵威仪 / 战阵接令

定位：物理队领袖、减益开团、集火节奏。

**固有被动·列阵威仪**

| 静态属性 | 数值 |
| --- | ---: |
| 物理攻击 | +12% |
| 命中属性 | +10% |
| 速度 | +8% |

战旗使需要比队友更早建立破甲、减速、易伤等战场条件，因此采用攻击、命中、速度三项，而非再堆泛用最终伤害。

**传承·战阵接令**

| 使用者 | 效果 |
| --- | --- |
| 本职战旗使 | 自身成功施加一个新减益后，对该目标挂上 `军令` 2 回合，每名战旗使每回合最多指定 1 个目标。第一名**不同于战旗使的队友**以技能直击命中该目标时，获得本次最终直击伤害 +12%、命中率修正 +12%，并留下 `应旗`。战旗使下一次以技能直击命中同一目标时，忽略其对应防御 12%，获得 20 战意并消耗 `应旗`。 |
| 旁修 | 自身成功施加新减益后，对该目标挂上简化 `军令` 2 回合；下一名不同队友的技能直击获得最终伤害 +8%、命中率修正 +8% 后消耗。无 `应旗`、防御穿透和战意返还。 |

这使标准连段成为“战旗使上减益 → 队友接令 → 战旗使回砍”，而不是所有人各自堆伤害。一次军令只接受一次队友接令，避免多段 AoE 被重复放大。

### 2.3 剑豪·锋芒专注 / 临界识破

定位：单体破甲、弱点斩杀、物理暴击核心。

**固有被动·锋芒专注**

| 静态属性 | 数值 |
| --- | ---: |
| 暴击率修正 | +33% |
| 暴伤属性 | +12% |

剑豪的固有是当前唯一以高暴击率修正为核心的二转。它在暴击抗性对抗完成后补足未满足概率，不会增加人物暴击数值，更不会直接增加 33 个百分点；高暴击抗性的 Boss 与抗暴率修正仍能分别压低基础概率和当前概率。

**传承·临界识破**

| 使用者 | 效果 |
| --- | --- |
| 本职剑豪 | 每个目标每回合首次被自身单体技能命中时，若目标带有破甲、易伤或追猎之一，本次攻击获得暴击率修正 +12%，并施加 `裂口` 2 回合。下一名不同队友的单体技能直击该目标时，获得暴击率修正 +15%、忽略对应防御 12%，随后消耗 `裂口`。 |
| 旁修 | 满足同样前置时施加 `裂口`；下一名不同队友的单体技能直击获得暴击率修正 +8%，随后消耗。无本次暴击率修正和防御穿透。 |

`裂口`不强制暴击，不消耗目标原有的破甲、易伤、追猎。剑豪适合先找出已经被队伍打开的缺口，再把单体爆发交给下一名队友完成。

### 2.4 元素使·四相感应 / 异相共鸣

定位：冰、火、风、雷四系循环、元素队协作、群体法术输出。

**固有被动·四相感应**

| 静态属性 | 数值 |
| --- | ---: |
| 火元素精通 | +50 |
| 冰元素精通 | +50 |
| 风元素精通 | +50 |
| 雷元素精通 | +50 |

只作用于冰、火、风、雷；光与暗留给后续三转、四转。实现时必须把这四项加入人物详情缓存和战斗单位元素精通，而不是仅在技能命中时临时加值。

**传承·异相共鸣**

| 使用者 | 效果 |
| --- | --- |
| 本职元素使 | 自身成功给敌人施加一种此前不存在的冰、火、风、雷印记或对应元素减益时，施加 `导相` 2 回合，每个目标每回合最多一次。下一次以**不同元素**造成技能直击的角色命中该目标时，本次元素直击最终伤害 +12%，该施法者恢复 4% 最大 MP；若触发者是元素使本人，额外获得 20 奥术。随后消耗 `导相`。 |
| 旁修 | 满足同样条件后施加简化 `导相`；下一次不同元素的技能直击最终伤害 +8%，施法者恢复 2% 最大 MP 后消耗。无奥术返还。 |

“不同元素”只识别冰、火、风、雷，暗、光、无属性、持续伤害不触发。这样火印记后接冰、风、雷都有价值，四系循环会自然形成，而不是让某一元素独占全部加成。

### 2.5 唤灵师·灵息 / 灵契余荫

定位：多灵并存、持续场面、治疗与护盾协作。

**固有被动·灵息**

| 静态或战斗规则 | 数值 |
| --- | ---: |
| 最大 MP | +18% |
| 每次自身回合开始恢复 MP | 4% 最大 MP |
| 灵位上限 | +2（无该被动时为 1，因此本职最多同时维系 3 只灵） |
| 存活召唤灵最大生命 | +20% |

召唤灵仍是独立单位，有生命、会被击倒退场，并按既有规则继承召唤者的部分属性；`+20%` 是召唤灵最终生命，不改变其攻击继承公式。

**传承·灵契余荫**

| 使用者 | 效果 |
| --- | --- |
| 本职唤灵师 | 每回合首次有队友在生命低于 60% 时获得直接治疗、生命护盾或减伤壁垒，会被标记为 `灵荫` 至回合结束。若场上至少有一只存活召唤灵，则回合结束时该队友恢复 3% 最大生命，生命比例最低的存活召唤灵恢复 12% 最大生命，唤灵师获得 15 灵契。 |
| 旁修 | 每回合首次有队友在生命低于 50% 时获得直接治疗、生命护盾或减伤壁垒，为其施加 6% 最大生命的生命护盾 1 回合。无召唤灵修复和灵契返还。 |

本职效果把“灵在场”转化为稳定但不爆炸的队伍续航；旁修不凭空产生召唤物，保留一次濒危护佑即可。

### 2.6 战斗法师·咒钢护身 / 攻势换挡

定位：物魔混合、攻防切换、连续施法。

**固有被动·咒钢护身**

| 静态属性 | 数值 |
| --- | ---: |
| 魔法攻击 | +14% |
| 物理防御 | +10% |
| 魔法防御 | +10% |

这与战斗法师物理技能的混合攻击基础 `物攻 + 魔攻 × 35%` 相配合：魔攻成长会反馈给近战技，但物理技能仍以物防结算，不会反过来全面压过纯法术。

**传承·攻势换挡**

| 使用者 | 效果 |
| --- | --- |
| 本职战斗法师 | 技能直击造成伤害后，下一次直接治疗、生命护盾、减伤壁垒或友方增益效果强度 +20%，获得 `回路` 2 回合。该支援技能实际生效后，下一次技能直击最终伤害 +12%，并忽略目标对应防御 10%，随后消耗 `回路`。每回合只能完成一轮“伤害 → 支援 → 伤害”。 |
| 旁修 | 每回合首次完成“伤害 → 支援”时，支援效果 +12%；支援实际生效后，下一次技能直击最终伤害 +8%。无防御穿透和持续 `回路`。 |

只有真正改变生命、护盾、壁垒或成功附加友方状态的支援技能才会接上后半段，空放技能不能刷增伤。

### 2.7 夜刃·暮影本能 / 低光狩猎

定位：追猎收割、低血斩杀、短时自保。

**固有被动·暮影本能**

| 静态属性 | 数值 |
| --- | ---: |
| 暴击率修正 | +18% |
| 暴伤属性 | +28% |
| 速度 | +10% |

夜刃与剑豪同样享受暴击，但侧重暴伤和速度，而非剑豪的高暴击稳定性。两者不会获得相同的固有构成。

**传承·低光狩猎**

| 使用者 | 效果 |
| --- | --- |
| 本职夜刃 | 每个目标每回合首次被自身技能直击时，若其生命不高于 45% 或带有自身追猎，本次最终直击伤害 +16%，并使夜刃进入 `退影` 至下次自身回合开始。`退影` 期间首次受到技能直击时伤害 -20%；若这次攻击击杀目标，则额外清除自身一个可驱散普通减益。 |
| 旁修 | 每个目标每回合首次符合低血条件时，本次最终直击伤害 +8%，自身获得 `退影`：首次受到技能直击伤害 -10%。无追猎前置扩展和击杀净化。 |

不把“低血”写成无限叠加斩杀；每目标每回合一次的限制让夜刃强在选择收割窗口，而非持续常驻高伤。

### 2.8 蚀毒师·蚀痕 / 渗毒判断

定位：持续压制、状态联动、Boss 毒伤节奏。

**固有被动·蚀痕**

| 静态或战斗规则 | 数值 |
| --- | ---: |
| 破韧命中修正 | +20% |
| 自身施加的剧毒与毒血引爆伤害 | +25% |

“破韧命中修正”在破韧与敌方韧性对抗完成后，补足本次控制或减益未满足的命中概率；它不增加人物面板中的破韧数值。Boss 的剧毒每层 1.5% 最大生命、最多 3 层有效、引爆单次不超过 6% 最大生命，以及所有 Boss 掉血减益的既有上限，均保持不变。

**传承·渗毒判断**

| 使用者 | 效果 |
| --- | --- |
| 本职蚀毒师 | 自身剧毒首次存在于某目标后，若该目标在同一回合被任意队友成功施加另一种新减益，获得 `蚀媒` 2 回合，每目标每回合一次。下一次由**不同角色**造成的技能直击触发 `毒性回流`：立刻结算该蚀毒师一层剧毒下回合伤害的 35%，普通敌人最多不超过目标最大生命 1.2%，Boss 最多不超过 0.45%。此伤害计入该目标本回合的百分比掉血上限，随后消耗 `蚀媒`。 |
| 旁修 | 自身成功对带有任意持续伤害的目标施加另一种新减益时，施加 `腐蚀暴露` 1 回合：下一次不同队友的技能直击最终伤害 +6%，随后消耗。无即时剧毒结算。 |

本职让队友“补第二种减益”改变毒伤结算时点，但不增加剧毒层数，也不绕过 Boss 上限。实现前需要为每一层持续伤害保留施放者来源与下次结算量；没有来源记录时不得用全场最高毒伤代替。

### 2.9 机关游侠·猎手测距 / 猎线回响

定位：稳定命中、集火追踪、拆除敌方防护。

**固有被动·猎手测距**

| 静态或战斗规则 | 数值 |
| --- | ---: |
| 命中属性 | +10% |
| 速度 | +10% |
| 命中率修正 | +15% |

前两项作为最终人物配置缓存；“命中率修正 +15%”在命中/闪避对抗之后补足 15% 的未命中概率，专门保证机关游侠面对高闪避 Boss 仍能维持陷阱与追猎命中，而不是额外加 15 点命中或 15 个百分点。

**传承·猎线回响**

| 使用者 | 效果 |
| --- | --- |
| 本职机关游侠 | 当一名其他队友本回合已以技能直击命中过某目标，机关游侠再以技能直击该目标时施加 `猎线` 2 回合。`猎线`存在期间，另外两名不同队友以技能直击该目标后触发 `收线`：驱散其一个可驱散的闪避、加速或命中增益；若无此类增益，则施加 20% 减速 1 回合。随后消耗 `猎线`，机关游侠获得 20 机巧。每目标每回合一次。 |
| 旁修 | 满足相同的“两名不同队友命中”条件后，施加 12% 减速 1 回合。无增益驱散、无机巧返还。 |

这是一条“队友先锁定 → 游侠布线 → 队友收线”的集火机制。`收线`只移除列明的机动型增益，不会误驱散护盾、护甲、战吼等其他 Boss 机制。

## 3. 已开放隐藏二转

隐藏二转的战斗系统依赖粒子、器阵、异械、筹策等特殊状态。为了避免旁修角色得到不存在的粒子背包、器阵、设备能源或预案菜单，当前阶段四条隐藏传承均维持“本职可装配、旁修不开放”。它们同样是绑定·固有与绑定·传承，不占普通被动槽；强化重点是做出完整循环，而不是把旧的首次 4% 生命护盾单纯放大。

### 3.1 魔学者·奇釜实验 / 善后笔记

定位：粒子调配、风险转化、异常处理。

**固有被动·奇釜实验**

| 静态属性 | 数值 |
| --- | ---: |
| 最大 MP | +25% |
| 魔法攻击 | +12% |
| 破韧命中修正 | +12% |

战斗规则：每回合首次以 3～4 颗、且至少 3 种不同基础粒子完成成功或大成功调配后，获得 `观测记录` 2 回合并记录主粒子。下一次以**不同主粒子**调配时消耗记录：若本次失败，友方伤害倍率由既有的 35% 降为 20%，且只保留一项、持续 1 回合的普通事故；若本次成功或大成功，则获得 15 实验值。`万象奇釜`不能消耗观测记录，禁用、失控与其他重大事故不被改写。每回合最多形成一次记录。

**传承·善后笔记（本职）**

每回合第一次以 `反应中和` 实际移除己方一项由自己造成的事故后，获得 8% 最大生命生命护盾 2 回合、恢复 30 MP，并得到 `复盘` 2 回合。下一次不同主粒子的有效调配成功命中时，第一个非控制类正面效果持续时间 +1 回合；若为大成功，额外恢复 10 实验值。未移除事故而仅给队友补护盾时不触发。

核心循环是“高风险三/四粒子调配 → 观测换主材 → 事故中和 → 复盘强化下一份配方”。它保留失败风险，但不会让一次失败完全断掉后续回合。

### 3.2 御器师·百器共鸣 / 归鞘余响

定位：多武器组合、器性切换、连段回收。

**固有被动·百器共鸣**

| 静态属性 | 数值 |
| --- | ---: |
| 物理攻击 | +12% |
| 魔法攻击 | +12% |
| 抗暴率修正 | +10% |

战斗规则：同一次器阵行动中，第二种不同武器类别成功命中后，对目标留下 `器性回响` 至行动结束。之后该行动内每种尚未使用的武器类别首次命中，可额外继承上一种武器**已经成功生效**的普通器性 50%：剑/书只继承物防或魔防降低数值，拳刃只继承伤害降低数值，法球只继承护盾数值。继承不再进行控制命中判定，不复制额外目标、驱散、终结、追击与资源获得。每次器阵行动最多继承一次。

**传承·归鞘余响（本职）**

每 2 回合一次，`三器合锋`使用至少两种不同类别、且所有选定武器均成功命中时，恢复 15 器鸣并获得 `归鞘` 2 回合，记录本次最后一种武器的普通器性。`归鞘`期间下一次以**不同类别**发动的御击、合锋或归宗命中时，附带该记录器性 60% 的普通数值效果，随后消耗；不复制控制、额外目标或终结效果。这样御器师有“合锋建回响 → 换器消费 → 再合锋”的循环，而不是只把多段伤害做大。

### 3.3 发明家·异械主脑 / 验收合格

定位：双器械联动、能源调度、稳定爆发。

**固有被动·异械主脑**

| 静态属性 | 数值 |
| --- | ---: |
| 最大 MP | +20% |
| 物理攻击 | +10% |
| 魔法攻击 | +10% |
| 命中率修正 | +10% |

战斗规则：最近两个自身行动中，两种不同主能力的异械都实际产生有效结果时，获得 `主脑链路` 2 回合。链路期间，下一次驱动第三种不同主能力的异械时，其第一个可缩放、非伤害附属效果以 60% 强度投影给另一合法目标：友方效果投影给生命比例最低的另一名队友，敌方效果投影给当前目标。不能投影控制、驱散、生命护盾、额外召唤、随机效果或一次性减伤。每 2 回合一次，投影后消耗链路。

**传承·验收合格（本职）**

每 2 回合一次，`双机协同`让两台不同异械均实际生效后，恢复当前能量较低的一台 20 点能量，并使两台异械各减少 1 回合原生冷却，获得 `验收` 2 回合。`验收`期间下一次单器械行动若成功命中或成功影响队友，会把本轮未使用的另一台异械标为 `待机`：其下一次能源消耗降低 25%，最低仍为原消耗的 60%。待机只对同一台异械生效，不能与全域调试的即时启动叠成零成本。

核心循环是“异能力 A → 异能力 B → 主脑链路投影 C → 双机协同验收 → 待机回收”。它加强的是设备调度效率和功能覆盖，不直接突破双机协同原有的控制、驱散、治疗、护盾预算。

### 3.4 执奕者·全局视野 / 留下一手

定位：回合预判、计划干预、战场次序。

**固有被动·全局视野**

| 静态属性 | 数值 |
| --- | ---: |
| 最大 MP | +15% |
| 物理攻击 | +8% |
| 魔法攻击 | +8% |
| 速度 | +12% |
| 控制抗性 | +15% |

战斗规则：每回合开始时，自动记录下一个敌方行动单位及其已公开行动类型（攻击、支援、准备）。对该单位设置的条件预案成为 `预判计划`。预判计划成功时，额外揭示该单位下一次行动，并允许执奕者在下一自身行动前免费替换一次尚未触发的预案；若替换后目标或模式不再合法，则该免费替换失效而不返还筹策。该效果不提高守势减伤、接应护盾或截断基础概率，强在让玩家准确调整下一手。

**传承·留下一手（本职）**

每 2 回合一次，任意条件预案成功触发后获得 `余策` 2 回合。`余策`会根据预案类型附加一个不同的残局处理：守势使被保护队友清除 1 个普通减益；接应使实际生成的生命护盾延长至下次目标回合结束；截断成功时使目标获得 20% 减速 1 回合。随后下一次设置预案的筹策消耗降低 25%，最低仍为原消耗的 60%，并消耗 `余策`。若预案没有真正触发，或截断被目标顶住，则不产生余策。

核心循环是“读取先手 → 预判预案 → 成功触发 → 余策修正残局 → 更低成本布置下一手”。执奕者强化的是信息与回合次序，不能靠堆直接倍率取代输出职业。

| 夜刃 | 标定、背隙、割喉、终章均为物理刺击。 | 物攻对物防。 | 暴击率、暴伤与速度比直接物攻更符合追猎收割，不与剑豪重复。 |
| 蚀毒师 | 蛇吻为物理刺击；腐雾、毒爆、封喉为暗系魔法，另有剧毒与引爆。 | 同时使用物攻、魔攻、敌方双防与 Boss 百分比掉血规则。 | 不单偏向物攻或魔攻；`剧毒/引爆 +25%`与破韧命中修正才会同时覆盖整套混合循环。 |
| 机关游侠 | 钩索、测绘、协猎为物理刺击；烟幕为机关支援。 | 物攻对物防，且束缚、追猎、测绘依赖命中。 | 不额外堆物攻是有意取舍；命中、速度、最终命中率修正强化其稳定锁定和队伍协猎。 |
| 圣愈者 | 四项均为治疗、净化、再生与壁垒。 | 直接治疗取魔攻系数，随后结算治疗加成；再生与群体效果按技能规则。 | 治疗 +12%、再生额外恢复、MP 三项直接覆盖核心；不额外叠魔攻以免救援链过度膨胀。 |
| 圣盾使 | 四项均为减伤壁垒、生命护盾、濒危不倒。 | 主要按目标最大生命与固定减伤规则，不以攻击造成伤害。 | 生命、双防、自身减伤正确；魔攻不会显著提高本职保护量。 |
| 晨星祷者 | 烙印、驱邪、连祷、破晓均为光系魔法。 | 魔攻对魔防，再乘光系技能最终伤害。 | **魔攻 +12%、光系技能最终伤害 +15% 正确**；它是唯一明确的光系输出支援。 |

这张表只复核主动技能真正走到的伤害/治疗/防护公式，不把技能名称当成类型判断依据。世界树 12 职的固有强化选择可以保持不变；本轮无需为普通二转改动攻击属性。

## 4. 强度复核与队伍配合

### 4.1 固有属性强度分层

| 类型 | 职业 | 强化理由 |
| --- | --- | --- |
| 高成长单轴 | 剑豪、元素使、蚀毒师 | 分别压在暴击、四元素、破韧/毒伤的专属赛道；不再额外给全能攻击。 |
| 攻防混合 | 盾卫、战斗法师、圣盾使 | 用防御、生存与对应攻击构成，避免仅靠最终减伤变成无条件硬坦。 |
| 节奏属性 | 战旗使、夜刃、机关游侠、执奕者 | 速度与命中服务先手、锁定、收割和计划，不直接复制主输出数值。 |
| 支援成长 | 唤灵师、圣愈者、晨星祷者、魔学者、发明家 | MP、治疗、光系或特殊系统收益，避免通用暴击把支援职业推向同质输出。 |

### 4.2 建议的四人协作样例

```text
战旗使先上减益
  -> 队友接「军令」
  -> 战旗使以「应旗」回砍
  -> 剑豪命中破甲/易伤目标，制造「裂口」
  -> 单体爆发队友消费裂口

元素使上火/冰/风/雷中的新印记
  -> 另一元素技能消费「导相」
  -> 唤灵师借治疗/护盾触发「灵荫」维持场面
  -> 圣愈者濒危治疗跨过 50%，把余辉转给第二名队友

圣盾使的护盾或壁垒承伤
  -> 目标获得「誓痕」与下回合恢复
  -> 盾卫的「护阵」转移关键单段伤害
  -> 晨星祷者驱散敌方增益，打开两种伤害类别的「晨钟判词」
```

这三条链的状态分别是军令/裂口、导相/灵荫、誓痕/护阵/晨钟，不共享同名层数，能够并行存在；但每条都有每回合与目标限制，因此不会被 AoE 多段无上限放大。

### 4.3 风险控制

| 风险 | 约束 |
| --- | --- |
| 暴击叠得过高 | 剑豪的 +33% 按未满足概率补足，强度高于属性加成；因此本职裂口收敛为 +12% / +15%，旁修为 +8%，且每次只给一名不同队友。抗暴率修正在正向修正后降低当前被暴击概率。 |
| 元素循环过强 | 元素 +50 只覆盖四系；导相要求不同元素且每目标每回合一次。 |
| 毒伤跳过 Boss 血量设计 | 毒性回流严格计入 Boss 百分比掉血上限，且有 0.45% 最大生命即时上限。 |
| 保护链无限套娃 | 护阵转移不触发其他承伤事件；圣盾使每名队友每回合仅结算一次。 |
| 治疗滚雪球 | 余辉只在生命跨越 50% 时生效，且以实际恢复量计算。 |
| 多人 AoE 重复消费 | 军令、裂口、导相、晨钟都限制“下一名”或“不同伤害类别的首次”触发。 |

## 5. 实施映射

### 5.1 配置与属性缓存

1. 在 `advanced-profession.config.ts` 中将固有被动拆为 `panelEffect`、`probabilityModifier` 与 `battleEffect`。`probabilityModifier` 缓存为角色最终配置，但只在目标对抗概率已得出后应用：正向修正补足未满足概率，负向修正降低当前概率；避免把“每回合回蓝”“元素精通”或概率修正伪装成普通数值属性。
2. 人物详情刷新时，按既定顺序结算：六维 → 装备数值词条 → 进化百分比与装备百分比合算 → 二转 `panelEffect`。二转百分比不可被重复写入战斗单位。
3. 增加火、冰、风、雷四项 `elementMasteryBonus` 缓存字段；元素使 +50 必须在角色详情与战斗单位共用同一份最终元素精通。
4. 暴击率、命中率、破韧命中率的正向修正统一使用补足未满足概率语义；抗暴率、控制抗性等防御侧修正统一降低当前概率。暴伤仍为人物暴伤属性，不使用“修正”一词；界面统一展示为“暴击率修正”“抗暴率修正”“命中率修正”“破韧命中修正”“控制抗性”。

### 5.2 传承状态与战斗钩子

1. 传承不应再只保存一组 `[本职数值, 旁修数值]`。配置需增加明确的 `mechanicId`、触发者范围、目标范围、次数上限、持续时间与本职/旁修分支。
2. 为 `军令`、`应旗`、`裂口`、`导相`、`护阵`、`灵荫`、`回路`、`退影`、`蚀媒`、`猎线`、`誓痕`、`晨钟判词` 建立可展示、可到期清理的战斗状态定义。
3. 每个带“成功施加”“成功驱散”的传承，都读取实际命中与实际驱散结果。不能以技能配置表中“拥有某效果”作为触发依据。
4. 百分比持续伤害应在一次回合内先汇总，后按目标是否 Boss 的总上限截断；`毒性回流`必须走同一入口。
5. 生命护盾层需保存创建序号、来源、数值、到期回合；受击按最早创建的层优先消耗，单层数值不超过持有者最大生命。

### 5.3 UI 与说明

- 角色详情只展示固有的静态属性；战斗触发效果写在对应被动说明内，避免误以为常驻。
- 二转成功后才展示本职完整固有与传承说明；未完成试炼时不暴露隐藏固有。
- 技能面板中的传承说明要逐条包含：触发条件、作用对象、持续回合、次数限制、是否消耗状态，以及本职/旁修差异。
- 不为本方案新增二转主动技能专精入口或等级分数显示。

## 6. 上线顺序与验收

建议分三批上线，避免一次性改变所有队伍伤害曲线。

1. **属性批**：盾卫、战旗使、剑豪、元素使、夜刃、蚀毒师、机关游侠、圣愈者、圣盾使、晨星祷者的固有静态层；先用角色详情、PvE 假人和 32 级 Boss 核对属性顺序。
2. **常驻传承批**：军令、裂口、导相、护阵、灵荫、回路、退影、蚀媒、猎线、余辉、誓痕、晨钟；逐条建立单人、本职四人队、旁修四人队测试用例。
3. **隐藏系统批**：魔学者、御器师、发明家、执奕者。由于依赖特殊资源与菜单，需要单独验证不会污染普通主动技能和自动出招配置。

每条传承至少验证以下情形：

- 本职触发一次、旁修触发一次、同回合重复触发被阻止一次。
- 目标死亡、换目标、驱散、护盾耗尽、持续时间结束时，状态均正确清理。
- AoE、追击、部位 Boss、召唤灵独立行动不会多消费一次“下一名队友”状态。
- 自动战斗只把当次无法释放的技能替换为当次普通攻击，不修改保存的自动出招配置。

## 7. 与当前实装的差异

| 项目 | 当前状态 | 本方案 |
| --- | --- | --- |
| 固有被动 | 多数为 2%～15% 的单一小数值 | 每职业有明确静态成长轴；元素使为四元素精通各 +50，剑豪为按未满足概率结算的暴击率修正 +33%。 |
| 传承 | 大多是一次性减伤、少量增伤或小护盾 | 改为可识别的出招链、状态消费、资源返还或保护时序。 |
| 旁修 | 常见为本职数值缩小版 | 保留一段可组合机制，但移除职业专属资源、召唤物、器械、筹策等不可借用部分。 |
| 状态判定 | 部分仅检查技能是否配置效果 | 要求依据本次真实命中、真实挂状态、真实驱散结果。 |
| 隐藏二转传承 | 当前主要为首次触发的 4% 生命护盾 | 改为与调配、换器、设备联动、计划干预相关的独立机制。 |

本文是平衡与实现蓝图，不代表上述数值已经生效。下一步实施前，建议先确认“剑豪 +33% 暴击率修正（补足未满足概率）”和“元素使四元素精通各 +50”作为两条标杆数值，再按本方案分批写入并进行 32 级 Boss 实测。
