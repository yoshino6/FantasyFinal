## 2. 72项新增主动技能

- 24物理、30魔法、18辅助；11基础、33下位、28中位。没有新增上位技能。
- 基础直伤95；奥术双矢为48＋47，两段分别结算防御，不按合计95一次穿防。
- 学习等级逐项遵循设计；学习SP按基础1、下位2、中位3。研读技能书只领悟，不替玩家扣SP学习。
- 三类物理、十类魔法覆盖单体、不同多目标、全体；直接威力参与攻防计算，不额外乘统一的防御后AOE折扣。
- 表内MP就是未专精、未装备减耗的实际消耗。物理数据库基础MP反算为表值÷0.4，避免再次打折。
- 全部72项接入共享战斗执行器，PvE和现有单挑PvP调用同一新增技能效果实现；不是只打印技能名称。
- 净化、治疗、最大生命盾、再生、双攻/双防、命中/闪避属性、速度、概率修正、灼烧和各类弱化均有执行分支。
- 普通净化不解除石化、魅惑、无限梦魇和机制保护；纯净化没有合法可清除目标时，提交前拒绝，不扣MP、不占行动。
- 同组新增增益取较强效果；不把旧强值与新弱值的较长持续时间拼接。一般新增持续效果最多4回合；灼烧最多3跳，并同时受Boss比例及施法者魔攻上限限制。
- 下位命中/闪避是属性点数，中位按概率修正处理，不偷换为最终百分点。没有顺手重做旧职业绑定被动或装备概率加成。

### 专精口径

严格沿用两份文档核对的**当前代码**：过充威力×1.06、强效×1.06、瞬息时间基数×0.94；前三项每次投入蓝耗×1.12，节能×0.88。没有恢复历史讨论中的8%或4%版本，也未改武器专精、鉴识及原有SP计价。

新增技能只开放实际适用的成长方向，固定目标数、段数、净化数量、穿透等固定机制不随强效放大。详情增加当前有效效果和到达上限提示。

### 目标与吟唱

- 友方单体优先选中的合法队友，未选时默认自身；双目标支援默认补充血量比例最低者。
- 两/三个不同目标有独立勾选确认面板；首个为主目标。选目标与行动提交共享事务，校验会话、回合和存活状态。
- 多目标及单体目标在提交时锁定；某个目标退场不会自动补打别人，不把主目标限定附效转给副目标。
- 全体技能释放时枚举当时合法存活目标，并过滤受机制保护不可选的目标。
- 吟唱复用现有开始、自动释放、状态中断与释放后起算CD流程；锁定目标保留至释放。当前回合使用“【角色】开始了技能吟唱。。。”文案。
- 技能详情仍按“威力/蓝耗/冷却/吟唱/效果”分行；新增辅助威力显示“—”，明确敌我与目标数量。

## 4. 浮叶航路任务与入口

任务：《风从未寄达的地方》，12幕。

入口：世界树根冠分会委托板，或 `/浮叶航路`。非M01浮叶开局，完成初行、Lv.6、已登记冒险者并选职业后可在(-5,-3,0)接取。没有初行记录的合格旧号也可接取；M01玩家继续原有剧情。

阶段：接取 → 查档 → 三处测风 → 乱流遭遇 → 修复风标 → 菲萝缇复核 → 三次校准 → 两波守风遭遇 → 安全确认 → 排障登舱 → 风枝会馆登记 → 公馆结案。

- 三个草原测风点：(0,-12,0)、(8,-16,0)、(16,-12,0)，避开世界树城镇覆盖区域。
- 进度、步骤、revision、难度与经验快照落库；旧按钮不能推进新阶段；结案奖励只发一次。
- 可从任务面板回顾已抵达的幕，支持离线后继续；队伍管理入口允许自行离队，不暗中解散整队。
- 任务战为私有镜像。乱流两只分别有斩击/打击弱点；风结两只低血低防，第二波是单体引航风核。
- 风核出场首次蓄势时暂停本场自动执行，提供一次“重新锚定”：占行动，打断蓄势并降20%双防2回合。也可手动选择常规攻击继续，不修改全局自动设置。
- 敌人以接取等级clamp(level,6,10)快照，使用同级普通怪物公式，不随玩家装备变强。乱流HP×0.8/攻击×0.75，风结HP×0.55/防御×0.6，风核HP×2/攻击×0.85/双防×1.1。
- 无战斗经验与掉落；战敗/撤离恢复入场HP/MP，接回世界树安全公会，保留该幕重试资格，不掉装备。正常战斗中的主动道具消耗不复制返还。
- 结案：600铜币、60贡献度、150战技券、个人航路许可、浮叶地图及接取时Lv.6～10经验需求的25%；经验通过现有境界规则结算，不强行突破。
- 世界航路开放和个人许可分开；首次结案在锁定世界记录后发布一次开通事件，其他玩家仍可完成自己的任务。
- M01原籍、旧号既有地图/仓库存图/已到镇内/历史抵达和原游镇记录有兼容许可。旧号兼容是一次性迁移，不会每次启动把新到访者自动变成旧号。
- 普通移动、地图路径、公会接驳、初行纪念物接驳补个人许可；队伍逐人检查。试航临时权限仅限已登舱的11/12幕及镇内行走，不能代替正式商店许可。
- 镇内保留安全返回及晚期任务的临时票重新接驳；管理员关闭区域时不强行开启地图。
- 原浮叶开局游镇、瓶颈、哥布林救援等仍按原籍条件走原支线，访客许可不赠送出生奖励。
