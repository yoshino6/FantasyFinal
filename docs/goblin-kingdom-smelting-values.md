# 哥布林王国怪材熔铸数值补充

> 本文为《哥布林王国怪物与掉落实施清单》的熔铸数值补充。仅修改设计文档，不实现源码。

## 设计定位

哥布林王国掉落的怪材用于熔铸时，统一采用直接数值加成，不使用仅描述性或百分比占位效果。整体数值高于幽暗密林常规材料，定位为接近森林大怪专属材料的高阶辅材；同一件装备的同类属性仍遵守现有熔铸上限与冲突规则。

## 规则与边界

- 表中数值均为熔铸后的固定数值加成，不解释为百分比。
- 同名材料的数值不叠加；不同材料可以叠加，但必须服从装备部位现有属性上限。
- “全属性 +6”分别增加力量、敏捷、体质、智力、精神、幸运各 6 点。
- 王旗残片与上校军徽的掉落率显著低于普通兵种材料；上校军徽每件装备最多生效一枚。
- 数值强度参考“森林大怪专属材料”：普通兵种材料高于幽暗密林常规材料，敢死血晶、暗蚀晶核、穿岩甲片进入接近档，王旗残片与上校军徽进入精英档。
