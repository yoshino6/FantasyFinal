# 幽暗密林深处·哥布林王国

> 状态：待实施设计稿
>
> 本文是本次内容的第一阶段交付物，只列出完整改动清单、数据设计与验收口径；本轮不修改游戏源码与数据库种子。

## 1. 目标与范围

在 `dark_forest_deep`（幽暗密林深处）加入一套 8–25 级的哥布林王国敌对生态：

- 普通遭遇以 2–4 只为一队生成，并共享同一坐标、同一遭遇组。
- 极小概率生成“哥布林上校”带队的精英队伍；上校不会作为普通地图池中的独立怪物出现。
- 兵种覆盖先锋、战士、弓箭手、自爆兵、敢死队、祭司、法师、刺客、土行者，并加入盾卫、战鼓手、网罗工兵三个新兵种。
- 所有本组战斗技能使用新的 `goblin_*` 技能编码，尽量不复用现有史莱姆、野兽、NPC 或地下迷宫技能。
- 新增一批可掉落、可打造、可熔铸的哥布林怪材；暂不加入新的装备成品。
- 保留现有怪物图鉴、鉴识、经验、掉落、技能领悟与锻造熔铸流程，优先通过新增模板和少量通用能力扩展完成接入。

## 2. 当前实现基线

### 2.1 已有区域

`src/database/bootstrap.ts` 已有：

- `dark_forest`：幽暗密林外围。
- `dark_forest_deep`：幽暗密林深处，范围约为 `x=-50..49`、`y=-210..-111`、`z=0`，危险等级 2。
- 深处目前有移动文本和资源池，但没有哥布林王国怪物池。

### 2.2 现有怪物属性生成方式

属性不能简单把模板六维当成最终面板。实际生成链如下：

1. 模板六维作为随机分配权重。
2. 按 `monster_class` 随机生成总六维点数：
   - `normal`：45–65。
   - `large`：65–90。
   - `elite`：90–120。
   - `boss`：120–150。
3. 六项初始各为 1，剩余点数按模板权重与 `0.85–1.15` 的随机扰动分配。
4. 最终六维为：

   `最终属性 = 随机分配属性 + max(0, 等级 - 1) × 对应成长`

5. 使用 `calculateDerivedStats()` 计算生命、魔力、双攻、双防、命中、闪避、暴击、暴伤、暴抗、速度等派生属性。
6. 再按怪物类别叠加虚拟装备：`large` 为 1.00 倍、`elite` 为 1.15 倍；虚拟装备只提供武器主攻和五件防具的双防。

因此，下表中的“模板六维”是权重，不是固定出生属性；“代表面板”是用该类别平均总点数、等级区间中位数计算的平衡参考，实际生成值会有随机波动。

## 4. 队伍生成规则

### 4.1 组队概率

每个普通哥布林遭遇组按下表决定人数：

| 人数 | 概率 |
|---:|---:|
| 2 | 45% |
| 3 | 40% |
| 4 | 15% |

队伍总遭遇中：

- `99.5%` 为普通哥布林队伍。
- `0.5%` 为上校带队队伍。
- 上校队伍人数仍为 2–4，其中 1 只固定为上校，其余为普通兵种；额外成员至少包含先锋、战士、盾卫、战鼓手之一。
- 普通队伍优先从池权重抽取首个兵种，后续成员再次按池权重抽取；同一队允许重复兵种，但祭司、法师、战鼓手、网罗工兵的数量最多各 1 只。

### 4.2 数据库表达

建议给 `monster_spawns` 增加：

- `encounter_group_id CHAR(36) NULL`：同一队共享 UUID；旧怪物为空时按现有单体逻辑兼容。
- `encounter_group_role ENUM('member','leader') NOT NULL DEFAULT 'member'`：只有上校为 `leader`。
- 索引 `(region_id, pos_x, pos_y, pos_z, defeated_at, encounter_group_id)`。

无需改变现有 `combat_sessions.spawn_id` 语义。进入战斗时仍通过同坐标查询所有怪物；新增字段用于刷新、清理、上校带队标识、日志与防止半支队伍被清理。

### 4.3 刷新与清理

- `spawnMonsters()` 在 `dark_forest_deep` 使用“补齐队伍数”而不是“补齐单只数量”。
- 一个队伍的所有成员写入同一坐标、同一 `encounter_group_id`，整队计为一个刷新单元。
- 计算刷新上限时按队伍计数；清理超额目标时整队清理，不能只删除队伍中的一只。
- 若某队伍已有成员在战斗中，刷新与清理均跳过该 `encounter_group_id`。
- 现有其他地图继续保持单体刷新行为，避免影响外围幽暗密林、地下迷宫和追捕系统。

## 6. 技能效果与战斗引擎改动

### 6.1 可复用的现有效果

以下效果可直接复用已有 `effect_definitions`：`burn`、`slow`、`stun`、`bind`、`barrier`、`regeneration`、`mana_regeneration`、`vulnerability`、`armor_shatter`、`imbalance`、`sprint`、`shadow_pierce`。

### 6.2 需要新增的效果或特殊分支

- `goblin_mark`：被标记者受到哥布林命中修正；战斗结束清除。
- `goblin_formation`：上校的协同攻击防重复触发标记。
- `goblin_revenge`：自爆/敢死队的反噬与一次性触发状态。
- `goblin_hidden`：影缝的隐匿状态；展示为状态而非普通闪避数值永久修改。
- `goblin_reflect_barrier`：土行者反伤护盾，护盾消失时只结算一次。
- `goblin_colonel_execution`、`goblin_last_fuse`、`goblin_sacrificial_return`、`goblin_colonel_gather`：加入怪物技能 AI 特殊分支，不能只依赖普通 `applySkillEffects()`。

自爆规则必须保证：

- 同一个自爆兵每场战斗最多触发一次。
- 触发后把自身标记为已击败，并正常进入结算；爆炸伤害只对仍存活的玩家和哥布林目标结算。
- 若自爆兵被直接击败，按“濒死触发”配置决定是否在死亡前结算一次；不能重复触发两次。
- 自爆兵的死亡仍提供经验与普通掉落，爆炸不是额外一只怪物。

### 7.1 预计掉落规则

- 所有哥布林：`goblin_ear` 65%–90%，数量 1–2；`goblin_scrap_iron` 25%–55%，数量 1–2；铜币按等级 8–35。
- 先锋 / 战士 / 盾卫：废铁、粗磨刃石；盾卫额外掉落战鼓皮。
- 弓箭手 / 网罗工兵：林弦筋；网罗工兵少量暗幕布。
- 自爆兵 / 敢死队：爆裂核心 45%–70%，数量 1；敢死队 8% 概率额外掉落 1 个。
- 战鼓手：战鼓皮 55%–75%，数量 1–2。
- 祭司 / 法师：沼影图腾片 35%–60%；祭司 10% 概率掉落军令残印。

## 8. 技能领悟规则

沿用 `monster_skill_learn_rules`：

- `source_skill_code` 必须是对应怪物实际持有的 `goblin_*` 技能。
- 目标技能与来源技能的 `category`、`damage_type` 必须一致，满足现有战斗结算查询的兼容条件。
- 领悟概率使用本表“可领悟”数值，并继续叠加全知者洞察与家园训练加成。
- 普通兵种最多为 1–3 个可领悟技能；上校技能默认不可领悟，避免稀有带队技能被大量复制。
- 可领悟技能的 `learn_cost`：基础兵种 1，进阶技能 2，上校专属技能不开放学习。
- 技能图鉴只有在玩家实际领悟后开放详情，符合现有“未领悟不可查看完整信息”的行为。

建议可领悟技能总数控制在 16 个左右：

`goblin_crossrush`、`goblin_marking_horn`、`goblin_sawtooth`、`goblin_bloodrush`、`goblin_forest_bolt`、`goblin_volatile_flask`、`goblin_death_oath`、`goblin_spiked_net`、`goblin_dust_retreat`、`goblin_shieldwall`、`goblin_war_drum`、`goblin_bone_prayer`、`goblin_mudstar`、`goblin_soulscorch`、`goblin_silentthroat`、`goblin_burrow`。

## 10. 平衡与风险控制

- 上校虽然是 `elite`，但其等级固定 25、成长和完整技能组应使其明显高于其他哥布林；不应再叠加 Boss 的生命 ×4 规则。
- 上校队伍的实际难度来自“协同”而不是单纯堆叠属性；军令技能必须有冷却、蓝耗和每回合触发锁。
- 自爆兵不得通过复生、撤退或重复战斗结算产生第二次爆炸掉落。
- 普通队伍不应把四只高阶施法者同时抽出；支持兵种每队最多 1 只的限制必须在生成器而不是展示层执行。
- 新怪材熔铸效果不得绕过现有稀有度上限，也不得加入普通主材精炼路径。
- 新技能使用全新 code，但控制、护盾、灼烧等底层效果可以复用；若确实新增效果，必须在 `effect_definitions` 中说明最大层数、持续回合和叠加规则。
- `dark_forest_deep` 被 `dark_forest` 的危险等级覆盖逻辑识别后，必须确认深处刷新不会被外围池覆盖。
- 旧有幽暗密林的 `goblin`（4 级哥布林）保留，不能让新模板替换或删除外围既有生态；新王国只在深处出现。
