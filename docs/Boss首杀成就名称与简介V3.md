# Boss首杀成就名称与简介V3

覆盖当前17组正式Boss遭遇，为11档随机难度及固定剧情档预备204组独立文案。文案预备不等于开放全部组合，仅实际胜利结算的组合会进入成就定义库。内部编号与达成名次保持不变；稀有度和点数按用户最新确认表，属性方向按本表分配，不重复发放道具匣。

迷宫镇守者为未被现行迷宫选用的旧模板，不参与Boss成就；大学者·噶为剧情角色，不参与Boss首杀成就。哥布林国王、哈巴龙与王庭随从只按一个完整遭遇结算，统一使用goblin_king编号与整场胜利的实际难度，哈巴龙不单列。

具体Boss与难度映射仅供维护审核，游戏公告与详情不显示操作要求。

**已按用户确认落实：英雄为优秀+2，地狱为精良+3，猩红为稀有+3，其余按新表；固定档暂保留普通+1。每个Boss的12档各覆盖六维两次。完整204项预备目录合计901点：力量151点，其余五维各150点。实际已开放难度的子集不保证同样均衡。**
