# 开局系统设计差异与新手安全指引复核

> 后续变更说明（2026-09-08）：初始能力正在按[天赋 V2](./初始天赋重设计方案V2.md)迁移，地图奖励新增[奖励 V4](./地图初始路线奖励与信物修订V4.md)。本文 113 分支与全绿验证属于修复时的旧能力快照，不涵盖后续新增天赋；当前代码冲突与本轮检查结果见[天赋与开局衔接复核](./天赋V2与地图开局衔接复核.md)。

复核日期：2026-09-08。依据当前工作区源码、V1 系统与 F01～F03、V2 保留路线、V3 重写六图，以及后续用户明确修订。

## 结论

**在当前配置快照和本轮修复后的代码下，新角色可以由注册、选择恩赐、首次行动，经初行故事抵达安全公会。**隔离 MySQL 已逐一执行 14 图、42 路线、113 个分支的注册与剧情 SQL；全部完成安全落脚、入会及必要的凭物交接，无额外经验时到 Lv.3。

这不等于整套设计全部实装，也不等于正式 QQ 客户端已完成验收。完整属性重算和开化档案在本次流程测试中使用替身；正式库只读取地图、结构与物品等配置，未执行生产初始化、迁移或重启。

目前正式配置有 **10 张可供普通玩家降临的地图**。沉星沼泽、霜冠高原、雷鸣断崖、月蚀遗迹未开放给普通玩家，所以现在不会随机出生到这四图；它们的分支已在临时库单独开放后验证。没有为了测试修改正式地图开关。

## 本轮发现并修复

| 问题 | 原行为与影响 | 修复及验证 |
| --- | --- | --- |
| 未开始剧情的“继续”无效 | 角色仍是 `armed` 时，消息提交翻页，但服务不接受该阶段翻页；先点其他功能的新手可能收到不能继续的提示。 | 新页面改为 `/继续剧情` 启动；旧 `/初行选择 0 next` 也兼容启动，重试不重复推进。SQL 与消息入口测试通过。 |
| 抵达后先办理、后入会 | 非百纳镇角色仍站在门口，主线却先引导凭物服务；服务层要求已进入公会，出现指引与门槛矛盾。 | 当前路线主线先检查实际位置和入会状态，再引导凭物／女神／选职。113 分支逐一验证入会后的下一步可办理。百纳镇原有建筑进入状态也兼容识别。 |
| 安全终点仅检查部分配置 | 原出生筛选只看安全地图开放；结算不核验公会坐标的地块归属，也可能选择缺当地地图物品的终点。 | 出生及护送共用安全公会筛选：开放、公开、无普通刷怪、真实公会建筑、合法地块坐标、当地地图物品齐全。结算前不可用则改道；全部不可用则事务回滚并保留故事保护。 |
| 王冠混穿丢失护持 | 史诗读取只保留件数最高的一套；例如其他史诗三件＋王冠一／两件时，王冠计数被覆盖。 | 王冠残光护持独立计件，开战读取与装备摘要同步。验证混穿时仍获得对应 5%／8% 护盾，其他史诗套装的原有计数保留。 |
| G08 提示名称不一致 | 交涉提示使用“倾听万物”，与目录“万语聆听”不一致。 | 统一为“万语聆听”，未改变交涉概率或心情公式。 |
