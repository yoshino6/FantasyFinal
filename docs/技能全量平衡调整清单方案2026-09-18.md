# 技能全量平衡调整清单方案（2026-09-18）

## 1. 本轮范围

本方案覆盖所有会进入实际战斗结算的技能：

| 范围 | 当前盘点 | 处理方式 |
|---|---:|---|
| 玩家原生/历史可学习技能 | 253 项 | 按基础、下位、中位重新核对威力、蓝耗、冷却、目标范围与附效 |
| 域民可领悟技能 | 104 项 | 保留域民自身技能池；同步辅助比例、硬控边界和吟唱补偿 |
| 三地技能书 | 72 项 | 与普通技能统一规则；吟唱技能单独补偿；群体技能维持直接威力显示 |
| 二转职业固有、传承与绑定技能 | 12 套职业配置及其主动/被动 | 以职业定位和二转冷却档位复核，取消必中/必暴式绝对结果 |
| 怪物、精英、Boss 技能 | 由 `bootstrap.ts`、怪物模板与地图技能轮换共同驱动 | 玩家同类技能同步规则；Boss 机制、部位破坏、阶段技能保留独立上限 |

本文件是改动清单方案，不代表本轮已经写入源码。实现时必须同步配置、数据库初始化覆盖、实际战斗执行器、技能详情文案和测试。

## 2. 总体数值基准

### 2.1 回合成本

1. 技能消耗行动；吟唱技能在当前回合只记录吟唱，下一回合自动释放。吟唱期间被打断时，按现有规则处理已支付 MP，不提前进入完整冷却。
2. 冷却是技能释放后的完整等待回合数；持续 3 回合的辅助技能冷却不得低于 3，持续 2 回合不得低于 2。
3. 对无吟唱、无冷却技能，专精时间计算仍以 `+1` 为基数，结算百分比后再 `-1`，避免 0 值技能被错误放大成负数或永久可用。
4. 强效可提高普通数值和持续时间，但不延长石化、魅惑、梦魇等机制硬控；瞬息只能加速时间，不改变硬控免疫边界。

### 2.2 分阶攻击基线

| 档位 | 单体直接威力参考 | 群体直接威力参考 | 常见冷却 | 说明 |
|---|---:|---:|---:|---|
| 基础 | 90–105 | 55–70 | 0–1 | 用于循环、补刀、低成本铺垫；附效极少 |
| 下位 | 110–140 | 70–100 | 1–3 | 单体有明显用途；群体按目标数折损，不用隐藏倍率 |
| 中位 | 135–180 | 90–135 | 3–6 | 允许强条件、吟唱或高质量辅助；同冷却下群体仍低于单体 |
| 二转专属 | 120–190 | 85–145 | 2–6 | 由职业定位决定，不能只靠高倍率覆盖所有场景 |

实际威力还要结合属性、攻击/防御公式、目标数量、附加状态和吟唱行动成本；群体技能不再使用无法从详情理解的隐式二次倍率。

### 2.3 辅助技能比例

| 类型 | 下位建议 | 中位建议 | 冷却/持续约束 |
|---|---|---|---|
| 群体攻击提升 | 以“施法者×12%+受益者×8%（3回合）”和“施法者×16%+受益者×12%（2回合）”作为**上沿参考**；普通下位技能建议取上沿的 70%～100%，允许上下约 5%～10%波动 | 在下位实际系数上提高约 15%～20%，但先检查目标数量、冷却和蓝耗，不强制所有中位技能达到上沿 | 冷却不得小于持续时间；中位一般 4–6 回合 |
| 群体防御提升 | 攻击增益实际系数的 1.3～1.5 倍；只有高冷却/高蓝耗技能才取满 1.5 倍，并允许小幅上下波动 | 在对应下位实际系数上提高约 15%～20% | 防御增益冷却不得短于持续时间 |
| 群体命中/暴击 | 攻击增益实际系数的 1.6～2.0 倍；基础/低蓝耗技能取低位 | 在下位实际系数上提高约 15%～20%，或把部分数值转成命中/暴击修正 | 不写“必定命中/必定暴击”；采用评分、命中值或命中修正 |
| 单体攻击/防御/命中/暴击 | 群体同档实际效果的 1.75～2.5 倍；只有 5–6 回合冷却或明显高蓝耗时才取 2.5 倍；同档技能之间允许约 5%～10%波动 | 群体中位实际效果的约 2 倍 | 单体强辅助必须有更长冷却或更短持续时间 |
| 下位敌方减益 | 单体降低 8%～15%；群体为单体的约 50% | 效果提高约 20%，或增加第二个弱减益 | 双属性减益分别取单属性的 60%～70% |

辅助数值采用“施法者系数 + 受益者系数”的混合公式，但系数是**按技能档位取范围**，不是所有技能固定套同一组数。以群体攻击增益为例：

```text
三回合群体攻击（下位常用） = 施法者对应攻击属性 × 0.084～0.12 + 受益者对应攻击属性 × 0.056～0.08
两回合群体攻击（下位高成本） = 施法者对应攻击属性 × 0.112～0.16 + 受益者对应攻击属性 × 0.084～0.12
```

取值规则：基础技能取范围下沿；普通下位取中段；高蓝耗、长冷却或需要吟唱的下位技能才接近上沿；同一档位不同技能可以有约 5%～10% 的上下波动，用于区分职业定位和附加条件；中位先在实际下位系数上乘 1.15～1.20，再根据冷却和目标数决定是否接近用户给出的上沿。物攻增益读取物攻，魔攻增益读取魔攻；混合技能分别计算两种属性。施法者部分受技能等级、专精和职业加成影响，受益者部分只读取受益者当前战斗属性。

### 2.4 多 Buff 技能的总预算

辅助技能允许同时提供多个 Buff，但不能把多个单项技能的满额数值直接相加。每个技能先计算一个“单回合辅助预算”，再在 Buff 之间分配：

| 同时存在的独立 Buff | 每项建议强度 |
|---:|---:|
| 1 项 | 使用该档位的 90%～100% |
| 2 项 | 每项使用该档位的 65%～80% |
| 3 项 | 每项使用该档位的 45%～60%，且至少有一项应为命中、抗性或功能性小效果 |
| 4 项及以上 | 不建议用于普通玩家技能；仅限高冷却中位、二转或 Boss 阶段机制，并要求更高蓝耗/吟唱 |

例如，一个下位 3 回合群体技能同时提供攻击和命中时，不应同时给满额的攻击 12%+8% 和命中 24%+16%；更合理的是攻击、命中各取该档位约 70%，或保留一项满额、另一项降到约 50%～60%。这样可以让复合辅助有战术价值，但不会取代两个专门辅助技能的组合。

为了避免高难 Boss 战中出现一次群体辅助永久改变战局，建议增加软上限：群体攻击/防御/命中/暴击的单次增益不超过受益者对应基础属性的 30%（3 回合）或 40%（2 回合）；单体技能可放宽到 50%/65%，但必须付出更长冷却或更高蓝耗。超过软上限的部分按 50%效率计入，而不是直接溢出。

## 3. 具体修改清单

### 3.1 玩家原生技能（253 项）

- 基础技能：统一到低威力、低成本、0–1 回合冷却；发现“基础技能却拥有中位级威力/强控”的，降威力或移入下位。
- 下位攻击：单体通常落在 110–140；附带一个普通减益时，威力在纯伤害基础上小幅下调，附效按单体 8%～15%核定，群体折半。
- 中位攻击：按 3–6 回合冷却重新核对；高于 180 的仅保留给高成本、吟唱、明确条件或二转专属。
- 下位辅助：把“施法者×12% + 受益者×8%”和“施法者×16% + 受益者×12%”当作上沿参考，普通技能取其 70%～90%，高成本技能才取满；命中/暴击约为攻击增益 1.6～2 倍，防御约为 1.3～1.5 倍。
- 中位辅助：在实际下位系数上提高约 15%～20%，同时增加冷却；不以简单延长持续时间替代完整的行动成本。
- 复合辅助：允许同一技能同时提供多个 Buff，但按多 Buff 总预算衰减；攻击、命中、防御同时存在时，各项通常取单项强度的 65%～80%，不允许每项都取上沿。
- 取消所有玩家技能的绝对“必中/必暴”。改成“命中值、命中修正、暴击值、暴击修正、暴击伤害”中的一种，并在描述里写清是属性值还是最终修正。
- 单体治疗、单体护盾和单体增益统一优先读取战斗中选定的己方目标；未选择目标时才走技能默认目标。

重点复核原生配置中的 `precision`、`critical_focus`、`shadow_pierce`、`moonbolt`、`moonlight_bolt`、部分职业/装备联动效果：把“下一次必定命中/必定暴击”替换为高额但有上限的命中或暴击修正，并保留其冷却与触发消耗。

### 3.2 域民技能（104 项）

- 域民主动技能继续从其本局携带技能池抽取，最多 4 个主动；本轮只调整技能本体，不扩大抽取数量。
- 5 个吟唱域民技能按额外占用一回合补偿：石化咒提高控制基础命中但不延长硬控；援护回响提高复制比例；断罪之光和蚀印终结提高直接威力；根系共鸣提高每次根系回复值但仍保留每回合触发次数上限。
- 域民的必中类描述统一改为命中值/命中修正；控制命中受韧性、Boss 抗性和部位机制限制。
- 域民单体辅助按照群体同类效果的 2–3 倍核对，并确保冷却不短于效果持续时间。

### 3.3 三地技能书（72 项）

- 纯群体伤害技能：在同冷却单体技能的 60%～70%区间核对直接威力；不再通过隐藏倍率表达。
- 16 个吟唱技能重点增强：纯伤害群攻提高约 20%～30%；附带灼烧、减速、命中抑制、驱散等效果的技能提高约 15%～25%威力并同步加强附效；群体净化、护盾、再生提高核心数值而不增加无限叠加。
- 三个战技商店的技能书入口并入各自“我要买”页面；交易仍使用 `skill_shop_offers` 与技能书专用事务，不混入普通书籍库存扣减逻辑。
- 技能详情必须同时显示：威力、蓝耗、冷却、吟唱、目标范围和效果；“效果：”后写实际效果，不把效果塞进技能名。

### 3.4 二转职业技能与被动

- 12 套二转职业逐职业复核主动技能的威力/冷却/蓝耗和被动的最终乘区，先保证职业定位，再按上述基础/下位/中位档位落点。
- 战士/剑豪：高物理单体与破防不同时叠加过高易伤；群体战技保持较低直接威力，用号令和窗口效果体现价值。
- 法师/元素使/战斗法师：元素伤害按属性克制体现，不用必暴覆盖抗性；吟唱或高蓝耗技能才保留高爆发。
- 盗贼/夜刃/机关游侠/蚀毒师：命中、暴击和持续伤害改为高评分/高修正，不出现无条件必暴；攻击附带减益时威力折半校核。
- 牧师/圣愈者及支援路线：治疗、护盾、净化按施法者与受益者各 50% 计算；攻击/防御/命中/暴击增益改用本方案的固定系数，群体效果弱于单体，冷却至少覆盖持续时间。
- 唤灵师：灵位协同不通过额外无限行动放大；灵体的攻击/治疗/防御效果纳入同一回合预算。

### 3.5 怪物、精英与 Boss 技能

- 所有使用玩家同名技能的怪物，跟随玩家技能的基础威力、冷却、附效修订；怪物蓝耗仍按怪物模板资源单独缩放。
- 怪物独有技能在 `bootstrap.ts` 的技能定义和 `skill_effects` 表中逐项建立复核表：直接威力、目标数、减益数值、持续时间、控制概率和冷却必须同时记录。
- 普通怪物遵守同档技能区间；精英可在同区间上沿；Boss 可超出直接威力区间，但必须用阶段、部位、机制或明显冷却作为代价，不能直接使用必中/必暴常驻结果。
- Boss 的石化、魅惑、梦魇等机制硬控不改为普通净化可解除；解除条件仍由部位击破、阶段转换或神圣净化权限决定。
- Boss 群体技能按目标数和实际威胁同步检查，群体减益按单体的约 50%，双属性减益按单属性的 60%～70%。
- 复核三首雾沼蛇母、山脉心核·格鲁恩、熔炉监工·瓦尔克及其他区域 Boss 的全体技能，确保玩家获得反制窗口：吟唱提示、部位破坏、驱散类别、抗性与冷却均要在战斗记录中可读。

## 4. 取消必中/必暴的替换表

| 原机制 | 新机制 |
|---|---|
| 下一次攻击必定命中 | 命中值 +20～40 或命中修正 +10%～20%，按技能档位取值 |
| 下一次攻击必定暴击 | 暴击值 +20～40 或暴击修正 +10%～20%；不突破最终暴击上限 |
| 单体必中/必暴重击 | 保留高威力与低血条件，改为命中/暴击修正并提高冷却 |
| Boss 常驻必中/必暴 | 改为阶段窗口或机制状态；状态可被指定部位/阶段事件解除 |

## 5. 实装顺序与验收

1. 先生成全量平衡表：技能 code、类别、档位、目标数、威力、蓝耗、冷却、吟唱、辅助强度、持续时间、控制概率、是否玩家/怪物共用。
2. 修改配置与数据库初始化覆盖，保证重复启动只更新技能定义，不重置玩家已学技能、SP、专精、快捷栏和自动战斗设置。
3. 修改共享战斗执行器：辅助混合属性、目标选择、控制抗性、吟唱释放、群体效果和专精计算必须与详情一致。
4. 同步三个技能商店的“我要买”入口和所有技能详情文本。
5. 增加/更新测试：档位边界、冷却不短于持续时间、群体/单体比例、必中/必暴清零、吟唱技能释放时点、Boss 硬控净化边界、玩家与怪物同名技能一致性。
6. 验证命令：`npx tsc --noEmit`，再运行技能平衡与战斗规则专项测试；若数据库不可用，至少完成配置级和执行器级测试，并在实装报告中单独标记数据库验收缺口。

## 6. 本方案的平衡结论

用户提出的方向总体合理：高难度 Boss 战中，辅助应当改变队伍解题方式，而不是成为低成本的全队常驻乘区。建议把“效果强度”与“行动成本”绑定：群体效果牺牲数值，单体效果牺牲冷却；攻击附效牺牲威力；吟唱技能获得高威力或强效果；必中/必暴改为高修正但保留失败概率；复合辅助按总预算分摊而不是每项取满。数值在锚点上下保留小幅波动，可以区分技能个性并避免所有技能同质化。这样可以让辅助在高难战中关键，但仍给 Boss 抗性、部位机制、驱散和目标选择留下反制空间。
