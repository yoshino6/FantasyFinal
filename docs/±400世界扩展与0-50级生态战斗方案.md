# ±400 世界扩展与 0–50 级生态、战斗方案

## 1. 目标、边界与现状结论

本方案将地表世界扩展为 `x=-400..400、y=-400..400、z=0`，形成从世界树到 50 级内容的完整生态闭环；地下迷宫仍使用现有独立 `z=-30..-10` 逻辑，本期不改变其生成规则。

本期交付目标是后续实现的唯一内容基线，包含：

- 世界树外围 50 格宽草原环带、河道、石滩、山地、湿地、雪原、断崖和遗迹；所有地形均有名称、资源和生态用途。
- 幽暗密林、幽暗密林深处、百纳镇整体向南移动 50 格，并向东西扩展森林范围。
- 0–50 级分段怪物、精英、世界 Boss、掉落、可领悟技能和副职业消耗链。
- 以现有体力、经验、组队奖励和战斗公式为约束的成长节奏与验收口径。

### 1.1 现有实现必须保留

| 现有内容 | 保留策略 |
| --- | --- |
| `world_tree`、`dark_forest`、`dark_forest_deep`、`baina_town` | 更新边界和坐标，不改 code，避免剧情、NPC、传送、图鉴与存档失效。 |
| 幽影狼王 | 仍是幽暗密林的 Lv.12 Boss，保留召狼、践踏、扑杀、诅咒、噬牙与 `sky_dust`。 |
| 哥布林王国 | 仍位于幽暗密林深处；普通哥布林编队、上校编队、哥布林国王与哈巴龙同坐标双体遭遇均保留。 |
| 百纳镇功能 | 现有铁匠铺、糖水屋、异工坊、书屋、教堂、公会、百纳居一起下移 50 格。 |
| 现有怪物经验与 20 级后经验表 | 必须统一重平衡；当前 `experienceRequiredForLevel()` 在 20 级后固定返回 6000，不能承载 20–50 的目标节奏。 |

### 1.2 重要结构决策：区域不等于地形

当前 `map_regions` 同时承担角色所在区域、怪物刷新边界、资源边界和高危险区域覆盖判断。若把河流、道路、草地都直接插成重叠区域，会使 `spawnMonsters()` 的覆盖排除和角色 `current_region_id` 产生歧义。

因此采用两层模型：

1. **进度区域（`map_regions`）**：互不重叠或仅以明确危险等级覆盖，决定怪物池、资源池、移动、Boss、任务和角色所在区域。
2. **地形区（新增 `map_terrain_zones`）**：只提供地形名、移动修正、采集标签、遭遇修正和地图展示；可由多个矩形段拼成河道，不写入 `characters.current_region_id`。

不为 641,601 个地表坐标逐格建表。地形区以矩形片段、优先级和标签表示；河道、山脊等不规则形状由连续片段组成。每次坐标变动只查询当前位置命中的最高优先级地形区。

## 3. 生态与遭遇设计

### 3.1 通用约束

- 每个战斗区域固定 10 种常规/大型/精英敌人；Boss 不计入这 10 种。幽暗密林和深处沿用已有 15/13 种内容，不删减。
- `normal` 为单体常规怪，`large` 为高血量单体，`elite` 为精英；每个区域刷新构成建议为普通 70%、大型 22%、精英 8%。
- 当前深处哥布林维持 2–4 人同格编队；新区域首版保持现有单体遭遇，避免把编队刷新逻辑扩散到所有地图。仅 Boss 可拥有数据驱动的召唤物/护卫。
- 每只怪物至少有 2 条遭遇文本、一个生态材料、一个主要战斗定位；可领悟技能仅选择明确且可被玩家复用的技能，禁止把 Boss 即死、阶段切换和召唤技能开放给玩家。

### 4.1 Boss 刷新与收益

- 每个 Boss 同时只允许一个活跃实例；普通 Boss 击败后 60–90 分钟重生，50 级 Boss 120 分钟重生。
- 不使用“每次普通刷新随机尝试”作为唯一机制。新增 `map_boss_rules` 保存 `respawn_minutes`、`next_spawn_at`、`encounter_rule_code`，管理员刷新沿用现有接口。
- Boss 战消耗按非召唤目标数结算体力；召唤物不给额外经验、材料或体力消耗，防止反复刷小怪套利。
- 首杀额外给一次图鉴、地图通行/配方或稀有图样；重复击杀给稳定材料与低概率稀有，不能给可交易的无限首杀奖励。

### 5.3 掉落规则

- 常规怪每次至少拥有一个 55%–85% 的生态材料条目、一个 15%–45% 的特色材料条目；大型怪数量 2–3，精英追加 35%–60% 的精英材料。
- Boss 的核心材料 `chance=1`，数量固定 1；其余材料按独立条目判定。现有组队掉率、全知者掉率、幸运效果只能增加概率，不能复制固定核心材料。
- 玩家可领悟技能走现有 `monster_skill_learn_rules`：基础技能 10%–20%，精英技能 4%–8%，Boss 技能不开放；来源技能 code 必须确实存在于该怪物技能序列中。

## 6. 成长、体力与收益平衡

### 6.1 节奏口径

当前体力上限为第一境界 120，且每 5 分钟恢复 1 点，即自然恢复约 288 点/日；胜利体力按非召唤敌对目标数量扣除。以下周期按“角色不囤体力、仅用自然恢复、单人基准、没有成长祝福/经验药”的 288 点/日计算。组队的现有 +10%～35% 经验会相应缩短周期，属于组队收益，不再额外提高地图基础经验。

| 等级段 | 目标周期 | 可消耗体力 | 建议累计经验需求 | 目标经验/体力 | 常规遭遇经验与体力 |
| --- | ---: | ---: | ---: | ---: | --- |
| 10→20 | 约 3 日 | 864 | 30,000 | 34.7 | 单体 45–65 XP / 1 体力；2 体队 75–100 XP / 2 体力。 |
| 20→30 | 约 7 日 | 2,016 | 82,000 | 40.7 | 单体 70–95 XP / 1；精英 180–240 XP / 2。 |
| 30→40 | 约 15 日 | 4,320 | 198,000 | 45.8 | 单体 95–125 XP / 1；大型/精英 220–360 XP / 2–3。 |
| 40→50 | 约 25 日 | 7,200 | 396,000 | 55.0 | 单体 125–155 XP / 1；精英 320–450 XP / 2；Boss 900–1,500 XP / 目标数。 |

必须把 `experienceRequiredForLevel()` 改为 1–50 显式表或分段公式；推荐各段内每级需求平滑递增，段末不跳变超过前一级的 15%。现有 Lv.10–20 总需求约 29,100，可微调到 30,000；20–50 不能继续固定 6,000。

### 6.2 战斗数值与收益限制

- 普通同级单体：预期 3–5 回合击杀、承受 20%–35% 最大生命伤害；大型 5–8 回合；精英 6–10 回合；Boss 10–18 回合（两人队伍）。
- 等级压制：怪物比玩家高 3 级时，命中/控制压力明显上升但不应形成必败；高 5 级只作为风险预警或组队挑战，不作为主刷点。
- 每级区域的铜币与材料期望收益应覆盖约 1.2 倍同级治疗消耗；装备打造的主材则以 2–3 天稳定刷取为目标，Boss 核心以 3–6 次击杀为一个成品周期。
- 现有 `resolveStrike()` 命中、暴击、伤害和 `tenacityContest()` 控制对抗公式不改。新数值先通过模板六维、虚拟装备档位、经验和掉率调整；只有模拟确认无法达标时才动通用公式。

### 6.3 必做模拟

对每个 5 级档至少模拟战士、法师、盗贼、牧师各一套白板和一套同级打造装备，分别测单人、双人、四人：

1. 平均回合数、玩家剩余生命/魔力、药剂消耗；
2. 每 100 点体力的经验、铜币、普通材料、稀有材料；
3. 控制链、召唤物、再生/护盾是否能无限循环；
4. 成长祝福、幸运、全知者、经验药和四人队奖励叠加后的上限；
5. 旧有森林史莱姆、幽影狼王、哥布林国王遭遇的回归结果。
