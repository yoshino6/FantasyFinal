# 哥布林王国怪材熔铸数值定稿

本稿为上校军徽熔铸效果的最新定稿，覆盖此前“不可全属性”的限制。仅修改设计文档，不实现源码。

## 上校军徽熔铸效果

上校军徽可以提供基础六维加成，并根据装备部位追加高额战斗属性：

| 装备部位 | 基础效果 | 部位特化效果 | 备注 |
|---|---|---|---|
| 武器 | 力量、敏捷、体质、智力、精神、幸运各 +6 | 物理攻击 +18、魔法攻击 +18 | 高额双攻 |
| 防具 | 力量、敏捷、体质、智力、精神、幸运各 +6 | 物理防御 +22、魔法防御 +22 | 高额双防 |
| 饰品 | 力量、敏捷、体质、智力、精神、幸运各 +6 | 无部位特化效果 | 仅保留六维加成 |

## 生效限制

- 每件装备最多生效一枚上校军徽。
- 同一件装备不可通过多枚上校军徽重复获得六维或部位特化属性。
- 武器只触发双攻特化，防具只触发双防特化，饰品不触发双攻或双防。
- 所有数值均为固定数值加成，不是百分比加成。
- 上校军徽仍为哥布林上校极低概率掉落的精英材料。
- 由于每件装备只能生效一枚，六维与双攻/双防不会出现无限叠加。
