# 首领首通成就矩阵验收 V1

日期：2026-09-10。

本记录覆盖 17 组正式首领与 12 档难度的动态首通成就，共 204 条。它们按 `首领模板代码 + 难度代码` 稳定生成编号，不计入“当前有效静态目录 223 项”的逐项统计。

## 最终效果与正式入口

战斗胜利在 `combatAction → finishPartyVictory → achievementCombatVictory` 的同一事务中处理。单人须具备体力资格且造成实际伤害、实际治疗或对队友实际生效护盾，才会为本场合格首领写入对应难度的首通事实。两名以上真人同场时，只要其中一人满足该有效贡献口径，同场全部真人成员都会共享该首通；NPC不参与。成就账本随后在同一事务创建动态定义、完成记录、全服名次、首发名单、首发公告和奖励账本。

交涉不调用这一结算链，故降服不计。测试首领、导师试炼、召唤物、首领部位、城镇追捕和 NPC 切磋则在正式胜利入口与首领成就服务两层排除。单人无有效贡献，或多人同场均无有效贡献时，不会创建动态定义或完成记录。

首发的同场真人成员共享首发资格：首位公告只建一条，所有同场合格首发成员各获得一次首发奖励。公告按 `【甲】、【乙】、【丙】达成` 将名单合并在同一条消息中，随后依次显示成就名、引用简介和正常文本的 `获得：奇珍道具匣 ×1`。非首发的后来完成者只有该成就的常规奖励。首通不额外消耗 SP、快捷栏次数或独立货币；仍遵循该场正式 PVE 的正常开战体力与胜利结算。

## 验收结果

执行 `FF_ACHIEVEMENT_DB_TEST=1 npx tsx --test --test-force-exit test/achievement-boss-first-clear.integration.test.ts` 通过。

- 主效果与落库：矩阵中的 204 个动态定义均产生首发公告与至少一条首通完成；主验收角色拥有全部 204 条。所选合作首发额外使两名有效贡献者与一名零贡献真人队友完成其中一条，因此动态首通完成与首发成员记录均为 206 条。
- 条件与排除：单人无贡献、以及两名真人均无贡献的组队首领胜利都不生成动态定义或完成记录；带 `boss_test` 标记的目标被服务层拒绝。服务层同时拒绝导师试炼、召唤物、首领部位、城镇追捕和 NPC 切磋，即使未来有新入口直接调用也不会绕过。
- 时点与支付：事实只从正式 PVE 胜利结算服务产生；交涉没有该调用。成就本身无额外支付，常规战斗体力和胜利奖励维持原规则。
- 回滚与重试：对月蚀守望者·塞勒斯的梦幻档在提交前回滚后，动态定义、完成、公告均为 0；随后矩阵重试才产生首通。复用同一战斗凭据再次结算后，完成数、首发名单与奖励收据均保持不变。
- 全服首发：根冠公羊普通档以两名有效贡献者和一名零贡献真人队友验收；三人同时进入首发名单、各获得一次首发奖励，公告只有一条且三人名字合并显示。

本轮直接调用的是正式 PVE 胜利结算服务，并以源码断言守住 `finishPartyVictory` 的调用接线；没有将后台造数、管理员刷新或交涉事件当作玩家首通验收。
