# 新世界旅途

## 本次范围

入口 `新世界`（也支持 `/新世界`）；领取命令 `/新世界领取 等级`。每个角色每档只能领取一次，达到或超过等级即可补领，各档独立。

| 等级 | 奖励 |
| --- | --- |
| 1 | 新手生命药水（大）、新手魔力药水（大）各100；经验秘药（大）、幸运秘药（大）各10 |
| 10 | 10级普通装备，品质100%：头肩、上装、腰部、下装、脚部五件轻甲，加职业主副手两件 |
| 20 | 20级优秀装备，品质100%：同样七个部位 |
| 30 | 曜金合锭3、月银锻锭10、星铜锻锭20、陨铁锻锭50 |

用户已确认两档均为轻甲。武器按领取时职业匹配：战士长剑/盾牌，盗贼匕首/拳刃，法师法杖/法书，牧师法书/法球；普通二转按当前二转所属职业匹配，隐藏二转沿用角色基础职业。未选职业时保留装备礼包，选职后再领。

秘药以用户最后一次修正为准：小25%/10场，中50%/10场，大100%/10场，经验与幸运各一套。1级礼包只发大秘药。沿用同类取强、不叠加的现有使用规则。新增中、大秘药定义，不新增商店售卖。

## 实现与边界

- 发入背包，沿用新手奖励个人绑定规则，不自动穿戴；装备使用现有同等级、同稀有度的基础属性公式。
- 面板展示未解锁、可领取、已领取；未达等级、已领取时没有领取链接。QQ蓝色链接全部 `autoEnter:false`。
- 新世界入口与领取不触发初行剧情，1级角色也能获取补给。
- 角色行锁、领取表复合主键和同一事务保护：整档奖励与领取记录同时提交，任何失败整档回滚。
- 本次只实现明确给出的1/10/20/30级，不自行扩展“等等”后的等级或奖励。
