# 动态世界系统第三阶段实施结果

## 本次完成

- 地图与世界地图仅显示可进入建筑；NPC、资源与特殊物体不再成为地图标识。
- 动态居民在感知中统一显示为“域民”，但只有真实战斗试炼目标带有 `[试炼]` 操作。
- 42 名动态居民拆分为“称谓·本名”，默认驻守各自建筑；仅关联公共奇遇激活时临时出勤，现场结束后归位，并记录账本。
- 每名居民都有独立的晨间、午后、夜间、谨慎、熟络、信任语料；每个时段与五档好感关系均随机给出两种以上不同对白。
- 特色建筑升级为功能站点：委托/传闻、天气预警、区域材料交换、线索回看、35 分钟区域天气庇护；各项具独立日限、消耗/产出与账本记录。
- 公共奇遇增加护送、破译、物资支援。协作同时校验一格距离、参与身份、角色冷却、同队上限和唯一键；重复请求不会重复结算。
- 后台增加内容预览、校验、灰度启停和权重调整。校验包含分支可达性、终局、文本长度、奖励物品、世界线、站点与 NPC 引用。已创建实例保存标题与定义快照，后台修改不会回写历史。
- 天气结算改为统一的 `weatherEffectAudit` / `weatherElementMultiplier`：元素直击、投掷物、火灵追击继承天气；持续伤害因当前没有元素归属字段、治疗为平衡稳定性，均明确不继承元素倍率。

## 验证

- `npx tsc --noEmit`：通过。
- `npm run test:world`：默认安全跳过，不连接正式库。
- 设置 `DYNAMIC_WORLD_TEST_DATABASE=<独立数据库名>` 后，测试会初始化隔离库并覆盖：同格曝光、节点二次选择、隐藏物唯一发放、同队协作唯一、公共现场过期、世界线首领阈值、战斗天气快照。

## 运营注意

- 内容预览可发现无效模板；无效模板不能被启用或改权重，但不会影响已经创建的快照实例。
- 要让 NPC 立即响应新开的公共奇遇，奇遇创建时已将关联 NPC 的出勤时间提前到当前；后台十分钟结算会完成调度。
- 若未来要让持续伤害继承天气，需要先为 `effect_definitions` 或战斗状态保存元素字段，再把 `damage_over_time` 审计项切换为继承，避免用名称猜元素导致重复加成。
