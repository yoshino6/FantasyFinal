# 副手属性与装备精通修正

日期：2026-09-09。代码与当前数据库角色面板已更新。

副手装备的主词条、副词条统一乘以副手发挥系数。系数由**副手自身武器类型**对应的装备精通第二分支“随心”决定，主手类型不能代替副手类型。

| 随心等级 | 副手属性发挥 |
| --- | ---: |
| 未学习 / Lv.1 | 50% |
| Lv.2 | 60% |
| Lv.3 | 70% |
| Lv.4 | 80% |
| Lv.5 | 90% |
| Lv.6 | 100% |

计算方式：副手属性贡献＝装备原词条×原品质发挥×副手发挥系数。主手保持原品质发挥，不乘副手系数。正负词条均按同一比例折算；精通上限与升级费用保持原规则。

本次接入全部15项战斗属性的固定值和百分比、装备六维加成、元素精通与元素抗性。角色详情、感知等六维读取、普通面板和天赋餐食的基础面板使用相同口径。随心升级原有的立即重算逻辑继续生效。

装备特殊效果不乘副手系数，例如减伤、吸血、命中保底、触发效果、神器与史诗装备机制等，继续沿用各自的现有生效规则。不会改写装备实例中的原始词条，不会将品质、副手比例永久写入装备数值。装备详情仍可展示原始词条，人物面板展示实际生效贡献。

例：满品质副手提供物攻100、生命200和特殊效果减伤12%。未学习精通时提供物攻50、生命100，减伤仍为12%；随心Lv.4提供物攻80、生命160，减伤仍为12%；Lv.6属性全额发挥。若该装备品质发挥仅70%，则属性还需乘0.7，特殊效果按原有品质规则处理，不额外乘副手系数。

此前第二分支只参与副手武器精通本身的加成，人物汇总装备词条时没有使用该比例。本次补上装备属性计算，并把技能详情中“副手装备效果+10%”改成明确的主、副词条发挥说明。导师毕业构筑原本固定随心Lv.6，因此继续全额计算；只有一把虚拟主武器的普通怪物和域民不新增副手惩罚。
