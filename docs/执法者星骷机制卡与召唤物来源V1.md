# 执法者星骷机制卡与召唤物来源 V1

配套：[主设计](./怪物卡片与装备附魔设计V1.md)、[常规卡片表](./怪物卡片逐怪设计表V1.md)、[掉率测算](./怪物卡片最终掉率计算V1.md)。状态：已实现并通过定向自动化测试；尚未实机或真实数据库验证。

按用户最新补充：城镇执法者可以掉落；星级/骷髅强度决定不同卡片；机制侧重移动速度、感知、交涉等。召唤物卡加入对应来源 BOSS 掉落表，召唤物死亡不独立掉卡。首领部位与转职试炼不产卡。

## 1. 执法者卡片版本与现有阵容

当前源码 `adventure.service.ts` 的追捕烈度 = 通缉基础星级 + 击退次数；界面为三星、四星、五星、1–5骷髅。1/2星没有该追捕阵容，不臆造其卡片。下表按当前阵容覆盖21个“执法者×烈度”组合，同名不同烈度是不同卡，不是击杀时随机抽低高版本。

## 3. 机制精确定义

### 3.1 地图移动与感知

地图移动速度是单次移动格数，不是战斗 `speed` 或出手顺序。当前实现按 `基础最大步长=min(10,原敏捷步长+原装备移速+卡片常驻格数)` 计算，再应用负重惩罚、取整、最低1格。凯尔充能增加的2格也受绝对10格上限限制；达到10格时明确显示无额外格数收益。

负重惩罚减少20%指原移动惩罚率乘0.8，原惩罚30%变24%，不是变10%。莱拉地形减耗仅降低地形附加部分：基础耗体力4、地形额外4，减耗后消耗7，不是总消耗8×0.75。内部可累计小数体力或结算向上取整，V1定为最终总消耗向上取整，且不得小于基础消耗。

常驻移动加格来自同槽卡自然互斥；和凯尔充能可组合但受10格限制。移动仍受碰撞、路径每格事件、门槛、跨地图/楼层规则与剩余体力限制，不能一次跳过事件。充能按角色状态持久化，换装、传送、进入战斗时清零；反复卸装不能刷新次数。自动移动也逐次记录。

普通感知半径在原地图感知值后增加整数格；卡片来源合计最多+3格，同类多个+1/+2不是无限扩大。仅扩展普通地表可见怪物、资源和地标的观察范围；不扩大 PvP攻击距离、技能射程、交涉距离、采集距离或拾取范围。地下迷宫固定1格、剧情遮蔽和未解锁区域优先，卡片不能穿墙、穿层或揭开隐藏地图。

凯尔的NPC交谈距离是明确单独例外，只限普通NPC交谈；不能越过楼层、区域、剧情门槛或隔墙触发。原需近身的商店/提交物品仍按原距离，卡片不远程购物。

追迹只保存“最后确认坐标”，目标离开感知后不持续更新；不会暴露玩家或追捕者位置。到达标记位置可能发现怪物已离开。目标死亡标记清除，移动计数到期清除，切地图/楼层清除；BOSS标记也不追踪跨阶段虚拟部位。标记不增加攻击/交涉可选目标。

遭遇降低仅用于已有可随机发生的野外移动遭遇，`p新=p原×(1-r)`；主动接战、追捕、剧情强制战、地宫固定战不受影响。如果某路线没有这种随机遭遇判定则该效果无作用，不能虚构减少怪物刷新数量。

当前源码尚无普通随机野外遭遇判定、地形附加体力消耗事件，以及地表连续路径移动与墙体视线判定；因此依赖这些底层事件的遭遇降低、地形附加体力减免、逐格事件与墙体遮蔽约束目前没有可观察效果，保留为待相应底层事件接入后生效的数据规则。已接线的地图移动上限、感知半径和追迹等效果不受此状态说明影响。

### 3.2 交涉成功和重判

先走全部交涉资格与黑名单；只有合法对象进入概率公式。卡片不能让城镇执法者、禁止交涉BOSS、转职试炼或已开战目标变得可交涉。

设原 `negotiationProbability` 结算值为p：`p新=min(1,p+Σδ卡)`，卡片来源合计上限+10个百分点。例：原20%，戴四骷髅琳恩+5及索拉+5，变30%；戴五骷髅各+6，按上限也是30%，不是32%。戒指/项链单槽覆盖让玩家选择交涉机制组合。

加成读取实际执行交涉动作的角色；不把全队四人装备相加。交涉成功率与送礼/交谈引发敌意的概率是两条独立流程，成功率卡不顺带降低敌意。原概率0且是“资格禁止”时不能补到正数；原概率0但合法、只是心情差时可按上述公式增加。

“中性礼物敌意降低15%”为 `a新=a原×0.85`；讨厌礼物、明确拒绝保护、强制开战和已存在冷却均不受益。每场一次原概率重判相当于该次触发概率 `a²`，不是额外一次交涉成功 roll。例 a=20%，重判后最终触发开战为4%。重判第二次消耗同一动作，不再扣礼物、不加第二份心情和熟练度、不形成重判递归。

一次性次数按交涉 session 和角色持久化，开始时装备快照固定。退出重开同一怪物仍沿用该怪物上的已用状态；换卡、换入口不能刷新。多人重判保护同一动作最多1次，取实际执行者的效果，不让不同玩家轮流救回无限次。礼物揭示只揭示配置已有喜好，若全部已知则显示“喜好已全部掌握”，不伪造收益。

当前机制字段分别使用 `mapMoveBonus`、`mapPerceptionBonus`、`mapBurdenPenaltyReductionPct`、`mapRandomEncounterReductionPct`、`neutralGiftAggressionReductionPct`、`negotiationActualBonusPct`、`negotiationRetryPolicy` 等；不借用战斗命中、speed或六维感知字段代替。

掉落台账唯一键改为 `(source_spawn_id, channel='monster_card', card_code)`，同时记录sourceBossCode与representedMonsterCode。母体自己和附加卡不同键，重复完成、读档恢复、复活、重启都不加次数。母体是测试怪/无奖励会话时整张表关闭。

## 6. 执法者奖励路径与资格

现有战斗把追捕者从普通奖励目标剔除；当前实现另建“执法者卡片奖励目标”列表，没有把追捕者塞回普通 `rewardTargets`，因此不会意外开放经验、材料、悬赏或其他奖励。原追捕胜负、通缉、扣款与升级逻辑照常执行。

真实追捕战胜利后，对该场阵容中实际被击败的每名执法者进行一次卡片判定。战斗失败、逃跑、旧追捕清理、管理员生成、旁观者触发、再次读同一战报都不判定。当前实现套用主文合资格玩家和共享分配公式，并显式计算追捕玩家的卡片资格快照；无体力奖励资格则不掉卡，不会因普通 `rewardMembers` 为空而令执法者卡永远0掉落。

星骷不同版本各自固定效果，一次击杀只roll当前版本，不同时roll低档卡。五星有4名精英时各1%，不把整场压缩成一个1%；五骷髅是凯尔0.5%加三名精英各1%。来源与计算见掉率文档。

## 7. 新增验收

验证21个星骷版本及8个召唤物映射无遗漏；开战后星级上升不改变本场卡片；追捕卡不连带开放旧材料/经验奖励；母体速杀与拖延召唤次数拥有相同卡片机会；首领部位和导师试炼始终0。机制需验证真实地图移动/感知/交涉服务和直接命令，不能仅装备详情显示数值。
