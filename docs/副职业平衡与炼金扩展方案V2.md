# 副职业平衡与炼金扩展方案 V2

> 日期：2026-09-06。状态：功能已实装，完成代码与隔离数据库复核；线上交互和长期实战平衡待验证。
>
> 本文保留批准的设计目标，覆盖成本与药效、副职业定位、奇趣战斗道具、技能点洗练、一键未尝试配方、炼金手记与稳定组合、确认与继续尝试交互，以及城镇副职业商店仅售成品的调整。当前实现、校准附件和验收边界见[实装复核](副职业平衡与炼金扩展实装复核.md)。已只读导出当前材料与旧货架数据，并在全新隔离数据库中运行真实事务测试；不能把数值模型样本当成线上实战结果。

## 1. 本次目标与结论

炼金师用会永久消耗的材料，换取一次明显强于同等级、同用途常规技能的效果。强度必须计入失败、大成功、多产物和制作链成本，不能只按物品名字或材料等级统一加倍。

同时解决六件事：

1. 高级材料有可靠的成品等级下限，避免昂贵材料反复炼出初级药。
2. 药剂既有强回复、强增益，也有储伤、转移、引爆、反射、转化等可以改变战斗决策的效果。
3. 新增可炼制的「归悟洗练露」，付费学会的技能遗忘并回到可领悟列表，保留发现记录；有流水按实际投入返还技能点。
4. 炼金首页加入「一键配方」，自动抽取本人尚未实际尝试的可用组合；确认面板显示主材、辅材、催化剂；确认才扣料，结果消息底部提供「继续尝试」。
5. 炼金首页加入「炼金手记」，自动记录每一次实际耗材与全部成果，并从真实重复试验中整理稳定炼金信息，支持耗材、成果关键词筛选和翻页。
6. 城镇副职业商店改为只售卖对应副职业的成品，取消代炼、代提纯、代锻造、代解构等副职业操作与商店回收功能；玩家个人副职业能力保留。

**炼金没有图纸设定，也不新增图纸门槛。** 本文的「配方」指玩家实际投放的材料组合与数量；「一键配方」负责选材，「我的配方」是手动保存的快捷投料，「炼金手记」是真实试验与稳定结果的个人记录。它们都不是图纸，不需要购买、掉落、学习图纸后才能使用。解构师既有异械图纸是另一套系统，不套用到炼金。

本次以补齐炼金价值为主。锻造师、解构师进入同一成本与战斗收益评估，但不先凭印象削弱它们。

| 副职业 | 应有优势 | 成本核算 | 此次处理 |

| 解构师 | 资源加工、粒子供给、被动及主动异械 | 分解收益、构件逐层成本、图纸、耗材及耐久 | 复用现有粒子价值和构件成本来源；检查炼金是否形成套利循环 |
| 炼金师 | 强力临场应对、短时爆发、异常组合、洗点服务 | 三槽消耗、失败率、平均数量、产物分布、职业制作优势 | 提高单次效果、减少高级投料贬值、补齐操作便利与交易价值 |

比较采用同角色等级、同一材料价值预算、同样的 10 / 30 / 100 场战斗样本。分别记录实际省下的行动、伤害、有效治疗、承伤减少、材料净变化及制作操作次数。

验收方向：10 场的关键战斗中，合理配置的炼金消耗品应提供更强的临时战术收益；100 场的持续收益允许装备与异械更占优。单次技能比较之外，必须观察“买药后普通职业使用”与“炼金师亲自制造”的差别。

不把虚构的玩家均价当作数据。本轮没有足够证据给出三个副职业的当前胜率、小时利润或最终平衡百分比。

## 4. 制作平均成本与药效预算

### 4.1 材料价值来源

统一使用铜币等价值，并记录价值来源。现有可复用锚点：

- 基础粒子：血肉残渣 2、能量余烬 2、魔力微弧对应 `magic_unit` 10；元素微尘 3～5，取自 `baseMaterialTradeValues`。
- 解构构件：复用 `constructionValueByCode` 的原料展开，再计入各层制作的实际成功率、返还与产量，不能只用原料面额之和。
- 通用提纯甲材：已有 `purifiedCraftMaterialValue` 的 20 铜等价值。
- 怪材等级价值倍率：已有 `1.2 ^ floor((等级 - 1) / 10)`；它只作为来源倍率，不能重复乘在已经包含等级的价格上。
- 其他材料：使用明确配置的获取价值；稳定 NPC 获取价、回收价分别记录。缺失的材料必须列出待补配置，不能默认为零成本。

若同一材料存在多条可重复获取路径，选可持续路径中的合理低成本，避免用最昂贵配方人为抬高药效。玩家间成交价可作为后续观察项，不直接实时改药效，防止操纵价格影响战斗数值。

### 4.2 一瓶平均成本

对一个固定配方 r，按真实结算计算：

```text
C(r) = 三槽本批实际扣除材料的价值总和
N(r) = Σ[分支概率 × 该分支的成品数量]
平均每瓶投入 = [C(r) - 可兑现副产物的保守回收值] / N(r)
```

失败算进概率；大成功双产算进数量；粒子转化与药剂分支分别核算；不存在的失败残渣不能抵扣。数量不齐时按当前真实批次数核算，不能把面板填入但没扣除的材料算作成本。城镇代加工取消后，不再计算 NPC 代炼服务费。

例：单批投入 45 铜，成功率 86%，成功后 10% 大成功且双产，无残渣，则期望数量为 `0.86 × 1.10 = 0.946`，每瓶平均投入约 `47.57` 铜。这是公式示例，不是当前某条配方的实测报价。

不能把每一种随机成品都按 `总投入 / 抽中它的概率` 定价，否则同一炉的全部随机结果都会虚增价值。先按各类成品的战术预算分摊联合产出成本，再计算目标药的定向制作成本；需要定向制作时，另报“扣除其他可兑现产物后，拿到目标药的期望成本”。

具体分摊：先以第 4.3 节同用途技能参照给每个产物固定预算权重 `W(i)`，分摊比例为 `E[N(i)] × W(i) / Σ(E[N(j)] × W(j))`。权重不引用本轮算出的价格，不做循环自我抬价。

### 4.3 怎样保证比技能更强

比较对象是同等级、同用途、合理投入技能点的常规技能；不是零专精技能，也不是全职业极限加成后的终极技能。

技能基准必须从实际战斗链提取：例如治愈祷言有 `1.35 × 魔攻` 的基础治疗，还会经过治疗加成、受治疗加成、专精和附加效果；不能仅拿技能面板的一个百分比比较。

| 平均成本相对同档标准消耗品 | 一次使用的综合收益目标 | 适合的强化方向 |
| --- | --- | --- |
| ≤1 倍 | 同用途技能的 1.20～1.35 倍 | 强基础回复、稳定增益 |
| 1～2 倍 | 1.35～1.60 倍 | 回复加净化、伤害加软控制 |
| 2～4 倍 | 1.60～1.90 倍 | 条件引爆、储伤、转化、群体支援 |
| >4 倍 | 1.90～2.20 倍，超出部分优先换副作用减轻或更好范围 | 稀有救场与独特机制 |

这里是收益目标区间，不是对所有字段一起乘倍率。持续 3 回合的 +30% 攻击要按实际多造成的伤害计算；治疗要扣除溢出；控制要乘有效概率与被阻止的行动；群体效果要按真实目标数计总收益。

普通增益、回复不得超过引擎硬上限。硬控制的概率、持续回合、免疫次数不随成本无限增长；高成本控制品通过额外直伤、破盾或保底软减益兑现预算。

### 4.5 成品等级、成本与品质

1. 有效等级继续由主材、辅材中的非粒子材料决定，催化剂不能单独把低级主辅材抬成高级药。
2. 候选成品限制在有效等级向下最近的两个已配置等级台阶；例如有效等级 37，选 Lv.20 / Lv.30，建议权重 20% / 80%；有效等级 50，选 Lv.40 / Lv.50。Lv.1～9 走基础模板。
3. 超额价值决定可承担的效果预算、稀有模板资格和品质分布，不允许通过昂贵但无效的乱投把普通药无限升值。
4. 同物品代码必须对应相同效果。采用「标准 / 精制 / 匠造」有限品质代码区分，建议主要效果系数 1.00 / 1.20 / 1.40；禁止把不同药效塞进同一个堆叠。
5. 成品一次生成后，交易、转交、使用者副职业变化均不改变它的药效。版本调整按定义统一更新，并保留旧代码映射。
6. 大成功保留基础、下位双产；更高档大成功提高一个品质档，已经匠造时不继续乘药效。最终成本按新规则重新计算，不能沿用旧单产期望。

## 5. 匠心与职业等级收益

修复“制作者药效优势”时，应把结果写入成品品质，而不是在使用时检查喝药者职业。

建议保留现有匠心 Lv.1～5 对应 +10%～50% 的名义制作优势：生产结算中把它解释为额外品质预算，以概率映射到有限品质档；超过匠造上限的预算用于增加产量，不能丢失。正式实现必须给出每个职业等级的分布和期望，确认与显示的名义优势一致。

品质只增强回复量、护盾量、直伤、受上限约束的属性增益。控制概率、回合数、复活次数、洗点返还量不增强；这些产品改为制作者产量优势，并在匠心说明中明确。

Lv.6～11 暂保留匠心 50% 上限，不随公共等级上限直接放大到 110%；高级职业继续从既有成功率、大成功率与更多配方容量获益。是否调整顶级熟练度曲线，应另根据真实升级投入核对，不能顺手改掉所有副职业成长。

现有晴儿 Lv.3 代炼、代提纯服务按本次修订取消；一键配方、炼金手记、制作品质与熟练度均围绕玩家个人副职业。非炼金师可以购买并使用成品，不能通过糖水屋绕过副职业资格制作。旧代炼会话及按钮的处理见第 10.4 节。

## 7. 共通战斗规则

### 7.1 行动、目标与持续时间

- 保留一次使用占一个行动的基础规则，强化药效必须把这个机会成本算进去。
- 治疗药可选自己或存活队友；未指定默认自己，群体药使用明确筛选规则。旧纯自用药保持原默认。
- 敌对道具可指定当前合法目标；目标死亡、离场或完全无效时，在扣物前重新检查，不擅自换成另一个目标。
- 以使用者和受益者实际行动时点定义回合；持续 2 回合必须覆盖两个预期生效窗口，不能刚施加就扣掉一回合。PVE、PVP、自动战斗一致。
- 单体直伤、群体直伤、附加状态分别拥有明确范围，修正天罚符的范围表述与结算不一致。

### 7.2 叠加与副作用

- 同效果族用药后取较强值，较弱药不能覆盖较强技能或药剂；期限不累加到无限。
- 同族新效果与旧效果合并时，不拼出“旧的超长时长 + 新的超高强度”；保留完整实例或按明确优先级替换。
- 回复可受正常治疗修正；药品不吃技能专精、吟唱增伤等专属加成。品质只计算一次。
- 引爆、反射、反刺、回声附伤带来源标记，禁止互相递归触发。多段、群攻、Boss 多部位全部按总预算结算。
- 同一强力效果族的每场次数跨物品等级、品质共享，不能换一种低级版本绕过限制。
- 元素药遵循现有元素精通与数值抗性，Boss 本体减伤与部位机制正常参与；不能把“药剂强”实现成忽略机制。

### 7.3 首领控制与 PVP

建议把现在整场共用一次的炼金抗性拆为硬控制与普通减益：

- 晕眩、混乱等硬控制共享抗性；Boss 一场最多成功生效一次，持续最多 1 回合；尝试失败后设置 2 回合共同冷却，避免无限赌概率。
- 灼烧、封疗、破防等软减益不占硬控制次数，各按等级、明确免疫标签及同族规则处理。
- 纯硬控完全无效时不扣物；复合药仍有有效直伤或其他作用时，可以使用，但扣物前说明控制无效。
- PVP 的常规伤害、回复、护盾、驱散等走同一语义；硬控制另按 PVP 现有韧性与免控规则，并限制连续控制。不能仅加一层 PVE 数值后让对方永久失去行动。

这项会改变现有 Boss 抗性策略，必须在审阅中单独确认。若保留旧策略，需在药品面板显示该目标已经免疫哪些效果，新模板仍要保留未被免疫部分的可用性。

## 9. 一键配方：完整玩家流程

### 9.1 首页与按钮

炼金首页主按钮：`一键配方`、`开始炼金`、`炼金手记`、`我的配方`，其中「炼金手记」直接可见。保留手动选材、数量输入、搜索与个人提纯入口。「我的配方」只保存快捷投料，不提供图纸购买、配方解锁或学习操作。

显示统一称「主材 / 辅材 / 催化剂」。现有“反应剂”命令保留为别名，内部 `reagent` 字段无需改名。

点击「一键配方」只创建新预览，各槽默认投入 1 份。不自动消耗材料，不启动炼金，也不一次跑完所有组合。

```text

主材：影狼绒 ×1
辅材：暗纹皮 ×1
催化剂：魔力微弧 ×1

这是你尚未尝试过的材料组合。

[确认炼金] [换一组] [取消]
```

图示材料名仅为排版示例，实际从背包读取。推演是方向提示，不承诺确切产物，也不以“预计获得洗点药”诱导投料。等级失衡时在同一确认面板插入现有定性风险提示；不再额外强迫点击两次确认，不擅自显示旧设计隐藏的精确成功率和炸炉率。

### 9.2 什么算“没有尝试过”

采用按角色持久化的有序三元组：`角色 + 主材物品ID + 辅材物品ID + 催化剂物品ID`。

- 主辅交换是不同组合，因为槽位职责不同。
- 数量不进入组合键；1 / 1 / 1 与 10 / 10 / 10 不冒充新的材料组合。
- 同物品可占两个或三个槽，但背包必须有合并后的总份数。
- **实际结算成功提交后**才算尝试；炼成、失败、炸炉、粒子转化都算。取消、换组、过期和事务回滚不算。
- 手动、快捷配方、手记再次投料和一键配方的实际炼制都写历史、手记。商店代炼取消，不再形成新的代炼记录；历史若有真实结算凭据则保留并标明旧来源，不编造缺失记录。
- 结果不同不代表组合不同；继续试未知组合和反复制作已知配方是两个明确入口。

旧系统没有完整历史，不可能还原所有旧尝试。上线后从新记录开始；首次使用提示“未尝试组合从本次更新后记录”。不能把旧快捷配方直接标记成尝试，因为保存配方本来无需成功炼制。

### 9.3 随机选择与耗尽判定

只纳入当前手动炼金规则允许的材料，并排除明确的任务专用、不可消费、锁定物品。手动与自动必须共用同一个资格校验，避免一边显示可放一边执行失败。

默认在所有合法且本人未尝试的有序三元组中随机选取。为避免“换一组”还显示原组合，本次选择排除当前预览；若只剩这一组，保留它并提示没有其他组合。近期预览可以只在当前会话内短暂去重，取消后不永久封存。

算法建议：

1. 按固定顺序读取材料ID、数量，构建按三槽序号可遍历的组合空间；历史用有索引的查询或集合判断。
2. 稀疏历史时做有限次随机拒绝采样，每次验证合并数量和尝试键。
3. 随机多次未找到时，改为分块扫描剩余空间并做蓄水池抽样；不在内存生成 `n³` 份组合对象。
4. 大背包扫描超出单次处理预算时，保存游标并显示“正在查找可用的新组合”，允许继续查找；只有完整扫描证实为空才能显示耗尽。
5. 若库存或历史版本变化，候选在保存和确认前重新验证；数据库条件扣除确保数量不为负。

精确耗尽文案：`当前背包中可炼金的材料组合都已尝试过。补充新材料后可以继续探索，也可以从“我的配方”重复炼制。`

不得随机尝试 20 次没命中就宣称组合耗尽，也不得在没有新组合时偷偷改成已经试过的组合。

### 9.4 预览绑定与事务

复用 `player_alchemy_sessions`，增加随机确认凭证、投料修订号、预览来源、过期时间、三槽数量与个人副职业资格的快照。旧商店服务模式仅用于迁移识别，不再作为可执行模式。

确认命令携带凭证。校验事件发起人、角色、会话、修订号、过期、个人炼金师资格、炼制中状态与库存。用户改材料、数量、副职业资格、换组或取消时，旧凭证立即失效。

状态顺序：`待确认 → 已结算`，或 `待确认 → 已取消 / 已过期`。结算凭证需要有唯一约束或等效的一次消费条件；材料扣除、产物发放、熟练度、尝试记录、手记明细与结算摘要同事务提交。

确认后已提交而消息发送失败：重试只重发原结果，不再炼一炉。数据库失败回滚：保留可重试预览或重新生成，不写尝试历史。高风险确认和一般确认采用相同安全边界。

### 9.5 结果底部继续尝试

```text
炼金结果

① 投料：……
② 融合：……
③ 催化：……
④ 反应：……
⑤ 收取：获得【……】×1。

[继续尝试] [炼金手记]
[保存配方] [返回炼金]
```

- 「继续尝试」直接生成下一条未尝试组合的确认面板，仍需玩家确认，不自动扣料。
- 「炼金手记」打开本人手记，并可定位本次已写入的记录；手记自动保存，不需要点击此按钮才记录。
- 成功、普通失败、炸炉、粒子转化的结果都提供它；发送结果后不再强制另发一整页材料菜单把结果顶走。
- 「保存配方」绑定这次已结算的三槽快照，不能读取玩家之后换过的当前槽位；保存数量，修复现有加载总回到 1 的信息丢失。
- 已知配方重复制作从「我的配方」进入；与「继续尝试」含义分开，避免误用旧配方。
- 库存不足、无新组合等情况给出短提示和返回入口。旧结果按钮也应检查发起人；不能使群内其他玩家操作原玩家的材料。

### 9.7 炼金手记：每一次耗材与成果

手记默认显示「全部记录」，另有「稳定组合」视图。全部记录是永久保留的真实结算明细，稳定组合是在这些记录之上自动归纳的信息；不能只记录成功或稳定的结果。

每一次实际完成的炼金结算生成一条手记，包括手动炼金、快捷投料、一键配方、手记再次投料、洗练露定向炼制。失败、炸炉、粒子转化、大成功都记录；取消、仅预览、库存不足与事务回滚不构成炼金试验。个人提纯在手记中作为独立「提纯」类型记录耗材与成果，不混入三槽稳定组合统计。

| 记录内容 | 规则 |
| --- | --- |
| 编号与时间 | 稳定的个人记录编号、实际结算时间，按最新优先展示；同一请求重试不能生成第二条 |
| 炼制类型与入口 | 普通炼金 / 洗练露反应 / 提纯，以及手动、一键、快捷或手记投料来源 |
| 三槽耗材 | 主材、辅材、催化剂的物品标识、当时名称、等级、每槽实际消耗份数；同物品跨槽另列合并消耗 |
| 本批与分批信息 | 请求数量、实际执行批次、各批成功/大成功/失败结果；详情保留逐批成果，列表显示合计 |
| 全部成果 | 每一种实际到账产物的物品标识、当时名称、等级、品质、数量及当时效果数值/说明快照；无产出明确写“无成果” |
| 制作条件 | 当时炼金师等级、匠心状态、影响结果的条件、反应规则版本；不记录不参与计算的装饰性环境 |
| 其他实际变化 | 实际获得熟练度及确有发生的炸炉损失；不存在的损失不写入 |
| 成本快照 | 若当时材料价值已配置，保留估算成本及价格版本供详情参考；缺价标“未估价”，不能因此漏记真实耗材 |

历史名称和数量用快照保留，物品改名、平衡调整或下架后仍能看懂旧记录。当前可用性、当前物品详情与历史效果分别标注；不把新药效改写成当年实际炼出的药效。

### 9.8 稳定炼金信息：从重复试验归纳

「稳定」表示**本人在可比较条件下多次试验获得了较集中的成果**，不是学习了图纸，也不锁死下一次产物或取消失败率。

稳定统计与一键去重使用不同口径：一键去重按有序三槽物品；稳定统计还区分每批三槽配比、反应类型、会影响概率的职业/匠心条件和规则版本。普通 1 / 1 / 1 与批量 10 / 10 / 10 可按实际每批配比归到一起；改变配比或使用洗练露专用反应时必须另分组。

建议首轮识别门槛如下，属于可调整的设计数值：

1. 同一统计分组至少有 **5 次独立结算、合计 10 个实际批次**，避免一次批量炼制就冒充长期规律。
2. 成功批次占全部实际批次至少 **60%**。
3. 同一主要成果在成功批次中的出现比例至少 **80%**，并且至少出现 **5 批**。
4. 主要成果按成品本体与等级识别，标准/精制/匠造的品质差异单独展示；不能把不同药或不同等级都合并成“药剂”来凑稳定。
5. 若反应一次固定产生多个共同产物，按完整成果组合归纳，并列出每种副产物，不能只挑最有利的一项宣称稳定。

满足后自动进入「稳定组合」，展示主/辅/催化剂与配比、样本量、实际成功率、常见成果、成功时的成果占比、各品质次数、单批产量范围和最近一次试验时间。例如：“10 批中成功 8 批，其中 7 批获得复苏药·Lv.30；成功时出现占比 87.5%。”这些是个人历史统计，不是服务器精确概率或未来保证。

继续炼制后同步更新。若当前数据不再满足门槛，从当前稳定视图移出，详情保留“曾稳定，当前记录出现分歧”；既有手记不删除。规则版本变化或制作条件不同的新记录另组积累，旧稳定信息显示“旧条件记录”，不直接背书新版本。

稳定信息不占用「我的配方」的快捷保存容量，也不消耗道具。所有真实手记都可重新投料，稳定标记不是制作权限；不稳定组合仍然可以继续尝试。

### 9.9 关键词筛选、分页与查看

全部记录与稳定组合都支持：

- 筛选字段「全部 / 耗材 / 成果」；耗材匹配三槽名称与物品代码，成果匹配所有实际产物名称与代码，不只查第一项。
- 默认按整段关键词作大小写不敏感的包含匹配，中文关键词正常处理；去掉首尾空白。关键词中的 `%`、`_` 等按普通字符处理，查询参数化，不成为通配表达式或 SQL。
- 同时匹配物品当时名称与当前名称时，历史行仍显示当时名称；提纯记录也参与全部记录的对应字段筛选。
- 每页 5 条；「上一页 / 搜索 / 下一页」固定一排；另一排提供「全部记录 / 稳定组合」，筛选字段与「清除筛选 / 返回炼金」按平台按钮数量分行。
- 搜索按钮预填当前范围和字段，等待玩家输入，不自动提交空关键词；搜索或切换视图回到第一页，翻页保留所有筛选条件。
- 同一次浏览保留记录时间/编号锚点，以免新炼金记录插入后翻页重复或漏项；重新打开或刷新时取最新锚点。
- 空结果显示当前关键词与“未找到匹配记录”，保留搜索、清除筛选、返回入口；页码越界修正到有效范围，首页和末页不生成非法页码。
- 详情和投料按钮只访问本人记录，不能凭记录编号读取其他玩家的耗材历史。

```text
炼金手记 · 全部记录
筛选：成果「复苏」

① 09-06 20:15 · 炼金成功
主材：……×1｜辅材：……×1｜催化剂：……×1
成果：复苏药·Lv.30【精制】×1
[查看详情] [再次投料]

当前第 1 / 3 页
[上一页] [搜索] [下一页]
[全部记录] [稳定组合]
[全部字段] [耗材] [成果]
[清除筛选] [返回炼金]
```

详情展示全部批次与成果；内容过长时继续分页。点击「再次投料」按记录中的材料和数量生成新的确认面板；库存缺失时逐项说明缺口，不自动买材料、不替换材料、不直接扣料。对旧版本或旧条件稳定组合，同时说明当前条件已变化。

### 9.10 历史保存与一致性

手记与炼金发放同一事务，以结算请求编号去重；汇总统计可重建，原始手记不能被“只保留稳定配方”覆盖。批量炼制既留单次结算合计，也保留各批次实际结果，确保失败批次进入统计分母。

旧系统没有记录的耗材与成果不补造。已有可信完整结算日志才可导入，并标明历史来源；快捷配方、物品图鉴或现有背包都不足以还原历史。首次打开无历史时提示：“炼金手记从本次更新后开始记录，你每次实际炼制的耗材与成果都会自动保存。”

手记不设置职业等级容量上限、不因取消快捷配方而删除，也不自动只保留最近若干条。数据量大时使用索引、分页与归档存储，归档仍可查询；角色注销时按既有角色数据清理规则处理。转离炼金师后仍可查阅个人历史，再次投料仍须当前具备炼金资格。

### 10.3 交易与回收

成品继续可通过玩家交易流通。三家城镇副职业商店向玩家出售对应成品，同时保留原有物品收购范围、价格和交易校验；“只售成品”不表示取消玩家向 NPC 出售物品。回收核算覆盖三家店及其他既有回收渠道，检查 NPC 购买→炼制→回收、材料→粒子→构件→炼制等闭环。

回收价不按最昂贵路线定。建议使用高熟练度、匠心、大成功条件下的可持续最低单位投入的 35% 为起始上限，再计 NPC 的回收倍率；必须满足 `该批全部产物期望回收收入 < 可持续最低实际投入`。没有完成闭环检查的新增模板暂不开放 NPC 回收，并在状态表中明示，不假称全部交易链完成。

### 10.4 城镇副职业商店：只售对应职业成品

本节按用户 2026-09-06 的澄清修订：进店保留「我要买、我要卖、闲聊、关于××、离开」，以及既有剧情、切磋、授艺和转副职业流程。「我要买」进入对应成品货架，「我要卖」进入原有收购列表；仅删除打造、精炼、熔铸、炼金、提纯、分解、构造等商店加工入口，制作操作统一从玩家自身的「副职业」面板进入。

| 商店 | 对应成品货架 | 取消的商店能力 |
| --- | --- | --- |
| 铁匠铺 | 可直接使用的武器、防具等锻造成品 | 商店代锻造、代融合、代强化、代维修等加工 |
| 糖水屋 | 药剂、投掷物、符咒、秘药与归悟洗练露等炼金成品 | 晴儿代炼、代提纯、一键代提纯 |
| 异工坊 | 可直接装备或使用的异械等解构师最终成品 | 商店代分解、代构造、构件加工、图纸/材料货架 |

货架采用明确成品白名单，不把材料、半成品、图纸或“购买后代做”的服务伪装成成品；三家店的商品归属必须与对应副职业一致。不是所有最高品质和稀有成品都必须无限供应，品级、库存与价格按成本校准，不能让固定廉价 NPC 供货抹掉玩家制作者收益。归悟洗练露列入糖水屋可购买成品，作为非炼金师的稳定获取入口，售价需在制作成本明确后填写。

功能取消要覆盖按钮、路由、服务层资格校验、帮助文案和旧消息快捷链接。点击旧商店代加工命令时只提示“城镇副职业商店现仅出售成品，请从个人副职业面板操作”，不得恢复旧服务模式、扣料、收费或获得熟练度。购买成品不要求买家具备该副职业，只检查位置、库存、货币及物品使用条件。

玩家个人锻造、融合、维修、炼金、提纯、分解、构造等已有能力继续存在，分别核验个人副职业；不能只删商店按钮却把个人能力一并删除。取消商店代维修后，要检查非锻造师已有的个人修理/维修成品获取途径；若现状缺少合法入口，实施时补齐对应锻造成品维修道具，并同样按成本定价，不能暗中保留 NPC 维修服务。

副职业入门任务、转职与既有授艺继续从店内 NPC 的「关于××」或闲聊进入，保留门槛、进度、任务交付和奖励。独立「副职业」面板及导师入口作为补充，不替代进店互动。个人配方和制作成长保留；解构师自身的图纸机制及任务、探索等获取渠道保留，不新增炼金图纸。

迁移时作废尚未确认的商店投料会话，已选择但未扣除的材料保持在背包；已成功提交的旧结算保留产物、扣料与熟练度结果，只允许查询/重发，不再次执行。不直接清零玩家个人投料、快捷配方、副职业等级或历史。若旧结算尚在执行，先按事务边界完成或完整回滚，再启用禁用规则。

同时导出三店原有商品与服务清单，逐项标为「对应成品保留 / 原料或图纸下架 / 个人能力迁出 / 商店服务关闭」，检查必需材料和旧任务物品的剩余合法获取途径；有缺口则在个人制作、探索或既有非副职业商店渠道补齐，并写进实装状态，不能靠重新开放三店代加工解决。

## 11. 实施顺序与验收

### 11.1 实施阶段

1. 导出只读材料锚价、产物分布、技能基准和旧技能点账本覆盖情况，保存校准附件；冻结本次所用技能版本。
2. 先做一键组合、绑定预览、结果继续尝试和尝试历史；同时做炼金手记逐次明细、关键词分页、稳定组合统计，以及保存配方的数量与结果快照。
3. 修复平均成本、等级池下限、匠心、现有药剂数值和描述一致性，建立有限品质物品。
4. 实现归悟洗练露及账本退款，验证转职与道具洗点交替使用不会重复返还。
5. 按效果族实装 24 个战术模板，共用 PVE/PVP 语义与规则，逐项验证自动战斗。
6. 三店购买货架仅售对应成品，保留收购、闲聊、关于职业、转职及离开；关闭旧代加工，制作从个人副职业进入。检查原料、图纸、维修与洗练露的可获得性。
7. 校准产出、市场与其他 NPC 回收闭环，再判断是否需要调整另外两个副职业；不把前三步完成当作全部平衡完成。

### 11.2 必须通过的行为测试

| 范围 | 验收条件 |
| --- | --- |
| 选材 | 同物品跨槽数量相加；主辅交换算不同组合；数量改变不冒充新组合 |
| 未尝试 | 手动失败也写历史；预览取消不写；重启仍记得；手记投料也更新尝试记录；不产生新代炼记录 |
| 无图纸炼金 | 手动、一键、洗练露反应均不检查图纸或手记解锁；稳定标记不构成制作权限 |
| 手记完整 | 每次真实结算的实际三槽消耗和全部成果均可查；失败、粒子转化、批量、洗练露、提纯不漏记；回滚不写、消息重发不重复 |
| 稳定信息 | 相同配比与可比条件才聚合；一次批量不能替代多次结算；展示分子分母、品质和产量；数据不稳移出当前稳定视图但保留历史 |
| 手记筛选 | 耗材三槽、所有成果均可命中；搜索与翻页保留范围/字段/关键词；第一页、末页、空结果、新记录插入时正确；不能查看他人记录 |
| 再次投料 | 从手记或稳定组合回填真实配比并先确认；库存不足说明缺口；旧版本明确提示；无购买、换料或直接扣料副作用 |
| 穷尽 | 剩一组能找到；随机连续失败不误报；扫描预算不足不谎报全部试完 |
| 确认 | 所有一键投料先显示三槽；错人、过期、旧修订不能扣料；换组作废旧按钮 |
| 并发 | 双击一次结算；消息失败可重发；扣料后出错全部回滚；库存不会负数 |
| 结果 | 成功与失败消息自身底部均有继续尝试；点击后生成新预览；不自动炼制 |
| 成本 | 分支概率总和正确；失败与双产计入期望；多产物不重复分摊整炉成本；缺价报错 |
| 品质 | 同代码同效果；交易不改变药效；匠心仅作用一次；效果和产量的期望与文案一致 |
| 战斗 | 每个新增模板至少一个正常生效场景和一个关键反制场景；群体/多段总预算正确 |
| 生命周期 | 回合数完整；驱散与到期行为正确；延迟伤害不被取消；附伤不递归 |
| 模式 | PVE、PVP、Boss、多部位、自动战斗分别覆盖；未支持用途扣物前拦截 |
| 洗练 | 有明细按记录，无明细按等级重置；最终可用点数不超过等级；无任何需重置内容不扣药；预览改变须重算 |
| 洗练交叉 | 道具→转职→道具、重复回调、断线重试都不重复退款；账本可追踪 |
| 数据迁移 | 新库与存量库均可重复初始化；旧代码库存不消失；无历史不伪造历史 |
| 商店仅售成品 | 进店保留我要买、我要卖、闲聊、关于职业及离开；买卖和转职可用。购买货架只售成品，商店加工入口关闭，旧代加工命令不能执行服务 |
| 个人副职业 | 个人能力和入门成长仍可达、仍按个人资格校验；非炼金师可购买洗练露；维修与必要材料有合法获取渠道 |
| 旧商店会话 | 未确认会话失效且不扣料；已提交结算不丢成果、不重复扣料；不影响个人配方、等级与真实历史 |

按照项目要求，代码实装后运行 `npx tsc --noEmit` 与针对性测试。全仓若有原有错误，记录具体文件与行号并与本次改动区分。数据库事务、QQ 按钮、战斗实测只有实际运行后才记为通过。

平衡验收除均值外，还输出 10 / 30 / 100 场的结果区间、平均材料消耗与最差随机结果；检查低级药跨等级使用、满专精技能对照、群体叠加及顶级制作者收益。无法达到药剂目标优势的模板继续调整或合并，不用“种类很多”代替实用性。
