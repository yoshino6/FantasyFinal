# 死灵法师·乌兹：技能与机制重设计 V1

> 状态：**首轮代码已实装，数值待真实对局校准**。技能、模板与战斗状态机已写入工程，需在服务执行数据库初始化并重启后才会对服务器生效。乌兹的主动与被动技能仅作用于本遭遇；第 3.2 节的召唤物继承 Boss 词条已作为适用于**所有 Boss 召唤物**的通用规则接入现有召唤路径。本次未修改地图、掉落或首杀。

## 1. 战斗定位与设计原则

乌兹是 Lv.32 暗系召唤型 Boss。战斗要让队伍在「清理召唤物」与「压低本体血量」之间反复权衡：清场会阻止分伤、命匣和骨龙，却让存活亡灵的**狂热**变强；放任召唤物则会让下一批继续加入，带来更多控制、乌兹分伤和骨龙咏唱机会。后半场增加定点汲蓝与残血处刑，迫使队伍管理资源和救援时机。

本文的百分比威力均指现有技能定义中的 `power` 百分数，即 120% 记作 `power=120`；直接伤害继续经过现有命中、元素、攻防、暴击、减伤与护盾链。文中的概率为**基础概率**，控制抗性和免疫照常生效。数值是首轮建议值，需用队伍实战数据校准。

## 2. 与现状的关系

实装前的 `necromancer_uz` 使用葬印蚀魂、髓骨缚鞭、墓群和鸣、噬魂收割、魂匣折返、遗骸应召，且遗骸应召固定生成两只 Lv.16 普通骷髅、最多两次。本次已将模板技能序列和乌兹专用 AI 整体替换为本文方案；旧技能定义为兼容既有数据仍可保留在技能表中，但乌兹的新序列与状态机不再选择旧魂匣、旧收割或旧召唤逻辑。数据库初始化还会把已刷出的存活迷宫 Boss 同步为模板的新技能序列。

## 3. 统一口径

| 项目 | 规则 |
|---|---|
| 回合 | 文中「第 N 回合」是乌兹第 N 次**实际可行动**的行动槽。插入召唤、统御或咏唱的行动会占用本次行动；普通四步循环指针在插招后保持原位。怪物被控制而跳过行动不推进循环、不缩短以「自身行动」计的间隔。 |
| 阶段 | 乌兹当前 HP **低于**最大 HP 的 50% 进入二阶段，进入后锁定，不因治疗回到一阶段；低于 75% 与敌人低于 30% 也都采用严格小于。阶段切换不直接赠送额外行动。 |
| 召唤数量 | **不设普通亡灵在场上限，也不设整场召唤次数上限。**每次召唤固定加入 2 只；未清理的旧召唤物持续留场，新的召唤物照常叠加。冰霜骨龙仍全场至多召出 1 只，其数量不限制普通亡灵的后续召唤。 |
| 阶段替换 | 开场只有一个「召唤」决策槽及一套召唤计时；乌兹进入二阶段后，此槽的**骷髅召唤直接替换为死灵召唤**，往后不再施放骷髅召唤。场上已有骷髅不消失，也不转换种类；下一次达到召唤时机就加入幽魂与法师。阶段转换不重置上次召唤时间或被清场后的冷却。 |
| 计数范围 | 「召唤物」「友方单位」在乌兹机制中仅指**乌兹本场召出的、仍存活的普通亡灵**；此处「普通亡灵」是相对骨龙的机制分组，包含 `normal` 小怪和 `large` 大怪，并非怪物档位名。骨龙仅参与狂热的死亡事件，不作为统御门槛、命匣祭品或再召唤占位。其他怪物、玩家契灵、随从不计入。 |
| 持续时间 | 「持续 2 回合」按受影响单位接下来 2 次行动结算；控制 1 回合只跳过其下次可行动机会。咏唱的 2 回合指乌兹接下来 2 次行动槽：起唱占第一槽，若未打断则下一槽完成召唤，不同时使用其他技能。 |
| 冷却 | 沿用项目「冷却 1 需间隔 1 回合」的口径；以下列出的主动技能冷却按该技能再次可用前，至少隔开的**乌兹行动槽**数解释。命匣转生无冷却且没有整场触发次数上限。 |
| 目标 | 单体默认选最高仇恨的存活玩家；处刑、汲蓝和虚弱连招另有明确选取。若并列，按稳定角色 ID 选择，避免随机跳靶。 |

### 3.1 四种负面状态

| 名称 | 本方案效果 | 叠加/清除 |
|---|---|---|
| 恐惧 | 控制 1 回合，跳过下一次行动。 | 同名不叠加；再次命中只刷新。受抗性、控制免疫与常规净化影响。 |
| 破甲 | 物理防御 -15%，持续 2 回合。 | 同名取较强值并刷新，不累加；对应现有碎甲/脆弱类规则，不能误当作魔防降低。 |
| 虚弱 | 物攻、魔攻各 -15%，持续 2 回合。 | 需新战斗效果或复用经核对的双攻减益；与同名不叠加。 |
| 中毒 | 每次行动结算损失最大 HP 的 2%，持续 2 回合。 | 同名仅刷新，不因乌兹多次施加而叠层；伤害按现有持续伤害与护盾规则处理。 |

`黑暗凋零`对每个**实际命中**的玩家独立且等概率抽取上述一种状态，只赋予一种；免疫/抵抗后不补抽。这样全队控制不会因一次范围技必然同时发生。若工程沿用既有 `poison`、`armor_shatter` 等效果，最终显示名与数值应以本文为准，但须在实装时核对是否与玩家同名状态共享叠加层。

### 3.2 所有 Boss 召唤物继承 Boss 词条

每个由 Boss 召出的战斗内怪物，包括乌兹的骷髅、幽魂、法师及骨龙，在生成时继承**召唤者当前 Boss 词条对生命以外属性的加成**。先按该召唤物自己的 `normal` / `large` / `elite` 模板计算六维、等级成长、派生属性和对应虚拟装备，再使用与召唤者相同的词条倍率和逐项属性修正，但**跳过所有最大 HP/当前 HP 加成**：词条的通用倍率若原本同时提高 HP 与其他属性，只对其他属性生效；词条专门给 HP 的倍率或百分比也不生效。物攻、魔攻、防御、MP、命中、闪避、速度、韧性等非生命属性仍按词条原定义分别生效。不能把乌兹的最终面板复制给它们，也不能另随机一条词条。生成时当前 HP 等于**未继承词条生命加成**的自身 HP 上限，当前 MP 等于继承非生命加成后的自身 MP 上限。同一召唤物只应用一次，不因跨阶段或每回合刷新而重复乘算。

这是一条所有 Boss 通用的继承规则，不限乌兹。继承的是词条的**非生命战斗加成**，而非 `boss` 怪物档位、Boss 虚拟装备或任何 Boss 生命倍率；经验、掉率等奖励字段不在召唤物上结算。召唤物的名称、目标列表、鉴识词条栏和战报**均不显示继承的词条名称或前缀**，但鉴识到的攻击、防御等实际数值要反映加成，HP 则显示独立模板与召唤物自身被动计算值，不受词条生命加成影响。内部需保存来源 Boss 与词条代码，使战斗计算可追溯且不会被隐藏显示逻辑一并删除。Boss 的本场词条通常固定；若确有战斗中换词条机制，已召出的单位以生成时继承的词条为准，新召出的单位继承当时的词条。

## 4. 乌兹本体技能

建议乌兹保留现有基础面板、光弱点和暗抗性，先观察机制强度；不同时提高其基础魔攻和 HP。蓝耗与冷却是技能定义建议值，召唤/机制技不能因低蓝无限绕过优先级：低蓝时先进入现有 Boss 回蓝动作，下一次再重评条件。

**乌兹被动·亡灵体质**：乌兹受到的**非光属性魔法伤害 ×0.50**，受到的**物理伤害 ×1.25**，受到的**光属性伤害 ×1.50**。先用正常命中、攻防、元素抗性、词条、护盾前减伤等规则得到本次待承受伤害，再叠加此被动的适用乘数；它只作用于乌兹，不自动赋予召唤物或骨龙。物理与光属性可同时成立，故光属性物理伤害为 `×1.25×1.50＝×1.875`；光属性魔法只取 `×1.50`，不再取「非光魔法」的减半。无属性魔法属于非光魔法；没有物理/魔法分类的真实伤害与纯状态损血不受此被动增减。此被动与乌兹现有光元素弱点/抗性按正常结算顺序分别生效，不将既有光弱点覆盖成单一 +50%。

| 来袭伤害 | 亡灵体质乘数 | 说明 |
|---|---:|---|
| 非光属性魔法（含无属性魔法） | `×0.50` | 仅这一类享受减伤。 |
| 光属性魔法 | `×1.50` | 光属性优先，不再额外减半。 |
| 非光属性物理 | `×1.25` | 包括无属性物理。 |
| 光属性物理 | `×1.875` | 物理与光的两项增伤相乘。 |
| 无分类真实伤害、纯状态损血 | `×1.00` | 仍受各自既有专门规则。 |

### 4.1 二阶段转场：亡者开门

乌兹的当前 HP 首次严格低于 50% 时锁定二阶段，并在轮到乌兹结算时触发一次转场。该转场不占用行动槽，不推进四步循环，也不会因乌兹当轮受到恐惧、眩晕等硬控而跳过；此后即使乌兹回复到半血以上也不再重复播放。**手动战斗先发送完整回合消息，再发送独立转场剧情消息；自动战斗则把同一段内容写在当轮全部战斗正文之后。**

**亡灵统御的分伤算法**：乌兹受到一次伤害时先照常算命中、攻防、元素、暴击、词条、乌兹的**亡灵体质**与其他自身减伤，得到待扣除生命的伤害 `D`；若本次命中开始时至少有 3 只普通亡灵，乌兹承受 `ceil(0.6D)`，其余 `D－ceil(0.6D)` 平均分给当时存活的普通亡灵，余数按稳定 ID 分配。分摊部分是转移伤害，不对召唤物重新算防御、继承的 Boss 词条、暴击或二次范围命中；各自护盾可吸收，超出其当前 HP 的部分不回弹乌兹。召唤物**直接被攻击**时仍按自身面板与继承词条正常承伤。一次范围技能按每个被命中目标分别结算；乌兹受击所产生的转移伤害不会再触发一轮分伤。门槛以该次受击开始时快照判断，即使本次分伤击杀了召唤物，也只影响**下一次**乌兹受击。

## 5. 召唤物设计

所有召唤物都按**独立的 30 级怪物**计算，不引用乌兹的 HP、攻击、防御、速度或其他面板百分比。骷髅召唤的狂战士、神箭手是 `monster_class='normal'`（小怪）；死灵召唤的幽魂、法师是 `monster_class='large'`（大怪）。每次召唤都使用该模板的六维权重，按现有 `randomMonsterBaseAttributes` 分配初始六维：小怪总点数随机 45–65，大怪 65–90；再按 `monsterGrowthAllocation` 计算 30 级六维，使用 `calculateDerivedStats` 得到派生属性，最后加上 `virtualEquipmentStats(30, 对应档位, …)` 的虚拟武器和防具，**随后按第 3.2 节只继承乌兹本场 Boss 词条对非生命属性的加成**。继承正常怪物计算顺序与取整，不引用乌兹的 Boss 虚拟装备或把其最终面板再乘一次。生成时 HP 设为自身模板计算出的上限，MP 设为非生命词条加成后的自身上限。以下六维与成长是**待评审的模板建议值**，不是固定生成后的六维或已验证面板；列序均为体 / 精 / 力 / 智 / 敏 / 感。

| 骷髅法师 | `large` 大怪 / Lv.30 | 13 / 34 / 6 / 36 / 16 / 27 | 0.6 / 1.9 / 0.2 / 2.0 / 0.7 / 1.4 | `灵魂冲击`：暗魔法单体 98%，蓝耗 40，冷却 1，忽略 20% 魔防；优先攻击已有虚弱者，没有则打最高仇恨者。 |

四种模板独立于已有地图怪物模板，不借用 `skeleton` 或 `skeleton_warrior` 的等级、六维或精英档位；仅作为乌兹的战斗内召唤目标生成。召唤物无经验、掉落、任务击杀或独立交涉资格。由于六维分配有随机性，同一种召唤物之间的最终面板允许正常波动；需要先生成样本检验难度，再调整表内权重/成长。

**狂热（四种普通亡灵被动）**：该单位在场期间，每有一个乌兹侧的**其他**普通亡灵或骨龙死亡，获得 1 层狂热；每层使自身物攻、魔攻、速度分别提高 10%，最多 10 层，即三项各 +100%。只统计真实死亡，每个召唤实例只计一次；命匣献祭也算死亡。新召出的单位从 0 层开始，乌兹本体死亡不为其加层；被击杀者不为自己加层。不同来源的速度变化按后文速度规则计算。

## 6. 冰霜骨龙

骨龙只可由成功完成咏唱生成一只。它是**独立的 `monster_class='elite'`、Lv.30 怪物模板**，不能按乌兹面板的固定百分比生成。建议模板六维权重（体 / 精 / 力 / 智 / 敏 / 感）为 **42 / 34 / 28 / 41 / 19 / 30**，成长（同序）为 **2.2 / 1.7 / 1.5 / 2.2 / 0.9 / 1.5**。每次召出时按精英怪正常随机分配 90–120 点初始六维，再经 30 级成长、派生属性与 `elite` 虚拟装备计算基础面板；随后按第 3.2 节只继承乌兹本场 Boss 词条的非生命加成，再应用自己的「庞大身躯」被动。骨龙入场当前 HP 等于其**精英模板 HP ×2**，不受 Boss 词条生命加成；MP 以非生命词条加成后的自身上限入场。它不额外获得 Boss 怪物档位的生命倍率，也不复制乌兹面板。以上六维仍需样本和实战校准。骨龙不为乌兹提供统御人数，也不能被命匣消耗；乌兹死亡时骨龙与其他普通亡灵立即退场，不产生经验、掉落或额外战利品。

**骨龙被动·庞大身躯**：在其独立精英面板的基础上，最大 HP **×2.00**；继承词条对闪避等非生命属性的加成后，闪避再 **×0.50**。召唤入场时当前 HP 等于翻倍后的最大 HP。即使乌兹持有「普通的」等带生命倍率的 Boss 词条，骨龙也**不继承该生命倍率**，其最大 HP 仍仅为自身精英模板 HP 的 `×2.00`；词条若放大闪避，则先按词条放大，再由庞大身躯减半。这项被动只属于骨龙，不随 Boss 词条继承给其他召唤物。

| 技能 | 威力/蓝耗/冷却 | 行为 |
|---|---|---|
| 寒冰吐息 | 冰魔法全体 102% / 85 / 3 | 每名实际命中的玩家速度 -25%，持续 2 次其自身行动；与领域减速相加，其他同名吐息只刷新。骨龙首个可行动槽优先施放，以后到冷却且至少 2 名玩家存活时再优先；否则使用冰属性单体 95% 普攻。 |
| 凛冬领域（被动） | 0 / 0 / 常驻 | 骨龙存活期间，场上**除骨龙自身外的所有单位**速度 -20%，包括乌兹、其普通亡灵与玩家召唤物。任一单位释放非冰属性**魔法**时，其造成的伤害 -25%；火属性魔法也按此减伤，火属性物理攻击不受影响。骨龙死亡即刻解除。 |
| 冰霜铠甲 | 0 / 70 / 4 | 骨龙首轮吐息后且未持有铠甲时优先释放；持续 3 次自身行动。受到非火属性伤害 -25%，受到火属性伤害不减免；自身冰属性伤害 +10%。再次释放只刷新，不叠加。 |

领域与吐息的速度惩罚**按百分点相加后统一乘基础速度**：普通单位只受领域为 `×0.80`，玩家同时受领域与吐息为 `×0.55`；狂热的速度加成在此之后乘算，例如 2 层狂热且受领域为 `基础速度 ×1.20×0.80`。速度最低保底 30% 基础速度。铠甲减伤与其他减伤依现有防御层顺序乘算，不把 25% 理解成「免疫冰」。这组数值意在让骨龙入场成为明显的战场转折，同时避免领域把乌兹一方无代价强化。

## 7. 被动：命匣转生

乌兹受到**本可将其当前 HP 降至 0** 的一次最终伤害时，若至少有 1 只存活普通亡灵，先拦截致死：从存活普通亡灵中按稳定 ID 排序后等概率抽取 1 只作为祭品，将祭品当前 HP 归零并记为死亡；乌兹保留 1 HP，再回复**祭品被献祭前的当前 HP**，最高不超过乌兹最大 HP。也就是说「回复该友方单位生命值」按祭品**当前**生命解释，不按其最大生命解释。此次攻击的剩余溢出伤害不二次打到乌兹；祭品死亡可给其他存活普通亡灵增加狂热层。

命匣转生**没有冷却，也没有每场触发次数上限**。只要致死伤害结算时仍有普通亡灵存活，乌兹就能继续献祭并复活；连续多段伤害若多次把乌兹打至致死，也可逐段消耗不同祭品连续触发。只有普通亡灵已全部死亡时，乌兹才会正常死亡。对同一攻击先处理统御分伤，再判断乌兹所承担的伤害是否致死；若同一次范围伤害同时击中乌兹和召唤物，先结算召唤物的直接受击与死亡，再检查命匣，因此已经阵亡者不可献祭。乌兹一旦在无可用祭品时死亡，后续毒伤/连击不再触发命匣。

## 8. 出招优先级与状态机

下表从高到低检查。每次乌兹行动最多执行**一项**，条件不成立、技能冷却或蓝耗不足才继续往下找；不允许在同一行动里「召唤+统御」或「起唱+普通攻击」。控制状态先于所有主动技能判定。命匣是受击被动，不占行动，始终先于下一次主动技能决策。

| 顺序 | 条件 | 选择及限制 |
|---:|---|---|
| 0 | 已在咏唱且未被打断 | 完成骨龙召唤；若在咏唱期间遭任何会阻止行动的控制（眩晕、恐惧、睡眠等），立刻打断并清除咏唱，下次按普通优先级重评；束缚/减速等非硬控不打断。 |
| 1 | 二阶段、至少 2 名存活骷髅法师、骨龙技未尝试 | 起唱骨龙；此优先级高于补召与统御，但不在乌兹已被控制或当前 MP 不足时非法起唱。 |
| 2 | 开战首次行动，或距上次召唤至少隔 6 个乌兹行动槽；若场上被清空，还须满足清场后的 5 槽冷却 | 这是**同一个召唤槽**：一阶段使用骷髅召唤，二阶段直接改用死灵召唤。每次固定召 2 只，不检查场上剩余数量；只要战斗继续且计时/蓝量允许，后续仍能一直召。若上次召唤的最后一只在之后才死亡，额外要求该清场事件后**隔 5 个乌兹行动槽**；与 6 槽间隔取较晚者。 |
| 3 | HP <75%、普通亡灵 ≥3、统御未生效 | 亡灵统御。人数跌至 2 时立刻解除；再补到 3 只须重新施放且遵守冷却。 |
| 4 | 无普通亡灵、至少一名玩家 HP <30%、死亡缠绕可用 | 死亡缠绕。若召唤也就绪，先召唤；这是乌兹错过补召窗口时的残血反扑。 |
| 5 | 二阶段且循环当前为第 4 槽 | 灵魂汲取；选**当前 MP 数值最高**的存活玩家，数值并列选当前 MP 比例最高者；所有玩家 MP 为 0 时改选 HP 比例最低者，仍可造成基础伤害，但不汲蓝。 |
| 6 | 普通循环槽 | 按下一节的 4 槽轮转。槽对应技能不可用时在其余**本阶段普通技能**中按 `灵魂冲击/撕裂 → 黑暗凋零` 顺序选可用项；都不可用则现有 Boss 回蓝/普攻。只有成功施放普通槽技能才推进指针。 |

召唤计时举例：第 1 行动槽召骷髅，最早第 8 槽再次召唤（中间隔 6 槽）；即使第 8 槽时原两只都存活，也照常再加入 2 只。若乌兹在第 5 槽进入二阶段，第 8 槽召出的就是**幽魂和法师**，不会再召骷髅。若最后一个召唤物在第 10 槽后死亡，最早第 16 槽再召（其间隔 5 槽）。**召唤被击败后的 5 回合冷却**不会被「场上无召唤物」条件绕过；未被清场时仅检查 6 槽间隔。

### 8.1 基础四槽循环

| 槽位 | 一阶段（HP ≥50%） | 二阶段（HP <50%） | 连招作用 |
|---:|---|---|---|
| 1 | 灵魂冲击 | 灵魂撕裂 | 单体穿透；二阶段建立虚弱。 |
| 2 | 黑暗凋零 | 黑暗凋零 | 范围压血并撒一个随机状态。 |
| 3 | 灵魂冲击 | 灵魂冲击 | 借穿透追击已受压制目标。 |
| 4 | 灵魂冲击 | 灵魂汲取 | 一阶段维持输出，二阶段优先抽取当前 MP 最多的目标并给乌兹续航。 |

四槽重复，直到战斗结束；从一阶段进入二阶段时**保留当前槽位**，只按新阶段映射改招。例如一阶段刚完成槽 2 后降到 49% HP，下一普通行动仍执行槽 3 的灵魂冲击，随后槽 4 才汲取。被召唤、统御、咏唱、死亡缠绕插招打断时，下一次普通行动继续原槽，不重置到槽 1。

### 8.2 召唤物连招与变招

| 场景 | 战场组合 | 乌兹/召唤物的实际循环 | 玩家可利用的空档 |
|---|---|---|---|
| 开局立阵 | 狂战士 + 神箭手 | 骷髅召唤 → 冲击 → 凋零 → 冲击；箭手优先打破甲目标，狂战士压最高仇恨。 | 第 1 次召唤占乌兹行动；清掉一只会阻止 3 人统御，但另一只获得 1 层狂热。 |
| 75% 门槛 | 第二次召唤后累计至少 3 只 | 下次乌兹行动插入统御，再从原槽续接；群攻与分伤竞争玩家输出。 | 清到 2 只使统御即时失效，但下一次召唤仍会按计时到来。 |
| 半血换阵 | 旧骷髅仍可存活，后续新召的是幽魂 + 法师 | 同一个召唤槽改为死灵召唤；撕裂虚弱 → 幽魂尖啸控场 → 凋零撒状态 → 法师冲击追击。 | 优先打断/击杀幽魂可减少群控；击杀法师可阻断骨龙门槛。 |
| 汲蓝压制 | 玩家治疗/法师当前 MP 最高 | 乌兹第 4 槽抽取目标当前 MP 的 50%；自身 MP 满后，后续抽取量按 1:1 转成 HP，同轮法师追击虚弱目标。 | 在汲蓝前安排高 MP 角色消耗资源，或为被盯上的角色准备防护；提前消耗 MP 会同时降低被抽蓝量与乌兹可能获得的治疗量。 |
| 命匣反扑 | 至少 1 名普通亡灵存活 | 每次致死均可献祭 → 乌兹恢复祭品当前 HP → 其他存活亡灵狂热 +1；没有冷却或次数上限。 | 必须先清空普通亡灵再斩杀本体；只压低祭品血量只能减少单次回血，不能阻止再次复活。 |
| 处刑窗口 | 普通亡灵全灭且玩家低于 30% | 若召唤仍冷却则死亡缠绕优先于普通循环；若召唤已就绪则先召唤。 | 无召唤物时必须先救起低血队友，或用护盾/控制拖过乌兹行动。 |
| 骨龙起唱 | 二阶段存活法师 ≥2 | 起唱 → 玩家可控/杀法师 → 若未打断，下个乌兹行动召骨龙 → 骨龙吐息 → 铠甲/单体攻击。 | 2 个法师是可见前置；起唱后硬控乌兹可打断，杀法师不单独打断**已经开始**的咏唱。 |

### 8.3 同时满足多个条件时的决策示例

1. 乌兹 47% HP、3 只普通亡灵、其中 2 名法师、统御未开启、有人低于 30%：先**起唱骨龙**。因为仍有召唤物，死亡缠绕不合法；若咏唱完成，下一行动再判断统御。
2. 乌兹 70% HP、已有 3 只普通亡灵、距上次召唤已隔 6 槽：先**骷髅召唤**再增加 2 只；下一行动再放统御。乌兹若已低于 50%，同一槽则施放**死灵召唤**，不会继续生成骷髅。
3. 乌兹 20% HP、普通亡灵全灭、玩家 25% HP：无祭品使命匣不会触发；召唤若仍在冷却则用死亡缠绕，召唤就绪则先召唤。命匣没有冷却状态需要额外判断。
4. 乌兹正咏唱，玩家同时击杀 2 名法师：已经起唱的咒文继续；必须控制乌兹或击杀乌兹才能阻止骨龙。这样避免玩家在咏唱后才发现「杀法师是否有效」不明确。

## 9. 战斗提示与反制信息

- 乌兹每次召唤显示本次召出种类、当前普通亡灵总数 `n`、下次最早可召唤行动槽；二阶段显示「骷髅召唤已替换为死灵召唤」。召唤物卡片显示狂热层数和对应三项增益。
- 乌兹被动在鉴识/战斗说明中列出「亡灵体质」及光魔法、非光魔法、物理的承伤变化；骨龙展示「庞大身躯」与 HP/闪避效果。召唤物继承的 Boss **词条名不显示**；非生命战斗属性应包含词条加成，HP 不包含词条生命加成。
- 亡灵统御显示「40% 待扣血伤害转由 X 只亡灵分担」；人数降至 2 时立即显示解除，不用一个不可见的永久 Buff。
- 命匣触发显示祭品名称、祭品原当前 HP、乌兹实际回复量，并明确提示「只要仍有普通亡灵即可再次触发」；不显示冷却或剩余次数，因为这两项限制已移除。
- 死亡缠绕在乌兹行动前，若有人低于 30% 且无普通亡灵，显示可见的「死亡缠绕待发」提示；若召唤优先级更高，提示应改为「正准备召回亡灵」，不要误导玩家。
- 骨龙起唱显示明确的 **2 槽**倒计时、「硬控可打断」和已尝试次数；打断、完成、乌兹死亡都要清除咏唱标记。骨龙在场时持续展示领域对象与非冰魔法 -25% 的信息。

## 10. 数值风险与校准方案

| 风险 | 原因 | 首轮校准观察与调整顺序 |
|---|---|---|
| 持续召唤导致行动长度暴涨 | 普通亡灵没有在场或全场次数上限；长期不清理会持续累积敌方行动。 | 记录每轮战报长度、四人队与单人队的平均战斗时长；先校准召唤间隔、怪物六维或技能威力，不把限制数量当作调参手段。实装时须保证分页/战报展示和异常结束清理能处理较多临时目标。 |
| 词条继承造成非生命属性过强 | 高阶 Boss 词条可大幅放大召唤物攻击、防御、闪避等；骨龙另有独立 HP `×2.00` 与闪避减半。 | 按每个实际 Boss 词条生成五种召唤物面板样本，核对它们的 HP **不随词条变化**、骨龙 HP 只由庞大身躯翻倍，并记录伤害、闪避与清场时间。 |
| 凋零 + 尖啸形成连续控制 | 凋零可能抽到恐惧，幽魂又提供群体恐惧。 | 记录每名玩家连续失去的行动次数；若多数队伍连续失去 ≥2 次行动，先将尖啸恐惧率 18% 下调到 12%，或给同一目标 1 槽短暂恐惧保护。 |
| 命匣过度拖战 | 命匣无冷却、无次数上限；放任普通亡灵累积会让乌兹拥有相同数量的连续复活机会，大怪祭品血量还可能较高。 | 记录每场命匣触发次数、平均回血/乌兹最大 HP及队伍清场频率；本机制要求玩家先清兵再斩杀。若拖战超过预期，先校准召唤间隔、召唤物生存力或祭品回复规则，不暗加触发上限。 |
| 死亡缠绕事实上的斩杀 | 目标 HP <30% 时，其已损 HP >70%，追加真实伤害 >35% 最大 HP，未被盾/免死抵挡时几乎必死。 | **这按初稿的 50% 已损血量原样保留，是明确的处刑技**；观察提示是否给了足够救援窗口。如希望改为高威胁非必杀，应另行决定改系数，不能在实现时暗加上限。 |
| 骨龙触发过少或过稳 | 需要场上同时留住两名法师；死灵召唤至少成功两次，每次受同一 6 槽计时约束。 | 统计第二次法师召出率、成功起唱率、成功召龙率；若几乎不出现，校准召唤间隔或法师存活能力，不直接删去 2 法师门槛。 |
| 领域过度压制速度与暗法 | 骨龙让乌兹和幽魂的暗法也 -25%，但玩家也被减速。 | 核对双方每轮行动次数与法术伤害；若骨龙反而削弱乌兹过多，优先调整骨龙魔攻/吐息，再讨论领域是否区分敌我。 |
