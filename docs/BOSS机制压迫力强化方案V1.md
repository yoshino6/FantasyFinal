# BOSS机制压迫力强化方案 V1

状态：待确认的设计方案，未实装、未进行胜率验证。

范围更新：用户确认本轮只调整格鲁恩、瓦尔克。本文其余三只BOSS的提案全部暂缓，不进入本轮实施。以《格鲁恩与瓦尔克·单体压制强化方案V3.md》作为本轮评审版本。

## 一、范围与目标

本案按前文讨论的五只BOSS编写：哥布林国王＆哈巴龙、死灵法师乌兹、三首蛇母、格鲁恩、瓦尔克。四只史诗图纸BOSS均包含在内，乌兹单独纳入机制设计；若本轮仅调整四大图纸BOSS，可整体暂缓乌兹章节。

目标不是“每回合都打得更痛”，而是：正常处理机制时有喘息与输出窗口；无视预警继续站桩时，承受明显高额伤害；连续忽略机制足以导致减员或团灭。

### 必须保留的边界

- 不提高BOSS基础六维、成长、出生生命、普通攻击和常规技能基础威力；不新增梦幻专用基础属性倍率。
- 新增伤害只来自明确触发的机制失败分支；高难强化放进BOSS专属词条，不给普通档强塞完整高难组合。
- 不改现有元素抗性、奖励、图纸掉率、刷新地图、装备打造与职业技能。
- 哥布林国王地图仍只显示“哥布林国王＆哈巴龙”；小怪战斗开局召唤，退出重进从合体阶段满状态重新打。
- Lv.18哥布林国王主线不直接套用本案新增惩罚，保留现有主线难度；测试场按所选正式难度验证。
- 梦幻仍以完整史诗装备和成熟构筑为目标，但装备不能替代机制；这只是校准目标，不是已验证的门槛，也不做装备准入限制。

## 二、统一惩罚与预警规则

### 2.1 判定时序

1. 第T回合满足蓄势条件，先完成本回合战报。
2. 在战报后发送独立预警；记录参与者、目标与截止回合。
3. 玩家至少获得完整的第T+1轮行动机会，随后判定成功、部分成功或失败。
4. 机制失败伤害替代该次机制原本的伤害，不与其旧版伤害重复结算。

速度、额外回合、多段、反击、召唤物行动不能缩短预警。自动战斗必须在预警轮停止批量推进并发送消息。预警期间击杀BOSS则取消该机制，死亡后不得追罚。

### 2.2 机制伤害统一口径

以下百分比均为“受击者最大生命的百分比”，不是当前生命，不是技能威力，也不是对BOSS生命的百分比。

- 建议新增独立的机制伤害标签：不暴击、不闪避，不再乘BOSS攻击、技能威力、难度属性、元素精通、风蚀或直击易伤。
- 护盾、明确适用的最终减伤、免死与时间守护正常生效；本案不新增无视免死、禁止治疗或无条件穿盾。
- 本案中“防御减半”指玩家在本次响应轮实际成功执行防御，对该次机制基础伤害×0.5。此倍率代替防御动作原有减伤，不能重复叠算；其他不同来源保护仍按现有规则处理。
- 独立机制不得触发反伤、吸血、追击或再触发自身。直接通过正式伤害结算，不手改血量。
- 为避免多个新惩罚叠加无预警秒杀，每个BOSS每轮对同一玩家新增机制伤害合计，在护盾/减伤前最多为最大生命的70%。仅限制本案新增机制伤害，不限制原有普攻和DOT，也不保证角色能存活。
- 成功处理机制会清除对应“连续失误”计数；上限2次升级，不无限成长。退出、重开、胜利均清空会话状态。

### 2.3 强度目标（待模拟校准）

| 行为 | 预期体验 |
| --- | --- |
| 正确处理关键机制 | 消除大部分新增惩罚，获得至少一轮可利用的窗口 |
| 没处理但提前防御/开保护 | 仍亏血和行动，但有机会救场 |
| 首次无视关键预警 | 常见为全队35%–45%最大生命机制伤害，或单人更高惩罚 |
| 连续两次无视 | 提升到50%–60%，叠加既有战斗压力后容易减员 |
| 梦幻忽略机制 | 专属词条进一步提高失败代价；不缩短基本响应窗口 |

这些是配置候选值，实际扣血受保护影响；不能将“45%机制伤害”表述为一轮总共只掉45%。

## 三、哥布林国王＆哈巴龙：放任王庭，就吃协同重击

### 现有基础

保留合体、王座分离、王车易位、孤王/孤龙狂怒及援军周期。现有随从已强化，不再普遍增加随从基础生命和攻击。

### 新机制：王旗合围

- 同组至少一名盾卫与一名雷矛侍卫连续存活到两个完整回合结束时，触发一次王旗合围预警。
- 记录预警时存活的两类随从；下一完整玩家轮结束后检查同组是否仍同时存在这两类单位。新补员同样参与此存活判断。
- 任一类被清空：合围解除，本体下一轮承伤提高15%；不削弱已经存在的共生之外其他属性。
- 两类都在：全队承受35%最大生命机制伤害；连续失败第二次及以后为50%。主动防御减半。
- 合围结算替代王龙该轮一次联合进攻，不额外让双核心各打一轮惩罚。参与合围的盾卫、雷矛侍卫该轮不再普攻或协同追击。
- 每次结算后重新累计两轮存活，最早不会在下一轮立刻再次合围。合围与末日践踏不能同轮结算，后者保留排队且重新保证完整响应轮。

### 末日践踏补充

- 保留现有蓄势与常规技能伤害，不提高基础威力。
- 响应轮未防御者追加20%最大生命机制伤害；已防御者无此追加。护盾是另一种承受手段，但单纯持盾不等于执行防御。
- 任一核心在蓄势期间倒地，则取消尚未结算的合体践踏，进入既有孤核阶段；已分离形态的普通践踏不追溯套用此合体条件。

专属词条方向：王庭再征将合围失败伤害增加10个百分点，但仍最多60%；保留现有补员效果。王兽血盟原有孤核强化不再额外叠一套惩罚倍率。

预警示例：“王旗骤然压低，盾卫封住退路，雷矛同时指向龙腹两侧。哈巴龙开始蓄力。”

## 四、死灵法师乌兹：不清祭品，仪式就完成

### 新机制：亡者献祭

- 每次普通亡灵召唤后，第3个完整回合结束时，若尚有该批普通亡灵存活，开始献祭预警。骨龙不计入祭品。
- 锁定该批存活祭品，给予一个完整玩家轮；后续新召唤物不加入本次祭品名单。
- 截止时祭品全部死亡：取消献祭，乌兹下一轮承伤提高20%。
- 仍有祭品：消耗剩余祭品，造成全队最大生命伤害 `min(50%, 20% + 10% × 剩余祭品数)`。因此剩1/2/3只及以上分别为30%/40%/50%；防御减半。
- 献祭替代乌兹本次进攻；祭品先退出行动队列，不先打完再献祭。被献祭单位不提供独立击杀奖励，也不触发额外死亡爆炸或命匣回血，避免形成额外复合惩罚。
- 原有普通召唤间隔、清场延后与命匣规则在其他场景保持不变。

### 骨龙咏唱必须有非硬控解法

- 保留现有打断路径，并增加“破坏锚点”：咏唱开始时从存活普通亡灵中标记最多2只；在原有完整咏唱窗口内击杀全部锚点，可打断本次骨龙召唤。
- 不要求玩家必须携带硬控；若没有可用亡灵锚点，则改以咏唱期对乌兹累计造成其最大生命8%的实际生命伤害作为替代打断条件。护盾吸收不算生命伤害，单次溢出不重复统计。
- 咏唱完成时不额外插入骨龙瞬发吐息；骨龙登场后另外发出吐息预警，下一完整玩家轮后才释放。
- 吐息保留原技能伤害；未防御者追加25%最大生命机制伤害。击杀骨龙取消吐息，硬控只按原有可控规则延迟其行动，不能跳过预警直接结算。
- 献祭与骨龙咏唱/吐息的新惩罚不并发：优先完成已经公开的预警，其他事件延后重新给窗口。

专属词条方向：只在未阻断献祭时加10个百分点，上限60%；不增加祭品基础生命，不移除替代打断途径。具体绑定现有哪条专属词条需实施前核对配置，不能凭空假设已有该名称。

## 五、三首蛇母：不处理灾蚀，就会发生灾变

不恢复旧版每层风蚀+100%的失控倍率，不取消击杀蛇首清对应灾蚀，不提高三个蛇首的常规AOE基础威力。

### 新机制：灾蚀临界

- 回合结束时，玩家任意两种蛇母专属灾蚀达到3层，标记该玩家并发出预警；同一人同一轮只记一次。
- 下一完整响应轮结束后，该玩家仍有任意两种专属灾蚀≥3层，则承受35%最大生命机制伤害；连续失败为50%。
- 玩家通过净化使条件不成立，或击杀对应蛇首触发全队清灾，均可解除。击杀可行，不以特定净化职业为唯一入口。
- 结算前确定伤害，随后将该玩家三种蛇母灾蚀各消耗2层；不得触发额外立即DOT引爆。失败不会留下原封不动的高层状态连续追罚。
- 新临界伤害不乘风蚀，与原有自然DOT分开；临界结算轮，对该玩家跳过蛇母专属灾蚀的自然跳伤及独首立即引爆，其他来源DOT不受影响。

### 灾劫焚风与独首

- 灾劫焚风保留现有双回合蓄势与“击杀参与蛇首即可中断”。失败追加全队25%最大生命机制伤害，但不再叠加原本一次各3层的新灾蚀，改为各1层。
- 灾劫结算优先于个人临界，同轮个人临界延后一个完整响应轮；不把两项惩罚同回合集中兑现。
- 独首保留每3次实际行动引爆，但在第2次行动的战报后明确预警；第三次行动引爆时，响应轮成功防御者的本次引爆伤害减半。
- 独首不再额外增加一种全新计时机制，以免本来复杂的BOSS继续堆叠规则。

专属词条方向：只为临界失败增加10个百分点，上限60%；不要再次增加风蚀倍率、额外自然跳伤频次或引爆次数。若现有词条已经强化同类伤害，采用替换而不是相乘。

## 六、格鲁恩：高压贪输出，必须承担崩山风险

保留压力来源、70%/35%阶段、元素抗性与基础技能。问题不是缺少压力条，而是高压增伤收益可能让队伍愿意硬吃现有失败伤害。

### 崩震按压力给出明确结果

| 响应轮结束压力 | 结果 |
| --- | --- |
| 0–29 | 逆脉卸力，保留原本失稳输出窗口，不追加失败伤害 |
| 30–59 | 正常崩震，只有既有基础招式伤害 |
| 60–84 | 断层崩震，原基础招式之外追加全队25%最大生命机制伤害 |
| 85–99 | 万壑倾覆，追加全队45%最大生命机制伤害 |

- 上述追加伤害可用响应轮防御减半。承重点/碎岩追震保留既有伤害，不另加百分比惩罚。
- 新追加伤害不乘压力出伤倍率、山心共振、暴击、易伤或元素倍率。
- 成功降到30以下会清除连续失误计数；连续两次在85以上结算时，45%升级为55%，此后不再增长。

### 压力100：改为可预见的山崩，而不是行动中突然团灭

- 压力首次达到85时在该轮战报后显示临界预警；首次达到100时锁定山崩，压力暂时封顶100。
- 山崩必须在预警送达后的下一完整玩家轮结束才判定；同一轮后续玩家可以泄压，绝不因速度顺序让队伍来不及反应。
- 截止压力降到85以下：解除；否则造成全队50%最大生命机制伤害，连续失败为60%，结算后压力35。
- 此伤害替换现有“立即35%最大生命且移除普通护盾”逻辑；不再移除普通护盾，玩家可选择付出护盾资源救场。已有减速/易伤持续时间保留。
- 山崩优先于该轮普通崩震，两者只结算一个；不能用一次过载吃两份新增全队伤害。

专属词条：山心共振保持高压直击强化，不放大百分比机制伤害；地脉复铸保留首次护盾。梦幻压力来自高压常规直击与失败惩罚组合，不额外提升本体基础属性。

## 七、瓦尔克：个人乱动会挨罚，全队不协同会被清算

保留现有炉令、有效行动人数、领班投票、炉温及鞭痕上限。不能把所有违令都视为错误：集体违令本来就是降温解法。

### 分清“正确违令”与“孤立违令”

- 集体停炉成功：只结算原有鞭痕代价，不加新的违令惩罚，保留降温、破绽与隔次取消工序。
- 未达到停炉人数：孤立违令额外伤害由6%提高到15%最大生命，针对实际违令者；同一成员连续孤立违令升到25%，服从或成功停炉清零。
- 孤立惩戒不套用领班1.5倍，该倍率仍仅用于原鞭痕伤害；不因身份对新增惩罚再次乘算。
- 硬控停工者不计入有效行动分母、不算服从或违令；全员停工时不给成功、不给回血，新截止顺延一轮，避免零人投票被判团灭。
- 第一次派令即配叙事提示“孤身违抗者会被铁链拖出队列”，但不公开人数答案；孤立惩戒随该次炉令响应轮结算，不另开第二套倒计时。

### 封炉清算

- 炉温100继续预警并补发炉令，保留一个完整响应轮。
- 停炉成功：取消清算，不受新增伤害。
- 未成功：用全队45%最大生命机制伤害替换封炉清算原直接伤害，不两者叠加；响应轮防御减半。连续清算失败升到60%。
- 保留鞭痕+1与结算后炉温重置，避免失败后连续锁在100温度。
- 第三阶段总罢工首次失败额外造成全队35%最大生命机制伤害，连续失败为50%；不再叠该轮孤立惩戒，仍两轮后重试。
- 总罢工、封炉同轮到期时优先总罢工；若成功则取消封炉，失败则本轮只结算总罢工惩罚并将炉温重置55，不在下一轮补扣一份清算。

专属词条：永燃余烬保留失败后炉温75与后续灼烧，新灼烧从下一轮开始；拘魂连锻原抽检附伤保留，但不在总罢工/清算轮额外补一次抽检追罚。

## 八、信息展示与自动战斗

- 面板仅显示可观察状态：压力、炉温、炉令、鞭痕、灾蚀、标记和当前蓄势。不得写“清某只即可解除”“需要几人违令”“防御减伤50%”等攻略。
- 本文数值与解法是开发设计，不直接拼进玩家消息；鉴识沿用既有信息权限，不自动揭露全部新机制答案。
- 预警需具备辨识度：知道是谁蓄势、谁被标记、危险将在下一轮或稍后发生；不能只有含混台词却没有任何可观察状态。
- 自动战斗应识别公开危险，优先清祭品/随从、集中断首、泄压与停炉；预警时不能继续盲目快进。
- 自动只使用真实可用技能、MP和道具，计入已提交手动行动，不修改保存的配置、不替手动玩家擅自操作。没有可行解时选择保护，不能伪造机制成功。
- 单人同样有解：国王可清一类随从或防御承受；乌兹可清锚点/打断/削血；蛇母可断首；格鲁恩可防御泄压；瓦尔克一名有效成员违令即可满足普通停炉。

## 九、实施顺序与验收

建议先做统一伤害标签、预警时序和同轮互斥，再依次改格鲁恩/瓦尔克、国王/乌兹，最后处理蛇母，避免五种机制同时叠进旧伤害链而无法定位问题。

必须覆盖：

1. 每只BOSS×1–4人×现有各难度，分别跑正确处理、偶发失误、持续站桩三组策略。
2. 记录战斗回合、胜率、首次减员轮次、预警后可响应行动数，以及每轮直击/DOT/新增机制伤害各自占比。
