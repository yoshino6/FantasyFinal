# 自动前往与换乘确认

先使用已持有地图寻找连续步行路线；能步行到达时不推荐换乘。步行不可达时，搜索实际存在且开放的世界树—百纳镇界门、世界树—浮叶镇/霜龙客舍公会接驳，以及换乘前后的步行路段。没有目的地地图或任何有效线路时仍拒绝移动。

换乘必须先显示“行动确认”，展示换乘站坐标、目的坐标、总耗时并给出确认按钮。确认绑定玩家、起点、队伍、目标与路线，十分钟失效；确认时重新检查。浮叶个人许可与公共航路、剧情行动限制、队伍权限仍适用。

步行耗时按实际可通行的最短网格路线和现有速度/天赋计算；界门跨越不计步行距离，过门计一秒；公会接驳按两站的三维曼哈顿距离及当前移动速度计算，至少一秒。各段相加得到移动倒计时。

沿用现有长距离移动语义：倒计时结束前坐标停留在出发点，取消时留在出发点；到时在事务中核对保存路线、执行换乘并结算目的地事件。取消不消耗物品，不提前推进传送剧情。持久化路线配合原有重启补偿结算。

## 实施与验证

源码已实现，未部署，未连接真实玩家库。新增 `player_travel_routes` 表由更新后的启动初始化创建，用来保存确认和计时路线。`/前往`、`/前往地图`、回家入口均接入确认；新确认按钮不直接发送指令。

计时结束时再检查目的坐标、地图、站点、队伍和资格。失去通路或队伍变化时停止并保留起点；数据库临时错误或传送执行失败则回滚，保留计时记录供重试。实际换乘调用事务内的原界门/公会入口，保留原剧情结算，重要传送对白随到达结果显示。
