# 岩脊山麓与赤铁山道 Boss 机制重设计 V2

> 设计状态：2026-09-16 已完成源码实装；真实装备与数据库实战校准未完成。
>
> 后续指令覆盖：常驻面板隐藏机制攻略；基础属性与常规技能沿用正常BOSS标准；高难专属词条强化；两只BOSS补齐独立被动与差异元素抗性。最终参数、必要设计补充与验证边界见《格鲁恩与瓦尔克V2实装与验收.md》。本文的旧面板示例仅保留为设计历史，不是最终展示。
>
> 设计对象：Lv.32【山脉心核·格鲁恩】与 Lv.32【熔炉监工·瓦尔克】。
>
> 本文是对现有“本体 + 三部位”方案的玩法级替换，不是在旧部位数值上继续加技能。

## 1. 为什么需要重做

现版格鲁恩与瓦尔克虽然技能名称和击破收益不同，但底层打法高度相似：

1. 开场均为本体加三个部位。
2. 每个部位均提供同一种本体减伤，玩家主要任务都是转火拆件。
3. 常规部位负责加防，紧急部位负责倒计时，击破后负责削弱本体。
4. 自动战斗的主要决策也是“紧急部位 > 常规部位 > 本体”。

这使两场战斗的最优思路最终都收敛为“先拆常驻防护件，看到预警再切紧急件，最后输出本体”。表现层不同，操作层却没有真正分开。

本次重做参考现有三只新式 Boss 的优点，但不复制它们的机制骨架：

| 参考 Boss | 现有核心体验 | 本次只借鉴什么 | 明确不复制什么 |
| --- | --- | --- | --- |
| 哥布林国王 | 双核心合体与分离、王车易位、援军共生、末存核心狂暴 | 阶段转换真正改变目标和技能逻辑；面板持续公开关键状态 | 不再做双核心、护驾或循环召唤 |
| 死灵法师·乌兹 | 召唤物数量管理、半血换招、统御、可打断骨龙咏唱 | 玩家可以通过读预警改变 Boss 的下一步，而不是只承受伤害 | 不再做清召唤物、献祭或二阶段换召唤表 |
| 三首蛇母 | 三个独立蛇首、伤害分摊、DOT 组合、共鸣大招与独首狂暴 | 机制直接进入伤害结算；残局不是简单削弱版开场 | 不再做多目标共享伤害、分头击杀或独体狂暴 |

两只新 Boss 都改为**单一本体目标**，删除部位血条和部位传伤。两场战斗的核心问题分别是：

- 格鲁恩：这一轮还能不能继续贪伤，还是必须主动泄压？
- 瓦尔克：这一轮谁服从炉令恢复状态，谁承担违令代价组织停炉？

## 2. 两场战斗的差异总览

| 项目 | 山脉心核·格鲁恩 | 熔炉监工·瓦尔克 |
| --- | --- | --- |
| 核心玩法 | 全队共同管理“地脉压力” | 每名成员处理自己的“监工炉令” |
| 决策性质 | 贪伤与止损，围绕一个共享数值 | 分工与轮换，围绕多人是否集体违令 |
| 主要反制手段 | 适时防御、辅助或使用道具进行泄压 | 按指定行动服从，或故意违令并凑足停炉人数 |
| 主要危险 | 压力过高时触发山崩；过早泄压又会浪费输出窗口 | 少数人单独违令会遭孤立惩戒；全员服从会把炉温推向过载 |
| 输出窗口 | 高压时 Boss 更易受伤，但也更危险；成功泄压后短暂“地层失稳” | 集体停炉成功后出现“罢工破绽” |
| 阶段变化 | 压力区间和预震节奏逐步收紧 | 炉令从轮流试探发展为集体罢工终局 |
| 是否需要切换敌方目标 | 否 | 否 |
| 是否依赖特定元素或职业 | 否 | 否 |

## 3. 岩脊山麓：山脉心核·格鲁恩

### 3.1 遭遇定位

格鲁恩是一场“山体承压”战。玩家越猛烈输出，地脉压力越高，格鲁恩的岩层也越容易被撕开；但压力若在山心崩震到来前没有降下去，全队会遭到失控山崩。

正确打法不是固定的技能顺序，而是反复完成以下循环：

1. 在安全区积累压力并正常输出。
2. 进入高压区后利用 Boss 的高承伤窗口集中爆发。
3. 看到地脉预震后停止贪伤，由部分成员防御、辅助或使用道具泄压。
4. 压力被压回安全线时，使 Boss 因逆向卸力进入短暂失稳。
5. 下一轮重新积压，但后续阶段的安全时间越来越短。

### 3.2 核心资源：地脉压力

地脉压力属于整场战斗共享状态，范围为 `0–100`，开场为 `20`。每名成员每次实际行动只结算一次压力变化，多段技能、追击、反击和持续伤害不会重复加压。

| 玩家行动 | 压力变化 | 说明 |
| --- | ---: | --- |
| 普通攻击 | `+6` | 命中或被闪避都算完成一次施压；被硬控而未行动不增加 |
| 造成直击伤害的技能 | `+10` | 多段、群攻和追加攻击仍只增加一次 |
| 纯治疗、纯护盾、纯强化或纯弱化技能 | `-8` | 同时造成直击伤害的混合技能按攻击技能处理 |
| 使用道具或对队友使用药剂援助 | `-8` | 充能但未施放的异械视为辅助行动 |
| 主动防御 | `-18` | 全队最稳定的通用泄压手段 |
| 因控制无法行动 | `0` | 不奖励也不惩罚 |

压力在一次玩家行动结算完毕后立即更新，并公开显示。压力不会因为固定百分比伤害、DOT、反伤、召唤物自动攻击或环境伤害变化，避免不可控来源把队伍直接推入山崩。

### 3.3 压力区间

| 压力 | 状态 | 格鲁恩承受最终伤害 | 格鲁恩造成最终伤害 | 战术意义 |
| ---: | --- | ---: | ---: | --- |
| `0–29` | 沉静 | `80%` | `90%` | 最安全，但不适合长时间输出 |
| `30–59` | 开裂 | `100%` | `100%` | 常规交战区 |
| `60–84` | 断层 | `125%` | `115%` | 主要爆发窗口 |
| `85–99` | 临界 | `150%` | `130%` | 高风险贪伤区，预震期间通常应立即泄压 |
| `100` | 山崩 | — | — | 立即触发失控山崩，然后压力重置为 `35` |

“山崩”不应被做成无视一切的一击团灭。建议造成全体最大生命 `35%` 的机制伤害，清除全队普通护盾，并施加 1 回合“碎岩压身”：速度 `-25%`、受到直击伤害 `+15%`。该伤害不暴击、不受元素抗性影响，但仍允许保命、复苏和时间守护类能力正常工作。

### 3.4 Boss 行动循环

格鲁恩不使用随机技能轮换，采用可学习的四槽循环。阶段变化只压缩预警时间和追加余震，不把循环打乱。

| 槽位 | 技能 | 效果 |
| ---: | --- | --- |
| 1 | 山脊测重 | 攻击当前最高仇恨成员，并给该成员施加“承重点”2 回合。承重点成员的攻击额外增加 `4` 点压力，主动防御则额外降低 `8` 点压力。 |
| 2 | 断层推进 | 全体中等打击伤害。当前压力每高于 `30` 点 `10` 点，本次伤害提高 `5%`，最多提高 `30%`。 |
| 3 | 地脉预震 | 不造成伤害，公开提示下一槽将结算山心崩震；给予全队完整一轮玩家行动进行泄压。 |
| 4 | 山心崩震 | 根据结算瞬间的压力区间产生不同结果，然后回到槽位 1。 |

山心崩震按压力分支结算：

| 结算压力 | 结果 |
| ---: | --- |
| `0–29` | **逆脉卸力**：崩震失败，格鲁恩本次行动取消，进入“地层失稳”1轮；期间承受最终伤害 `+25%`。结算后压力回到 `20`。 |
| `30–59` | **常规崩震**：全体中等土属性打击伤害，并使压力回到 `25`。 |
| `60–84` | **断层崩震**：全体高额打击伤害；当前承重点成员额外承受一次 `45%` 威力追震。结算后压力回到 `30`。 |
| `85–99` | **万壑倾覆**：全体高额打击伤害，附加 1 回合束缚；结算后压力回到 `35`。 |
| `100` | 玩家行动结算时已立即触发山崩，不再等待格鲁恩行动。 |

这里的最优解不是每轮都把压力降到 0。队伍可以在前两槽主动把压力推到断层甚至临界区换取输出，等预震出现再用一轮行动集中泄压。若队伍爆发不足或成员状态较差，也可以提前进入沉静区稳过循环。

### 3.5 三阶段变化

#### 第一阶段：山体苏醒（100%–71%）

- 使用完整四槽循环。
- 地脉预震后有一整轮玩家行动。
- 承重点只改变该成员的压力效率，不追加控制。

教学目标：让玩家认识“高压增伤”和“预震泄压”之间的交换。

#### 第二阶段：断层裸露（70%–36%）

- 每轮第一次进入 `60+` 压力时，格鲁恩立刻获得“岩层剥落”：本轮额外承受最终伤害 `+10%`。
- 山脊测重命中承重点时，额外施加 1 层“碎岩”。碎岩达到 2 层后，下次山心崩震会追加一次单体追震；主动防御可清除自身 1 层。
- 地层失稳结束后，压力从 `25` 而不是 `20` 重新开始。

第二阶段鼓励队伍继续主动踏入高压区，而不是从头到尾保守控在 30 以下。

#### 第三阶段：山心裸露（35%–0%）

- 格鲁恩进入“无根山体”，不再使用山脊测重，循环缩短为：断层推进 → 地脉预震 → 山心崩震。
- 压力最低只能降到 `15`。
- 临界区的格鲁恩承受最终伤害由 `150%` 提高至 `165%`，但山崩后的“碎岩压身”持续 2 回合。
- 每次成功触发逆脉卸力后，格鲁恩损失最大生命 `3%`，但同场最多触发两次，避免无限防御成为最优输出方式。

终局鼓励队伍在最后一次预震前决定：稳妥泄压再打一个失稳窗口，还是冒险留在临界区直接斩杀。

### 3.6 面板与预警

战斗面板必须始终显示：

```text
【山脉心核·格鲁恩】HP 72%
地脉压力 68/100｜断层
本体承伤 125%｜本体伤害 115%
行动：地脉预震 → 下一次行动结算山心崩震
安全目标：压力降至 29 以下可触发逆脉卸力
承重点：玩家甲（攻击额外+4压力，防御额外-8压力）
```

关键预警文案：

- 压力进入断层：`【地脉压力 60】山体裂隙完全张开，格鲁恩承受伤害提高，但崩震也开始增强。`
- 压力进入临界：`【地脉压力 85】山麓正在整体下沉；继续攻击可能直接引发山崩。`
- 地脉预震：`格鲁恩将于下一次行动释放山心崩震。将压力降至 29 以下可使崩震失败。`
- 逆脉卸力：`队伍逆向卸去山压，崩震沿裂隙倒灌！格鲁恩进入地层失稳。`
- 压力到达 100：`地脉压力突破极限，山体在格鲁恩行动前提前崩塌！`

## 4. 赤铁山道：熔炉监工·瓦尔克

### 4.1 遭遇定位

瓦尔克是一场“服从与罢工”战。Boss 会给每名存活成员下达一条监工炉令，要求其下一次行动必须使用指定类型。玩家可以服从炉令以消除个人伤势，但服从会继续为熔炉供热；也可以故意违令降低炉温。只有同一轮有足够多人一起违令，才能形成集体停炉并打断瓦尔克的工序。

正确打法是让队员轮流承担违令代价：

1. 低鞭痕、血量健康的成员负责违令。
2. 高鞭痕或濒危成员服从一次，清除压力。
3. 队伍确保每次违令人数达到停炉门槛，不能让少数成员被孤立惩戒。
4. 在高炉温阶段优先组织停炉，在低炉温阶段可以适度服从恢复。

这不是动作猜拳。炉令、停炉门槛、每名成员的鞭痕和当前炉温都必须提前公开。

### 4.2 核心资源一：监工炉令

炉令只使用所有职业都天然拥有的行动，不依赖特定元素：

| 炉令 | 合规行动 | 备注 |
| --- | --- | --- |
| 轻锤令 | 普通攻击 | 追击不会改变判定 |
| 重锻令 | 任意主动技能 | 伤害、治疗、护盾和强化技能均算技能 |
| 固炉令 | 主动防御、使用道具、药剂援助或仅为异械充能 | 异械实际施放算主动技能，不算固炉 |

每名成员只按其本轮最终提交的行动判定一次。被硬控而无法行动时视为“停工”，不算服从也不算违令，不进入本轮停炉人数分母。

炉令生成应满足以下约束：

- 同一成员不会连续两轮收到相同炉令。
- 当前 MP 不足以释放任何技能的成员不会收到重锻令。
- 无可用道具不影响固炉令，因为主动防御永远合法。
- 自动战斗与手动战斗读取完全相同的炉令结果。

### 4.3 核心资源二：炉温与鞭痕

炉温是全队共享值，范围 `0–100`，开场为 `40`。

| 结果 | 炉温变化 | 个人结果 |
| --- | ---: | --- |
| 服从自己的炉令 | `+8` | 清除自身 1 层鞭痕；该行动正常生效 |
| 故意违令 | `-12` | 获得 1 层鞭痕；该行动仍正常生效 |
| 被控制而停工 | `0` | 不增减鞭痕 |
| 瓦尔克完成一次正常攻击行动 | `+10` | 无 |
| 集体停炉成功 | 额外 `-15` | 产生罢工破绽 |

鞭痕最多 4 层。违令者在本轮炉令结算时受到最大生命 `2% × 结算后鞭痕层数` 的机制伤害。该伤害不暴击、不受防御与元素抗性影响，但可以被生命护盾吸收。

炉温区间：

| 炉温 | 状态 | 瓦尔克变化 |
| ---: | --- | --- |
| `0–29` | 冷炉 | 造成最终伤害 `-15%`，受到最终伤害 `+10%` |
| `30–59` | 常温 | 无额外修正 |
| `60–84` | 赤热 | 火属性技能伤害 `+20%`，炉令鞭痕伤害仍不提高 |
| `85–99` | 白热 | 火属性技能伤害 `+35%`，下一次炉令面板标为高危 |
| `100` | 熔炉过载 | 立即进入“封炉清算”预警，不在玩家行动中直接结算伤害 |

### 4.4 集体停炉与孤立违令

每次炉令覆盖一整轮成员行动。有效行动成员数为 `N`，集体停炉门槛为 `ceil(N / 2)`：

| 有效成员 | 停炉所需违令人数 |
| ---: | ---: |
| 1 | 1 |
| 2 | 1 |
| 3 | 2 |
| 4 | 2 |

炉令轮结束后统一结算：

- 违令人数达到门槛：触发**集体停炉**。炉温额外降低 `15`，瓦尔克下一次工序技被替换为低威力普通攻击，并获得“罢工破绽”1轮，承受最终伤害 `+25%`。
- 违令人数未达到门槛但大于 0：触发**孤立违令**。违令者额外受到最大生命 `6%` 的机制伤害，瓦尔克不产生破绽。
- 无人违令：触发**满额开炉**。瓦尔克恢复最大生命 `3%`，但每场最多触发两次，避免高治疗造成无限拖延。

集体停炉在连续两次炉令中只能取消一次工序技。若队伍连续成功停炉，第二次仍会降温并产生破绽，但瓦尔克下一次行动不再被替换，防止稳定半数违令把 Boss 永久锁死。

### 4.5 Boss 行动循环

瓦尔克采用“派工 → 检查 → 工序”三槽循环：

| 槽位 | 技能 | 效果 |
| ---: | --- | --- |
| 1 | 监工派令 | 不造成伤害；向每名存活成员发放个人炉令，并显示本轮停炉门槛。 |
| 2 | 赤铁抽检 | 攻击鞭痕最高的成员；每层鞭痕使本次最终伤害 `+12%`。若目标服从了上一轮炉令，则改为攻击当前最高仇恨成员。 |
| 3 | 炉场工序 | 按当前炉温使用对应技能；随后回到槽位 1。若上轮集体停炉可取消工序，则改为普通攻击。 |

炉场工序按炉温选择：

| 炉温 | 工序技能 |
| ---: | --- |
| `0–29` | **冷砧回火**：单体中等物理伤害；瓦尔克自身获得 1 回合双防 `+15%`。 |
| `30–59` | **赤铁横锻**：全体中等物理伤害，给最高仇恨成员附加 1 层破甲。 |
| `60–84` | **炉渣喷流**：全体火属性魔法伤害，附加 2 回合灼烧。 |
| `85–99` | **白热裁决**：攻击鞭痕最高者，并对其余成员造成 `55%` 溅射伤害。 |
| `100` | **封炉清算**：先预警一轮；若期间集体停炉成功则完全取消，否则造成全体高额火属性伤害，将所有鞭痕各追加 1 层，炉温重置为 `55`。 |

### 4.6 三阶段变化

#### 第一阶段：试工（100%–66%）

- 使用标准三槽循环。
- 每次炉令只处理服从、违令、停炉和鞭痕。
- 面板明确告诉玩家哪些成员适合承担本轮违令。

教学目标：让队伍理解“个人服从恢复”和“集体违令降温”不能只选一边。

#### 第二阶段：强制加班（65%–31%）

- 瓦尔克每次监工派令额外指定 1 名“领班”。
- 领班若违令，本轮停炉计数额外 `+1`，但其鞭痕机制伤害提高 `50%`。
- 领班若服从，可额外清除 1 层鞭痕，但炉温额外 `+5`。
- 赤铁抽检优先检查领班，其次才检查鞭痕最高者。

领班让同一套炉令产生轮换职责：血量健康时可以用一次高风险违令帮助队伍达标，状态差时则服从并让其他成员凑够人数。

#### 第三阶段：总罢工（30%–0%）

进入阶段时触发一次专属转场：瓦尔克焊死炉门并下达“禁攻令”。

- 所有存活成员本轮炉令均为**固炉令**。
- 队伍需要所有有效成员都违令，才能触发一次“总罢工”。
- 总罢工成功：瓦尔克永久失去炉温增伤，双防降低 `20%`，清空全队鞭痕；之后恢复标准炉令循环，但炉温上限降为 `80`。
- 总罢工失败：服从者正常清除鞭痕，违令者按孤立违令结算；两轮后再次出现禁攻令，直至成功或战斗结束。

总罢工不是要求某一职业带特定技能，而是要求全队在明确的高风险轮次共同选择攻击或主动技能。它形成与前两阶段不同的终局目标，也保留低血量队伍先服从恢复、下一轮再尝试的选择。

### 4.7 面板与预警

战斗面板必须始终显示：

```text
【熔炉监工·瓦尔克】HP 61%
炉温 72/100｜赤热｜火属性技能伤害+20%
本轮炉令：4名有效成员，至少2人违令可触发集体停炉
玩家甲：轻锤令｜鞭痕0（适合违令）
玩家乙：重锻令｜鞭痕3（建议服从）
玩家丙：固炉令｜鞭痕1｜领班
玩家丁：轻锤令｜鞭痕2
下一工序：炉渣喷流
```

关键预警文案：

- 发放炉令：`瓦尔克敲响监工钟：本轮至少 2 人违令才能停炉。`
- 达到停炉门槛：`违令者彼此响应，炉场传动轴开始停转；本轮已满足集体停炉条件。`
- 孤立违令：`没有足够同伴响应，违令者被监工单独拖到白热铁砧前。`
- 炉温进入白热：`炉温升至 85，下一次炉场工序将执行白热裁决。`
- 封炉清算：`熔炉已经过载。下一轮若不能集体停炉，瓦尔克将发动封炉清算。`
- 总罢工：`瓦尔克下令全员固炉。所有人必须共同违令，才能彻底砸毁监工炉门。`

## 5. 自动战斗规则

这两场战斗不能沿用普通 Boss 的“技能就绪即释放”。自动战斗必须读取与手动面板相同的状态，否则自动玩家会稳定破坏队伍机制。

### 5.1 格鲁恩

1. 无地脉预震时，压力 `<60` 正常输出。
2. 无地脉预震且压力 `60–84` 时，保留可用爆发技能，但不主动把压力推到 `85+`，除非预计本次行动可击杀 Boss。
3. 地脉预震后，根据尚未提交行动的人数计算最大可泄压值。
4. 仅安排足够成员防御或使用辅助行动，把预测压力降至 `29` 以下；其余成员继续输出。
5. 承重点成员优先承担防御，因为其额外泄压 `8` 点。
6. 压力已经无法在本轮降到 `29` 以下时，改以存活为目标：低血量成员防御，其余成员尝试击杀或把压力控制在 `84` 以下。

### 5.2 瓦尔克

1. 每轮先确定停炉门槛，再一次性分配“服从组”和“违令组”，不能让每名自动玩家独立随机决定。
2. 违令优先级：低鞭痕、高生命、有护盾、领班且能承受额外伤害者。
3. 服从优先级：鞭痕 3–4 层、生命低于 40%、无保命状态者。
4. 炉温 `85+` 或封炉清算预警时，必须优先凑足停炉门槛。
5. 炉温 `<30` 且无人处于高鞭痕时，可以全员服从一轮恢复状态，但不得连续两次全员服从。
6. 总罢工轮若预计所有有效成员都能行动，则全员违令；若有成员被硬控，不在有效人数中。

### 6.1 保留

- 两只 Boss 的名称、等级、地图区域、刷新方式和首杀成就编号。
- 现有普通/强大/梦幻随机 Boss 词条框架。

- 格鲁恩的土系山体主题、瓦尔克的火炉监工主题。

### 6.2 删除或替换

- 删除六个战斗部位的生成、目标展示、行动、清理与自动选中。
- 删除 `0.70^存活部位数` 本体承伤公式。
- 删除部位受伤向本体传伤以及同次 AOE 最大候选去重。
- 删除格鲁恩的角鸣、重臂、永固之铠击破反噬。

### 6.3 不在本次顺带修改

- 哥布林国王、死灵法师·乌兹、三首蛇母的任何技能、数值或遭遇结构。

## 8. 实装拆分建议

建议按以下顺序实施，避免新旧机制半并存：

1. 先建立两只 Boss 的纯函数状态模型，覆盖压力、炉温、炉令、停炉门槛和阶段转换。
2. 将格鲁恩和瓦尔克从区域部位生成名单中移除，但暂时保留旧配置文件，直到迁移测试完成。
3. 接入玩家行动分类，确保普通攻击、主动技能、纯辅助、道具、援助、异械充能、防御和硬控跳过均有唯一判定。
4. 接入 Boss 新行动循环与阶段转场。
5. 接入战斗面板、鉴识、日志和自动战斗决策。
6. 重写两只 Boss 的专属随机效果。
7. 删除无引用的旧部位模板、状态键和测试；数据库已有临时部位模板不需要物理删除，但必须不再生成，也不得进入地图池和奖励。

## 9. 验收清单

### 9.1 格鲁恩

1. 战斗中只存在一个敌方目标，不生成三个部位。
2. 每名成员每次实际行动最多改变一次压力，多段、追击、DOT、反伤不重复计数。
3. 压力区间实时改变双方最终伤害，跨区间后本次后续行动立即读取新值。
4. 压力到 100 在玩家行动后立即山崩，不等待 Boss 回合。
5. 地脉预震保证至少一轮玩家响应时间。
6. 压力 `0–29` 时结算山心崩震必须转为逆脉卸力和地层失稳。
7. 承重点的攻击加压和防御泄压均只对该成员生效。
8. 单人、双人、三人、四人队都能用现有行动完成泄压。

### 9.2 瓦尔克

1. 每名有效成员每轮只有一条炉令，且不会连续收到相同炉令。
2. 所有职业始终可以完成轻锤、重锻和固炉三类行动。
3. 服从、违令、停工的判定互斥，行动本身照常生效。
4. 停炉门槛按有效行动人数计算，硬控成员不进入分母。
5. 达标违令触发集体停炉；未达标违令触发孤立惩戒；零违令触发满额开炉。
6. 鞭痕伤害按结算后层数计算，服从能准确清除 1 层。
7. 封炉清算有完整一轮可反制窗口，成功停炉必须取消清算。
8. 总罢工成功后清空鞭痕、降低双防并把炉温上限固定为 80。

### 9.3 共通

1. 自动战斗能完成两场机制，不会无脑攻击导致稳定团灭。
2. 战斗面板在未高鉴识时也显示必须知道的压力、炉令、倒计时和停炉门槛；高鉴识只额外公开具体倍率和数值。
3. 胜利、战败、逃跑、和平结束和异常会话清理均不残留新状态。
4. 掉落、成就、悬赏和图纸只按本体结算一次。
5. 普通、强大、梦幻难度分别完成 1–4 人队模拟，目标战斗长度为普通打造四人队约 7–10 个 Boss 行动。
