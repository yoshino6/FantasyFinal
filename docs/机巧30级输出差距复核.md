# 机巧 · 30级输出差距复核

日期：2026-09-06。范围：复核当前设计文档的基础攻击数值，不修改游戏代码、数据库或已保存的成长表。最新确认：已在设计文档中取消人偶专属系数，人物与人偶共用对应战斗公式。成长预算尚未重算；本页保留旧折扣对照作为问题记录。

## 1. 结论

此前含0.60折扣的设计样例，确实只有标准白装角色约45%～48%的基础攻击伤害。现已取消该折扣，伤害、治疗、护盾、持续伤害及对应被动按人物同类规则计算。同一个660物攻样例的基础攻击比例恢复到约75%～80%；剩余差距来自面板与非线性攻防公式，成长预算仍待校准。V3权重、守恒测试通过，不代表输出目标已经达成。

## 2. 同口径参照

- 玩家：Lv.30，初始六维总100、每级成长总10且均分；此时每项六维65。普通长剑、品质100、采用名义主词条；不含随机打造浮动、材料附加、精炼、神器、职业技能、被动和药剂。
- 玩家裸物攻：`8+4.3×65=287.5`；武器物攻：`287.5×1.2³=496.8`；装备后物攻：`floor(287.5+496.8)=784`。品质100系数为1。
- 人偶：当前V3公开测算种子的“激进＋持续锋刃”样例，30级物攻660，约为上述玩家的84.18%。这是一个实例样例，不是所有人偶的均值或保底。
- 两方攻击同一目标，基础攻击倍率相同。暂不计命中、暴击和伤害随机浮动时，源码直击公式为 `floor(攻击²/(攻击+max(1,防御)))`。旧设计曾对人偶再乘0.60并向下取整；当前设计已取消，以下折扣列仅用于历史对照。

## 3. 旧方案为什么偏低

1. 旧曲线把武器预算按 `(等级-1)/49` 逐步补齐，30级只有约59.18%的该级武器预算；到50级才完整。与“同等级白装玩家”的参照不同。
2. 成长偏向被通用份额、人格与材料混合分散。激进＋锋刃在初段普通升级的物攻单点抽中率约8.66%，虽然高于其他多项属性，但并不是高度集中的输出成长。是否足够要看期望攻击与实际伤害，不能只看概率排名。
3. 面板不足之后，另乘0.60，又将每次结果削去40%。原方案“伙伴仅使主人综合收益增加10%～25%”的目标，与用户要求的接近白装角色的独立战斗单位不一致，后续不应同时强求这两个目标。

## 4. 已确定规则与剩余校准建议

- **已确定**：取消所有人偶身份折扣，伤害、治疗、护盾、持续伤害、被动和属性对抗复用人物对应公式。技能自身的系数和统一状态规则保留；治疗与护盾的技能预算另做收益测试，不再用单位类型系数修补。
- 主攻培养以同级白装角色为参照，分别核算10/20/30/40/50级，不再只在50级补齐攻击预算。30级标准物理主攻路线的群体期望可先设在物攻800～850附近；具体值需用多实例样本验证，不能保证每个随机实例都落在这个窄区间。
- 继续保留15项属性非零抽中概率、人格差异、材料倾向、每级随机分配和十级总预算四倍；提高主攻预算或主攻概率时，明确对应方向与总预算变化，不能把所有属性统一翻倍。
- 物理与法系输出分别校准，避免只修锋刃而漏掉灵辉；同时检查主攻成长是否间接抬高治疗，守御预算是否压过普通盾牌参照。不同人物实际六维、武器词条和技能构筑会影响结论，标准参照必须与真实构筑分开报告。
- 下一轮至少统计各等级多个人偶的主攻均值、分位数、同目标期望普攻与完整技能循环。随机点数守恒不等于战斗强度相等。
