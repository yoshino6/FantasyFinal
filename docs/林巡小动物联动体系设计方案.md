# 林巡小动物联动体系设计方案

> 定位调整：林巡从“标记/控场游侠”改为“与林伴共生的巡林者”。整套主动技能、专属资源、固有被动与传承被动都围绕三只林伴展开；林伴是战场实体，继承林巡属性，可能被攻击离场，离场后其提供的加成与触发效果全部消失。

---

## 1. 设计目标

1. 让林巡拥有区别于唤灵师的召唤体验：林伴**不独立行动**，而是通过“在场光环 + 受击响应 + 回合结束效果”参与战斗。
2. 三只林伴各有明确职责，玩家需要根据敌人类型选择携带哪一只猎伴。
3. 林伴是**可被击杀的临时优势**，不是常驻面板：林伴没有持续回合限制，但常规单体攻击不会点名林伴，BOSS 仇恨点名与群体攻击会打到林伴；一旦倒地离场，就进入 3～5 回合冷却，且所有相关效果立即消失，形成“放着很强、但要规避 AOE”的战术深度。
4. 数值与现有二转职业同档，避免单只林伴把林巡抬成超模。

---

## 2. 林伴总览

| 林伴 | 新名字 | 原型 | 定位 | 在场核心效果 |
| --- | --- | --- | --- | --- |
| 雾枭 | 夜巡者·雾枭 | 猫头鹰 | 侦察/命中/感知 | 林巡命中 +40%、感知 +30%，每回合标记目标弱点 |
| 栗影 | 松梢客·栗影 | 松鼠 | 迅捷/干扰 | 林巡速度 +25%、闪避 +15%，闪避成功时减速目标 |
| 青鳞 | 藤下客·青鳞 | 蛇 | 压制/持续削弱 | 猎物中毒加深，林巡对带标记/中毒目标伤害 +12% |

> 名字说明：三只林伴不再使用“猫头鹰、松鼠、蛇”的泛称，分别以“雾枭、栗影、青鳞”作为正式名，导师与技能文案统一使用新名。

## 3. 林伴通用机制

### 3.1 召唤与在场

- 每只林伴由对应技能召唤，召唤后**持续在场，没有回合限制**，直到倒地离场、被替换离场或林巡倒下。
- 对同一只林伴重复施放对应技能，不会重复召唤，而是为在场林伴**恢复全部生命**（等同重新安置），并结算该技能本身的伤害/状态效果。
- 场上同时可存在 **3 只林伴**：雾枭、栗影、青鳞各占一席，互不挤占，三只可以同时在场。
- 同一只林伴不会重复召唤；重复施放对应技能时，为在场林伴**恢复全部生命**，并正常结算该技能本身的伤害/状态效果。
- 林伴之间不互相替换，不存在旧猎伴被新猎伴挤占离场的情况。
- 林巡倒下造成的离场**不进入冷却**；只有林伴生命归零倒地才触发冷却。
- 林伴不占用灵位、不进入独立行动轮；林巡倒下时林伴一并离场。

### 3.2 属性继承

林伴的属性由林巡当前属性按固定系数继承，战斗开始时（召唤时）快照一次：

| 属性 | 雾枭 | 栗影 | 青鳞 |
| --- | --- | --- | --- |
| 生命 | 45% | 35% | 55% |
| 物攻 | 25% | 45% | 60% |
| 魔攻 | 20% | 20% | 35% |
| 物防 | 35% | 25% | 55% |
| 魔防 | 35% | 25% | 55% |
| 命中 | 110% | 85% | 90% |
| 闪避 | 100% | 120% | 70% |
| 速度 | 95% | 140% | 80% |
| 暴击 | 70% | 60% | 65% |

固有被动会额外提高林伴继承属性（见第 5 节）。

### 3.3 受击与离场

- 林伴默认**不进入常规单体攻击的目标池**：普通敌人与常规单体技能不会点名林伴，林伴也不会替林巡挡刀。
- 是否被单体攻击选中，要看 **BOSS 仇恨**：BOSS 使用“锁定 / 点名 / 仇恨转移”类技能时，可将在场林伴作为独立个体选中；仇恨目标在场时，此类技能优先打仇恨目标。
- 群体攻击命中全部在场林伴；**AOE 是林伴最主要的离场来源**。
- 林伴受到的伤害按自身继承后的防御、闪避、暴抗结算；生命归零立即离场。
- 林伴倒地离场后进入**倒地冷却**：雾枭 4 回合、栗影 3 回合、青鳞 5 回合（雾枭兼顾 3～5 回合区间，青鳞因继承属性最高而冷却最长）。
- 冷却期间，对应召唤技能不可用，技能按钮显示“林伴恢复中 X 回合”；每回合结束时冷却 -1，归零后林巡才能再次召唤该林伴。
- 林伴离场后：
  - 对应在场光环立即消失；
  - 未结算的回合结束效果不再触发；
  - 已施加给敌人的专属印记/减速/毒层**保留**，但不再产生新的联动。

### 3.4 专属资源：侦察

- 林巡施放林伴技能、林伴造成命中/状态效果时积攒「侦察」。
- 大招「林野同契」消耗 50 侦察；后续可扩展更高消耗的强化档位。

## 4. 主动技能重做

以下四项全部替换现有林巡技能，按钮标签与技能列表同步更新。

### 4.1 雾枭·巡林（替换猎手印记）

| 字段 | 数值 |
| --- | --- |
| 类别/距离 | 物理 / 远程 / 单体 |
| 蓝耗 / 冷却 | 120 / 3 |
| 威力 | 105% |
| 效果 | 造成 105% 物理伤害，施加「雾标」3 回合，并召唤雾枭（无回合限制） |

雾枭在场时：

- 林巡命中属性 **+40%**、感知属性 **+30%**（感知按现有派生规则参与命中与先手相关结算）；
- 每回合结束时，雾枭对当前主目标刷新「雾标」1 回合：全队对该目标命中 +12%；
- 林巡远程技能直击带「雾标」的目标时，命中率修正 +10%。

> 原设想“提升自身 100% 命中感知”过高，方案先给 40% 命中 + 30% 感知；后续三转成长可将雾枭光环提升至 50%～60%，保持与其他二转同档。

### 4.2 栗影·穿林（替换连发缚网）

| 字段 | 数值 |
| --- | --- |
| 类别/距离 | 物理 / 远程 / 单体 |
| 蓝耗 / 冷却 | 190 / 3 |
| 威力 | 80% |
| 效果 | 造成 80% 物理伤害，以 60% 基础概率束缚 1 回合（首领降级为 30% 减速），并召唤栗影（无回合限制） |

栗影在场时：

- 林巡速度 **+25%**、闪避 **+15%**；
- 每回合林巡首次成功闪避后，栗影立刻对攻击者施加减速 15%（1 回合）；
- 束缚类技能对 Boss 仍按现有规则降级，但减速效果由栗影追加。

### 4.3 青鳞·缠猎（替换侧翼狙击）

| 字段 | 数值 |
| --- | --- |
| 类别/距离 | 物理 / 远程 / 单体 |
| 蓝耗 / 冷却 | 110 / 2 |
| 威力 | 130% |
| 效果 | 造成 130% 物理伤害，施加 1 层青鳞毒（普通目标每层每回合损失 3% 最大生命，最多 3 层；首领每层 1%，最多 2 层），并召唤青鳞（无回合限制） |

青鳞在场时：

- 林巡对带追猎、雾标、束缚或中毒的目标，技能直击伤害 **+12%**；
- 每回合结束时，青鳞对生命比例最低的带毒目标再结算一层青鳞毒；
- 青鳞毒不视为普通毒，不与其他剧毒叠加，也不受蚀毒师被动影响。

### 4.4 林野同契（替换鹰眼领域，大招）

| 字段 | 数值 |
| --- | --- |
| 类别/距离 | 辅助 / 自身 / 全体 |
| 蓝耗 / 冷却 | 300 / 4 |
| 消耗 | 50 侦察 |
| 效果 | 三只林伴分别回应一次；回应后在场林伴恢复 30% 最大生命 |

- 雾枭回应：全队命中 +20%、速度 +15%（2 回合），并对全体敌人施加 1 回合雾标；
- 栗影回应：全队闪避 +12%、速度 +15%（2 回合），并对全体敌人施加减速 15%（1 回合）；
- 青鳞回应：对全体敌人施加 1 层青鳞毒，并施加「暴露」（易伤）15%（1 回合）。
- 若某只林伴已倒地且处于冷却中，大招会**临时唤醒**它回应一次，回应结束后立即重新进入倒地冷却；
- 若三只林伴都在场，本次回应效果提升 50%。

> 「暴露」即现有「易伤」状态：目标受到的直击伤害提高 15%（1 回合），与灵契·弯月猫施加的易伤同一套结算；三只林伴都在场时，林野同契效果提升 50%，暴露变为 22.5%（按现有数值规则向下取整）。三只林伴平时可同时在场，收益集中在“林野同契”这一波；林伴倒地后 3～5 回合内无法回归，玩家需要权衡召唤节奏与 AOE 规避。

## 5. 固有被动与传承被动

### 5.1 固有被动「林语者」

保留基础属性与修正，同时加入林伴强化：

- 命中 +10%、速度 +10%、闪避 +5%、命中率修正 +12%；
- 林伴继承属性额外 +20%；
- 林伴在场时，林巡受到的技能直击伤害 -6%（林伴替巡林者分担风险）。

### 5.2 传承被动「林道共鸣」

改为与林伴联动：

- **本职**：每回合首次有林伴在场并成功造成标记、束缚、减速或中毒时，林巡与生命最低的队友获得 1 回合 6% 闪避与速度加成；随后该林伴对目标留下「林迹」2 回合，另一名不同队友命中林迹目标时减速 8%（1 回合）并消耗林迹。
- **旁修**：每回合首次林伴成功造成状态时，林巡自身获得 1 回合 4% 闪避与速度加成。

## 6. 数值对齐与风险控制

| 风险 | 控制手段 |
| --- | --- |
| 光环数值过强 | 命中 40%、速度 25% 均绑定“林伴在场”，倒地离场立即消失并进入 3～5 回合冷却；三只林伴同时在场时三光环叠加，作为林巡的构筑上限 |
| 继承属性放大 | 继承系数控制在 25%～60%；常规单体不点名，但 AOE 与 BOSS 点名会清场，需要靠召唤节奏与减伤保护 |
| 三光环叠满 | 三只林伴可同时在场叠满三光环；倒地冷却与 AOE 清场让叠满状态需要持续维护，不是无代价常驻 |
| 与唤灵师重叠 | 林伴不独立行动、不占灵位，走“领域/响应”路线而非独立出手 |
| 毒系抢蚀毒师定位 | 青鳞毒独立命名、独立结算，不触发蚀毒师被动，偏“压制”而非爆发 |

## 7. 战斗接线建议

1. 新建 `combat_warden_companions` 表（或复用 `combat_spirits` 增加 `kind='warden'`），字段：`owner_character_id`、`companion_code`、`name`、`current_hp`、`hp_max`、`stats_json`；另记录各林伴的 `cooldown_remaining`。
2. 复用现有灵兽受击逻辑，但关闭常规单体点名：常规单体攻击不选林伴，仅 BOSS 仇恨点名与群体攻击命中林伴；生命归零删除并播报“林伴离场”，同时写入倒地冷却。
3. 在场光环在每回合开始统一刷新；效果读取 `combat_warden_companions` 是否存在对应林伴。
4. 召唤技能在对应林伴冷却中不可用；每回合结束冷却 -1。技能种子、平衡配置、按钮文案、导师试炼、NPC 切磋与资源消耗同步更新。
5. 林伴离场后清理其专属状态源标记，防止“已离场仍触发联动”。
