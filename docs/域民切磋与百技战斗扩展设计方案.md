## 1. 目标与边界

本方案新增约 104 个可由域民传授的主动/被动技能，并让每一名地图域民都拥有每日一次的【切磋】入口。切磋使用正式战斗规则，但它是友好演练：不产出经验、掉落、铜币、好感、任务进度或怪物击杀记录；结束时只可能获得一次“技能发现”。发现的技能仍需在技能列表中消耗 SP 学习，沿用现有的“领悟不等于立即掌握”规则。

设计目标：

- 让元素、状态、回合、法力、驱散、反制、队伍协同、天气与信息战彼此能组合，而非只叠伤害。
- 保留技能选择的代价：蓝耗、冷却、站位、触发条件、被动槽位、负面副作用至少占其一。
- 地图居民的职业、地区、天气和世界线进度会影响其战斗风格与可传授技能，避免“所有 NPC 只是同一只训练假人”。
- 以当前玩家六维和 `calculateDerivedStats` 为唯一属性口径；域民不再维护另一套脱离玩家的攻防公式。
- 切磋不会变成刷经验、刷掉落、刷药、刷战斗消耗或无限叠加状态的入口。

本设计中的“全体”指敌我同阵营的所有存活单位；“一次攻击”均指一次直接伤害判定，不包括持续伤害、反击、追击造成的二次触发，除非条目明确写出。

## 2. 现有基础与本方案的接入原则

现有项目已有 `skill_definitions`、`effect_definitions`、`skill_effects`、`player_skill_discoveries` 与 `player_skills`；怪物战斗胜利后也已有按规则写入“技能发现”的流程。域民切磋应复用这条发现与学习链路，不新造第二种技能背包。

战斗状态现以 `combat_status_effects` 保存，玩家六维先叠加成长、装备、进化等来源，再由 `calculateDerivedStats` 派生面板。切磋域民将复用该派生函数和现有 PvE 战斗结算；只有“战斗模式为切磋”时跳过奖励、体力、掉落、赏金、怪物死亡与地图刷怪变更。

现有 `map_npcs` 区分 `npc` 与 `building`。本方案将“可对话的服务建筑”按其实际域民人格映射为切磋对象，例如 `/切磋 blacksmith` 实际是和漠北切磋；界门、住宅、纯建筑和特殊地图物件不产生切磋按钮。所有 `interaction_kind='npc'` 的常驻/动态域民，以及已有可交互人格的服务建筑，都覆盖在内。

## 3. 通用战斗规则与平衡护栏

### 3.1 伤害、增益与状态的结算顺序

统一为以下顺序，新增技能不得绕开顺序直接写伤害：

```text
选目标 → 目标改写（混乱/魅惑/嘲讽） → 命中 → 技能本体伤害
→ 元素附伤/条件增伤 → 护盾与减伤/伤害转移 → 受击反应
→ on_hit 状态 → 追击/额外行动 → 回合开始与回合结束结算
```

- 同类“最终伤害提高”先加算，再与其他乘区相乘；单次直接伤害的非暴击增伤总和上限为 +150%。
- 元素附伤不能暴击、不能吸血、不能再次触发 `on_hit`，也不能被“下一次技能全体化”重复扩散。
- 同名状态刷新持续回合并取较高数值；可叠层状态明确写层数上限。不同来源的减伤合计最多 80%，直接伤害减免最多 90%。
- 一次行动至多获得一次额外行动；额外行动不能再触发额外行动、全队追击、全体扩散和支援回声；不额外推进冷却、再生和持续伤害计时。
- 一个单位每回合至多触发一次追击，协同追击只造成 40% 普攻直击伤害，不触发技能、暴击、吸血、装备特效或状态。

### 3.2 新控制状态的精确定义

| 状态 | 规则 | 平衡限制 |
| --- | --- | --- |
| 混乱 | 持续 3 回合。发动攻击时有 50% 概率改为攻击自己或随机友方；辅助技能仍按原目标施放。 | 与魅惑互斥；首领仅持续 1 回合。 |
| 沉睡 | 持续 3 回合，无法行动；首次受到直接伤害后解除。 | 对首领最多 1 回合；持续伤害不唤醒。 |
| 目盲 | 持续 3 回合，最终命中率降低 50%。 | 仍受最低命中率保护，不能把命中降为负数。 |
| 石化 | 持续 3 回合，无法行动；首次受到直接伤害时额外承受最大生命 4% 的伤害后解除。 | 对首领额外伤害改为 1%，且不低于 1、不高于施法者攻击的 150%。 |
| 魅惑 | 持续 2 回合。攻击和指定伤害技能会优先攻击友方；无友方时攻击自身。 | 与混乱互斥；首领免疫。 |
| 恐惧 | 跳过下一次自身行动，然后立即移除。 | 不可叠层；首领只承受 20% 速度降低 1 回合。 |
| 沉默 | 持续 3 回合，不能使用主动技能，仍可普通攻击、使用道具和被动触发。 | 不影响正在吟唱的最终结算，改为打断后续吟唱。 |
| 梦魇 | 持续 2 回合，对手无法从战斗信息、鉴识与日志中看到该单位的精确 HP、MP、状态和技能冷却，只显示“信息被雾遮蔽”。 | 不隐去自身；不改变仇恨或目标合法性。 |

硬控（沉睡、石化、魅惑、恐惧）同时最多存在一种。新硬控命中时会替换旧硬控，而不会无限延长。对首领的控制成功率在现有破韧/韧性对抗后再乘 40%，沉睡、石化最多保留 1 回合，魅惑免疫。

### 3.3 被动槽与获取约束

- 50 级前的域民技能只使用【基础】【下位】【中位】三档；本方案不向玩家投放上位或超位技能。104 项中建议基础 28 项、下位 48 项、中位 28 项，中位只作为地区后段、导师或高条件组合技，不用稀有度替代数值代价。
- 所有“域民被动”仍占用现有被动链接槽；未链接不生效。
- 同一“流派标签”的被动最多链接一个，例如不能同时链接两个【血线】被动或两个【法力过载】被动。
- 高风险被动会明确写出代价，例如全技能蓝耗上升、护盾上限降低、无法享受某类增益等；不会只给纯正收益。
- 发现概率只让玩家“看见技能”，学习仍消耗 SP。基础/下位/中位的 `learn_cost` 分别为 2 / 3 / 5 SP，避免一天内获得很多发现就立刻形成完整毕业配置。

## 5. 域民构筑与本局领悟范围

> 已按最新要求收紧：下面的流派映射只用来生成域民所掌握的技能，绝不是整套可领悟列表。每局只携带少量主动与链接被动；领悟只能从开战时实际携带的清单抽取。

- 15 级以下：最多 2 个主动、1 个被动。
- 15–29 级：最多 3 个主动、1 个被动。
- 30 级及以上：最多 4 个主动、2 个不同流派的被动。
- 开战后保存主动、被动与属性快照，途中等级、进度或配置变化不会扩大本局领悟范围。
- 结算只取快照中的主动及被动并集，再排除已掌握、已发现或尚未满足阶位等级条件的技能；不得回退到整个流派库。
- 携带但因本局没有合适目标而未施放的技能仍属于本局构筑，可参与领悟；不是只从战斗日志里已经施放过的招式抽取。

### 5.1 映射原则

每名域民根据自身身份与中文职业描述，从相应流派生成稳定的小型构筑。流派范围不是领悟池，也不会直接展示给玩家。主动按携带序列使用；冷却、MP 不足或单挑中缺少支援对象时改为普攻。链接被动始终参与本场结算，未使用过的携带技能仍然属于本局可领悟范围。

| 树守、巡哨、守望者、守祈者 | 承伤与控制 | 信息战 | F、B、H |

## 6. 【切磋】完整流程

```text
地图/域民资料 → 点击 [切磋] → 校验位置、开放进度、当日次数
→ 写入当日锁定记录 → 按域民档案生成临时对手 → 进入切磋战斗

```

### 6.1 入口与用户体验

- `/域民详情 <代号>` 的“今日互动”下新增 `切磋 0/1`，并增加蓝色 `[切磋]` 按钮。
- NPC 交互面板和动态站点前台也展示同一按钮；按钮命令为 `/切磋 <npcCode>`，路由参数使用 schema 校验。
- 首版为单人切磋。队伍战会让每日归属、临时对手属性、发现归属和无奖励结算变得含混，留作后续扩展。
- 切磋不允许自动战斗、消耗品、逃跑道具或异械充能消耗；玩家可以正常使用已学主动技能和链接被动。
- 胜、负、主动离开和超时都消耗该域民当日一次切磋资格，防止反复撤退刷最优随机状态。
- 结算后恢复切磋前的 HP、MP，清除本场临时异常与召唤物；体力、物品和战斗外状态不在切磋中扣除。临时对手清空生命和构筑数据，保留不可见的会话审计引用。这样切磋的外部产出严格只剩“可能发现技能”。

### 6.2 技能发现概率

每次切磋只有一次发现掷骰，发生在战斗结束时；已发现或已学习的技能不再占据候选位。

```text
发现率 = 基础 5%
       + 胜利 3%
       + 以有效克制元素命中域民 2%
       + 好感等级加成（0% / 1% / 2% / 3%）
       + 鉴识或全知加成最多 2%
上限 = 15%
```

- 战败、离开和超时不享受“胜利 +3%”，但仍可保留基础概率，鼓励尝试而非逼玩家只找弱 NPC。
- 相对推荐等级低 5 级以上时，发现率 -2%；高 8 级以上时不额外增加概率。
- 每个域民每天只进行一次发现判定；成功后仅在本局携带快照中排除已学/已发现及等级未开放项，再等概率抽取一项。无候选则无新发现，不从外部流派补位。
- 好感加成沿用 50 / 200 / 500 分门槛，分别 +1% / +2% / +3%；识珠或当前全知有效等级每级 +0.5%，封顶 +2%。
- 不引入跨 NPC 的额外日上限。平衡主要由 5–15% 的单次机会、地区开放、SP 学习成本和被动槽位控制；这保证“每名 NPC 每日一次”字面规则成立。

## 7. 数据与代码实施方案

### 7.1 实际新增数据

| 数据对象 | 关键字段 | 用途 |
| --- | --- | --- |
| `npc_spar_profiles` | `npc_code`、`profile_json`、`updated_at` | 最近生成的域民构筑，不参与本局结算抽取。 |
| `player_npc_spar_attempts` | `id`、`character_id`、`npc_code`、`business_date`、`session_id`、`snapshot_json`、`profile_json`、`state`、`discovered_skill_id` | 每日资格、战前资源与实际携带技能快照；每日键和会话键均唯一。 |
| `combat_sessions` 扩展 | `mode`（`pve`/`spar`） | 明确分流无奖励切磋，不靠怪物名称判断。 |

`business_date` 由 `Asia/Shanghai` 的业务日期写入。创建记录使用事务、唯一键和 `INSERT` 冲突处理，不使用“先查今天次数再写入”的非原子流程；因此双击按钮或重复事件不会获得第二场切磋。

### 7.2 临时对手与属性

为最小化改动，首版使用“临时切磋怪物模板 + 带 `npc_sparring` 标记的临时 spawn”接入现有 PvE `combat_sessions`/`combat_targets`。临时 spawn 不出现在地图，不进入正常刷新，也不调用怪物死亡结算。它仅保存本场由域民档案计算出的等级、六维、派生属性和招式。

计算步骤：

1. 取区域推荐等级带、玩家等级与世界线阶段，得出域民本场等级。
2. 按档案分配基础六维与成长六维，获得最终六维。
3. 调用 `calculateDerivedStats` 得出 HP、MP、双攻、双防、命中、闪避、双暴、韧性、破韧与速度。
4. Lv.10 起按一转职业给对应两项六维成长各 +1.2；这一加成先进入六维再派生，不能重复添加。
5. Lv.20 及以下不进化；之后最多计 9 次注入。战士/牧师偏 HP、MP 和双防，每次 +2%；法师/盗贼偏主攻每次 +2.5%，并每次 +1% 暴击和速度。使用玩家现有进化属性映射。
6. 每人生成 6 件虚拟装备，装备等级为人物等级减 0～3，最低 1。Lv.15 前普通；15～29 为普通/优秀/精良；30 起增加稀有。导师为稀有。品质按等级分 30/60/80，副词条数按稀有度为 0/1/2/3。叠加方式复用现有装备函数。
7. Lv.30 起约三分之一一般域民有匹配职业的二转；明确身份和导师按实际职业。二转面板被动通过玩家缓存属性函数仅叠一次，伤害/治疗乘区在战斗时结算。
8. Lv.15 前最多 2 主动 + 1 被动，15～29 最多 3 + 1，30 起最多 4 + 2；两个被动必须不同流派。本局领悟候选严格等于这份携带清单，不等于流派库。

### 7.3 新效果执行器

现有通用效果表适合持续伤害、属性修正、控制、护盾、净化与回蓝；百技中条件复杂的效果应登记为可审计的“规则效果”，而不是继续在战斗服务里按技能代号散落 `if`。

已引入 `combat-rule-registry`：每条规则声明 `code`、触发时点、目标范围、叠层/刷新策略、首领修正、PVP 修正与日志模板。优先实现通用规则：目标改写、下一次技能范围改写、元素附伤、一次额外行动、驱散计数伤害、下一次魔法反射、全队追击、信息隐藏、临时 MP 返还。只有确实独特的职业/首领机制才允许专用处理器。

## 10. 需要确认的三项决定
