# 机巧 · 性格与材料成长 V3

数值复核：已取消人偶专属折扣并统一人物战斗公式；当前660物攻的30级样例约有白装参照75%～80%的基础伤害，成长预算仍待校准。详见[30级输出差距复核](机巧30级输出差距复核.md)。

日期：2026-09-06。状态：设计修订，尚未接入游戏。本文替换主方案中的固定出生面板、手选五方向成长、统一原液和低成本任意改方向规则。技能库、十级必得特殊技能、材料经验、不能穿戴装备及交易绑定规则继续有效。

## 1. 每具人偶长成自己的样子

每一级的成长分配由 **15% 通用基础＋25% 出生性格倾向＋60% 本级实际消耗的培养材料倾向**共同决定。这些百分比是成长分配的组成比例，不是最终伤害加成，也不是“25% 概率性格生效”。

每一级按属性权重随机分配成长点：普通升级抽取 30 次，十级突破抽取 120 次，每次只选中 15 项属性中的一项。每项都有非零概率，但本级可能一次也没有抽中，也可能连续获得多点。同一种锋刃原液连续喂养，也可能这一等级偏物攻、下一等级偏命中或暴击；不是固定面板加一点连续浮动。

性格不会把培养方向锁死：胆小人偶吃锋刃原液仍明显增强输出，激进人偶长期吃坚壳原液也能走防御路线。菜单中的“输出、防御、续航”等按钮变为**推荐选料筛选**，不会凭一次免费点击改变材料的真实效果。

## 2. 成长预算与性格映射

### 2.1 预算基底

保留[逐级属性重算 V2](机巧逐级属性重算V2.md)的五组预算向量：均衡、战锋、灵术、守御、灵巧。它们是内部计算基底，不是玩家、人偶的五维属性，也不再是五条固定升级路线。

记 V2 中到达等级 L、方向 d 的未取整增量为 `D(L,d)`。它用于计算各属性的期望成长和抽取权重，不是本次必得属性。保留原阶段预算及十级权重：普通升级 1 份，十级突破 4 份。V2 五条固定属性表降为预算边界和校验样例，不能直接写入实际人偶面板。

统一的强度目标仍为同级标准玩家配品质 100 的普通武器；V3 用该目标约束总成长预算，不要求每个人偶在 Lv.50 都得到完全相同的生命或双攻。不同构筑按定位有攻防取舍，“预算相当”并不等于实战战力已经相等。

### 2.2 十二核心与人格词条

复用人格方案十二种核心的主、次技能主题，以 `2/3 主主题＋1/3 次主题` 生成核心成长向量。八种主题映射如下，顺序统一为“均衡、战锋、灵术、守御、灵巧”：

| 主题 | 成长向量 |
| --- | --- |
| 战锋 | 0 / 1 / 0 / 0 / 0 |
| 灵术 | 0 / 0 / 1 / 0 / 0 |
| 守御 | 0 / 0 / 0 / 1 / 0 |
| 灵巧 | 0 / 0 / 0 / 0 / 1 |
| 支援 | 0.2 / 0 / 0.4 / 0.4 / 0 |
| 干扰 | 0 / 0 / 0.5 / 0 / 0.5 |
| 持续 | 0.4 / 0.3 / 0.3 / 0 / 0 |
| 应变 | 0.5 / 0 / 0 / 0.25 / 0.25 |

出生的四条兼容词条中，只有“风险取向、守护倾向、战术兴趣”参与成长。表达方式、天气喜好、亲密表达等生活词条不改变战斗属性，避免玩家为了数值放弃喜欢的性格。

- 风险取向：沿人格目录的 1～10 顺序，令 `u=(序号-1)/9`，取 `(1-u)守御＋u战锋`。
- 守护倾向：同样按序号，取 `(1-u)均衡＋u守御`。
- 战术兴趣：锋线/术式/厚甲/修护/身法/封锁/持续/应变分别映射至战锋/灵术/守御/支援/灵巧/干扰/持续/应变；攻辅均衡取战锋与支援各半，守辅均衡取守御与支援各半。
- 有这些词条时，`P = 70%核心向量＋30%有效词条向量的平均值`；没有时 `P=核心向量`。不能把缺失词条当零向量导致总权重缩水。

P 非负且总和为 1，在出生时保存配置版本与计算结果。性格影响属性、技能与行动，但三个系统分别计算：材料不更改已固定的技能对齐方向，也不重抽人格。命名、表情、语录训练和表达反馈不改变 P。

### 2.3 出生属性也有小幅个性差异

保留“出生总预算约为标准无装备 Lv.1 玩家 80%”，取消所有人偶必须拥有同一张初始表。

```text
B = V2 的 Lv.1 中性出生预算表
A0 = 0.80×均衡向量 + 0.20×P
出生属性 i = floor(B[i] × Σd(A0[d] × V2测算脚本weights[d,i]))
```

出生不加入虚拟武器预算，不受制造者的材料价格、点击次数或未认主交易影响。人格先生成，再算初始属性和技能；制造成功即保存全部结果，详情、交易行和认主页面显示同一个实例。20% 性格分配不增加额外点数；按 B 归一化后的本体预算仍为 15 份（取整前）。

## 4. 逐级计算与混合喂养

每种原液的向量为 T(j)，实际划入目标等级 L 的经验为 x(j,L)。本级只能使用凑满所需经验的部分，不按瓶数、市场价格或最后使用的原液决定方向。

```text
E(n) = 200 + 40n + 4n²（当前n级升下一级）
Σj x(j,L) = E(L-1)
M(L) = Σj[x(j,L)×T(j)] / E(L-1)
A(L) = 0.15×均衡 + 0.25×P + 0.60×M(L)
期望增量 G(L,i) = Σd[A(L,d)×D(L,d,i)]
K(i) = 本阶段一个普通升级的V2均衡增量（十级仍取该阶段普通级）
属性权重 w(i) = G(L,i)/K(i)
总预算 S = Σi w(i)
每次抽中属性i的概率 p(i) = w(i)/S
抽取次数 n = 普通级30，十级120
每点预算 v = S/n
次数 c(i) = n次独立有放回抽取中命中属性i的次数
实际增量 Δ(L,i) = c(i)×v×K(i)
面板(L,i) = floor(出生整数属性[i] + Σk=2..L Δ(k,i))
```

A 的各分量非负、总和为 1。所有 G/K 都大于零，因此每项都可被抽中。归一化以处理生命、攻击、暴击等不同量纲，不能把原始生命增量直接当抽取权重而挤占其他属性。

每次升级的总预算严格守恒：`Σi Δ(i)/K(i)=S`；每项的数学期望 `E[Δ(i)]=G(i)`。点数本身只是后台分配单位，30次抽取不会生成玩家技能点，也不是把所有属性直接加30。某项本级至少加到一次的概率为 `1-(1-p(i))^n`，允许加0，不设置每项保底+1。最终显示取整前必须累积小数，避免把多次小增量吞掉。

单具人偶不会保证每项恰好追平普通武器玩家；该目标约束总体预算和长期期望，个体实际面板有随机差异。若未来需要限制极端分配，应另做分布校准，不能未经说明增加封顶重抽而仍宣称期望公式不变。经验投入超出当前级时，仅超出的部分进入下一等级；其材料谱必须一并带入。

例如 Lv.1→2 需 244：按序使用 2 瓶锋刃和 1 瓶坚壳，本级计入锋刃 200、坚壳 44，`M=(200×锋刃谱＋44×坚壳谱)/244`；若选择“培养到Lv.2”，剩余56点是**坚壳谱余额**；若选择连续喂3瓶，则56点继续记入下一等级未满进度，仍为坚壳贡献。两种模式不能同时记余额和进度，不会变成无属性的通用经验。

开瓶余额存为有序分段：来源 item code、配方版本、剩余经验、成长谱快照、原消费流水。已有余额按入账先后使用，再使用本次明确选择的物品；预览提示旧余额对本级的影响。玩家不可免费修改旧余额谱，但可以选择下一批开瓶顺序。相同投入顺序在拆单与批量时结果一致；跨越等级边界时改变顺序可以改变逐级分配，这是可见且可预览的培养选择。

部分进度还应保存本级各谱实际贡献，不仅保存一个总经验数字。材料谱用整数基点、实际贡献用整数经验记账，先累计“经验×基点”再归一，避免拆批浮点误差改变结果。成功升级将该级 M/P/A、抽签序列、各项命中次数、增量原值、配置版本与来源账单一起冻结。

随机种子在制造成功时生成并绑定人偶实例，服务端保密。以实例种子、成长版本、目标等级、抽取序号派生稳定抽签序列；不能把配方、请求ID、时间、点击次数或材料顺序作为重新抽签的种子。未完成本级时不抽取；确认前只展示每项概率、期望增量和材料贡献，完成事务后展示实际结果。换料会改变概率，但不能刷新该等级的随机序列。

重试、重启、改名、重新认主、主人降级再恢复不重新抽签，也不读取更新后的原液模板改写旧属性。不同人偶即使性格与食谱相同，仍因实例种子不同得到不同结果；同一人偶同一级重试返回原结果。

### 4.1 十级突破

十级分配 120 点，普通级分配 30 点；同人格与食谱下总预算为同阶段普通升级的 4 倍，同时保证 1 个特殊技能，普通技能独立按原 30% 判定。点数每次独立有放回抽取，点数分布随性格和材料改变。

**四倍约束针对总成长预算，不再针对每一个属性。** 即使同一种锋刃原液，普通级可能没有抽到物攻，十级可能抽到多次，无法定义其单项“上级的4倍”；不同食谱更不能逐项比较。旧版“每一项都必须是上级的3～5倍”已被这次随机成长规则替换。十级点数更多，按比例看分配通常更稳定，但仍不保证每项都中。

突破预览显示“本阶段四倍成长预算、120次属性分配”、各项抽中概率及期望增量；概率页同时区分“每点抽中率”和“本级至少获得一次的概率”。抽属性不会增加技能抽取次数，材料昂贵不额外奖励特殊技能，也不改变技能稀有度权重。

## 5. 重调、成本与使用边界

取消“支付10%通用经验就任意把过去方向改成另一种”的规则，否则材料选择可以被廉价洗掉。建议重调只选少数已完成等级，按原人格重新配料：

1. 为所选等级重新投入等于其原 E 总量的目标原液经验，形成替代 M，使用该目标等级已保存的同一组抽签序列按新概率重放；这些经验只用于替换属性分配，不升级、不触发领悟。
2. 另付原 E 总量的 10% 作为调校经验，整体向上取整，最低 100；调校部分可来自任意原液，但不贡献材料谱或属性。
3. 旧材料不返还，旧账不删除；替换消费和调校消费分别记账。人格、出生属性和技能保持原值，不能用洗练露改写。
4. 未满一级的既有材料贡献不免费改谱，继续喂到升级或另选已完成等级重调。若目标材料谱与原谱完全相同，直接拒绝且不收费；不允许用不同请求重抽。不同目标谱即按预览成本执行，不能先免费试算隐藏的抽签结果再决定付费。

Lv.30 全部重调示例：替换经验 57420＋调校经验 5742＝63162，空余额使用同一种原液需 632 瓶，剩 38 点保留该原液谱。期望自产成本约 **98311.11**，按187参考价采购 **118184**。这是完整重新培养29级的费用；默认界面只推荐选择需要改变的少数等级，并在确认前显示总材料成本。

原升级费用曲线不变：Lv.10/30/50 仍需48/575/2205瓶（从零开始且保留零头），统一预算价下期望自产成本仍为7466.67/89444.44/343000铜币。选择哪一种培养材料影响成长与市场实际开支，但相同经验不提高等级上限。不能再在成本表上附一张声称所有人偶相同的“实际均衡属性”。

战斗中不能喂养。战外属性增长保持 HP/MP 当前比例，增加上限不等于立即免费回满；停机不会被重调或喂养解除，维修规则继续生效。到上限拒绝无目的开瓶，只允许明确进入重调流程。已有余额不得提取、交易、转移或返炼。

## 6. 界面、记录与复核要求

人偶与人物共用战斗公式，伤害、治疗、护盾与属性对抗不额外打折。这里的“60%材料倾向”只决定成长概率，与已取消的战斗折扣无关。技能自带倍率、Boss控制衰减等继续执行人物同类效果的统一规则。

`机巧 → 培养` 显示人格成长倾向、本级已有材料贡献、可用有谱余额；选料后显示“物攻倾向来自锋刃，防御倾向部分来自谨慎”等简短解释，并展示各项抽中概率与期望增量。确认成功后再展示实际整数属性前后值，允许出现本级未增长的属性。

内联 `[详情] [使用] [加入] [移除] [输出] [防御] [续航] [返回机巧]` 均为不自动发送的蓝色命令链接。确认面板列出物品、绑定/非绑定数量、实际经验、开瓶顺序、逐级材料比例、十级领悟提示、到达等级和剩余有谱余额。筛选与预览均不消费材料。

数据结构新增/修订：出生 P 与属性快照；原液种类与配方版本；余额分段；本级材料贡献；升级事件的逐级 P/M/A/原始增量；重调的替换和费用分账。仍按绑定材料优先消费，再扣非绑定，重复请求幂等。具体实现须继续使用现有事务、库存、图鉴、手记与交易机制。

守恒式：`累计开瓶×100 = 历次升级经验＋未满进度＋重调替换经验＋调校费用＋有谱余额`。被替换的原始升级经验仍是真实消耗，不能从累计账中删掉。配方价格变化不重算过去账单；新版平衡调整必须单独预览和迁移，不能隐式重放成新配方谱。

已设计的验证矩阵：12核心×12材料×49升级；三类词条映射和无有效词条回退；所有权重归一与非负；同材料不同性格/同性格不同材料的差异；十级总预算4倍与30/120点数守恒；同一材料逐级结果有变化、各项概率非零但允许本级零增长；实例重试不重抽；混喂244/300分割；批量与拆单一致；出生与满级边界。数据库并发、真实材料扣除、战斗强度、市场供需与客户端蓝色链接仍需实装后验证。

现有语录种子库保持语言与技能标签用途。成长配置是单独版本，不直接给语料 JSON 的所有生活词条加属性，避免语录生成器重跑时覆盖战斗规则。
