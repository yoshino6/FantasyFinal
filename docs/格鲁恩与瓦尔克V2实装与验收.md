# 格鲁恩与瓦尔克 V2 实装与验收

日期：2026-09-16。范围：两只 Lv.32 区域 BOSS；不改变哥布林国王、乌兹、三首蛇母的平衡数值。

## 1. 本轮确定的边界

- 按《岩脊山麓与赤铁山道·Boss机制重设计V2》实现单本体新玩法，不继续扩充旧三部位机制。
- 基础六维、成长锚点、虚拟装备和普通至梦幻的通用属性词条沿用正常 BOSS。没有新增梦幻专用基础属性乘区，也不提高两只本体的出生生命。
- 常规招式采用普通区域 BOSS 的单体参照威力；群攻比例只在防御计算后应用一次。高难度由原有难度属性、通用词条、重写后的专属词条共同承担。
- 梦幻的目标装备门槛是完整史诗装备与成熟构筑，不是普通打造队。不增加“未穿史诗禁止进入”的硬性检查，也不把机制模拟冒充该装备门槛已经实测成立。
- 按后续展示要求覆盖原文的详细攻略面板：常驻面板仅显示压力/炉温、当前阶段状态、个人炉令、鞭痕、承重点/余痕、碎岩和领班。不显示倍率、停炉人数答案、推荐服从/违令、下次技能表或破解教程。
- 必要转场、预震、派令、封炉蓄势使用额外消息，统一在触发回合完整战报之后发送。高等级鉴识可以查看被动详情和完整九元素抗性。

## 2. 格鲁恩：共享压力战

### 已接入的规则

1. 单本体入场，压力20，上下限0–100；第三阶段下限15。
2. 一次实际行动结算一次压力：普攻+6，直击技能+10，纯辅助技能/道具/药剂援助/异械充能-8，防御-18。消耗失败、无效目标导致未完成、硬控停工不凭空获得泄压。攻击被闪避仍计数。
3. 施放异械按是否具有直接伤害分类；仅充能按辅助。混合规则技能实际发起直击时按攻击技能处理。多段、独立追击、反击、灵兽和DOT本身不再额外加压。
4. 压力五区间采用原设计：承伤80%/100%/125%/150%；造成直击90%/100%/115%/130%。第三阶段临界承伤165%。地层失稳和岩层剥落为独立乘区。
5. 压力100在玩家行动后立即山崩，移除普通护盾并造成35%最大生命机制伤害，施加减速25%和直击易伤15%；第三阶段持续2回合，否则1回合。保命和时间守护仍走原结算链。山崩后压力35。
6. 四槽：山脊测重 → 断层推进 → 地脉预震 → 山心崩震。预震无伤害，完整下一轮玩家行动之后才结算崩震。
7. 低压崩震转逆脉卸力，失稳保留至下一轮结束；随后压力重置20，第二阶段起重置25。中/高/临界崩震分别重置25/30/35，并分别执行追震、束缚分支。
8. 承重点的压力效率持续两轮：攻击再+4、防御再-8。为避免两轮标记在四槽崩震前必然到期而让追震永不触发，最近承重点另外保留“追震余痕”至本次崩震；余痕不再提供压力效率加成。
9. 第二阶段起命中测重叠碎岩，满两层时崩震追加45%参照威力追震并消耗层数；主动防御清一层。护盾吸收不算闪避，不规避承重点。
10. 70%/35%生命转阶段。第三阶段移除测重槽，保留已发生的预震；逆脉卸力额外自损最大生命3%，全场最多两次。

### 被动

| 被动 | 实际作用 |
| --- | --- |
| 山体承压 | 行动分类、压力区间与最终伤害联动 |
| 岩层剥落 | 第二阶段起，每轮进入60以上压力后本轮额外承伤10% |
| 无根山体 | 第三阶段压力下限、临界承伤及有次数上限的逆脉自损 |

## 3. 瓦尔克：个人炉令与集体停炉

1. 单本体入场，炉温40，上限100。三槽：监工派令 → 赤铁抽检 → 炉场工序。
2. 轻锤令对应普攻；重锻令对应主动技能，包括辅助技能及实际施放异械；固炉令对应防御、道具援助或异械充能。炉令在下一完整玩家轮结算，按每名成员的有效行动只判定一次。
3. 常规炉令不连续重复；派令时检查MP、冷却和沉默，没有当前可支付的主动技能就不派重锻令。禁攻令统一固炉是“不重复”规则的明确例外。
4. 服从+8炉温、清1鞭痕；违令-12炉温、加1鞭痕；鞭痕上限4，违令伤害按结算后层数×2%最大生命计算。炉温统一按整轮净变化限幅，成员排序不改变最终结果。
5. 硬控停工不算服从或违令，不进入停炉分母。1/2/3/4名有效成员的停炉门槛为1/1/2/2。
6. 集体停炉额外降温15、承伤破绽25%持续至下一轮结束；下一次工序改低威力普攻。连续两次成功只能新授予一次取消工序的机会，已授予但尚未兑现的机会不会被覆盖。
7. 少数违令额外承受6%最大生命孤立惩戒。全员服从回血3%，全场最多两次；无人有效行动不触发回血。
8. 炉温冷/常/赤热/白热分别对应防御回火、群体物理破甲、群体火法灼烧、最高鞭痕裁决及55%防御后溅射。正常攻击行动结束加温10。
9. 炉温100只启动封炉预警并补发可供应对的炉令。完整下一轮后若停炉成功则清算取消，否则全体高威力火伤、全体鞭痕+1并重置炉温55。
10. 65%生命后轮换领班：违令多一票且自身鞭痕伤害×1.5；服从多清一层、额外加温5；抽检优先领班，服从者改由仇恨目标承接。
11. 30%生命后专属转场与禁攻令。所有有效成员违令才总罢工成功；成功清空鞭痕、永久失去高温增伤、双防-20%、炉温上限80。失败按孤立规则结算，两轮后再派禁攻令。

### 被动

| 被动 | 实际作用 |
| --- | --- |
| 监工法度 | 炉令、有效成员、鞭痕和停炉判定 |
| 炉火锻身 | 冷炉降伤15%/承伤+10%，赤热与白热只强化火属性直击 |
| 不息工序 | 限制连续停炉与满额回血，执行总罢工永久削弱 |

抗性为项目既有数值单位，不是减伤百分比；仍遵循已有元素倍率上下限，不新增绝对免疫。相同元素精通下，各自仅两项负抗提供高伤收益。

| 地脉复铸 | 首次逆脉卸力后获得20%最大生命护盾，持续2回合，全场一次 | 仅一次防御资源，不重造部位或无限回血 |

专属词条继续由原有难度抽取规则赋予，不给普通档强塞完整高难组合。梦幻原有生命×12.8、常规战斗属性×2等框架保持不变。

## 5. 自动战斗、持久化与兼容

- 自动战斗一次性规划整队行动，计入已提交的手动行动；不会写回玩家保存的自动配置。
- 格鲁恩预测逐人的压力限幅与中途山崩风险，优先保留配置动作，仅替换必要的泄压成员；低血量时偏向防御。不会用“预计必杀”冒险越过临界，因为当前预测不把概率命中当保证斩杀。
- 瓦尔克按低鞭痕、高生命、护盾和领班收益分配违令者；高危优先停炉，冷炉可间隔全员服从恢复，总罢工轮共同违令。技能不可支付时不伪造服从，实际行动结果仍由战斗服务最终判定。
- 两只本体在完整玩家轮之后执行工序，其他单位内部仍保持原速度顺序。这是保证预警窗口与整轮炉令判定的一致性安排。
- 状态仅保存在当前 `combat_targets.cooldowns.regional_encounter_v2`，回合计数器不会递减整个状态对象。新遭遇创建独立状态；结束会话的历史记录不回灌玩家或地图实体。
- 新遭遇不生成旧六部位，不存在旧部位减伤与传伤。旧部位模板、处理和清理代码暂保留为历史会话兼容路径，而非直接删除历史数据。建议现有战斗结束后加载新代码。
- 旧伤害桥接同步修复：DOT/反击/追击按规则返回的实际伤害回写；复制主击最终伤害的追击先去除已计算的本轮承伤乘区，避免高压或破绽被重复乘算；免死仍保留规则结算后的生命。
- 地图、等级、刷新、掉落、成就、图纸和套装归属不改。新招式模板为BOSS专用，不加入玩家领悟规则；数据库初始化同步新技能和抗性，但本轮未执行生产初始化或机器人重启。

## 6. 验证边界

- 已执行规则、状态、属性与回合模拟测试，覆盖两个BOSS×普通/强大/梦幻×1–4人，共24组连续机制模拟。
- 模拟采用真实BOSS属性派生和固定参数测试角色，验证状态边界、自动策略与连续回合，不等同于真实职业/装备/专精/药剂/套装效果组合验收。
- “全套史诗才能稳定挑战梦幻”和“普通四人约7–10个BOSS行动”仍是实战校准目标，不能从固定参数模拟推导为已证实的装备门槛或胜率。
- 未进行真实数据库整场战斗、真实QQ消息投递或全套史诗角色对照实验。没有自动部署、改写玩家装备或操作活跃战斗。
- 专项回归122项通过，战斗展示与消息顺序专项5项通过；`npx tsc --noEmit`通过。未将这些专项结果表述为项目全量测试通过；既存的其他工作区改动均保留。

主要实现：`src/game/regional-boss-v2.ts`、`regional-boss-v2.config.ts`、`regional-boss-auto.ts`，以及冒险服务、自动战斗服务、战斗展示、世界地表配置与数据库初始化的接入点。
