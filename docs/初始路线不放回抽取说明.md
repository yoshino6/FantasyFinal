# 初始路线不放回抽取

- 全服新玩家共用普通路线轮次。成功注册占用一条路线，重复点击注册不会再次抽取；删号不会退回路线。
- 本轮尚有可用普通路线时，只从剩余路线中按权重抽取。当前开放且能够安全降临的普通路线全部用过后，下一个普通抽取开启新一轮。
- 原权重仍为档位 `10／55／25／10`，同档地图均分、每图三路线均分。将其展开为每条路线的原始权重后，从剩余池重新归一化。权重影响每轮的先后顺序；完整一轮内每条普通路线恰好一次，因此长期次数不再保持旧的有放回档位比例。
- A01「重返女神殿」独立判定，概率等于其在完整开放池中的原始概率；不因普通路线被抽走而升高，也不占用或重置普通轮次。全部十四张地图有效时为 `10%÷4÷3≈0.8333%`。沉星沼泽未开放或无法合法降临时不会抽到 A01。
- 女神已下界后的厄里斯接引变体沿用 A01 的独立抽取。阿库娅下界的世界唯一归属和剧情分支处理仍由现有流程决定。
- 新开放路线加入本轮剩余池；关闭路线暂时退出候选，不清空已抽记录。同一轮内重新开放已经抽过的路线不会恢复名额；所有当前有效普通路线耗尽后正常换轮。
- 原有角色保留既定路线。功能启用后的首次普通抽取开始第一轮，不追溯占用历史角色的路线。

数据库新增 `opening_route_draw_state`，由现有启动初始化创建。抽取在注册事务中锁住全服单例行，与角色、恩赐及故事记录一起提交；失败回滚会归还路线和轮次。无需修改地图开放状态、现有剧情内容或奖励。
