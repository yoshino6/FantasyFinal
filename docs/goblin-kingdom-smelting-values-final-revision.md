# 哥布林王国怪材熔铸效果最终修订

本稿覆盖此前关于上校军徽的武器双攻、防具双防设定。仅修改设计文档，不实现源码。

## 上校军徽

| 装备部位 | 熔铸效果 | 限制 |
|---|---|---|
| 武器 | 力量、敏捷、体质、智力、精神、幸运各 +6 | 每件武器最多生效一枚 |
| 防具 | 力量、敏捷、体质、智力、精神、幸运各 +6 | 每件防具最多生效一枚 |
| 饰品 | 力量、敏捷、体质、智力、精神、幸运各 +6 | 每件饰品最多生效一枚 |

## 已删除的效果

以下两项不再存在：

- 武器：物理攻击、魔法攻击各 +18
- 防具：物理防御、魔法防御各 +22

上校军徽现在只提供全属性固定数值加成，不再根据装备部位追加双攻或双防。

## 通用规则

- 每件装备最多生效一枚上校军徽。
- 同一件装备不可通过多枚上校军徽重复获得全属性。
- 全属性加成是力量、敏捷、体质、智力、精神、幸运分别 +6。
- 该效果为固定数值，不是百分比。
- 上校军徽仍保持哥布林上校极低概率掉落的精英材料定位。
