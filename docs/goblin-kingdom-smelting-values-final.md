# 哥布林王国怪材熔铸数值最终修订

本稿覆盖前述上校军徽熔铸设定，仅修改设计文档，不实现源码。

## 上校军徽：按装备部位分化

| 装备部位 | 熔铸效果 | 数值 | 说明 |
|---|---|---:|---|
| 武器 | 物理攻击 + 魔法攻击 | 各 +18 | 高额双攻，仅作用于武器 |
| 防具 | 物理防御 + 魔法防御 | 各 +22 | 高额双防，仅作用于防具 |
| 饰品 | 不可熔铸 | — | 防止前期饰品过早获得过高综合收益 |

## 限制规则

- 上校军徽不提供全属性。
- 上校军徽不增加力量、敏捷、体质、智力、精神、幸运等基础六维。
- 武器只能获得双攻，防具只能获得双防，不允许跨部位套用效果。
- 每件装备最多生效一枚上校军徽。
- 双攻、双防均为固定数值加成，不是百分比加成。
- 数值定位高于幽暗密林常规材料，接近森林大怪专属材料的精英战斗辅材档位。
- 上校军徽继续保持极低掉落率，避免前期装备轻易获得高额综合战斗属性。

## 原设定替换

将此前“物理攻击 +20”的单属性方案替换为本稿的装备部位分化方案：

> 武器：物理攻击 +18、魔法攻击 +18。  
> 防具：物理防御 +22、魔法防御 +22。  
> 饰品：不可熔铸。
