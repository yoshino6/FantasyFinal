# 巡游奇遇、站点交接与地图坐标修复报告

日期：2026-09-07

## 一、地图坐标结论

问题不是地图名称显示错误，而是旧的“前往该区域”算法使用区域外接矩形夹取坐标。真实移动使用 `map_region_areas` 的拼接区域，并按危险等级选择覆盖区域。两套规则不一致时，会进入其他地图。

另有一处已过期的特殊处理：幽暗密林深处固定入口 `(-25,-186)` 在当前数据库中属于百纳镇，不能继续使用。

已统一为：按真实区域几何及移动覆盖优先级，选取最近的合法曼哈顿距离落点；保留合法落点，修正缺口与覆盖点。地下楼层先返回地表，不直接用地表地图导航。

- 动态建筑和巡游路线初始化也使用真实区域校验。

## 二、站点委托无法推进

源码中原有交接入口只在“进入建筑且前台有人”时调用；单纯到达坐标不会自动完成，前台外出时也没有任务栏的补救操作。当前已接委托的目标坐标均合法，不能把所有无法推进都归因于坐标。

本次补齐：

1. 未完成委托在任务栏增加 `[提交交接]`，保留目标和前往链接，不增加缘由、情形等长篇任务栏文案。
2. 提交时校验委托归属、状态、玩家区域和完整三维坐标，不能异地提交或代他人结算。
3. 前台在站时完成交接，奖励仍在任务栏单独领取；原有进入建筑自动交接保持可用。
4. 前台外出时留下交接通知，并为收件域民登记 30 分钟回站服务窗口。新接委托也提前请求收件人回站。
5. 域民在下一次调度优先回站办理；公共事件现场优先级更高，需其事务结束后返回。现有调度通常十分钟一次，不承诺即时返回。
6. 等待、完成、领取分别记录账本，维持个人每日公共贡献和区域每日上限。反复提交不会重复发钱。

公共建筑无人时仍只有内部描述；私人建筑无人时仍是敲门无回应。接取委托仍由前台域民交付，没有增加户外远程接单入口。

## 三、巡游与观察点可参与内容

为现有 42 名域民接入 5 类巡游分支定义，共 210 个“域民 × 事件类型”的组合。它们使用区域生态素材和人物口吻；这是可复用分支结构，不宣称是 210 篇完全不同结构的手写长剧情。

| 场所 | 类型 | 处理方式 |
| --- | --- | --- |
| 普通巡游路段 | 巡路查线 | 核对痕迹，再补正方向或设置危险警示 |
| 观察点 | 定点观测 | 连续记录，再标定边界或保存原始资料 |
| 观察点 | 封存样本 | 安全采样后封存或附对照；也可只标记待复采 |
| 观察点 | 救援转移 | 稳定伤处，实际移动到公共站点门前后安置 |
| 观察点 | 护送旅人 | 说明险情带路，实际移动到公共站点门前后确认抵达 |

普通巡游提供巡查缘由和参与按钮；公共事件调遣中的域民指向已有公共现场，不额外开启普通巡查。

玩家通过感知找到域民，走到同一坐标后询问并参与。世界地图只保留建筑，不显示巡游域民。接手后任务栏显示当前目标、已知现场/交接地点和继续处理入口；这不是向世界地图公开 NPC 行踪。

每次实例保存人物、巡查批次、地点、文案、天气版本、选择和奖励资格。接手后即使域民继续巡游，玩家也能在约定现场处理自己的分支。救援/护送是叙事型同行任务，有真实到达校验，但本次没有新增可见的伤者/旅人地图实体、跟随寻路或途中战斗系统。

### 频繁移动与喊人保护

- 只有同区域同坐标才能新接；按真实调度版本校验旧按钮。
- 每角色每天最多 3 次、两次接手间隔至少 20 分钟、同一域民每天仅一次。
- 每个巡游批次最多 3 份资源报酬，同队最多 1 份；临时换队仍不能突破现场总上限。
- 名额外仍可走个人剧情，但不发铜币；资格一经接手即固化，中止或过期不返还名额。
- 同一巡游批次最多贡献一次区域进展，并共享既有区域委托日上限。
- 分支沿用实例/节点唯一决策和角色事务锁；交接校验区域、坐标、楼层。每次实际结算仅一次。
- 小事件终局报酬为 12～32 铜币；未完成不发放，未新增可反复领取的稀有物品。
